## 二、研发自动化 (Superpowers 系列)

> 来源: [obra/superpowers](https://github.com/obra/superpowers)

| Skill | 描述 | 使用场景 |
|------|------|----------|
| **brainstorming** | 在任何创造性工作之前必须使用 - 探索用户意图、需求和设计 | 创建功能、构建组件、添加新功能 |
| **writing-plans** | 将需求转化为详细的实施计划，包含具体步骤和文件路径 | 多步骤任务开始之前，生成实施蓝图 |
| **executing-plans** | 执行已制定的实施计划 | 按照计划逐步实施功能 |
| **systematic-debugging** | 系统化调试 - 在修复之前必须找到根本原因 | 遇到 bug、测试失败或意外行为 |
| **test-driven-development** | 测试驱动开发 - 先写测试，再写代码 | 实现任何功能或修复 bug |
| **subagent-driven-development** | 子代理驱动开发 - 分派独立任务给子代理 | 执行计划时需要并行处理 |
| **dispatching-parallel-agents** | 分派并行代理处理独立任务 | 需要同时处理多个独立任务 |

| **receiving-code-review** | 接收代码审查反馈 | 处理审查意见 |

## 常用命令

```bash
# 列出已安装的 skills
npx skills ls -g

# 搜索 skills
npx skills find <关键词>

# 安装新 skill
npx skills add <owner/repo@skill> -g -y

# 更新所有 skills
npx skills update
```
