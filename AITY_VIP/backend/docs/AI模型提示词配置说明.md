# AI模型提示词配置说明

## 概述

本系统为不同的AI模型配置了专属优化的提示词，以充分发挥各模型的独特优势。

## API接口

### 1. 获取所有默认提示词

**接口**: `GET /api/ai/prompt/default`

**响应示例**:
```json
{
  "code": 200,
  "message": "Success",
  "data": {
    "prompt": "通用提示词内容...",
    "modelSpecificPrompts": {
      "glm-4-flash": "智谱GLM-4-Flash专属提示词...",
      "deepseek-v3": "DeepSeek-V3专属提示词...",
      ...
    },
    "version": "2.0.0",
    "updatedAt": "2026-03-02",
    "modelsCount": 16
  }
}
```

### 2. 获取特定模型的提示词

**接口**: `GET /api/ai/prompt/model/:modelName`

**示例**: `GET /api/ai/prompt/model/glm-4-flash`

**响应示例**:
```json
{
  "code": 200,
  "message": "Success",
  "data": {
    "modelName": "glm-4-flash",
    "prompt": "智谱GLM-4-Flash专属提示词...",
    "isDefault": false
  }
}
```

### 3. 应用模型特定提示词到数据库

**接口**: `POST /api/ai/prompt/apply-model-specific`

**说明**: 将代码中定义的模型特定提示词应用到数据库中对应的模型配置

**响应示例**:
```json
{
  "code": 200,
  "message": "模型特定提示词应用成功",
  "data": {
    "totalModels": 16,
    "appliedCount": 16,
    "results": [
      {
        "modelName": "glm-4-flash",
        "displayName": "智谱GLM-4-Flash（推荐）",
        "applied": true
      },
      ...
    ],
    "message": "已为 16 个模型应用专属提示词"
  }
}
```

### 4. 批量更新所有模型的提示词

**接口**: `PUT /api/ai/prompt/all`

**请求体**:
```json
{
  "prompt": "统一的提示词内容..."
}
```

**说明**: 将所有模型的提示词更新为统一的提示词

### 5. 恢复默认提示词

**接口**: `POST /api/ai/prompt/reset`

**说明**: 清空数据库中的自定义提示词，恢复使用代码中定义的默认提示词

## 使用流程

### 初始化部署

1. **获取模型列表**: 调用 `GET /api/ai/configs` 查看所有配置的模型
2. **应用专属提示词**: 调用 `POST /api/ai/prompt/apply-model-specific` 应用模型特定提示词
3. **验证结果**: 再次调用 `GET /api/ai/configs` 确认提示词已应用到各模型

### 日常使用

1. **系统自动选择**: AI优化功能会自动使用当前激活模型的提示词配置
2. **提示词优先级**:
   - 数据库中的自定义提示词（最高优先级）
   - 代码中的模型特定提示词
   - 通用默认提示词（兜底）

### 自定义提示词

1. **查看当前提示词**: 调用 `GET /api/ai/configs` 查看各模型当前使用的提示词
2. **更新单个模型**: 调用 `PUT /api/ai/config/:id` 更新特定模型的提示词
3. **批量更新**: 调用 `PUT /api/ai/prompt/all` 统一更新所有模型的提示词

## 提示词设计原则

### 1. 统一的核心要求

所有模型提示词都遵循以下核心原则：
- **信息完整**: 保留原文所有信息、数据、URL链接
- **格式规范**: 使用Markdown格式（###标题、-列表、**粗体**）
- **结构优化**: 核心观点置顶，关键信息列表化
- **突出重点**: 操作建议、标的、价位等醒目标注

### 2. 模型特性适配

根据不同模型的特点进行针对性优化：
- **推理能力强的模型**（DeepSeek-R1, GLM-4.7）: 强调逻辑严密、深度分析
- **速度快的模型**（Qwen-Flash, Turbo）: 强调快速响应、简洁有力
- **通俗易懂的模型**（豆包）: 强调简化表达、增强可读性
- **综合能力强的模型**（Qwen3-Max）: 强调专业视角、全面优化

### 3. 输出格式统一

所有模型都要求：
- **直接输出优化结果**: 无开场白、结束语
- **Markdown格式**: 标题、列表、粗体等
- **核心观点置顶**: 1-2句话概括
- **保留所有URL**: 原文中的链接必须保留

## 技术实现

### 代码结构

**文件**: `backend/src/controllers/aiConfigController.js`

```javascript
// 通用提示词
const DEFAULT_PROMPT = `...`;

// 模型特定提示词映射
const MODEL_SPECIFIC_PROMPTS = {
  'glm-4-flash': `...`,
  'deepseek-v3': `...`,
  // ... 更多模型
};

// 获取模型特定提示词函数
function getModelSpecificPrompt(modelName) {
  return MODEL_SPECIFIC_PROMPTS[modelName] || DEFAULT_PROMPT;
}
```

### 数据库字段

**表**: `ai_config`

**字段**: `prompt_template` (TEXT)
- 存储自定义提示词（如果已设置）
- 如果为 NULL，则使用代码中定义的默认提示词

### 提示词优先级

```
数据库自定义提示词 (prompt_template 不为 NULL)
    ↓ (如果为 NULL)
代码中模型特定提示词 (MODEL_SPECIFIC_PROMPTS[modelName])
    ↓ (如果未配置)
通用默认提示词 (DEFAULT_PROMPT)
```

## 常见问题

### Q1: 如何为未在代码中配置的模型设置提示词？

**A**: 有两种方式：
1. 在代码中的 `MODEL_SPECIFIC_PROMPTS` 添加配置
2. 直接通过API更新数据库中的 `prompt_template` 字段

### Q2: 修改提示词后需要重启服务吗？

**A**: 不需要。提示词存储在数据库中，修改后立即生效。但如果修改了代码中的默认提示词，需要重启服务。

### Q3: 如何回滚到之前的提示词版本？

**A**:
1. 如果使用数据库自定义提示词，调用 `POST /api/ai/prompt/reset` 恢复默认
2. 如果修改了代码，使用Git回滚到之前的版本

### Q4: 不同模型的提示词差异有多大？

**A**:
- **核心要求一致**: 信息完整、格式规范、结构优化
- **侧重点不同**: 推理模型强调逻辑，快速模型强调简洁，通俗模型强调易懂
- **长度不同**: 根据模型能力和定位调整
