## 消息标签说明

### 标签类型
- **all_users**: 全部用户可见（8条）
- **short_term**: VIP短线用户可见（8条）
- **mid_term**: VIP中线用户可见（8条）
- **组合标签**: short_term + mid_term（2条）

### 权限对应表

```
体验用户:     all_users (8条)
VIP短线用户:  all_users + short_term + 组合标签 (18条)
VIP中线用户:  all_users + mid_term + 组合标签 (18条)
管理员:       所有标签 (26条)
```

## 常见问题

### Q1: 为什么用户看不到某些消息？
**A**: 检查用户的role和消息的tags是否匹配：
- 体验用户只能看 all_users 标签
- VIP短线用户只能看 short_term 标签
- VIP中线用户只能看 mid_term 标签

### Q2: 如何添加新的测试消息？
**A**: 使用管理员账号登录，通过后台创建消息，或执行创建脚本。

### Q3: 如何清空并重建测试数据？
**A**:
```bash
cd D:\your-mcp-proxy\AITY_VIP\backend
node create-complete-test-data.js
```

### Q4: 体验用户账号已过期怎么办？
**A**: 有两个方案：
1. 更新数据库中用户的expire_date字段
2. 创建新的体验用户账号
