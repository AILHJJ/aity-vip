## 4. 日常操作

### 更新代码并重启

```bash
cd /root/aity-vip/backend
git pull origin feature/iteration-1
npm install --production
pm2 restart aity-backend
curl http://localhost:3001/health
```

### 切换数据库环境

编辑 `.env.production`，修改 `DB_ENV`：

```bash
# 测试库
DB_ENV=test

# 生产库
DB_ENV=production
```

修改后需重启：`pm2 restart aity-backend`

### 常用 PM2 命令

```bash
pm2 status                    # 查看状态
pm2 logs aity-backend         # 实时日志
pm2 logs aity-backend --err   # 只看错误
pm2 restart aity-backend      # 重启
pm2 stop aity-backend         # 停止
pm2 delete aity-backend       # 删除进程
pm2 monit                     # 资源监控
```

## 5. 环境文件说明

项目使用按环境自动加载 `.env` 文件的机制（见 `src/index.js`）：

| NODE_ENV | 加载的文件 | 用途 |
|----------|-----------|------|
| `development` | `.env.development` | 本地开发 |
| `production` | `.env.production` | 腾讯云生产 |
| （回退） | `.env` | 默认配置 |

PM2 启动时通过 `--env production` 设置 `NODE_ENV=production`，自动加载 `.env.production`。

## 6. 数据库环境切换机制

代码逻辑（`src/config/db.js`）：

```
DB_ENV=test        → 自动连接「投研图灵室_test」
DB_ENV=production  → 自动连接「投研图灵室」
DB_NAME=xxx        → 直接指定库名（优先级最高，覆盖 DB_ENV）
```

## 7. 常见问题

### 数据库连接失败

```bash
# 1. 测试连接
mysql -u投研图灵室 -pfl10b312 -e "SELECT 1;"

# 2. 检查 .env.production 配置
cat .env.production | grep DB_

# 3. 确认 DB_HOST=localhost（不是 124.221.119.134）
```

### 端口 3001 被占用

```bash
netstat -tlnp | grep 3001
kill -9 <PID>
pm2 restart aity-backend
```

### PM2 进程不断重启

```bash
# 查看重启次数
pm2 show aity-backend | grep restart

# 查看错误日志
pm2 logs aity-backend --err --lines 50
```

### CORS 跨域问题

检查 `.env.production` 的 `ALLOWED_ORIGINS` 是否包含前端域名。
