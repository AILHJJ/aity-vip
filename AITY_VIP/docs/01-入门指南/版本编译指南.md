## 1. 版本类型说明

### 1.1 开发版 (dev) vs 生产版 (build)

| 特性 | dev (开发版) | build (生产版) |
|------|-------------|----------------|
| **代码压缩** | 否 | 是 |
| **SourceMap** | 包含 | 不包含 |
| **调试支持** | 完整 | 受限 |
| **包体积** | 较大 | 较小 |
| **编译速度** | 快 | 慢 |
| **热更新** | 支持 | 不支持 |
| **用途** | 本地开发调试 | 上线发布 |

### 1.2 版本选择建议

| 场景 | 推荐版本 |
|------|----------|
| 本地功能开发 | `dev:*` |
| 本地调试问题 | `dev:*` |
| 提测 | `build:*` |
| 预发布验证 | `build:*` |
| 正式上线 | `build:*` |

## 5. 部署指南

### 5.1 H5部署

#### 本地运行

```bash
# 方式1: 开发服务器（推荐调试用）
npm run dev:h5

# 方式2: 静态服务器（模拟生产环境）
npx serve dist/build/h5 -p 8080
```

#### 腾讯云服务器部署

**方式1: 手动部署**

```bash
# 1. 编译生产版本
npm run build:h5

# 2. 上传到服务器
scp -r dist/build/h5/* root@124.221.119.134:/root/aity-vip/aity-uni-app-v2/dist/build/h5/

# 3. 重启Nginx
ssh root@124.221.119.134 "systemctl restart nginx"
```

**方式2: 使用部署脚本**

```bash
# 在服务器上执行
/root/aity-vip/scripts/deploy.sh
```

**Nginx配置参考**:

```nginx
server {
    listen 8443 ssl http2;
    server_name aity88.online;

    # 前端静态文件
    location / {
        root /root/aity-vip/aity-uni-app-v2/dist/build/h5;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }
}
```

## 7. 常见问题

### Q1: 编译后代码报错？

**A**: 确保使用正确的编译命令：
- 调试用 `dev:*`
- 发布用 `build:*`

### Q2: H5页面空白？

**A**: 检查以下几点：
1. 后端服务是否启动
2. API地址是否正确
3. 路由配置是否正确（history模式需要nginx配置）

### Q3: 小程序无法请求API？

**A**: 检查以下几点：
1. 服务器域名是否在小程序后台配置
2. HTTPS证书是否有效
3. 后端服务是否运行

### Q4: 支付宝小程序和微信小程序代码冲突？

**A**: 不会冲突。编译产物输出到不同目录：
- 微信：`dist/*/mp-weixin/`
- 支付宝：`dist/*/mp-alipay/`

### Q5: 如何同时调试多个平台？

**A**: 可以同时运行多个编译命令：
```bash
# 终端1
npm run dev:mp-weixin

# 终端2
npm run dev:h5

# 终端3
npm run dev:mp-alipay
```
