## 常见问题快速解答

### Q: 如何使用AI投顾？
A: 点击底部导航栏"AI投顾"，在输入框输入问题，AI会实时回复。

### Q: 行情中心的数据是实时的吗？
A: 是的，行情中心数据实时更新，可以点击"刷新"按钮获取最新数据。

### Q: 什么是连板天梯？
A: 连板天梯按连续涨停天数分层展示股票，帮助用户发现强势股。

### Q: 如何联系技术支持？
A: 发送邮件至 support@aity-vip.com 或查看[常见问题](faq.md)。
