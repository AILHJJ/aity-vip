## 架构概览

VIP投研内部分享系统采用前后端分离架构，前端使用Vue 3 + uni-app实现多端支持，后端使用Node.js + Express.js构建RESTful API，数据库使用MySQL存储业务数据。

---

## 前端架构

### 架构分层

```
┌─────────────────────────────────────────────────────────────┐
│                      展示层 (View)                           │
│  页面组件：登录页、消息列表、消息详情、讨论页等               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     业务组件层 (Components)                  │
│  消息卡片、讨论组件、富文本编辑器、统计图表等                 │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     状态管理层 (Store)                       │
│          Pinia Store：用户、消息、讨论等状态                 │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      服务层 (Services)                       │
│  API服务、缓存服务、认证服务、工具函数                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     数据层 (Data)                            │
│           HTTP请求、本地存储、内存缓存                       │
└─────────────────────────────────────────────────────────────┘
```

### 核心模块

#### 1. 用户认证模块

**职责**：
- 用户登录/注册
- Token管理
- 权限验证

**技术实现**：
- JWT Token存储在localStorage
- Axios拦截器自动添加Token
- 路由守卫验证登录状态

**数据流**：
```
用户输入 → 表单验证 → API请求 → Token存储 → 状态更新 → 页面跳转
```

#### 2. 消息管理模块

**职责**：
- 消息列表展示
- 消息详情查看
- 消息搜索和筛选
- 消息收藏和导出

**技术实现**：
- 无限滚动加载
- 虚拟列表优化性能
- 本地缓存已读消息

**数据流**：
```
页面加载 → API请求 → 数据缓存 → 列表渲染 → 用户交互
```

#### 3. 讨论模块

**职责**：
- 讨论发起和回复
- 讨论可见性控制
- 富文本编辑

**技术实现**：
- Marked.js渲染Markdown
- DOMPurify防止XSS攻击
- 实时更新讨论列表

**数据流**：
```
用户操作 → 表单提交 → API请求 → 数据更新 → UI刷新
```

#### 4. 统计分析模块

**职责**：
- 数据可视化
- 统计报表生成
- 数据导出

**技术实现**：
- ECharts图表展示
- 响应式图表适配
- Excel数据导出

**数据流**：
```
选择时间范围 → API请求 → 数据处理 → 图表渲染
```

## 后端架构

### 架构分层

```
┌─────────────────────────────────────────────────────────────┐
│                      路由层 (Routes)                         │
│  定义API端点、请求路由、HTTP方法映射                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   中间件层 (Middleware)                      │
│  身份验证、权限检查、请求验证、错误处理、日志记录             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   控制器层 (Controllers)                     │
│  处理请求、调用服务、返回响应                                 │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     服务层 (Services)                        │
│  业务逻辑、数据处理、第三方服务集成                           │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   数据访问层 (Models)                        │
│  数据库操作、ORM映射、数据验证                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                      数据层 (Data)                           │
│           MySQL数据库、文件系统、外部API                     │
└─────────────────────────────────────────────────────────────┘
```

### 核心模块

#### 1. 认证模块

**职责**：
- 用户登录/注册
- Token生成和验证
- 权限检查

**技术实现**：
- JWT Token认证
- bcrypt密码加密
- Token过期时间24小时

**API端点**：
```
POST   /api/auth/register     用户注册
POST   /api/auth/login        用户登录
POST   /api/auth/logout       用户登出
GET    /api/auth/profile      获取用户信息
PUT    /api/auth/profile      更新用户信息
```

#### 2. 消息模块

**职责**：
- 消息CRUD操作
- 消息推送
- 定时发布

**技术实现**：
- Sequelize ORM操作数据库
- node-schedule实现定时任务
- 分组查询优化

**API端点**：
```
GET    /api/messages          获取消息列表
GET    /api/messages/:id      获取消息详情
POST   /api/messages          创建消息
PUT    /api/messages/:id      更新消息
DELETE /api/messages/:id      删除消息
POST   /api/messages/:id/push 推送消息
```

#### 3. 讨论模块

**职责**：
- 讨论CRUD操作
- 讨论回复
- 可见性控制

**技术实现**：
- 关联查询优化
- 权限控制中间件
- 富文本内容过滤

**API端点**：
```
GET    /api/discussions       获取讨论列表
GET    /api/discussions/:id   获取讨论详情
POST   /api/discussions       创建讨论
PUT    /api/discussions/:id   更新讨论
DELETE /api/discussions/:id   删除讨论
POST   /api/discussions/:id/reply 回复讨论
```

#### 4. 用户模块

**职责**：
- 用户CRUD操作
- 用户分组管理
- 用户权限管理

**技术实现**：
- 事务处理确保数据一致性
- 分页查询优化
- 数据验证

**API端点**：
```
GET    /api/users             获取用户列表
GET    /api/users/:id         获取用户详情
POST   /api/users             创建用户
PUT    /api/users/:id         更新用户
DELETE /api/users/:id         删除用户
GET    /api/users/:id/messages 获取用户消息
```

#### 5. 统计模块

**职责**：
- 数据统计
- 报表生成
- 数据分析

**技术实现**：
- 聚合查询优化
- 缓存统计结果
- Excel文件生成

**API端点**：
```
GET    /api/statistics/messages   消息统计
GET    /api/statistics/users      用户统计
GET    /api/statistics/discussions 讨论统计
GET    /api/statistics/export     导出统计数据
```

## 安全架构

### 认证与授权

```
┌─────────────────────────────────────────────────────────────┐
│                      安全层设计                             │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 认证机制                                                 │
│     - JWT Token认证                                        │
│     - Token有效期24小时                                     │
│     - Token刷新机制                                         │
│                                                              │
│  2. 权限控制                                                 │
│     - 基于角色的访问控制 (RBAC)                            │
│     - 路由级权限验证                                       │
│     - 接口级权限验证                                       │
│                                                              │
│  3. 数据保护                                                 │
│     - 密码bcrypt加密                                       │
│     - HTTPS传输加密                                         │
│     - 敏感信息脱密显示                                      │
│                                                              │
│  4. 防护措施                                                 │
│     - 防止SQL注入                                          │
│     - 防止XSS攻击                                          │
│     - 防止CSRF攻击                                         │
│     - 请求频率限制                                          │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 安全最佳实践

1. **密码安全**
   - 使用bcrypt加密（salt rounds: 10）
   - 密码复杂度要求
   - 定期更新密码

2. **Token管理**
   - JWT Token存储在localStorage
   - Token过期自动刷新
   - 登出时清除Token

3. **数据验证**
   - 前端表单验证
   - 后端数据验证
   - SQL参数化查询

4. **HTTPS传输**
   - SSL证书配置
   - 强制HTTPS跳转
   - 安全头部配置
