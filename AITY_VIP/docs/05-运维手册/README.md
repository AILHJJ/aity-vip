## 快速导航

### 日常运维

- **系统健康检查**
  ```bash
  /root/scripts/health-check.sh
  ```

- **查看服务状态**
  ```bash
  # 后端服务
  cd backend && pm2 status

  # Nginx
  systemctl status nginx

  # MySQL
  systemctl status mysql
  ```

- **查看日志**
  ```bash
  # 后端日志
  cd backend && pm logs

  # Nginx日志
  tail -f /var/log/nginx/error.log

  # MySQL日志
  tail -f /var/log/mysql/error.log
  ```

| **API 500错误** | 检查Proxy对象序列化 | [故障排查指南](./troubleshooting.md) |
| **API 404错误** | 检查API方法和路由 | [故障排查指南](./troubleshooting.md) |

| **SSL证书问题** | `certbot renew` | [故障排查指南](./troubleshooting.md) |

## 备份策略

### 备份计划

| 内容 | 频率 | 位置 | 保留时间 |
|------|------|------|----------|
| 数据库 | 每日 | 本地 + 远程 | 7天 |
| 代码 | 每日 | Git仓库 | 永久 |
| 配置文件 | 每周 | 本地 + 远程 | 30天 |
| 日志 | 每周 | 本地 | 14天 |

### 恢复流程

```bash
# 1. 恢复数据库
mysql -u fl -p 投研图灵室 < /root/backups/db_backup_20260305.sql

# 2. 恢复代码
git checkout <commit-hash>

# 3. 重启服务
pm2 restart backend
systemctl restart nginx
```
