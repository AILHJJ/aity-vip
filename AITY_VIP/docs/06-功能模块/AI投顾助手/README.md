# AI投顾功能

> AI投顾模块提供智能问答、金融选股、市场分析等功能
> 最后更新：2026-03-05

---

## 功能概述

AI投顾是AITY VIP的核心功能模块，基于大语言模型（LLM）和LangGraph框架，为用户提供：

- **智能问答**：自然语言交互，理解用户投资需求
- **金融选股**：基于用户条件筛选股票
- **市场分析**：实时行情数据分析
- **投资建议**：个性化投资组合推荐

---

## 核心特性

### 1. 多模型支持
- 支持GLM系列（智谱AI）
- 支持通义千问（阿里云）
- 支持文心一言（百度）
- 支持自定义OpenAI兼容接口

### 2. 用户隔离
- 基于用户ID的数据隔离
- 每个用户独立的对话历史
- 每个用户独立的会话上下文

### 3. 上下文对话
- 基于ThreadId的连续对话记忆
- 自动保存和恢复会话上下文
- 支持开启新对话

### 4. 实时数据展示
- 金融工具调用状态提示
- 结构化表格数据展示
- 涨跌幅颜色区分（涨红跌绿）
- 数字格式化（千分位、百分比、万亿）

### 5. 版本管理
- 配置自动版本化
- 支持版本回滚
- 支持版本差异对比

## 使用指南

### 用户端使用

1. **访问AI投顾页面**
   - 登录后，点击底部导航"AI投顾"

2. **开始对话**
   - 在输入框输入问题，例如：
     - "帮我找出今天涨幅前10的银行股"
     - "分析一下贵州茅台的近期走势"
     - "推荐一些低估值股票"

3. **查看结果**
   - AI会实时返回分析结果
   - 金融数据以表格形式展示
   - 涨跌幅用颜色区分（红色上涨，绿色下跌）

4. **开启新对话**
   - 点击顶部"新对话"按钮
   - 清空当前对话历史

### 管理员配置

1. **访问配置页面**
   - 管理员登录后，访问"管理后台 → AI配置"

2. **配置模型**
   - 填写模型名称、API地址、API密钥
   - 设置温度、最大Token数、系统提示词
   - 点击"测试连接"验证配置

3. **版本管理**
   - 每次保存自动创建新版本
   - 可回滚到历史版本

详细配置说明请参考：[AI配置指南.md](AI配置指南.md)

## 技术架构

### 前端
- **框架**：uni-app (Vue 3)
- **状态管理**：Pinia
- **存储**：uni.storage (按用户隔离)

### 后端
- **框架**：FastAPI (Python)
- **AI框架**：LangGraph
- **SSE流式传输**：Server-Sent Events

### 核心文件
- `aity-uni-app-v2/src/utils/ai-advisor-config.js` - AI配置和存储管理
- `aity-uni-app-v2/src/pages/ai-advisor/ai-advisor.vue` - AI投顾主页面
- `backend/app/api/routes/ai_advisor.py` - AI接口路由

## API接口

### 创建对话
```
POST /api/ai-advisor/chat
```

### SSE流式响应
```
Event: messages/partial       # 流式文本
Event: messages/complete      # 完整消息
Event: messages/metadata      # 会话元数据（thread_id）
Event: messages/tool          # 工具调用
Event: messages/tool_result   # 工具响应结果
```

详细API文档请参考：[api-config.md](api-config.md)

## 常见问题

### Q: 为什么我的对话历史消失了？
A: 可能是切换了用户账号，每个用户的数据是隔离的。

### Q: 如何修改AI的回复风格？
A: 管理员可以在"AI配置"页面修改"系统提示词"。

### Q: 金融数据为什么显示为表格？
A: 系统会自动识别金融工具返回的结构化数据，优先渲染为表格，更直观。

### Q: 涨跌幅颜色规则是什么？
A: 遵循中国股市习惯：红色上涨，绿色下跌。
