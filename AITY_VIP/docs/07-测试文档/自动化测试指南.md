# 自动化测试指南

> 本文档介绍项目的自动化测试框架和使用方法
> 最后更新：2026-02-28

---

## 📋 测试框架概述

项目使用 **Playwright** 作为自动化测试框架，支持以下测试场景：

- H5网页端测试
- 微信小程序测试（通过开发者工具）
- API接口测试
- 真机调试测试

---

## 🚀 快速开始

### 1. 环境准备

```bash
# 安装依赖
cd aity-uni-app-v2
npm install

# 安装Playwright浏览器
npx playwright install
```

### 2. 运行测试

```bash
# 运行所有测试
npm run test

# 运行特定测试文件
npx playwright test tests/e2e/login.spec.js

# 带界面运行
npx playwright test --ui

# 调试模式
npx playwright test --debug
```

### 3. 查看测试报告

```bash
# 生成HTML报告
npx playwright show-report
```

## 📱 小程序测试

### 微信开发者工具测试

1. 打开微信开发者工具
2. 导入项目：`aity-uni-app-v2/dist/dev/mp-weixin`
3. 使用开发者工具的自动化接口进行测试

### 真机调试

```bash
# 启动调试
adb devices
adb reverse tcp:8080 tcp:8080
```

## 🔧 测试配置

### playwright.config.js

```javascript
module.exports = {
  testDir: './tests/e2e',
  timeout: 30000,
  retries: 2,
  use: {
    baseURL: process.env.BASE_URL || 'http://localhost:5173',
    trace: 'on-first-retry',
    screenshot: 'only-on-failure',
  },
  projects: [
    {
      name: 'chromium',
      use: { browserName: 'chromium' },
    },
  ],
};
```

## 📊 测试报告

测试完成后，报告会保存在 `test-results/` 目录：

- `report.html` - HTML格式报告
- `screenshots/` - 失败截图
- `traces/` - 执行追踪

## 🛠️ 常用命令

```bash
# 运行CI模式（无头）
CI=true npm run test

# 只运行冒烟测试
npx playwright test --grep "@smoke"

# 并行运行
npx playwright test --workers=4

# 生成代码
npx playwright codegen http://localhost:5173
```
