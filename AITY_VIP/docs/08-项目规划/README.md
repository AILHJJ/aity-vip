## 文档使用指南

### 需求管理

1. **新增需求**：更新 `requirements.md` 并标注优先级
2. **需求变更**：在对应需求条目中记录变更历史
3. **未来规划**：将计划中的需求添加到 `future-requirements.md`

### 迭代管理

1. **迭代记录**：在 `iterations/README.md` 中记录主要迭代
2. **测试报告**：将测试相关文档放在 `iterations/` 目录
3. **优化方案**：记录具体的优化实施方案

### 发布管理

1. **发布前检查**：使用 `release-checklist.md` 进行验证
2. **版本标记**：在 `roadmap.md` 中更新版本状态
3. **发布后总结**：在 `iterations/` 中添加发布总结

## 贡献指南

更新规划文档时，请遵循以下规范：

1. **保持格式一致**：使用Markdown格式，保持现有结构
2. **标注更新日期**：在文档顶部标注最后更新时间
3. **记录变更历史**：重要变更需要记录变更原因和影响
4. **保持可读性**：使用清晰的标题层级和列表
