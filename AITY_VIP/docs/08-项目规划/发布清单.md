## 后端部署检查

### 部署前
- [ ] 备份数据库
- [ ] 备份当前代码
- [ ] 确认环境变量正确

### 部署步骤
```bash
# 1. SSH 到服务器
ssh root@aity88.online

# 2. 拉取代码
cd /root/aity-vip/backend
git pull origin feature/iteration-1

# 3. 安装依赖（如有新增）
npm install

# 4. 重启服务
pm2 restart aity-backend

# 5. 验证服务
pm2 status
pm2 logs aity-backend --lines 20

# 6. 测试 API
curl https://aity88.online:8443/api/health
```

### 部署后验证

## 紧急回滚

### 后端回滚
```bash
# 1. SSH 到服务器
ssh root@aity88.online

# 2. 回滚代码
cd /root/aity-vip/backend
git reset --hard <commit-hash>
git push origin feature/iteration-1 --force

# 3. 重启服务
pm2 restart aity-backend
```

### H5 回滚
```bash
# 恢复备份
cd /var/www/html/h5
rm -rf *
cp -r /backup/h5/<version>/* .
```

## 版本号规范

使用语义化版本：`MAJOR.MINOR.PATCH`

| 类型 | 说明 | 示例 |
|------|------|------|
| MAJOR | 不兼容的 API 变更 | 2.0.0 |
| MINOR | 向下兼容的功能新增 | 1.8.0 |
| PATCH | 向下兼容的问题修复 | 1.8.1 |
