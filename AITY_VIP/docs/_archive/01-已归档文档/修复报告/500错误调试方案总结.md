## 🔧 快速修复方案

### 如果发现tags问题

**修复**: 确保tags始终是数组
```javascript
tags: Array.isArray(formData.value.tags) ? formData.value.tags : []
```

### 如果发现attachments问题

**修复**: 确保attachments格式正确
```javascript
attachments: formData.value.attachments.map(a => ({
  type: a.type || 'image',
  url: a.url || a.path,
  name: a.name
}))
```

### 如果发现null值问题

**修复**: 添加默认值
```javascript
title: formData.value.title?.trim() || '',
content: formData.value.content?.trim() || '',
```
