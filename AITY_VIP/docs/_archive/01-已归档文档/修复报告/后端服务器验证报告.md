## ⚠️ 可能遇到的问题

### 问题1: 小程序仍连接本地API

**症状**: 看到请求 `http://192.168.2.140:3001`

**解决**:
1. 确认导入路径: `dist/build/mp-weixin` ✅
2. 确认不是: `dist/dev/mp-weixin` ❌
3. 微信开发者工具 → 工具 → 清除缓存 → 全部清除
4. 重新导入项目

### 问题2: Token过期

**症状**: 401 Unauthorized

**解决**:
1. 重新登录
2. 获取新token
3. 再次测试

### 问题3: 网络连接失败

**症状**: Network Error

**解决**:
1. 检查服务器网络: `ping aity88.online`
2. 检查端口开放: `telnet aity88.online 8443`
3. 查看PM2日志: `pm2 logs aity-backend`
