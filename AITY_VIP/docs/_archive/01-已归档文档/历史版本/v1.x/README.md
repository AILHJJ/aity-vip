## 🎯 重要历史决策

### 技术选型

#### 前端技术栈
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite 4.x
- **UI组件库**: Element Plus 2.x
- **状态管理**: Pinia 2.x
- **路由管理**: Vue Router 4.x

#### 后端技术栈
- **运行环境**: Node.js v20.20.0+
- **Web框架**: Express.js
- **数据库**: MySQL 5.7.0+
- **ORM**: Sequelize
- **认证**: JWT
- **进程管理**: PM2

### 项目定位

**核心目标**:
- ✅ 支持 H5 网页部署
- ✅ 提供金融信息和AI服务
- ⏳ 计划支持小程序部署

**技术限制**:
- 非真正的 uni-app 项目（虽项目名包含uni-app）
- 无法直接编译为小程序
- 使用了标准Vue 3技术栈
