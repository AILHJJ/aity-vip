## 1. 产品概述

### 1.1 背景说明

问小达3.0版本（基于LangGraph接口）已上线App数月，运行相对稳定。为避免重复开发，需要基于现有3.0版本进行简单调整，适配出PC客户端内嵌版本和Web浏览器版本。

### 1.2 设计原则

- **交互和UI保持不变**：只做网页版本大屏的适配，核心交互逻辑不修改
- **功能复用**：现有功能（收藏、分享、查看更多等）全部保留
- **最小改动**：基于现有代码进行布局适配，避免重复开发

### 1.3 适用范围

- PC客户端内嵌版本
- Web浏览器版本

## 2. 整体布局设计

### 2.1 三栏布局结构

PC版本采用经典的三栏布局设计，整体结构如下：

```
┌──────────────────────────────────────────────────────────────────────┐
│                            顶部栏 (Header)                            │
│  [切换回普通版本]                                    [登录信息]       │
├────────────┬─────────────────────────────────┬───────────────────────┤
│            │                                 │                       │
│   左侧栏   │           中间主体              │      右侧栏           │
│  (固定)    │         (自适应宽度)            │    (动态展开)         │
│            │                                 │                       │
│  280px     │          flex: 1               │     0~400px          │
│            │                                 │                       │
│  我的收藏   │         AI对话界面             │     详情页            │
│            │                                 │   (查看更多后展开)    │
│            │                                 │                       │
└────────────┴─────────────────────────────────┴───────────────────────┘
```

### 2.2 布局规格

| 区域 | 宽度 | 说明 |
|------|------|------|
| 顶部栏 | 100% | 固定高度，包含版本切换和登录信息 |
| 左侧边栏 | 280px | 固定宽度，可收起/展开 |
| 中间主体 | 自适应 | 填充剩余空间，最小宽度600px |
| 右侧边栏 | 动态0~400px | 默认收起，点击"查看更多"后展开，中间区域自动收缩 |

## 3. 功能模块详细设计

### 3.1 顶部栏 (Header)

#### 3.1.1 左侧区域

| 功能 | 说明 |
|------|------|
| 版本切换 | 显示"切换回普通版本"文字/按钮 |
| 跳转地址 | https://wenda.tdx.com.cn/site/wenda/index.html |
| 功能说明 | 跳转到问小达老版本（一句话选股版本，非AI对话版本） |

#### 3.1.2 右侧区域

| 功能 | 说明 |
|------|------|
| 登录信息 | 保持现有登录状态显示（复用现有实现） |

### 3.2 左侧边栏 - 我的收藏

#### 3.2.1 Tab切换

左侧边栏顶部包含两个Tab：

| Tab名称 | 说明 |
|---------|------|
| 历史对话 | 用户的历史会话列表 |
| 收藏问句 | 用户收藏的问题列表 |

#### 3.2.2 历史对话Tab

**数据来源**
- 接口：`GET /threads`（LangGraph会话列表接口）
- 详情接口：`GET /threads/{threadId}`（获取会话详情）

**列表项设计**

| 字段 | 说明 |
|------|------|
| 会话标题 | 显示该会话的第一句问句（截取前30字符） |
| 时间 | 会话创建时间或最后更新时间 |

**交互行为**

| 操作 | 行为 |
|------|------|
| 点击会话项 | 在中间主体区域加载该会话的所有对话记录，用户可继续对话 |
| 滚动加载 | 支持下拉或滚动到底部加载更多历史会话 |
| 当前会话标识 | 当前正在进行的会话高亮显示 |

**会话切换逻辑**
1. 用户点击某个历史会话
2. 调用 `/threads/{threadId}` 获取会话详情
3. 在中间区域渲染完整对话记录
4. 更新 `threadId`，后续对话基于该会话继续

#### 3.2.3 收藏问句Tab

**数据来源**
- 接口：`NLPSEU.CollectionGet`（复用现有收藏接口）

**分类设计**

保持现有的Tab分类：

| 分类 | 说明 |
|------|------|
| AI对话 | 通用AI对话收藏 |
| A股 | A股相关收藏 |
| 基金 | 基金相关收藏 |
| 指数 | 指数相关收藏 |

**列表项设计**

| 字段 | 说明 |
|------|------|
| 问句内容 | 用户收藏的问题文本 |
| 操作按钮 | 编辑、置顶、拖拽排序（复用现有） |

**交互行为**

| 操作 | 行为 |
|------|------|
| 点击问句 | 直接在中间区域发送该问句并执行 |
| 编辑 | 跳转到编辑页面 |
| 删除 | 批量删除选中的问句 |
| 排序 | 支持拖拽排序 |

### 3.3 中间主体 - AI对话界面

#### 3.3.1 保持现有交互

中间主体区域保持问小达3.0版本的所有交互功能，不做任何修改：

**核心功能（保持不变）**

| 功能 | 说明 |
|------|------|

| 深度思考 | 支持切换深度思考模式 |

| 行情图 | 股票/基金行情图展示 |
| 特殊内容 | 卡片、链接等特殊格式处理 |

**操作按钮（保持不变）**

| 按钮 | 说明 |
|------|------|
| 收藏 | 收藏当前问句 |
| 分享 | 分享对话内容 |
| 复制 | 复制AI回答 |
| 查看更多 | 触发右侧详情页展开 |

#### 3.3.2 历史对话查看

**滚动方式**

| 方式 | 说明 |
|------|------|
| 垂直滚动条 | 页面右侧显示滚动条 |
| 鼠标滚轮 | 支持鼠标滚轮滚动查看历史对话 |
| 下拉刷新 | 移动端下拉刷新功能保留（PC端可隐藏） |

### 3.4 右侧边栏 - 详情页

#### 3.4.1 触发条件

| 触发方式 | 说明 |

#### 3.4.4 详情页功能（保持现有）

## 4. 平台差异化功能

### 4.1 功能差异对照表

| 功能 | Web浏览器版 | PC客户端版 | 说明 |
|------|-------------|------------|------|
| 添加自选股 | 不显示按钮 | 显示批量加自选按钮 | Web版直接隐藏该功能 |
| 股票名称点击跳转 | 不支持 | 支持跳转到行情页 | PC版点击跳转个股/指数详情 |
| 平台检测 | 自动检测 | 自动检测 | 复用现有机制 |

### 4.2 添加自选股功能

#### Web浏览器版

- 详情页中不显示"添加"按钮
- 表格中不显示批量选择框
- 不影响其他功能使用

#### PC客户端版

- 详情页显示"添加"按钮
- 支持批量选择股票
- 点击后调用客户端接口添加到本地自选股
- 复用现有 `NLPSEU.CollectionUpdate` 接口

### 4.3 股票名称点击跳转

#### Web浏览器版

- 股票名称为纯文本显示
- 不支持点击跳转

#### PC客户端版

- 股票名称可点击（显示为链接样式）
- 点击后跳转到对应品种的行情页
- 支持跳转类型：个股、指数、基金

## 5. 接口依赖

### 5.1 历史对话接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/threads` | GET | 获取用户会话列表 |
| `/threads/{threadId}` | GET | 获取指定会话的详情（包含所有消息） |

**会话列表响应示例**

```json
{
  "threads": [
    {
      "thread_id": "thread_123456",
      "created_at": "2026-03-12T10:00:00Z",
      "last_message": "贵州茅台的最新股价是..."
    }
  ]
}
```

**会话详情响应示例**

```json
{
  "messages": [
    {
      "role": "user",
      "content": "贵州茅台的最新股价是多少？"
    },
    {
      "role": "assistant",
      "content": "贵州茅台（600519.SH）的最新价为1,789.00元..."
    }
  ]
}
```

### 5.2 收藏问句接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `NLPSEU.CollectionGet` | TQL | 获取收藏列表（复用现有） |
| `NLPSEU.CollectionUpdate` | TQL | 更新收藏状态（复用现有） |
| `JNLPSE.sortQuestion` | TQL | 排序收藏问句（复用现有） |

## 6. 设计规范

### 6.1 响应式断点

| 断点 | 宽度范围 | 布局 |
|------|----------|------|
| 大屏 | >= 1200px | 三栏布局（左侧280px + 中间自适应 + 右侧400px） |
| 中屏 | 768px ~ 1199px | 左侧收起，仅显示中间和右侧 |
| 小屏 | < 768px | 单栏布局（保持现有移动端布局） |

### 6.2 主题适配

- 保持现有红/黑双主题支持
- PC端布局同时支持两种主题

### 6.3 最小宽度限制

| 区域 | 最小宽度 |
|------|----------|
| 中间对话区域 | 600px |
| 左侧边栏 | 280px（可收起） |
| 右侧详情页 | 400px（可收起） |
