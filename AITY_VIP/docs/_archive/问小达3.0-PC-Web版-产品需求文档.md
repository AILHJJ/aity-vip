## 一、整体布局

### 1.1 三栏布局

```
┌──────────────────────────────────────────────────────────────────────┐
│                            顶部栏 (Header)                            │
│  [切换回普通版本]                                    [登录/用户信息]    │
├────────────┬─────────────────────────────────┬───────────────────────┤
│            │                                 │                       │
│   左侧栏   │           中间主体              │      右侧栏           │
│  (固定)    │         (自适应宽度)            │    (动态展开)         │
│            │                                 │                       │
│  240px     │           flex: 1               │      520px           │
│            │                                 │                       │
│  新会话     │         AI对话界面              │      详情页           │
│  历史对话   │       (复用3.0版本)            │   (点击查看更多后展开) │
│  收藏问句   │                                 │                       │
│            │                                 │                       │
└────────────┴─────────────────────────────────┴───────────────────────┘
```

**布局说明**:
- **左侧栏**: 240px固定宽度（可收起至60px），管理历史对话和收藏
- **中间主体**: 自适应宽度，最大1000px居中显示，完全复用3.0版本对话功能
- **右侧栏**: 520px固定宽度，默认隐藏，点击"查看更多"后从右侧展开

### 1.2 代码复用说明

**完全复用3.0版本** (`src/pages/tdx_wenda_ai_mobile/`):
- ✅ 所有UI组件（`components/`）
- ✅ 所有业务逻辑（`funcs/`）
- ✅ 所有样式（`css/`）
- ✅ 对话交互、流式输出、思考过程等所有功能

**PC端仅需调整**:
- 中间对话区域宽度: 最大1000px，居中显示
- 消息容器宽度、头像大小等尺寸参数（详见2.1.1）

## 二、功能需求

### 2.1 中间主体区域（复用3.0版本）

**核心说明**: **完全复用3.0版本的AI对话功能**，PC端只调整宽度参数

#### 2.1.1 AI对话模块

**复用组件**:
- `ui-welcome`: 欢迎页面（盘中点评 + 推荐问句）
- `ui-search`: 搜索输入（分类标签 + 深度思考开关）
- `ui-question` / `ui-answer`: 对话消息展示
- `ui-think`: AI思考过程展示

**PC端宽度调整**:
```scss
// 对话容器最大宽度: 1000px
.chat-container {
  max-width: 1000px;
  margin: 0 auto;  // 居中显示
}

// 消息宽度适配
.user-message {
  width: 90%;  // 用户消息90%
}
.ai-message {
  width: calc(100% - 46px);  // AI消息自适应
}
```

#### 2.1.2 欢迎页面

**完全复用3.0版本ui-welcome组件**
- 无需任何修改
- 包含: 盘中点评 + 推荐问句

#### 2.1.5 右侧详情栏

**功能说明**:
点击AI消息中的"查看更多"，在右侧展示完整数据（如选股结果列表）。

**开发要点**:
1. **基于3.0版本page-detail组件改造** (`src/pages/tdx_wenda_mobile/page_detail.vue`)

2. **按钮调整**:
   - ❌ **移除**: 云图、编辑、添加、收藏、分析、分享等所有多功能按钮
   - ✅ **保留**: 加自选按钮（在标题栏右侧）
   - ✅ **新增**: 关闭按钮（×）

3. **布局调整**:
   - 宽度: 固定520px
   - 显示: 标题 + 数量 + 加自选按钮 + 关闭按钮
   - 移除"解析条件"标题文字，直接显示条件标签

4. **交互**:
   - 点击"查看更多"从右侧滑出
   - 点击关闭按钮或再次点击"查看更多"收起

**注意**: 数据表格、分页加载等功能保持不变

### 2.2 左侧栏（新增）

**说明**: 左侧栏用于管理历史对话和收藏问句

#### 2.2.1 布局与交互

**尺寸**:
- 展开宽度: 240px
- 收起宽度: 60px
- 收起时只显示3个图标按钮（竖直排列）

**功能**:
1. **新会话**: 清空当前对话，创建新threadId
2. **历史对话**: 显示最近对话记录，点击切换
3. **收藏问句**: 显示收藏的问句，点击发送

**交互**:
- 提供◀/▶切换按钮
- 窗口宽度<1024px时自动收起

#### 2.2.2 历史对话

**接口**: `GET /api/thread/search`

**功能要点**:
- 显示最近对话记录
- 每条显示: 问题标题 + 时间
- 当前选中记录高亮
- 点击切换到历史对话

#### 2.2.3 收藏问句

**接口**: 复用3.0版本收藏接口

**功能要点**:
- 只保留"AI对话"分类（删除A股、基金等分类）
- 点击问句直接发送
- AI消息底部"收藏"按钮添加收藏
