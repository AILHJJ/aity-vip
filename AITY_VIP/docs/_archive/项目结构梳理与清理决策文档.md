## 三、各目录详细分析与决策建议

### 3.1 `backend/` - 后端服务 ✅ 保留

**用途**: Node.js + Express 后端，提供 RESTful API  
**文件数**: 202个  
**核心内容**:
- `src/` - 源码 (controllers/models/routes/middleware/config)
- `migrations/` - 数据库迁移脚本 (13个SQL)
- `scripts/` - 工具脚本 (数据库初始化/同步/测试等)
- `docs/` - 后端文档 (AI模块/API/数据库)
- `tests/` - Jest单元测试
- `uploads/` - 图片上传目录 (4张图)

**⚠️ 问题**:
1. 根目录散落大量一次性脚本: `check-messages.js`, `check-users.js`, `create-complete-test-data.js`, `diagnose-favorites.js`, `test-create-discussion.js`, `test-favorites-api.js` 等 (约15个)
2. 根目录散落 .md 文档: `AI模块开发完成报告.md`, `DATABASE_PERMISSION_FIX.md`, `NETWORK_ARCHITECTURE.md` 等 (约10个)
3. 多套部署脚本: `deploy.js`, `deploy.ps1`, `deploy.sh`, `deploy-cors-fix.sh`, `DEPLOY_TO_SERVER.sh`, `fix-backend.sh` 等

**💡 建议**:
- 将根目录散落的测试/诊断脚本移到 `scripts/` 或删除
- 将根目录散落的文档移到 `docs/` 或删除
- 统一部署脚本，删除重复的
