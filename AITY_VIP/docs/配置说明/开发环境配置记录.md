## 3. 安装与升级指南

### 3.1 Node.js 升级 (Windows)

**方式一: Chocolatey（推荐，需管理员权限）**

```powershell
# 以管理员身份运行PowerShell
choco upgrade nodejs-lts -y

# 刷新环境变量
refreshenv

# 验证
node -v
npm -v
```

**方式二: 官网下载**

1. 访问 https://nodejs.org/
2. 下载 LTS 版本
3. 运行安装程序，覆盖安装

**方式三: 使用 nvm-windows**

```powershell
# 安装 nvm-windows
# 下载: https://github.com/coreybutler/nvm-windows/releases

# 安装最新LTS
nvm install lts

# 切换版本
nvm use 24

# 验证
node -v
npm -v
```

### 3.2 npm 升级

```bash
# 升级npm到最新版本
npm install -g npm@latest

# 验证
npm -v
```

### 3.3 全局包更新

```bash
# 检查过时的全局包
npm outdated -g

# 更新所有全局包
npm update -g

# 或单独更新
npm install -g @anthropic-ai/claude-code@latest
```

### 3.4 Python 安装 (如需)

```powershell
# 推荐使用 Microsoft Store
# 或访问 https://www.python.org/downloads/

# 验证
python --version
pip --version
```

### 3.5 Git 安装/升级

```powershell
# 下载最新版
# https://git-scm.com/download/win

# 或使用 winget
winget install Git.Git

# 验证
git --version
```

### 3.6 MySQL 客户端

```powershell
# 下载 MySQL Community Server
# https://dev.mysql.com/downloads/mysql/

# 或仅安装客户端工具
# MySQL Shell: https://dev.mysql.com/downloads/shell/
```

### 3.7 PM2 安装

```bash
# 全局安装
npm install -g pm2

# 验证
pm2 -v
```

### 3.8 Playwright 安装

```bash
# 项目级安装（推荐）
npm install -D @playwright/test
npx playwright install

# 或全局安装
npm install -g playwright
playwright install
```

## 5. 环境变量配置

### 5.1 Windows 环境变量

**必需配置**:
```
NODE_ENV=development
```

**可选配置**:
```
# Python路径（如需要）
PYTHON_HOME=C:\Users\xxx\AppData\Local\Programs\Python\Python312
PATH=%PYTHON_HOME%;%PYTHON_HOME%\Scripts;%PATH%

# Git路径
GIT_HOME=C:\Program Files\Git
PATH=%GIT_HOME%\bin;%PATH%
```

## 6. 常见问题

### Q1: Node.js版本不兼容？

```bash
# 使用nvm切换版本
nvm install 20.19.3
nvm use 20.19.3

# 或重新安装LTS版本
```

### Q2: npm安装缓慢？

```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 或使用pnpm
npm install -g pnpm
```

### Q3: Python命令找不到？

```bash
# Windows可能需要使用py命令
py --version

# 或添加Python到PATH
```

### Q4: Git中文乱码？

```bash
git config --global core.quotepath false
git config --global gui.encoding utf-8
```

## 7. 版本检查脚本

创建 `scripts/check-env.js` 用于快速检查环境：

```javascript
// scripts/check-env.js
const { execSync } = require('child_process');

const checks = [
  { name: 'Node.js', cmd: 'node -v' },
  { name: 'npm', cmd: 'npm -v' },
  { name: 'Git', cmd: 'git --version' },
  { name: 'Python', cmd: 'python --version' },
  { name: 'PM2', cmd: 'npx pm2 -v' },
];

console.log('\n=== 开发环境检查 ===\n');

checks.forEach(({ name, cmd }) => {
  try {
    const result = execSync(cmd, { encoding: 'utf-8' }).trim();
    console.log(`✅ ${name}: ${result}`);
  } catch {
    console.log(`❌ ${name}: 未安装`);
  }
});

console.log('\n');
```

运行:
```bash
node scripts/check-env.js
```
