# 部署配置记录 - 2026-02-28

> 本次部署修复了 CORS 问题，优化了服务器目录结构

## 问题背景

H5 前端访问 API 时出现 CORS 错误，原因是前端配置使用了非标准 HTTPS 端口 `:8443`。

## 解决方案

### 1. 前端配置修改

修改 `aity-uni-app-v2/src/utils/config.js`：

```javascript
// 修改前
const PRODUCTION_CONFIG = {
  API_BASE_URL: 'https://aity88.online:8443/api',
  BASE_URL: 'https://aity88.online:8443',
  ENV: 'production'
}

// 修改后
const PRODUCTION_CONFIG = {
  API_BASE_URL: 'https://aity88.online/api',  // 使用标准 443 端口
  BASE_URL: 'https://aity88.online',
  ENV: 'production'
}
```

### 2. 服务器目录结构优化

```
/tmp/AITY/                           # Git 仓库根目录
├── backend/                         # 后端代码
│   ├── .env.production              # 生产环境配置
│   └── src/index.js
└── aity-uni-app-v2/                 # 前端代码
    └── dist/build/h5/               # H5 构建输出
```

### 3. Nginx 配置

宝塔面板 Nginx 配置路径：`/www/server/panel/vhost/nginx/www.aity88.online.conf`

关键配置：

```nginx
server {
    listen 443 ssl http2;
    server_name aity88.online;

    # 前端静态文件 - 直接指向构建目录
    root /tmp/AITY/aity-uni-app-v2/dist/build/h5;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理 - 端口 3000
    location /api {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 图片上传目录 - 静态文件服务
    location /uploads/ {
        alias /tmp/AITY/backend/uploads/;
        expires 30d;
        access_log off;
        add_header Cache-Control "public, immutable";
    }
}
```

> **注意**: `/uploads/` 配置用于提供图片等静态文件访问，必须添加否则图片会 404。

### 4. 后端环境配置

`/tmp/AITY/backend/.env.production`：

```env
NODE_ENV=production
PORT=3000

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_NAME=投研图灵室

# JWT配置
JWT_SECRET=your_jwt_secret

# CORS 配置
FRONTEND_URL=https://aity88.online
```

## 日常维护命令

### 更新后端

```bash
cd /tmp/AITY/backend
git pull
npm install --production
pm2 restart aity-backend
```

### 更新前端

```bash
cd /tmp/AITY/aity-uni-app-v2
git pull
npm install
npm run build:h5
# 无需其他操作，Nginx 直接指向构建目录
```

### 一键更新脚本

```bash
#!/bin/bash
# /tmp/AITY/update.sh

cd /tmp/AITY
git pull

cd /tmp/AITY/backend
npm install --production
pm2 restart aity-backend

cd /tmp/AITY/aity-uni-app-v2
npm install
npm run build:h5

echo "更新完成！"
echo "H5: https://aity88.online"
echo "API: https://aity88.online/api/health"
```
