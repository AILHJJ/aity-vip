# 更新日志

## [1.6.0] - 2026-02-03

### 新增 ✨

#### Markdown 富文本编辑器
- **编辑/预览双模式**
  - 无缝切换编辑和预览模式
  - 实时渲染预览效果

- **可视化工具栏**
  - 7 个快捷格式按钮（粗体、斜体、标题、列表、代码、链接、引用）
  - 一键插入 Markdown 语法
  - 点击反馈动画

- **Markdown 语法支持**
  - 标题（H1-H3）
  - 粗体（**text**）和斜体（*text*）
  - 代码块（```code```）和行内代码（`code`）
  - 引用（> text）
  - 无序和有序列表
  - 链接（[text](url)）

- **专业样式渲染**
  - 精美的排版设计
  - 代码块深色背景
  - 引用左侧蓝线
  - 响应式布局

### 已知限制 ⚠️

1. **光标位置**: 小程序环境无法精确获取光标位置，格式默认插入到文本末尾
2. **选中文本**: 小程序无法获取选中文本，无法实现"选中后包裹"功能
3. **高级语法**: 暂不支持表格、任务列表、删除线等高级语法
