# 更新日志

## [1.6.2] - 2026-02-06

### 新增 ✨

#### 消息列表优化
- **智能筛选系统**
  - 三级筛选：策略（全部/短线/中线）+ 类型（10种）+ 时间（5种+自定义）
  - 实时筛选结果计数显示
  - 筛选偏好本地存储
  - 自定义日期范围选择器

- **消息卡片优化**
  - 简化标签显示，只展示策略标签
  - 移除"全部用户"技术性标签
  - 跨策略消息显示为"短线+中线"
  - 无策略标签时隐藏标签区域

#### 消息发布表单重构
- **策略类型置顶**
  - 策略类型作为核心业务属性置顶显示
  - 单选设计（短线/中线）
  - 记住上次选择（localStorage）
  - 短线策略为默认选项

- **推送对象配置**
  - 新增推送对象字段（管理员可见）
  - 单选设计（短线VIP/中线VIP/全部用户）
  - 短线VIP为默认选项

- **消息类型多选**
  - 改为复选框多选设计
  - 支持10种消息类型组合

#### 讨论功能重构
- 讨论仅从消息详情页发起
- 移除独立"发起讨论"入口
- 讨论列表关联具体消息

### 改进 🎨

#### 用户体验
- 修复下拉刷新功能（`onPullDownRefresh is not defined`）
- 优化空状态提示
- 改进筛选交互体验
- 提升表单填写流程

#### 权限控制
- VIP用户不显示推送对象标签
- VIP用户只看到对应策略的消息
- 管理员可查看所有标签

## [1.6.0] - 2026-02-03

### 新增 ✨

#### Markdown 富文本编辑器
- **编辑/预览双模式**
  - 无缝切换编辑和预览模式
  - 实时渲染预览效果

- **可视化工具栏**
  - 7 个快捷格式按钮（粗体、斜体、标题、列表、代码、链接、引用）
  - 一键插入 Markdown 语法
  - 点击反馈动画

- **Markdown 语法支持**
  - 标题（H1-H3）
  - 粗体（**text**）和斜体（*text*）
  - 代码块（```code```）和行内代码（`code`）
  - 引用（> text）
  - 无序和有序列表
  - 链接（[text](url)）

- **专业样式渲染**
  - 精美的排版设计
  - 代码块深色背景
  - 引用左侧蓝线
  - 响应式布局

### 改进 🎨

#### 用户体验
- 优化消息内容编辑界面
- 提升内容可读性和专业性
- 改善输入交互体验

#### 技术实现
- 零依赖实现，不增加第三方库
- 轻量级 Markdown 解析器（~3KB）
