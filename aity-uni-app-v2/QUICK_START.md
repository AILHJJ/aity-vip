## 常见问题

### Q1: 工具栏按钮点击后格式插入到文本末尾？
**A**: 这是小程序环境的限制。在小程序中无法精确获取光标位置，所以默认在文本末尾插入。您可以手动将格式标记移动到需要的位置。

### Q2: 预览模式样式不对？
**A**: 确保您的 CSS 样式已正确加载。清除缓存后重新编译：
```bash
# 删除编译缓存
rm -rf dist/ unpackage/

# 重新编译
npm run dev:mp-weixin
```

### Q3: 代码块不显示？
**A**: 确保使用三个反引号（```）包裹代码，并且单独成行：
```javascript
function hello() {
  console.log('Hello');
}
```

### Q4: 链接点击无效？
**A**:
- 在小程序中，链接可能需要配置业务域名
- 在 H5 中，链接应该可以直接点击
- 确保 URL 格式正确：`[文字](https://example.com)`

### Q5: 草稿保存后丢失格式？
**A**: 草稿保存的是原始 Markdown 文本，不会丢失。如果出现问题，请检查浏览器控制台或小程序日志。
