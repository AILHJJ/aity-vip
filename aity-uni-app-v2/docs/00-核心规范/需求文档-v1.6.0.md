## 1. 产品概述

### 1.1 产品定位

VIP投研内部分享系统是一个面向高端用户的私密投研知识分享平台，专注于提供：
- 系统的研究方法论
- 深度的案例分析
- 专业的市场解读
- 及时的风险提示

### 1.2 目标用户

| 用户类型 | 特征 | 需求 |
|---------|------|------|
| 超级管理员 | 系统运营者 | 系统配置、用户管理、数据监控 |
| 管理员 | 投研专家 | 发布投研消息、回复用户讨论 |
| VIP用户（中线） | 中长期投资者 | 获取中线策略分析 |
| VIP用户（短线） | 短线交易者 | 获取短线策略分析 |
| 体验用户 | 潜在客户 | 了解平台价值，转化为付费用户 |

### 1.3 使用场景

- **早晨**: 查看盘前点评、早盘关注，制定当日交易计划
- **盘中**: 获取实时市场解读和风险提示
- **收盘**: 回顾收盘点评，总结当日操作
- **随时**: 发起讨论，与投研团队互动交流
- **AI咨询**: 使用AI投顾功能获取智能投研建议 (v1.6.0+新增)

## 4. 业务流程

### 4.1 消息发布流程

```mermaid
graph LR
A[管理员登录] --> B[进入发布页面]
B --> C[填写消息内容]
C --> D[选择消息类型]
D --> E[选择目标用户]
E --> F[提交发布]
F --> G{发布成功?}
G -->|是| H[用户收到消息]
G -->|否| I[显示错误信息]
```

### 4.2 用户查看消息流程

```mermaid
graph LR
A[用户登录] --> B[进入消息列表]
B --> C[应用筛选条件]
C --> D{筛选成功?}
D -->|是| E[显示筛选结果]
D -->|否| F[显示所有消息]
E --> G[点击消息详情]
F --> G
G --> H[标记已读]
H --> I{发起讨论?}
I -->|是| J[填写讨论内容]
I -->|否| K[返回列表]
J --> L[选择公开/私密]
L --> M[提交讨论]
```

### 4.3 讨论回复流程

```mermaid
graph LR
A[用户发起讨论] --> B{讨论类型?}
B -->|私密| C[仅管理员可见]
B -->|公开| D[所有用户可见]
C --> E[管理员收到通知]
D --> E
E --> F[查看讨论详情]
F --> G[撰写回复]
G --> H[提交回复]
H --> I[更新讨论状态]
I --> J[用户收到回复通知]
```
