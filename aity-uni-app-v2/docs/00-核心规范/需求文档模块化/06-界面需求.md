### 6.2.2 设计风格

**色彩体系**:
- 主色调: 紫色渐变 (#667eea → #764ba2)
- 辅助色: 10种消息类型独特配色
- 中性色: 灰度系统

**设计语言**:
- 关键词: 简洁、专业、高端
- 视觉特征: 流畅、直观、现代

**交互特点**:
- 流畅的过渡动画 (300ms)
- 及时的状态反馈
- 清晰的视觉层次

**视觉特性**:
- 渐变背景效果
- 细边框和分隔线
- 阴影效果
- 悬停状态反馈

## 6.3 组件规范

### 6.3.1 按钮组件

**尺寸**:
- 小按钮: height 32px, padding 8px 16px
- 默认按钮: height 40px, padding 12px 24px
- 大按钮: height 48px, padding 16px 32px

**类型**:
- 主要按钮: 紫色渐变背景
- 次要按钮: 白色背景,紫色边框
- 文本按钮: 无背景,紫色文字

**状态**:
- 默认: 正常显示
- 悬停: 轻微放大 (scale: 1.02)
- 点击: 缩小 (scale: 0.98)
- 禁用: 灰色,不可点击

### 6.3.2 卡片组件

**样式**:
- 背景: 白色
- 圆角: 12px
- 阴影: shadow-md
- 内边距: spacing-lg (16px)

**悬停效果**:
- 阴影: shadow-lg
- 过渡: transition-base

### 6.3.3 输入框组件

**样式**:
- 高度: 40px
- 圆角: radius-md (8px)
- 边框: 1px solid border-color
- 内边距: spacing-sm (8px) spacing-lg (16px)

**状态**:
- 默认: 灰色边框
- 聚焦: 紫色边框
- 错误: 红色边框
- 禁用: 灰色背景

## 6.4 响应式要求

### 6.4.1 断点系统

```scss
// 移动端优先
$breakpoint-xs: 0px;      // 超小屏
$breakpoint-sm: 576px;    // 小屏
$breakpoint-md: 768px;    // 中屏
$breakpoint-lg: 992px;    // 大屏
$breakpoint-xl: 1200px;   // 超大屏
```

### 6.4.2 适配策略

**H5**:
- 使用viewport meta标签
- 响应式布局
- 触摸优化

**微信小程序**:
- 使用rpx单位
- 适配不同屏幕尺寸
- 遵循小程序设计规范

**支付宝小程序**:
- 同微信小程序
- 独特的样式调整

## 6.6 无障碍设计

### 6.6.1 颜色对比度

- 文字与背景对比度 >= 4.5:1
- 大文字与背景对比度 >= 3:1

### 6.6.2 触摸目标

- 最小触摸区域: 44x44px
- 按钮间距: >= 8px

### 6.6.3 字体大小

- 最小字体: 12px
- 正文: 14-16px
- 标题: 18-24px
