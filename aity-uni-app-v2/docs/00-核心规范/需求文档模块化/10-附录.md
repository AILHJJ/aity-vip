## 10.1 术语表

### 10.1.1 用户角色相关

| 术语 | 英文 | 说明 |
|------|------|------|
| VIP中线用户 | VIP Mid-term User | 专注于中长期投资策略的用户,可查看中线策略消息 |
| VIP短线用户 | VIP Short-term User | 专注于短线交易策略的用户,可查看短线策略消息 |
| 体验用户 | Trial User | 潜在客户,有7天试用期,可查看所有消息 |
| 超级管理员 | Super Admin | 系统最高权限,负责系统配置和用户管理 |
| 管理员 | Admin | 投研专家,负责发布消息和回复讨论 |

## 10.4 常见问题 FAQ

### 10.4.1 功能相关

**Q1: 为什么我看不到某些消息?**

A: 消息可见性由您的用户角色和消息标签决定:
- VIP中线用户: 可查看"中线策略"和"全部用户"标签的消息
- VIP短线用户: 可查看"短线策略"和"全部用户"标签的消息
- 体验用户: 可查看所有消息

**Q2: 私密讨论和公开讨论有什么区别?**

A:
- 公开讨论: 所有用户可见
- 私密讨论: 仅管理员和发起者可见,标题后有🔒标识

**Q3: AI投顾是免费的吗?**

A: 是的,AI投顾功能对所有用户开放,无需额外付费。

**Q4: 消息草稿保存在哪里?**

A: 消息草稿保存在浏览器本地存储(localStorage),不会同步到服务器。

### 10.4.2 技术相关

**Q5: 前端如何调用API?**

A: 使用封装的request工具:
```javascript
import { request } from '@/utils/request';

// GET请求
const data = await request('/api/messages', { method: 'GET' });

// POST请求
const result = await request('/api/messages', {
  method: 'POST',
  data: { title, content }
});
```

**Q6: 如何部署到生产环境?**

A: 参考部署文档:
- [三种部署方案完整指南](../01-部署指南/三种部署方案完整指南.md)
- 推荐使用方案1(本地编译+SSH上传)

**Q7: 遇到编译错误怎么办?**

A:
1. 检查Node.js版本 >= 16.0.0
2. 删除node_modules和lock文件
3. 重新安装依赖: `npm install`
4. 查看错误日志,定位问题

---

### 10.4.3 账号相关

**Q8: 试用期多久?**

A: 体验用户默认7天试用期,到期后账号自动禁用,需联系管理员续费或升级。

**Q9: 如何升级VIP?**

A: VIP升级需联系管理员,管理员会修改您的角色和到期时间。

**Q10: 忘记密码怎么办?**

A: 当前版本暂不支持自助重置密码,需联系管理员重置。
