# H5手动部署指南 - Windows到Linux服务器

**场景**: 本地Windows已编译，上传到Linux服务器部署

---

## 📦 第一步：在本地Windows准备文件

### 1. 确认本地已编译
```powershell
# 在Windows PowerShell或CMD中执行
cd D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\build
dir h5
```

应该看到：
```
index.html
assets/
```

### 2. 压缩H5文件夹
```powershell
# 在Windows PowerShell中执行
cd D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\build
powershell -Command "Compress-Archive -Path h5\* -DestinationPath h5-build.zip -Force"
```

确认生成 `h5-build.zip` 文件

---

## 🚀 第二步：上传到服务器

### 方法1: 使用SCP（推荐，如果安装了Git Bash或OpenSSH）

```bash
# 在Git Bash或PowerShell中执行
scp D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\build\h5-build.zip root@111.48.74.245:/tmp/
```

### 方法2: 使用WinSCP（图形界面，更简单）

1. 下载并打开 WinSCP
2. 连接到服务器：
   - 主机: 111.48.74.245
   - 用户名: root
   - 密码: (您的服务器密码)
3. 上传文件：
   - 左侧: 选择本地文件 `D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\build\h5-build.zip`
   - 右侧: 导航到 `/tmp/`
   - 点击上传按钮

### 方法3: 使用FTP工具
- FileZilla、FlashFXP等FTP工具均可

---

## 🔧 第三步：在服务器上解压部署

登录到服务器后，执行以下命令：

```bash
# 1. 进入临时目录
cd /tmp

# 2. 确认文件已上传
ls -lh h5-build.zip

# 3. 备份旧版本（如果存在）
if [ -d /var/www/html/h5 ]; then
  cp -r /var/www/html/h5 /var/www/html/h5-backup-$(date +%Y%m%d-%H%M%S)
  echo "已备份旧版本"
fi

# 4. 创建部署目录
mkdir -p /var/www/html/h5

# 5. 解压文件
unzip -o h5-build.zip -d /var/www/html/h5/

# 6. 设置权限
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5

# 7. 验证部署
echo "========== 部署结果 =========="
ls -la /var/www/html/h5/

# 8. 清理临时文件
rm -f h5-build.zip
```

## 🎯 一键部署脚本（服务器端）

如果您已经上传了 `h5-build.zip` 到服务器，可以直接执行：

```bash
cat > /tmp/deploy-h5.sh << 'EOF'
#!/bin/bash
set -e
echo "开始部署H5..."

# 备份
if [ -d /var/www/html/h5 ]; then
  cp -r /var/www/html/h5 /var/www/html/h5-backup-$(date +%Y%m%d-%H%M%S)
fi

# 部署
mkdir -p /var/www/html/h5
unzip -o /tmp/h5-build.zip -d /var/www/html/h5/
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5

# 清理
rm -f /tmp/h5-build.zip

echo "部署完成！"
ls -la /var/www/html/h5/
EOF

chmod +x /tmp/deploy-h5.sh
/tmp/deploy-h5.sh
```

## 🐛 常见问题

### 问题1: 找不到unzip命令
```bash
# 安装unzip
yum install -y unzip
# 或
apt-get install -y unzip
```

### 问题2: 权限问题
```bash
# 修复权限
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5
```

### 问题3: 404错误
```bash
# 检查Nginx配置
nginx -t

# 查看错误日志
tail -f /var/log/nginx/error.log

# 重启Nginx
systemctl restart nginx
```
