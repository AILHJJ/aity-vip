## 📋 脚本清单

### Windows本地脚本（在Windows上执行）

| 脚本文件 | 功能 | 使用场景 |
|---------|------|---------|
| `scripts/full-deploy.bat` | 完整部署（前端+后端） | 日常开发，前后端一起更新 |
| `scripts/deploy-backend.bat` | 仅更新后端 | 快速修复后端问题 |
| `scripts/upload-h5-to-server.bat` | 仅上传前端 | 仅更新前端 |

### 服务器端脚本（在Linux服务器上执行）

| 脚本文件 | 功能 | 使用场景 |
|---------|------|---------|
| `scripts/server-deploy.sh` | 统一部署脚本 | 部署到 `/tmp/AITY/deploy.sh` |

## 🚀 快速开始

### 首次使用：服务器端准备

**1. SSH登录到服务器**
```bash
ssh root@111.48.74.245
```

**2. 创建部署目录**
```bash
mkdir -p /tmp/AITY
```

**3. 上传服务器端脚本**
```bash
# 在Windows本地执行
scp D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\scripts\server-deploy.sh root@111.48.74.245:/tmp/AITY/deploy.sh
```

**4. 添加执行权限**
```bash
# 在服务器上执行
chmod +x /tmp/AITY/deploy.sh
```

## 💡 日常使用

### 场景1: 完整部署（前后端一起更新）

**在Windows本地执行**:
```batch
cd D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\scripts
full-deploy.bat
```

**自动执行**:
1. ✅ 编译H5前端

**时间**: 约2分钟

```
┌─────────────────────────────────────┐
│   Windows本地执行 full-deploy.bat   │
└──────────────┬──────────────────────┘
               │
               ├─► npm run build:h5

               │
               └─► ssh 执行服务器脚本
                  └─► /tmp/AITY/deploy.sh
                     ├─► git pull 后端
                     ├─► pm2 restart
                     └─► 解压部署前端
```

## 🐛 常见问题

### Q1: 执行脚本提示"命令不存在"

**A**: 需要先安装Git Bash或OpenSSH客户端
- Windows 10/11: 自带OpenSSH
- 或安装Git for Windows

### Q2: SCP连接超时

**A**: 检查网络连接和服务器地址
```batch
ping 111.48.74.245
```

### Q3: 权限被拒绝

**A**: 检查SSH密钥配置或使用密码登录

### Q4: 前端部署失败

**A**: 检查服务器端目录权限
```bash
ls -la /var/www/html/
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5
```

### Q5: 后端重启失败

**A**: 查看PM2日志
```bash
pm2 logs aity-backend
pm2 status
```

## 📝 脚本配置

### 修改服务器地址

编辑脚本文件，修改以下行：
```batch
set SERVER_IP=111.48.74.245
set SERVER_USER=root
```

### 修改项目路径

编辑脚本文件，修改以下行：
```batch
set PROJECT_PATH=D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2
```

### 修改Git分支

编辑服务器端脚本，修改以下行：
```bash
git pull origin feature/iteration-1
```

## 🔧 高级用法

### 查看部署日志
```bash
# 服务器上查看PM2日志
pm2 logs aity-backend

# 查看Nginx日志
tail -f /var/log/nginx/error.log
```

### 回滚前端版本
```bash
# 列出备份
ls -la /var/www/html/h5-backup-*

# 恢复备份
rm -rf /var/www/html/h5
cp -r /var/www/html/h5-backup-YYYYMMDD-HHMMSS /var/www/html/h5
```

### 手动部署前端
```bash
# 服务器上手动执行
cd /tmp
unzip -o h5-upload.zip -d /var/www/html/h5/
chown -R www-data:www-data /var/www/html/h5
```
