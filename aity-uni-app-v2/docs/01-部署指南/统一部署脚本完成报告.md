## 🔧 首次使用：服务器端准备

### 步骤1: SSH登录服务器

```bash
ssh root@111.48.74.245
```

### 步骤2: 创建部署脚本

```bash
# 创建目录
mkdir -p /tmp/AITY

# 创建脚本
cat > /tmp/AITY/deploy.sh << 'EOF'
#!/bin/bash
set -e
echo "========================================="
echo "AITY 统一部署脚本"
echo "========================================="
echo ""

# 更新后端
echo "步骤1: 更新后端..."
cd /tmp/AITY/backend
git reset --hard
git pull origin feature/iteration-1
echo "✅ 后端更新完成"

# 重启后端
echo "步骤2: 重启后端服务..."
pm2 restart aity-backend -f
echo "✅ 后端服务已重启"

# 部署前端
echo "步骤3: 部署前端..."
if [ -f /tmp/h5-upload.zip ]; then
    [ -d /var/www/html/h5 ] && cp -r /var/www/html/h5 /var/www/html/h5-backup-$(date +%Y%m%d-%H%M%S)
    mkdir -p /var/www/html/h5
    unzip -o /tmp/h5-upload.zip -d /var/www/html/h5/
    chown -R www-data:www-data /var/www/html/h5
    chmod -R 755 /var/www/html/h5
    rm -f /tmp/h5-upload.zip
    echo "✅ 前端部署完成"
else
    echo "⚠️  未发现前端编译产物"
fi

echo ""
echo "========================================="
echo "部署完成！"
echo "========================================="
EOF

# 添加执行权限
chmod +x /tmp/AITY/deploy.sh
```

### 步骤3: 测试脚本

```bash
# 测试执行
bash /tmp/AITY/deploy.sh
```
