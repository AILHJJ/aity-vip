### 后端安全（已实现）

后端也需要有相应的权限控制：

**文件位置**: `backend/src/middleware/auth.js`

```javascript
// 检查管理员权限
const checkAdminPermission = (req, res, next) => {
  const { role } = req.user

  if (!['super_admin', 'admin'].includes(role)) {
    return res.status(403).json({
      code: 403,
      message: '无权限访问'
    })
  }

  next()
}
```

**建议**: 确保所有用户管理相关的API都使用了此中间件
