## 一、当前实现分析

### 1.1 现有功能评估

#### ✅ 优势
1. **已实现快捷筛选组合**: 5个预设筛选（全部、今天早盘、今天全部、本周关注、本周个股）
2. **支持筛选历史**: 最多保存5条历史记录
3. **状态持久化**: 筛选条件和展开状态会自动保存
4. **渐进式披露**: 默认收起详细筛选，按需展开
5. **横向滚动设计**: 使用scroll-view实现流畅的横向滚动

#### ⚠️ 待优化问题

**搜索功能问题**:
1. 搜索栏与筛选栏分离，视觉不够统一
2. 搜索历史面板遮挡内容区域
3. 缺少搜索结果高亮显示
4. 无实时搜索反馈

**筛选功能问题**:
1. 快捷筛选栏占用垂直空间，首屏可见内容少
2. 展开/收起动画可能不够流畅
3. 筛选结果数量反馈位置不够醒目
4. 自定义日期选择器展开后占用过多空间

**交互细节问题**:
1. 点击反馈（缩放动画）可能过于明显
2. 状态转换缺少过渡动画
3. 筛选面板展开时无背景遮罩
4. 搜索框无聚焦态视觉反馈

### 1.2 用户痛点总结

| 痛点 | 影响 | 优先级 |
|------|------|--------|
| 搜索和筛选分离，操作分散 | 需要在两个区域之间切换 | P0 |
| 筛选栏占用过多垂直空间 | 首屏可见消息少 | P0 |
| 搜索结果无高亮 | 难以快速定位关键词 | P1 |
| 自定义日期选择器占用空间 | 展开后页面过长 | P1 |
| 筛选历史入口不明显 | 功能可发现性低 | P2 |

## 四、交互设计详解

### 4.1 搜索交互

#### 4.1.1 搜索框交互流程

```
[默认状态]
  ↓ 点击搜索框
[聚焦状态]
  - 显示键盘
  - 显示搜索历史（如果有）
  - 背景遮罩
  ↓ 输入关键词
[输入状态]
  - 实时过滤消息列表
  - 显示清除按钮
  - 高亮匹配结果
  ↓ 点击搜索历史项
[应用历史]
  - 填入搜索框
  - 执行搜索
  - 关闭历史面板
  ↓ 点击清除按钮
[清空搜索]
  - 清空搜索框
  - 恢复完整列表
  - 隐藏清除按钮
  ↓ 点击遮罩
[取消搜索]
  - 失去焦点
  - 隐藏键盘
  - 关闭历史面板
```

#### 4.1.2 搜索结果高亮

**实现方式**:
```javascript
// 高亮搜索关键词
const highlightKeyword = (text, keyword) => {
  if (!keyword || !text) return text

  const regex = new RegExp(`(${keyword})`, 'gi')
  const parts = text.split(regex)

  return parts.map((part, index) => {
    if (part.toLowerCase() === keyword.toLowerCase()) {
      return `<mark class="highlight">${part}</mark>`
    }
    return part
  }).join('')
}
```

**样式**:
```scss
.highlight {
  background: linear-gradient(180deg, transparent 60%, #ffe066 60%);
  color: #333333;
  font-weight: 500;
  padding: 0 4rpx;
  border-radius: 4rpx;
}
```

#### 4.1.3 实时搜索防抖

**实现方式**:
```javascript
import { debounce } from 'lodash-es'

const debouncedSearch = debounce((keyword) => {
  searchKeyword.value = keyword
}, 300) // 300ms 防抖

// 在输入时调用
<input @input="debouncedSearch($event.detail.value)" />
```

## 六、性能优化方案

### 6.1 渲染优化

#### 6.1.1 虚拟滚动

**场景**: 消息列表超过100条

**实现**:
```vue
<template>
  <recycle-list :list="filteredMessages" :item-height="200">
    <template #default="{ item }">
      <message-card :message="item" />
    </template>
  </recycle-list>
</template>
```

**效果**:
- 只渲染可见区域的消息
- 减少 DOM 节点数量

<script setup>
import { computed } from 'vue'

const props = defineProps({
  text: String,
  keyword: String
})

const highlightedText = computed(() => {
  if (!props.keyword || !props.text) {
    return props.text
  }

  const regex = new RegExp(`(${props.keyword})`, 'gi')
  const parts = props.text.split(regex)

  return parts.map(part => {
    if (regex.test(part)) {
      return `<span class="highlight">${part}</span>`
    }
    return part
  }).join('')
})
</script>
