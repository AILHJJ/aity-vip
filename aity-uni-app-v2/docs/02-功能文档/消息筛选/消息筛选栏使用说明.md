# 消息筛选栏使用说明

## 快速开始

新的消息筛选栏已经集成到消息列表页面，提供了更直观、高效的筛选体验。

## 主要功能

### 1. 快捷筛选（推荐使用）

默认显示 5 个快捷筛选组合，一键应用常用筛选：

- **📋 全部消息** - 显示所有消息
- **🌅 今天早盘** - 只看今天的早盘关注
- **📅 今天全部** - 今天发布的所有消息
- **⭐ 本周关注** - 近一周的早盘关注
- **📈 本周个股** - 近一周的个股研究

### 2. 完整筛选面板

点击右上角的"展开"按钮，打开完整筛选面板：

#### 时间筛选
- 全部、今天、近一周、近一月、自定义
- 自定义时可以选择日期范围

#### 类型筛选
- 全部、盘前点评、早盘关注、午盘点评、尾盘关注
- 涨停分析、龙虎榜分析、个股研究、行业分析、宏观经济、其他

### 3. 筛选历史

- 自动记录最近使用的筛选条件（最多 5 条）
- 点击快速应用
- 点击 × 删除单条
- 点击"清空"删除所有历史

### 4. 重置筛选

当有筛选激活时，底部会显示：
- 当前筛选结果数量
- 重置按钮（点击清除所有筛选）

## 使用技巧

### 快速切换常用筛选

直接点击快捷筛选栏的 Chip，无需展开面板。

### 查看更多选项

点击"展开"按钮，打开完整筛选面板，选择时间和类型。

### 重复使用之前的筛选

在筛选历史中点击对应的筛选组合即可快速应用。

### 清除所有筛选

点击底部的"重置筛选"按钮。

## 保存机制

- **筛选条件**: 自动保存，下次打开页面自动恢复
- **展开状态**: 自动记住，下次保持相同的展开/收起状态
- **筛选历史**: 自动记录，最多保存 5 条

## 管理员功能

管理员会看到额外的"推送范围筛选"卡片，用于筛选不同推送范围的消息：
- 全部、短线策略、中线策略、全部用户

## 技术细节

### 文件位置

- 组件: `src/components/message-filter-bar.vue`
- 页面: `src/pages/messages/messages.vue`

### 数据流

```
用户操作 → message-filter-bar.vue
  ↓ @filter-change
messages.vue → basicFilters
  ↓ computed
filteredMessages → 消息列表
```

### 性能优化

- 使用计算属性缓存过滤结果
- 横向滚动使用原生 scroll-view
- 动画使用 CSS transition，保持 60fps

## 常见问题

**Q: 为什么快捷筛选只有 5 个？**
A: 这是基于用户行为分析预设的最常用组合。未来版本会支持自定义。

**Q: 筛选历史保存在哪里？**
A: 保存在本地存储（localStorage），不会上传到服务器。

**Q: 如何清除筛选历史？**
A: 展开筛选面板，在"最近使用"区域点击"清空"。

**Q: 管理员的推送范围筛选在哪里？**
A: 管理员登录后，会在基础筛选栏下方看到单独的"推送范围筛选"卡片。
