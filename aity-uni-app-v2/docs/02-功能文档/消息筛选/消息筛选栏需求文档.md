## 📋 需求概述

消息列表页的筛选功能分为两级：
1. **基础筛选**：所有用户可见，用于快速找到想看的内容
2. **推送范围筛选**：仅管理员可见，用于管理推送对象

---

## 🎯 核心概念

### 消息标签含义

**重要**：这些标签表示"推送范围"，而非"策略类型"！

| 标签 | 代码 | 含义 | 推送对象 |
|------|------|------|---------|
| 短线策略 | `short_term` | 短线相关消息 | VIP短线用户 |
| 中线策略 | `mid_term` | 中线相关消息 | VIP中线用户 |
| 全部用户 | `all_users` | 通用消息 | 所有用户 |

**业务逻辑**：
- 管理员发布消息时，选择该消息推送给哪些用户
- VIP短线用户只能看到带有"短线策略"或"全部用户"标签的消息
- VIP中线用户只能看到带有"中线策略"或"全部用户"标签的消息
- 这些标签与消息本身的类型（盘前、早盘等）无关

## 📱 基础筛选栏（所有用户可见）

### 设计原则
- **始终显示**，不需要展开
- **横向滚动chip选择**
- **节省空间，交互便捷**

### 筛选项

#### 1. 时间筛选
```
- 全部时间
- 今天
- 近一周
- 近一月
- 自定义（展开日期选择器）
```

**UI要求**：
- 横向滚动chip
- 自定义时间选择器放在前面（用户常用）
- 选择"自定义"时展开日期选择器

#### 2. 消息类型筛选
```
- 全部
- 盘前点评
- 早盘关注
- 午盘点评
- 尾盘关注
- 涨停分析
- 龙虎榜分析
- 个股研究
- 行业分析
- 宏观经济
- 其他
```

**UI要求**：
- 横向滚动chip
- 与时间筛选在同一行或换行显示

### 布局示例

```
┌─────────────────────────────────────────────┐
│ 时间: [全部] [今天] [近一周] [近一月] [自定义] │
�                                    ↓          │
│ 类型: [全部] [盘前] [早盘] [午盘] [尾盘]...  │
└─────────────────────────────────────────────┘
```

## 🔒 推送范围筛选（仅管理员可见）

### 设计原则
- **仅管理员可见**
- **可收起/展开**
- **默认收起状态**

### 筛选项

```
- 全部
- 短线策略（推送给VIP短线用户）
- 中线策略（推送给VIP中线用户）
- 全部用户（推送给所有用户）
```

### UI设计

#### 收起状态
```
┌─────────────────────────────────────────────┐
│ 推送范围筛选（管理员）        [展开 ▼]      │
└─────────────────────────────────────────────┘
```

#### 展开状态
```
┌─────────────────────────────────────────────┐
│ 推送范围筛选（管理员）        [收起 ▲]      │
├─────────────────────────────────────────────┤
│ [全部] [短线策略] [中线策略] [全部用户]    │
└─────────────────────────────────────────────┘
```

**视觉设计**：
- 淡紫色背景区分管理员功能
- 横向滚动chip
- 显示激活筛选数量徽章

## 🎨 UI交互设计

### 基础筛选

1. **Chip样式**
   - 未激活：灰色背景
   - 激活：渐变色背景 + 阴影
   - 点击：缩放反馈动画

2. **横向滚动**
   - 流畅的滚动体验
   - 清晰的视觉边界
   - 支持触摸滑动

3. **自定义时间**
   - 点击"自定义"chip展开
   - 显示开始和结束日期选择器
   - 带日历图标提示

### 推送范围筛选

1. **收起/展开**
   - 点击标题栏切换
   - 平滑的展开/收起动画
   - 自动保存展开状态

2. **状态持久化**
   - 保存筛选条件到localStorage
   - 页面刷新后自动恢复

## 📊 用户角色与权限

### VIP短线用户
- ✅ 可以看到：基础筛选（时间+消息类型）
- ❌ 不能看到：推送范围筛选
- ✅ 只能查看：带有"短线策略"或"全部用户"标签的消息

### VIP中线用户
- ✅ 可以看到：基础筛选（时间+消息类型）
- ❌ 不能看到：推送范围筛选
- ✅ 只能查看：带有"中线策略"或"全部用户"标签的消息

### 管理员
- ✅ 可以看到：基础筛选（时间+消息类型）
- ✅ 可以看到：推送范围筛选
- ✅ 可以查看：所有消息

### 体验用户
- ✅ 可以看到：基础筛选（时间+消息类型）
- ❌ 不能看到：推送范围筛选
- ✅ 只能查看：带有"全部用户"标签的消息

## 🔧 技术实现

### 文件结构
```
src/
├── pages/
│   └── messages/
│       └── messages.vue          # 消息列表页（包含基础筛选）
├── components/
│   └── filter-bar.vue            # 推送范围筛选组件（仅管理员）
└── utils/
    └── constants.js              # 标签常量定义
```

### 数据结构

```javascript
// 基础筛选（messages.vue）
const basicFilters = ref({
  timeRange: 'all',      // 时间范围
  customStartDate: null,
  customEndDate: null,
  messageType: 'all'      // 消息类型
})

// 推送范围筛选（filter-bar.vue，仅管理员）
const pushScopeFilters = ref({
  pushScope: 'all'        // 推送范围: all, short_term, mid_term, all_users
})
```

### 筛选逻辑顺序

1. **权限过滤**（根据用户角色过滤标签）
2. **时间筛选**（基础筛选）
3. **消息类型筛选**（基础筛选）
4. **推送范围筛选**（仅管理员，可选）
5. **搜索关键词**（客户端）

## 📝 示例场景

### 场景1：VIP短线用户查看今天的早盘关注
1. 选择时间："今天"
2. 选择类型："早盘关注"
3. 结果：显示今天带有"短线策略"或"全部用户"标签的早盘关注消息

### 场景2：管理员查看所有短线策略消息
1. 保持基础筛选：全部时间、全部类型
2. 展开推送范围筛选
3. 选择："短线策略"
4. 结果：显示所有带有"短线策略"标签的消息

### 场景3：体验用户查看最近一周的所有消息
1. 选择时间："近一周"
2. 选择类型："全部"
3. 结果：显示最近一周带有"全部用户"标签的消息
