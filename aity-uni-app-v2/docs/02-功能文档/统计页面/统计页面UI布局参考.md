## 交互特性

### 下拉刷新
- 所有数据支持下拉刷新
- 显示刷新动画
- 刷新完成后自动停止

### 空状态
- 数据为空时显示"暂无数据"
- 统一的空状态样式
- 友好的用户提示

### 加载状态
- 首次加载显示加载动画
- 下拉刷新显示刷新状态
- 加载失败显示Toast提示

## 响应式设计

所有尺寸使用 `rpx` 单位：
- 统计卡片: 自动适配 2×2 网格
- 饼图: 400rpx × 400rpx
- 横向柱状图: 100% 宽度，高度自适应
- 字体: 22rpx - 48rpx 范围

## 数据更新流程

1. **页面加载**
   ```
   onMounted → 权限检查 → loadStats() → 并行请求6个API
   ```

2. **下拉刷新**
   ```
   onRefresh → refreshing=true → loadStats() → refreshing=false
   ```

3. **数据组合**
   ```
   基础统计 + 用户增长 + 消息趋势 + 活跃用户
   + 角色分布 + 类型分布 → 完整统计面板
   ```

## 性能优化

- **并行请求**: 所有API并行调用，减少等待时间
- **计算属性**: 使用computed缓存计算结果
- **条件渲染**: 使用v-if/v-else避免不必要的渲染
- **CSS动画**: 使用CSS transition实现平滑过渡
