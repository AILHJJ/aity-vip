## 📋 本次更新内容

### 后端修改 (必须更新)

**修复问题**: 消息发布400错误

**修改文件**:
1. `backend/src/middleware/validation.js`
   - 第59行: `groupId` 从必填改为可选

2. `backend/src/controllers/messageController.js`
   - 第247行: 添加自动填充 `targetGroupId` 逻辑
   - 第277行: 使用 `targetGroupId` 创建消息

**影响**: 管理员发布消息时不再需要指定groupId,系统自动使用用户groupId或'all'

---

### 小程序修改 (必须更新)

**优化内容**:

1. ✅ **修复发布按钮被遮挡**
   - 按钮固定在底部,随时可见
   - 添加底部占位防止内容被遮挡

2. ✅ **Markdown编辑器优化**(参考mdnice设计)
   - 8个快捷格式按钮(粗体/斜体/标题/列表等)
   - 等宽代码字体
   - 自动高度调整
   - 编辑/预览Tab切换

3. ✅ **图片附件优化**
   - 缩略图显示(160x160rpx)
   - 圆角设计
   - 优化删除按钮

4. ✅ **粘贴图片功能**
   - 支持Ctrl+V粘贴图片
   - 自动验证大小和数量
   - 友好的提示信息

**修改文件**:
- `aity-uni-app-v2/src/pages/create-message/create-message.vue`
- `aity-uni-app-v2/docs/Markdown编辑器优化说明-v1.6.1.md`

## 🚀 部署步骤

### 一、后端部署

#### 1.1 连接到服务器

```bash

```

#### 1.2 进入后端目录

```bash

```

#### 1.3 拉取最新代码

```bash

```

## 🐛 常见问题排查

### 后端问题

#### Q1: PM2重启失败

**解决**:
```bash
# 查看详细错误
pm2 logs aity-vip-backend --err

# 重新启动
pm2 delete aity-vip-backend
pm2 start ecosystem.config.js
```

#### Q2: 端口被占用

**检查**:
```bash
netstat -tulnp | grep 3001
```

**解决**:
```bash
# 杀掉占用进程
kill -9 <PID>
```

#### Q3: 数据库连接失败

**检查**:
```bash
# 查看环境变量
cat .env

# 测试连接
mysql -u root -p aity_vip
```

---

### 小程序问题

#### Q1: 编译失败

**检查**:
```bash
# 清理缓存
rm -rf node_modules dist
npm install
npm run build:mp-weixin
```

#### Q2: 上传失败

**解决**:
1. 检查网络连接
2. 重新登录微信开发者工具
3. 重新导入项目

#### Q3: 粘贴图片不工作

**原因**: H5平台不支持textarea粘贴图片

**解决**:
- 仅在微信小程序中测试
- 或使用"上传图片"按钮
