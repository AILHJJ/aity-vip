## ⚠️ 注意事项

### Sass警告
编译时出现 `legacy-js-api` 废弃警告，这是Sass库的警告，不影响功能：
```
DEPRECATION WARNING [legacy-js-api]: The legacy JS API is deprecated
```
**解决方法**: 升级到最新版本的sass或sass-loader（可选）

### 图标资源
底部导航配置了图标路径，但图标文件可能不存在：
```
iconPath: "static/tabbar/message.png"
```
**建议**: 准备对应的图标文件，或暂时移除iconPath配置

### 跨策略推送
根据用户反馈，已降低跨策略推送提示功能的优先级，本次未实现。
