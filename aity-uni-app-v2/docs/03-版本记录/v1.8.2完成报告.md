## 🔧 核心修复

### 修复1: 消息类型筛选不一致

**问题描述**:
`message-filter-bar.vue`中的消息类型选项使用硬编码值，与`constants.js`中定义的不一致。

**修复前**:
```javascript
const messageTypeOptions = computed(() => [
  { label: '早盘关注', value: 'morning_focus' },
  { label: '午盘点评', value: 'afternoon_comment' },  // 错误！应该是尾盘点评
  { label: '涨停分析', value: 'limit_up_analysis' },  // 不存在于constants.js
  // ...
])
```

**修复后**:
```javascript
import { MESSAGE_TYPES, MESSAGE_TYPE_LABELS } from '../utils/constants'

const messageTypeOptions = computed(() => [
  { label: MESSAGE_TYPE_LABELS[MESSAGE_TYPES.PRE_MARKET_COMMENT], value: MESSAGE_TYPES.PRE_MARKET_COMMENT },
  { label: MESSAGE_TYPE_LABELS[MESSAGE_TYPES.MORNING_COMMENT], value: MESSAGE_TYPES.MORNING_COMMENT },
  { label: MESSAGE_TYPE_LABELS[MESSAGE_TYPES.MORNING_FOCUS], value: MESSAGE_TYPES.MORNING_FOCUS },
  // ... 所有类型与constants.js一致
])
```

**影响**: 确保筛选功能正常工作，避免因类型不匹配导致筛选失败。

### 修复2: 讨论私密性说明简化

**问题描述**:
原说明文案过于冗长，用户体验不佳。

**修复前**:
```
🔒 关于讨论可见性
• 默认为私密讨论，仅您和管理员可见
• 发帖后可在详情页申请公开
• 管理员审核通过后将公开给所有用户
• 这样可以确保内容质量，保护投资者决策
```

**修复后**:
```
🔒 私密讨论
为避免不同投资风格的影响，讨论默认私密。优质内容经管理员审核后公开，确保合规性与内容质量。
```

**影响**: 提升用户体验，界面更简洁，信息传达更直接。

## 🚀 部署说明

### H5部署到腾讯云

#### 方式1: 使用Windows脚本（推荐）
```bash
cd AITY_VIP\aity-uni-app-v2\scripts
deploy-h5.bat
```

#### 方式2: 手动部署
```bash
# 1. 压缩编译产物
cd aity-uni-app-v2\dist\build
powershell -Command "Compress-Archive -Path h5\* -DestinationPath h5-build.zip"

# 2. 上传到服务器
scp h5-build.zip root@111.48.74.245:/tmp/

# 3. SSH登录服务器并部署
ssh root@111.48.74.245
cd /var/www/html/
cp -r h5 h5-backup-$(date +%Y%m%d)
unzip -o /tmp/h5-build.zip -d h5
chown -R www-data:www-data h5
chmod -R 755 h5
```

#### 访问地址
```
http://111.48.74.245/h5/
```

### 微信小程序部署

#### 上传步骤
1. 打开微信开发者工具
2. 导入项目: `dist/build/mp-weixin/`
3. 点击"上传"按钮
4. 填写版本号: 1.8.2
5. 填写更新备注:
   ```
   v1.8.2 更新：
   - 修复消息类型筛选选项
   - 优化讨论私密性说明
   - 新增AI编程交互规范文档
   ```
6. 上传成功
