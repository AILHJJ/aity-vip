## ✨ 新增功能

### 1. 空状态组件

**文件**: `src/components/empty-state.vue`

**功能特性**:
- 支持6种预设状态类型
- 可自定义图标、标题、描述和操作按钮
- 优雅的浮动动画效果
- 完全可复用的组件设计

**使用方式**:
```vue
<empty-state type="message" />
<empty-state type="discussion" />
<empty-state type="no-result" actionText="重新加载" @action="handleReload" />
```

**支持的状态类型**:
- `default` - 默认空状态
- `message` - 消息空状态
- `discussion` - 讨论空状态
- `favorite` - 收藏空状态
- `network-error` - 网络错误
- `no-result` - 搜索无结果

### 2. 下拉刷新提示

**优化页面**:
- `src/pages/messages/messages.vue`
- `src/pages/discussions/discussions.vue`

**功能特性**:
- 下拉时显示"正在刷新..."提示

**实现细节**:
```vue

  </view>
</scroll-view>
```

### 4. 未读消息标识

**文件**: `src/store/user.js`, `src/pages/profile/profile.vue`

**功能特性**:
- 在用户store中管理未读消息数
- 个人中心页面显示未读消息数徽章
- 支持未读数量持久化存储
- 支持超过99显示为"99+"

**Store API**:
```javascript
import { useUserStore } from '@/store/user'

const userStore = useUserStore()

// 设置未读数量
userStore.setUnreadCount(5)

// 清空未读数量
userStore.clearUnreadCount()

// 检查是否有未读
if (userStore.hasUnread) {
  console.log('未读数量:', userStore.unreadCount)
}
```

**UI实现**:
```vue
<view v-if="userStore.hasUnread" class="unread-badge">
  <text class="unread-count">
    {{ userStore.unreadCount > 99 ? '99+' : userStore.unreadCount }}
  </text>
</view>
```

## 🔧 技术改进

### 1. 组件复用性提升

创建了可复用的EmptyState组件,替代了各个页面中重复的空状态代码,提高了代码复用性和维护性。

### 2. 状态管理增强

在用户store中新增未读消息数管理,提供了完整的API接口:
- `setUnreadCount(count)` - 设置未读数
- `clearUnreadCount()` - 清空未读数
- `hasUnread` getter - 判断是否有未读
- `unreadCount` state - 未读数量

### 3. 用户体验优化

- 所有列表页面统一下拉刷新体验
- 加载状态动画更加流畅
- 空状态提示更加友好
- 未读消息提示更加醒目
