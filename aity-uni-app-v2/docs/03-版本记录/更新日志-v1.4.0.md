## ✨ 新增功能

### 1. 消息已读/未读状态管理

**文件**: `src/utils/read-status.js`

**功能特性**:
- 本地持久化存储已读状态
- 自动计算未读消息数量
- 支持批量标记已读
- 最多保存500条已读记录

**API接口**:
```javascript
import {
  markAsRead,              // 标记单条消息为已读
  isMessageRead,           // 检查消息是否已读
  getReadMessages,         // 获取所有已读消息ID
  clearReadHistory,        // 清空已读记录
  markMultipleAsRead,      // 批量标记已读
  getUnreadCount           // 获取未读数量
} from '@/utils/read-status'

// 标记消息为已读
markAsRead(messageId)

// 检查是否已读
if (!isMessageRead(messageId)) {
  // 显示未读标识
}

// 计算未读数量
const unreadCount = getUnreadCount(allMessageIds)
```

**UI实现**:
- 未读消息显示渐变背景
- 左侧蓝色边框高亮
- 红色圆点脉冲动画提示
- 自动更新store中的未读数

### 2. 消息列表已读/未读标识

**优化页面**: `src/pages/messages/messages.vue`

**功能特性**:

- 左侧蓝色边框高亮
- 红色脉冲圆点提示

- 实时更新未读数量

**实现细节**:
```vue
<view
  v-for="message in filteredMessages"
  :key="message.id"
  class="message-item"
  :class="{ unread: isMessageUnread(message.id) }"
  @click="goToDetail(message.id)"
>
  <view class="message-header">
    <view class="message-type-badge">...</view>
    <view class="header-right">
      <!-- 未读红点 -->
      <view v-if="isMessageUnread(message.id)" class="unread-dot"></view>
      <text class="message-time">...</text>
    </view>
  </view>
</view>
```

**CSS动画**:

### 3. 消息详情页分享功能

**优化页面**: `src/pages/message-detail/message-detail.vue`

**功能特性**:
- 新增分享按钮
- 自动复制消息标题和内容摘要到剪贴板
- 复制成功后弹窗提示
- 支持粘贴到微信、QQ等平台分享

**实现代码**:
```javascript
const handleShare = () => {
  const shareText = `${message.value.title}\n\n${message.value.content.substring(0, 100)}...`

  uni.setClipboardData({
    data: shareText,
    success: () => {
      uni.showModal({
        title: '分享成功',
        content: '内容已复制到剪贴板，可以粘贴分享给好友',
        showCancel: false
      })
    }
  })
}
```

**UI布局**:
- 操作按钮布局优化: 收藏、分享、发起讨论
- 三个按钮横向排列,视觉平衡
- 分享按钮使用emoji图标 📤
