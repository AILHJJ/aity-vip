#### 1.1 添加语义图标

为每种用户标签添加了直观的语义图标，提升视觉识别度：

| 标签类型 | 图标 | 含义 |
|---------|------|------|
| **短线策略** | ⚡ | 闪电 - 快速决策 |
| **中线策略** | 📈 | 图表 - 趋势跟踪 |
| **全部用户** | 👥 | 人群 - 所有人可见 |

#### 1.2 增强视觉效果

**升级前**:
- 单一背景色
- 无图标
- 视觉区分度低

**升级后**:
- 渐变背景（12%透明度）
- 细边框（25%透明度）
- 增加内边距（10rpx）
- 图标+文字组合

#### 1.3 代码实现

**messages.vue:411-435**
```javascript
// 获取标签图标
const getTagIcon = (tag) => {
	const iconMap = {
		'short_term': '⚡',  // 闪电 - 快速

// 获取标签样式类名
const getTagClass = (tag) => {
	const tagMap = {
		'short_term': 'tag-short-term',
		'mid_term': 'tag-mid-term',
		'all_users': 'tag-all-users',
		// 兼容常量值
		[MESSAGE_TAGS.SHORT_TERM]: 'tag-short-term',
		[MESSAGE_TAGS.MID_TERM]: 'tag-mid-term',
		[MESSAGE_TAGS.ALL_USERS]: 'tag-all-users'
	}
	return tagMap[tag] || 'tag-default'
}
```

### 3. Bug修复 🔧

#### 3.1 标签值格式兼容性

**问题描述**:
后端返回的标签值为字符串格式（`'short_term'`），而前端常量为对象（`MESSAGE_TAGS.SHORT_TERM`），导致样式映射失败。

**解决方案**:
在`getTagClass()`函数中同时支持两种格式：
```javascript
const getTagClass = (tag) => {
	const tagMap = {
		'short_term': 'tag-short-term',
		'mid_term': 'tag-mid-term',
		'all_users': 'tag-all-users',
		// 兼容常量值
		[MESSAGE_TAGS.SHORT_TERM]: 'tag-short-term',
		[MESSAGE_TAGS.MID_TERM]: 'tag-mid-term',
		[MESSAGE_TAGS.ALL_USERS]: 'tag-all-users'
	}
	return tagMap[tag] || 'tag-default'
}
```
