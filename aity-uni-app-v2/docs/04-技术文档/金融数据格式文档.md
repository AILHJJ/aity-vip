# 金融数据格式文档

## 概述

本文档定义了AITY uni-app v2项目中金融选股工具返回数据的格式规范和渲染标准。

**适用范围**: AI投顾功能中的金融数据展示

---

## 一、数据格式标准

### 1.1 JSON表格格式

#### 1.1.1 完整数据结构

**类型**: `Array<Array<string | number>>`

**结构说明**:
- 第一行: 表头（列名）
- 第二行至倒数第二行: 数据行
- 最后一行: 统计信息

**示例**:
```json
[
  ["证券名称", "证券代码", "现价<br>2026.02.06", "涨跌幅<br>2026.02.06", "成交额"],
  ["平安银行", "000001", "12.34", "2.56", "123456789"],
  ["招商银行", "600036", "35.67", "-1.23", "987654321"],
  ["", "总数", "2"]
]
```

#### 1.1.2 表头规则

**格式**: `列名<br>日期` 或 `列名`

**示例**:
```json
[
  ["证券名称", "证券代码", "现价<br>2026.02.06", "涨跌幅<br>2026.02.06"]
]
```

**说明**:
- `列名`: 字段中文名称
- `<br>日期`: 可选，表示数据的时间点
- 日期格式: `YYYY.MM.DD` 或 `YYYYMMDD`

**处理逻辑**:
```javascript
headers = row.map(cell => {
  if (typeof cell === 'string') {
    // 移除HTML标签和日期
    return cell.replace(/<br>.*$/, '').trim()
  }
  return String(cell).trim()
})
// 结果: ["证券名称", "证券代码", "现价", "涨跌幅"]
```

#### 1.1.3 数据行规则

**格式**: 与表头一一对应的值

**示例**:
```json
[
  ["平安银行", "000001", "12.34", "2.56", "123456789"]
]
```

**数据类型**:
- 字符串: 股票名称、代码等
- 数字: 价格、涨跌幅等（以字符串形式传输）
- 空字符串: 表示无数据

#### 1.1.4 统计行规则

**格式**: `["说明", "总数", 数量]`

**示例**:
```json
["", "总数", "150"]
```

或

```json
["统计", "共找到", "150"]
```

**说明**:
- 第二个单元格包含"总数"字样
- 第三个单元格是具体的数量

## 三、数据格式化实现

### 3.1 DataFormatter工具

**位置**: `src/utils/markdown-renderer.js`

#### 3.1.1 涨跌幅格式化

**函数签名**:
```typescript
formatChange(
  value: string | number,
  compareValue: string | number | null,
  unit: string
): string
```

**参数说明**:
- `value`: 要格式化的数值
- `compareValue`: 比较基准（可选，默认使用value）
- `unit`: 单位（如%, 元）

**返回值**: HTML字符串，带颜色类名

**颜色规则**:
```javascript
const num = parseFloat(value)
const compareNum = compareValue !== null ? parseFloat(compareValue) : num

let colorClass = 'text-neutral'
if (compareNum > 0) colorClass = 'text-up'      // 红色-上涨
else if (compareNum < 0) colorClass = 'text-down' // 绿色-下跌
```

**CSS样式**:
```css
.text-up { color: #ff4d4f; font-weight: 600; }   /* 红色 */
.text-down { color: #52c41a; font-weight: 600; } /* 绿色 */
.text-neutral { color: #666666; }               /* 灰色 */
```

**使用示例**:
```javascript
// 示例1: 普通涨跌幅
DataFormatter.formatChange('2.56', null, '%')
// => <span class="text-up">2.56%</span>

// 示例2: 负涨幅
DataFormatter.formatChange('-1.23', null, '%')
// => <span class="text-down">-1.23%</span>

// 示例3: 使用比较值
DataFormatter.formatChange('2.56', '2.50', '%')
// => <span class="text-up">2.56%</span>

// 示例4: 涨跌额
DataFormatter.formatChange('0.50', null, '元')
// => <span class="text-up">0.50元</span>
```

#### 3.1.2 大数值格式化

**函数签名**:
```typescript
formatBigNumber(
  value: string | number,
  precision: number
): string
```

**参数说明**:
- `value`: 要格式化的数值
- `precision`: 小数精度（默认2）

**返回值**: 格式化后的字符串

**转换规则**:
```javascript
const num = parseFloat(value)
const absNum = Math.abs(num)

if (absNum >= 100000000) {
  return (num / 100000000).toFixed(precision) + '亿'
} else if (absNum >= 10000) {
  return (num / 10000).toFixed(precision) + '万'
}

return num.toFixed(precision)
```

**使用示例**:
```javascript
// 示例1: 亿级
DataFormatter.formatBigNumber('123456789', 2)
// => "1.23亿"

// 示例2: 万级
DataFormatter.formatBigNumber('12345678', 2)
// => "1.23万"

// 示例3: 小于万
DataFormatter.formatBigNumber('1234', 2)
// => "1234.00"

// 示例4: 自定义精度
DataFormatter.formatBigNumber('123456789', 3)
// => "1.235亿"
```

#### 3.1.3 百分比格式化

**函数签名**:
```typescript
formatPercent(
  value: string | number,
  precision: number
): string
```

**参数说明**:
- `value`: 要格式化的数值
- `precision`: 小数精度（默认2）

**返回值**: 带颜色和百分号的HTML字符串

**使用示例**:
```javascript
// 正百分比
DataFormatter.formatPercent('2.56', 2)
// => <span class="text-up">2.56%</span>

// 负百分比
DataFormatter.formatPercent('-1.23', 2)
// => <span class="text-down">-1.23%</span>

// 零值
DataFormatter.formatPercent('0', 2)
// => <span class="text-neutral">0.00%</span>
```

#### 3.1.4 日期格式化

**函数签名**:
```typescript
formatDate(
  dateStr: string,
  format: number
): string
```

**参数说明**:
- `dateStr`: 日期字符串（YYYYMMDD或YYYY-MM-DD）
- `format`: 格式类型
  - `1`: YYYY-MM-DD（默认）
  - `2`: MM-DD
  - `3`: YYYY

**返回值**: 格式化后的日期字符串

**使用示例**:
```javascript
// 格式1: 完整日期

// => "2026-02-06"

// 格式2: 月-日
DataFormatter.formatDate('20260206', 2)
// => "02-06"

// 格式3: 年份
DataFormatter.formatDate('20260206', 3)
// => "2026"

// 已包含分隔符
DataFormatter.formatDate('2026-02-06', 1)
// => "2026-02-06"
```

## 四、表格渲染实现

### 4.1 FinancialTableParser工具

**位置**: `src/utils/markdown-renderer.js`

#### 4.1.1 解析JSON表格

**函数签名**:
```typescript
static parse(
  content: string
): object | null
```

**参数说明**:
- `content`: JSON格式的表格数据字符串

**返回值**: 解析后的表格对象
```typescript
{
  headers: string[],    // 表头数组
  rows: any[][],        // 数据行数组
  total: number         // 总数
}
```

**解析逻辑**:
```javascript
static parse(content) {
  try {
    const data = JSON.parse(content)

    if (!Array.isArray(data) || data.length === 0) {
      return null
    }

    let headers = []
    let rows = []
    let total = 0

    // 提取总数（最后一行）
    if (data.length > 1) {
      const lastRow = data[data.length - 1]
      if (Array.isArray(lastRow) && lastRow.length >= 2) {
        total = parseInt(lastRow[1]) || 0
      }
    }

    // 解析表头和数据行（最多7行）
    const endIndex = data.length > 7 ? 7 : data.length - 1
    const tableData = data.slice(0, endIndex)

    tableData.forEach((row, index) => {
      if (index === 0) {
        // 第一行是表头
        headers = row.map(cell => {
          if (typeof cell === 'string') {
            return cell.replace(/<br>.*$/, '').trim()
          }
          return String(cell).trim()
        })
      } else {
        // 数据行
        rows.push(row)
      }
    })

    return { headers, rows, total }
  } catch (e) {
    return null
  }
}
```

**使用示例**:
```javascript
const jsonStr = JSON.stringify([
  ["证券名称", "证券代码", "现价", "涨跌幅"],
  ["平安银行", "000001", "12.34", "2.56"],
  ["招商银行", "600036", "35.67", "-1.23"],
  ["", "总数", "2"]
])

const tableData = FinancialTableParser.parse(jsonStr)
// {
//   headers: ["证券名称", "证券代码", "现价", "涨跌幅"],
//   rows: [
//     ["平安银行", "000001", "12.34", "2.56"],
//     ["招商银行", "600036", "35.67", "-1.23"]
//   ],
//   total: 2
// }
```

#### 4.1.2 渲染HTML表格

**函数签名**:
```typescript
static render(
  tableData: object
): string
```

**参数说明**:
- `tableData`: parse()返回的表格对象

**返回值**: HTML字符串

**渲染逻辑**:
```javascript
static render(tableData) {
  if (!tableData || !tableData.headers || !tableData.rows) {
    return ''
  }

  const { headers, rows, total } = tableData

  let html = '<div class="financial-table-container">'

  // 总数提示
  if (total > 0) {
    html += `<div class="table-info">共找到 ${total} 条结果，显示前 ${rows.length} 条</div>`
  }

  html += '<table class="financial-table">'

  // 表头
  html += '<thead><tr>'
  headers.forEach(header => {
    html += `<th>${header}</th>`
  })
  html += '</tr></thead>'

  // 数据行
  html += '<tbody>'
  rows.forEach(row => {
    html += '<tr>'
    row.forEach((cell, index) => {
      const formattedCell = this._formatCell(cell, headers[index])
      html += `<td>${formattedCell}</td>`
    })
    html += '</tr>'
  })
  html += '</tbody>'

  html += '</table></div>'

  return html
}
```

**单元格格式化**:
```javascript
static _formatCell(cell, header) {
  // 检查是否是涨跌幅列
  if (header && (header.includes('涨跌幅') || header.includes('涨幅'))) {
    return DataFormatter.formatChange(cell, null, '%')
  }

  // 检查是否是价格列
  if (header && (header.includes('现价') || header.includes('价格'))) {
    const num = parseFloat(cell)
    if (!isNaN(num)) {
      return num.toFixed(2)
    }
  }

  // 检查是否是大数值列
  if (header && (header.includes('成交额') || header.includes('市值'))) {
    return DataFormatter.formatBigNumber(cell)
  }

  return cell
}
```

**使用示例**:
```javascript
const html = FinancialTableParser.render(tableData)
// <div class="financial-table-container">
//   <div class="table-info">共找到 2 条结果，显示前 2 条</div>
//   <table class="financial-table">
//     <thead>
//       <tr>
//         <th>证券名称</th>
//         <th>证券代码</th>
//         <th>现价</th>
//         <th>涨跌幅</th>
//       </tr>
//     </thead>
//     <tbody>
//       <tr>
//         <td>平安银行</td>
//         <td>000001</td>
//         <td>12.34</td>
//         <td><span class="text-up">2.56%</span></td>
//       </tr>
//       ...
//     </tbody>
//   </table>
// </div>
```

## 七、常见问题

### 7.1 数据格式问题

#### 问题1: JSON解析失败

**错误信息**: `Unexpected token...`

**原因**:
- JSON格式错误
- 单引号代替双引号
- 缺少逗号或括号

**解决**:
```javascript
// ❌ 错误
{ 'name': 'value' }

// ✅ 正确
{ "name": "value" }
```

#### 问题2: 表格列数不一致

**错误信息**: 表格渲染错位

**原因**: 数据行列数与表头不匹配

**解决**:
```javascript
// ❌ 错误: 表头4列，数据行3列
["证券名称", "证券代码", "现价", "涨跌幅"]
["平安银行", "000001", "12.34"]

// ✅ 正确: 列数一致
["证券名称", "证券代码", "现价", "涨跌幅"]
["平安银行", "000001", "12.34", "2.56"]
```

### 7.2 格式化问题

#### 问题3: 涨跌幅颜色不正确

**原因**: 数值包含非数字字符

**解决**:
```javascript
// ❌ 错误: 包含百分号
DataFormatter.formatChange('2.56%', null, '%')

// ✅ 正确: 不包含百分号
DataFormatter.formatChange('2.56', null, '%')
```

#### 问题4: 大数值转换不准确

**原因**: 数值精度丢失

**解决**:
```javascript
// 使用字符串避免精度丢失
DataFormatter.formatBigNumber('123456789', 2)  // ✅
DataFormatter.formatBigNumber(123456789, 2)     // ⚠️ 可能有精度问题
```

## 八、性能优化

### 8.1 渲染优化

**建议**:
1. 限制显示行数（如前7行）
2. 提供"查看更多"功能
3. 分页显示大数据集

**实现**:
```javascript
const endIndex = data.length > 7 ? 7 : data.length - 1
const tableData = data.slice(0, endIndex)
```

### 8.2 缓存策略

**建议**:
1. 缓存格式化结果
2. 避免重复解析相同数据
3. 使用LRU缓存

**实现**:
```javascript
const cache = new Map()

function formatWithCache(value) {
  if (cache.has(value)) {
    return cache.get(value)
  }

  const result = DataFormatter.formatBigNumber(value)
  cache.set(value, result)
  return result
}
```
