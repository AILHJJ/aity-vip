## 🐛 问题1: H5登录401错误

### 问题描述
```
POST https://aity88.online:8443/api/auth/login
Status: 401 Unauthorized
Data: { code: 401, message: "Invalid credentials" }
```

### 原因分析
登录时使用的是 **username** 字段，但后端需要的是完整的 **email** 地址。

### 解决方案
使用完整的邮箱地址登录，而不是用户名。

### ✅ 正确的登录方式

| 测试账号 | 邮箱 | 密码 | 角色 |
|---------|------|------|------|
| 超级管理员 | admin@example.com | 123456 | super_admin |
| 管理员 | subadmin@example.com | 123456 | admin |
| VIP中线用户 | vip_mid@example.com | 123456 | vip_mid |
| **VIP短线用户** | **vip_short@example.com** | **123456** | **vip_short** |
| VIP测试账号 | vip_test@example.com | 123456 | vip_mid |
| 体验用户 | trial@example.com | 123456 | trial |

### 📝 登录示例

#### 错误方式 ❌
```javascript
{
  username: "vip_short",  // 错误：后端不识别用户名
  password: "123456",
  rememberMe: false
}
```

#### 正确方式 ✅
```javascript
{
  username: "vip_short@example.com",  // 正确：使用完整邮箱
  password: "123456",
  rememberMe: false
}
```

### 在H5页面登录
1. 打开 http://localhost:5173
2. 在登录页面输入：
   - **邮箱/账号**: `vip_short@example.com`（完整邮箱）
   - **密码**: `123456`
3. 点击登录

## 🐛 问题2: 微信小程序tabBar图标未找到

### 问题描述
```
app.json: ["tabBar"]["list"][0]["iconPath"]: "static/tabbar/message.png" 未找到
["tabBar"]["list"][1]["iconPath"]: "static/tabbar/discussion.png" 未找到
["tabBar"]["list"][2]["iconPath"]: "static/tabbar/ai-advisor.png" 未找到
["tabBar"]["list"][3]["iconPath"]: "static/tabbar/profile.png" 未找到
```

### 原因分析
项目中缺少 tabBar 图标文件。uni-app需要81px * 81px的图标文件。

### 解决方案
移除图标配置，使用纯文字tabBar（开发阶段临时方案）。

### ✅ 修复内容

**修改文件**: `src/pages.json`

```json
// 修改前（带图标）
"tabBar": {
  "color": "#7A7E83",
  "selectedColor": "#007AFF",
  "borderStyle": "black",
  "backgroundColor": "#F8F8F8",
  "list": [
    {
      "pagePath": "pages/messages/messages",
      "text": "消息",
      "iconPath": "static/tabbar/message.png",           // ❌ 文件不存在
      "selectedIconPath": "static/tabbar/message-active.png"
    },
    ...
  ]
}

// 修改后（纯文字）
"tabBar": {
  "color": "#7A7E83",
  "selectedColor": "#667eea",  // 修改为项目主题色
  "borderStyle": "black",
  "backgroundColor": "#F8F8F8",
  "list": [
    {
      "pagePath": "pages/messages/messages",
      "text": "消息"  // ✅ 纯文字，无图标
    },
    {
      "pagePath": "pages/discussions/discussions",
      "text": "讨论"
    },
    {
      "pagePath": "pages/ai-advisor/ai-advisor",
      "text": "AI投顾"
    },
    {
      "pagePath": "pages/profile/profile",
      "text": "我的"
    }
  ]
}
```

### 📱 如何重新编译小程序

```bash
cd aity-uni-app-v2
npm run build:mp-weixin
```

编译完成后，用微信开发者工具打开 `dist/build/mp-weixin/` 目录。

## 🎨 后续优化：添加tabBar图标

### 方案1: 使用iconfont图标
1. 访问 https://www.iconfont.cn/
2. 搜索并下载以下图标：
   - 消息: chat、message、comment
   - 讨论: forum、conversation
   - AI投顾: robot、ai、assistant

3. 转换为81px * 81px的PNG文件
4. 放入 `src/static/tabbar/` 目录
5. 修改 `pages.json` 添加图标路径

### 方案2: 使用在线生成工具
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

提供以下规范给设计师：
- 尺寸: 81px * 81px
- 格式: PNG（透明背景）
- 颜色: 灰色（未选中）+ 主题色（选中）
- 风格: 扁平化、线性图标
