## 工具栏功能说明

| 按钮 | 图标 | 功能 | Markdown | 快捷键 |
|------|------|------|----------|--------|
| 粗体 | **B** | 加粗文本 | `**text**` | Ctrl+B |
| 斜体 | *I* | 倾斜文本 | `*text*` | Ctrl+I |
| 标题 | H | 插入标题 | `# 标题` | Ctrl+H |
| 列表 | ≡ | 插入列表 | `- 项目` | Ctrl+L |
| 代码 | </> | 插入代码 | `` `code` `` | Ctrl+K |
| 链接 | 🔗 | 插入链接 | `[text](url)` | Ctrl+U |
| 引用 | " | 插入引用 | `> text` | Ctrl+Q |

## 支持的 Markdown 语法

### 1. 标题
```markdown
# 一级标题
## 二级标题
### 三级标题
```

**效果**:
<div style="font-size: 24px; font-weight: bold; border-bottom: 2px solid #ccc; padding-bottom: 8px;">一级标题</div>
<div style="font-size: 20px; font-weight: bold; margin-top: 16px;">二级标题</div>
<div style="font-size: 18px; font-weight: bold; margin-top: 12px;">三级标题</div>

---

### 2. 文本格式
```markdown
**粗体文本**
*斜体文本*
***粗斜体文本***
```

**效果**:
- **粗体文本**
- *斜体文本*
- ***粗斜体文本***

---

### 3. 代码
```markdown
行内代码：`const a = 1`

代码块：
```
function hello() {
  console.log('Hello');
}
```
```

**效果**:
- 行内代码：`const a = 1`（红色文字，灰色背景）
- 代码块：深色背景，白色文字，等宽字体

---

### 4. 引用
```markdown
> 这是一段引用文本
> 可以有多行
```

**效果**:
<div style="border-left: 4px solid #667eea; padding-left: 12px; background: #f9f9f9; color: #666;">这是一段引用文本<br>可以有多行</div>

---

### 5. 列表
```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

**效果**:
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2

---

### 6. 链接
```markdown
[链接文本](https://example.com)
```

**效果**:
<a href="https://example.com" style="color: #667eea; text-decoration: underline;">链接文本</a>

## 实际应用场景

**实施前**:

```
预测看好后续走势。风险提示：投资有风险
```

```markdown
# 市场分析报告

本周市场表现**良好**，主要指标如下：

> 风险提示：投资有风险
```
