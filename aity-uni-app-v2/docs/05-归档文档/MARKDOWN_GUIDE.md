# Markdown 编辑器使用指南

## 功能概述

VIP投研内部分享系统现已支持 Markdown 富文本编辑功能，让消息内容更加丰富多彩！

## 主要功能

### 1. 编辑/预览模式切换
- **编辑模式**：输入原始 Markdown 文本
- **预览模式**：实时查看渲染效果

### 2. 工具栏快捷操作

编辑模式顶部提供工具栏，包含以下快捷按钮：

| 按钮 | 功能 | Markdown 语法 | 示例 |
|------|------|--------------|------|
| **B** | 粗体 | `**text**` | **重要内容** |
| **I** | 斜体 | `*text*` | *强调内容* |
| **H** | 标题 | `# 标题` | # 一级标题 |
| **≡** | 列表 | `- 项目` | - 列表项 |
| **</>** | 代码 | `` `code` `` | `代码` |
| **🔗** | 链接 | `[文本](url)` | [链接](url) |
| **"** | 引用 | `> 文本` | > 引用内容 |

## 支持的 Markdown 语法

### 标题
```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本格式
```markdown
**粗体文本**
*斜体文本*
***粗斜体文本***
```

### 列表
```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

### 代码
```markdown
行内代码：`const a = 1`

代码块：
```
function hello() {
  console.log('Hello World');
}
```
```

### 引用
```markdown
> 这是一段引用文本
> 可以有多行
```

### 链接
```markdown
[链接文本](https://example.com)
```

## 使用技巧

1. **快速插入格式**：在编辑模式下，将光标定位到想要插入格式的位置，点击工具栏按钮即可插入对应的 Markdown 语法

2. **实时预览**：点击"预览"按钮查看渲染效果，随时切换回"编辑"模式继续修改

3. **草稿自动保存**：编辑内容会自动保存为草稿，不用担心丢失

4. **混合使用**：可以同时使用多种格式，创建富文本文档

## 示例内容

### 投研报告示例
```markdown
# 2024年市场分析报告

## 市场概况

> 根据最新数据，市场呈现稳步增长趋势

**关键数据**：
- 市场规模：`1000亿元`
- 增长率：*15%*
- 预测：明年达到 `1200亿元`

## 技术分析

代码示例：
```javascript
const growthRate = 0.15;
const prediction = marketSize * (1 + growthRate);
```

[查看详细报告](https://example.com/full-report)
```

## 注意事项

1. 字符限制：最大支持 5000 个字符
2. 代码块使用三个反引号（```）包裹
3. 链接格式：`[显示文本](URL地址)`
4. 在小程序环境中，预览效果可能与 H5 略有差异

## 技术实现

- 纯前端实现，无需额外依赖
- 轻量级 Markdown 解析器
- 兼容 uni-app 多端运行
- 优化的样式渲染
