### Markdown 富文本编辑器

为消息创建页面添加了完整的 Markdown 支持功能：

#### 🎨 核心特性
1. **编辑/预览双模式**
   - 编辑模式：输入原始 Markdown 文本
   - 预览模式：实时查看渲染效果
   - 无缝切换，响应迅速

2. **可视化工具栏**
   - 7个快捷格式按钮
   - 一键插入常用 Markdown 语法
   - 直观的图标和标签

3. **实时渲染**
   - 基于 Vue 3 computed 的响应式渲染
   - 内容变化自动更新预览
   - 性能优化，流畅体验

4. **精美样式**
   - 专业的排版设计
   - 代码块、引用、列表等元素美化
   - 符合现代设计规范

#### 📝 支持的 Markdown 语法

| 语法 | 示例 | 渲染效果 |
|------|------|----------|
| 标题 | `# 标题` | 大号字体，下划线 |
| 粗体 | `**text**` | **加粗显示** |
| 斜体 | `*text*` | *倾斜显示* |
| 行内代码 | `` `code` `` | `红色文字，灰色背景` |
| 代码块 | ```code``` | 深色背景，等宽字体 |
| 引用 | `> text` | 左侧蓝线，浅灰背景 |
| 无序列表 | `- item` | 圆点标记 |
| 有序列表 | `1. item` | 数字编号 |
| 链接 | `[text](url)` | 紫蓝色下划线 |

## 🔧 核心代码

### Markdown 解析器
```javascript
const parseMarkdown = (text) => {
  if (!text) return ''

  let html = text
    // 转义HTML特殊字符（安全）
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')

    // 代码块
    .replace(/```(\w*)([\s\S]*?)```/g, (match, lang, code) => {
      return `<pre><code class="code-block">${code.trim()}</code></pre>`
    })

    // 标题、粗体、斜体、引用、列表、链接等
    // ... 省略详细代码

  return html
}
```

## 🔍 已知限制

1. **光标位置**
   - 小程序环境无法精确获取光标位置
   - 格式默认插入到文本末尾
   - **影响**: 轻微
   - **解决方案**: 用户手动调整位置

2. **选中文本**
   - 小程序无法获取选中文本
   - 无法实现"选中后包裹"功能
   - **影响**: 轻微
   - **解决方案**: 插入后手动输入

3. **高级语法**
   - 暂不支持表格、任务列表等
   - **影响**: 轻微
   - **解决方案**: 后续版本扩展
