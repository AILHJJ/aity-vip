## 🎨 UI/UX重新设计亮点

### 1. 消息筛选栏重新设计

#### 新增组件
- **message-filter-bar.vue**: 新的消息筛选栏组件
  - 快速筛选组合（今天早盘、今天全部、本周全部、我的收藏）
  - 渐进式披露设计（默认收起）
  - 筛选历史（自动保存最近5次）
  - 实时反馈（显示筛选结果数量）

#### 优化现有组件
- **filter-bar.vue**: 推送范围筛选（仅管理员）
  - 明确为"推送范围"而非"策略类型"
  - 保持简洁的chip选择界面
  - 仅管理员可见

#### 分离设计
```
基础筛选（所有人可见）
├── 时间筛选：全部、今天、近一周、近一月、自定义
└── 消息类型筛选：全部、盘前、早盘、午盘、尾盘等

推送范围筛选（仅管理员）
└── 推送范围：全部、短线VIP、中线VIP、全部用户
```

### 2. 用户体验提升

#### 空间节省
- 原设计：筛选栏占用300-400rpx
- 新设计：收起状态仅100rpx
- **节省75%空间**

#### 交互优化
- 快速筛选：一键应用常用组合
- 筛选历史：快速恢复之前的筛选
- 实时反馈：立即显示筛选结果
- 响应式布局：适配不同屏幕

#### 视觉设计
- 渐变色主题
- 图标+文字组合
- 流畅的动画过渡
- 清晰的视觉层级

### 3. 管理员功能

#### 发布消息流程优化
- 推送范围筛选独立管理
- 清晰的推送对象标识
- 快速切换不同推送范围
