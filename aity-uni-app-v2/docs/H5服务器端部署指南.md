## 🚀 方案1: 在服务器上直接编译（推荐）

### 步骤1: 进入前端项目目录
```bash
cd /tmp/AITY/aity-uni-app-v2
```

### 步骤2: 安装依赖（首次需要）
```bash
npm install
```

### 步骤3: 编译H5生产版本
```bash
npm run build:h5
```

### 步骤4: 部署到Web目录
```bash
# 备份旧版本（如果存在）
if [ -d /var/www/html/h5 ]; then
  cp -r /var/www/html/h5 /var/www/html/h5-backup-$(date +%Y%m%d)
fi

# 创建目录
mkdir -p /var/www/html/h5

# 复制编译产物
cp -r dist/build/h5/* /var/www/html/h5/

# 设置权限
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5
```

### 步骤5: 验证部署
```bash
ls -la /var/www/html/h5/
```

应该看到 `index.html` 和 `assets/` 目录

### 步骤6: 访问测试
在浏览器访问: `http://111.48.74.245/h5/`

## 🚀 方案2: 使用自动化脚本

### 在服务器上创建并执行脚本:
```bash
# 创建脚本
cat > /tmp/AITY/aity-uni-app-v2/deploy-h5.sh << 'EOF'
#!/bin/bash
echo "开始部署H5..."
cd /tmp/AITY/aity-uni-app-v2

mkdir -p /var/www/html/h5
cp -r dist/build/h5/* /var/www/html/h5/
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5
echo "部署完成！访问: http://111.48.74.245/h5/"
EOF

# 添加执行权限
chmod +x /tmp/AITY/aity-uni-app-v2/deploy-h5.sh

# 执行部署
/tmp/AITY/aity-uni-app-v2/deploy-h5.sh
```

## 🚀 方案3: 从本地上传（如果本地已编译）

### Windows本地执行:
```powershell
# 在Windows本地PowerShell中执行
cd D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\build
Compress-Archive -Path h5\* -DestinationPath h5-build.zip

# 上传到服务器
scp h5-build.zip root@111.48.74.245:/tmp/
```

### 服务器上执行:
```bash
# 解压并部署
cd /var/www/html/
mkdir -p h5
unzip -o /tmp/h5-build.zip -d h5
chown -R www-data:www-data h5
chmod -R 755 h5
```

