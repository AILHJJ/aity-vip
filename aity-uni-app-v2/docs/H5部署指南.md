## 🚀 部署步骤

### 方式1: 使用SCP直接上传（推荐用于初次部署）

#### Windows系统（使用PowerShell）
```powershell
# 1. 压缩H5编译产物
cd aity-uni-app-v2\dist\build
Compress-Archive -Path h5\* -DestinationPath h5-build.zip

# 2. 上传到服务器
scp h5-build.zip root@111.48.74.245:/tmp/

# 3. SSH登录服务器
ssh root@111.48.74.245

# 4. 在服务器上解压并部署
cd /var/www/html/
# 备份旧版本（如果存在）
cp -r h5 h5-backup-$(date +%Y%m%d)
# 解压新版本
unzip -o /tmp/h5-build.zip -d h5
# 设置权限
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5
```

#### Linux/Mac系统
```bash
# 1. 压缩H5编译产物
cd aity-uni-app-v2/dist/build
tar -czf h5-build.tar.gz h5/

# 2. 上传到服务器
scp h5-build.tar.gz root@111.48.74.245:/tmp/

# 3. SSH登录服务器
ssh root@111.48.74.245

# 4. 在服务器上解压并部署
cd /var/www/html/
# 备份旧版本
cp -r h5 h5-backup-$(date +%Y%m%d)
# 解压新版本
tar -xzf /tmp/h5-build.tar.gz -C ./
# 设置权限
chown -R www-data:www-data /var/www/html/h5
chmod -R 755 /var/www/html/h5
```

### 方式2: 使用Git自动化部署脚本

创建部署脚本 `scripts/deploy-h5.sh`:

```bash
#!/bin/bash
# H5自动部署脚本

# 配置
SERVER_IP="111.48.74.245"
SERVER_USER="root"
DEPLOY_PATH="/var/www/html/h5"
LOCAL_BUILD_PATH="aity-uni-app-v2/dist/build/h5"

echo "=== 开始部署H5到腾讯云 ==="

# 1. 编译H5
echo "步骤1: 编译H5..."
cd aity-uni-app-v2
npm run build:h5
if [ $? -ne 0 ]; then
  echo "❌ 编译失败"
  exit 1
fi
echo "✅ 编译成功"

# 2. 备份服务器上的旧版本
echo "步骤2: 备份服务器上的旧版本..."
ssh ${SERVER_USER}@${SERVER_IP} "
  if [ -d ${DEPLOY_PATH} ]; then
    cp -r ${DEPLOY_PATH} ${DEPLOY_PATH}-backup-\$(date +%Y%m%d-%H%M%S)
    echo '✅ 备份完成'
  else
    echo '⚠️  首次部署，无需备份'
    mkdir -p ${DEPLOY_PATH}
  fi
"

# 3. 上传新版本
echo "步骤3: 上传新版本..."
rsync -avz --delete \
  ${LOCAL_BUILD_PATH}/ \
  ${SERVER_USER}@${SERVER_IP}:${DEPLOY_PATH}/

if [ $? -eq 0 ]; then
  echo "✅ 上传成功"
else
  echo "❌ 上传失败"
  exit 1
fi

# 4. 设置权限
echo "步骤4: 设置权限..."
ssh ${SERVER_USER}@${SERVER_IP} "
  chown -R www-data:www-data ${DEPLOY_PATH}
  chmod -R 755 ${DEPLOY_PATH}
  echo '✅ 权限设置完成'
"

echo "=== 部署完成 ==="
echo "访问地址: http://${SERVER_IP}/h5/"
```

使用脚本:
```bash
chmod +x scripts/deploy-h5.sh
./scripts/deploy-h5.sh
```

## 🔧 Nginx配置

### 配置文件位置
`/etc/nginx/sites-available/aity-h5`

### 推荐配置
```nginx
server {
    listen 80;
    server_name 111.48.74.245;

    # H5应用
    location /h5/ {
        alias /var/www/html/h5/;
        index index.html;
        try_files $uri $uri/ /h5/index.html;

        # 缓存配置
        expires 7d;
        add_header Cache-Control "public, immutable";

        # Gzip压缩
        gzip on;
        gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    }

    # API代理（如果需要）
    location /api/ {
        proxy_pass https://aity88.online:8443/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 重启Nginx
```bash
# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
# 或
sudo service nginx restart
```

## 🐛 常见问题

### 问题1: 404 Not Found
**原因**: Nginx配置错误或文件路径错误

**解决**:
```bash
# 检查Nginx配置
sudo cat /etc/nginx/sites-available/aity-h5

# 检查文件是否存在
ls -la /var/www/html/h5/index.html

# 重启Nginx
sudo systemctl restart nginx
```

### 问题2: API请求失败
**原因**: 跨域问题或API地址错误

**解决**:
1. 检查`.env`配置文件中的API地址
2. 确保后端服务器正常运行
3. 检查Nginx API代理配置

### 问题3: 页面空白
**原因**: JavaScript错误或资源加载失败

**解决**:
1. 打开浏览器控制台查看错误
2. 检查`assets/`目录是否完整
3. 检查`index.html`中的资源路径

### 问题4: 权限问题
**原因**: 文件权限不正确

**解决**:
```bash
sudo chown -R www-data:www-data /var/www/html/h5
sudo chmod -R 755 /var/www/html/h5
```
