### 部署脚本

| 脚本 | 功能 | 使用频率 |
|------|------|---------|
| `scripts/full-deploy.bat` | 方案1：完整部署 | ⭐⭐⭐⭐⭐ |
| `scripts/deploy-backend.bat` | 仅更新后端 | ⭐⭐⭐⭐ |
| `scripts/upload-h5-to-server.bat` | 仅更新前端 | ⭐⭐⭐ |
| `scripts/deploy-server-build.bat` | 方案3：服务器端编译 | ⭐⭐⭐⭐ |

### 决策流程

```
需要部署？
  ↓
SSH可用？
  ├─ 否 → 方案2（Git提交编译产物）
  └─ 是 ↓
      仅后端？
      ├─ 是 → deploy-backend.bat
      ├─ 否 ↓
      仅前端？
      ├─ 是 → upload-h5-to-server.bat
      └─ 否 ↓
          服务器有Node.js？
          ├─ 是 → 方案1或方案3
          └─ 否 → 方案1（默认）
```
