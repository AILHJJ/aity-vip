## 💡 文档使用建议

1. **新成员入职**
   - 先读 [项目README](../README.md) 了解整体
   - 再读对应角色的文档（见上方"按角色查阅"）

2. **功能开发**
   - 查阅 [需求文档](./需求文档.md) 理解业务

   - 遵循 [开发指南](./开发指南.md) 编写代码

3. **问题排查**
   - 先查 [问题追踪](./问题追踪.md) 是否已知问题
   - 再查 [开发指南](./开发指南.md) 调试技巧

4. **版本发布**
   - 查看 [更新日志](./更新日志-v1.1.0.md) 了解变更
   - 执行测试验证
   - 按部署流程发布
