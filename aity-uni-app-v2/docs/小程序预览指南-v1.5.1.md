## 🐛 常见问题排查

### 问题1: 网络请求失败

**症状**: 所有接口请求失败，控制台显示 `request:fail`

**排查步骤**:
```bash
# 1. 检查后端服务是否运行
cd D:\your-mcp-proxy\AITY_VIP\backend
npm status  # 查看是否在运行

# 2. 检查端口占用
netstat -ano | findstr :3001

# 3. 测试后端连接
curl http://192.168.2.140:3001/api/health

# 4. 微信开发者工具设置
- 确保"不校验合法域名"已勾选
- 检查网络连接
```

**解决方案**:
```bash
# 启动后端服务
cd D:\your-mcp-proxy\AITY_VIP\backend
npm start

# 或使用PM2
pm2 start server.js --name aity-vip-backend
pm2 status
```

### 问题4: 图片上传失败

**症状**: 选择图片后上传失败

**排查步骤**:
```bash
# 1. 检查图片大小
# 确保图片小于 10MB

# 2. 检查后端上传目录
cd D:\your-mcp-proxy\AITY_VIP\backend
ls -la uploads/  # 查看目录是否存在
mkdir -p uploads  # 如不存在则创建

# 3. 查看错误信息
# 在控制台查看详细错误
```

**解决方案**:
```bash
# 创建上传目录
cd D:\your-mcp-proxy\AITY_VIP\backend
mkdir -p uploads
chmod 755 uploads

# 检查Multer配置
# server.js 中确保配置正确
```

### 问题5: 标签样式显示异常

**症状**: 消息标签颜色不对或图标不显示

**排查步骤**:
```scss
// 1. 检查tokens.scss是否引入
// src/pages/messages/messages.vue
@import "@/styles/tokens.scss";

// 2. 检查getTagClass函数
// 确保返回正确的类名

// 3. 检查CSS样式
// 在开发者工具查看元素的computed样式
```

**解决方案**:
```vue
<!-- 确保模板正确 -->
<view class="message-tag" :class="getTagClass(tag)">
  <text class="tag-icon">{{ getTagIcon(tag) }}</text>
  <text class="tag-text">{{ getTagLabel(tag) }}</text>
</view>
```

## 🚀 部署流程

### 1. 构建生产版本

```bash
cd D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2
npm run build:mp-weixin
```

### 2. 上传到微信服务器

```bash
npm run upload:weixin
```

或在微信开发者工具中：
1. 点击"上传"按钮
2. 填写版本号: `1.5.1`
3. 填写描述: `正式发布版本 - UI全面优化`

### 3. 提交审核

1. 登录微信公众平台: https://mp.weixin.qq.com
2. 进入"版本管理"
3. 将开发版本提交审核
4. 填写审核信息:
   ```
   版本号: 1.5.1
   版本描述: 正式发布版本 - UI全面优化，建立设计系统，优化用户体验
   ```

### 4. 等待审核

- 审核时长: 1-7个工作日
- 审核状态查询: 微信公众平台

### 5. 发布上线

审核通过后：
1. 在微信公众平台点击"发布"
2. 全量发布或灰度发布
3. 用户即可在微信搜索到小程序
