# 行情页面UI优化 - 快速应用补丁

## ⚡ 快速应用（推荐方式）

### 方式1: 直接引入优化样式（最简单）

在 `src/pages/market/market.vue` 的 `<style>` 标签最前面添加：

```vue
<style lang="scss" scoped>
/* ========== 引入优化样式 ========== */
@import '@/styles/market-optimized.scss';

/* ========== 以下是原有样式，会被优化样式覆盖 ========== */
.market-page {
  min-height: 100vh;
  background: var(--bg-primary);
  color: var(--text-primary);
}

// ... 其他原有样式 ...
</style>
```

## 📝 需要修改的HTML结构

在 `market.vue` 中，需要为统计卡片添加class：

```vue
<!-- 修改前 -->
<view class="stat-card">
  <text class="stat-value up">{{ marketData.upCount }}</text>
  <text class="stat-label">上涨</text>
</view>

<!-- 修改后：为上涨卡片添加 stat-up class -->
<view class="stat-card stat-up">
  <text class="stat-value up">{{ marketData.upCount }}</text>
  <text class="stat-label">上涨</text>
</view>

<!-- 修改后：为下跌卡片添加 stat-down class -->
<view class="stat-card stat-down">
  <text class="stat-value down">{{ marketData.downCount }}</text>
  <text class="stat-label">下跌</text>
</view>
```

## ✅ 验证清单

应用优化后，请检查：

- [ ] 页面背景与卡片背景有明显区分
- [ ] 涨跌数据有淡色背景强化
- [ ] Tab切换时有背景色变化
- [ ] 点击卡片时有缩放反馈
- [ ] 市场情绪卡片有动态背景效果
- [ ] 指数卡片顶部有彩色指示条

## 🎯 最小改动方案

如果你只想做最小改动来改善可读性，至少要应用这三个：

1. **统计卡片背景**（区分上涨/下跌）
2. **Tab切换背景**（显示当前选中）
3. **加深边框颜色**（从1rpx改为2rpx，颜色加深）

这样就能立即改善用户的视觉体验！
