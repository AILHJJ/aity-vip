# 消息列表优化需求文档 v1.0

**文档版本**: v1.0
**创建日期**: 2026-02-06
**优先级**: P0 (核心功能)
**状态**: 进行中

## 1. 需求背景

当前消息列表存在以下问题需要优化：
1. 消息卡片标签显示过于复杂，包含"全部用户"等非核心业务标签
2. 缺乏智能筛选功能，用户难以快速找到目标消息
3. 消息发布表单用户体验不佳，核心业务标签（策略类型）不够突出
4. 下拉刷新功能存在错误
5. 讨论功能入口混乱，应该从消息详情页发起

## 2. 核心需求

### 2.1 消息卡片标签优化

**当前问题**: 消息卡片显示所有标签，包括"全部用户"等技术性标签

**优化方案**:
- ✅ 只显示策略标签（短线策略/中线策略）
- ✅ 如果没有策略标签，不显示标签区域
- ✅ 移除"全部用户"标签的显示
- ✅ 跨策略消息显示为"短线+中线"

**技术实现**:
```javascript
// 过滤并只显示策略标签
const displayTags = computed(() => {
  if (!message.value.tags) return []
  return message.value.tags.filter(tag =>
    tag === MESSAGE_TAGS.SHORT_TERM ||
    tag === MESSAGE_TAGS.MID_TERM
  )
})
```

**管理员**:
- 看到所有消息

## 6. 技术实现要点

### 6.1 标签显示逻辑

```javascript
// messages.vue
const displayTags = computed(() => {
  if (!message.tags) return []

  // VIP用户：只显示策略标签和类型标签
  if (!userStore.isAdmin) {
    return message.tags.filter(tag =>
      tag === MESSAGE_TAGS.SHORT_TERM ||
      tag === MESSAGE_TAGS.MID_TERM ||
      isTypeTag(tag)  // 类型标签
    )
  }

  // 管理员：显示所有标签（除了技术性标签）
  return message.tags.filter(tag => tag !== 'all_users')
})
```

### 6.2 筛选实现逻辑

```javascript
const filteredMessages = computed(() => {
  let result = messages.value

  // 策略筛选
  if (filters.strategy !== 'all') {
    result = result.filter(msg =>
      msg.tags?.includes(filters.strategy)
    )
  }

  // 类型筛选
  if (filters.type !== 'all') {
    result = result.filter(msg =>
      msg.tags?.includes(filters.type)
    )
  }

  // 时间筛选
  if (filters.timeRange !== 'all') {
    const now = new Date()
    let startDate

    switch (filters.timeRange) {
      case 'today':
        startDate = startOfDay(now)
        break
      case '3days':
        startDate = subDays(now, 3)
        break
      case '7days':
        startDate = subDays(now, 7)
        break
      case '30days':
        startDate = subDays(now, 30)
        break
      case 'custom':
        startDate = new Date(filters.customStartDate)
        break
    }

    result = result.filter(msg => {
      const msgDate = new Date(msg.createdAt)
      return msgDate >= startDate
    })
  }

  return result
})
```

### 6.3 本地存储策略

```javascript
// 保存筛选偏好
const saveFilterPreferences = () => {
  uni.setStorageSync('message_filters', {
    strategy: filters.value.strategy,
    type: filters.value.type,
    timeRange: filters.value.timeRange
  })

// 恢复筛选偏好
const loadFilterPreferences = () => {
  const saved = uni.getStorageSync('message_filters')
  if (saved) {
    filters.value = { ...filters.value, ...saved }
  }
}

// 保存上次选择的策略类型

}

// 恢复上次选择的策略类型
const loadLastStrategy = () => {
  return uni.getStorageSync('last_selected_strategy') || MESSAGE_TAGS.SHORT_TERM
}
```
