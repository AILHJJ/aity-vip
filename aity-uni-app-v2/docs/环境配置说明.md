## 🎯 配置原则

### 专业实践 ✅

**统一连接远程服务器**

```
前端本地开发 ──────→ 腾讯云后端服务器 ──────→ 腾讯云数据库
     ↓                              ↓
  H5浏览器                    https://aity88.online:8443
  微信开发者工具
```

**优势**:
- ✅ 数据一致性：所有人看到相同的数据
- ✅ 环境一致：开发和生产环境相同
- ✅ 多人协作：团队开发不会冲突
- ✅ 实时测试：立即看到真实效果
- ✅ 减少bug：避免环境差异导致的问题

### 不推荐的做法 ❌

**本地运行后端**

```
前端本地开发 ──────→ 本地后端 ──────→ 远程数据库
     ↓              ↓
  H5浏览器      http://localhost:3001
```

**劣势**:
- ❌ 数据不同步：本地和远程数据可能不一致
- ❌ 环境差异：本地环境和生产环境不同
- ❌ 协作困难：多人开发时数据冲突
- ❌ 测试不准：本地测试通过，远程可能失败

## 🔄 环境切换

### 方式1: 修改配置文件（推荐）

**文件**: `src/utils/config.js`

```javascript
// 第65行，修改此变量
const useLocalBackend = false // ⚠️ 改为 true 可切换到本地后端
```

| 值 | 说明 | 适用场景 |
|---|---|---|
| `false` | 连接远程服务器（推荐） | 日常开发、团队协作 |
| `true` | 连接本地后端 | 后端调试、离线开发 |

### 方式2: 不同环境对比

#### 远程服务器模式（默认）

```javascript
useLocalBackend = false

// H5浏览器
http://localhost:5173
  ↓
https://aity88.online:8443/api

// 微信小程序
直接请求
  ↓
https://aity88.online:8443/api
```

**配置**:
- API地址: `https://aity88.online:8443/api`
- 需要网络: ✅
- 数据同步: ✅

#### 本地后端模式（特殊调试用）

```javascript
useLocalBackend = true

// H5浏览器
http://localhost:5173
  ↓
http://localhost:3001/api (通过Vite proxy)

// 微信小程序
直接请求
  ↓
http://localhost:3001/api
```

**配置**:
- API地址: `http://localhost:3001/api`
- 需要网络: ❌（但需要连接远程数据库）
- 数据同步: ❌

## 🔧 开发环境设置

### H5开发（浏览器）

1. **启动H5开发服务器**
   ```bash
   npm run dev:h5
   ```

2. **访问地址**
   ```
   http://localhost:5173
   ```

3. **配置说明**
   - 使用远程模式：直接访问 `https://aity88.online:8443/api`
   - 使用本地模式：通过Vite proxy转发到 `http://localhost:3001`

### 微信小程序开发

1. **启动小程序编译**
   ```bash
   npm run dev:mp-weixin
   ```

2. **微信开发者工具设置**
   ```
   导入路径: dist/dev/mp-weixin
   AppID: 你的小程序AppID
   不校验合法域名: ✅ 开启（仅开发时）
   ```

3. **配置说明**
   - 使用远程模式：请求 `https://aity88.online:8443/api`
   - 使用本地模式：请求 `http://localhost:3001/api`（需要关闭域名校验）

### 微信小程序生产（正式发布）

1. **编译生产版本**
   ```bash
   npm run build:mp-weixin
   ```

2. **配置说明**
   - 固定使用远程模式：`https://aity88.online:8443/api`
   - 与开发模式保持一致

## ❓ 常见问题

### Q1: 什么时候应该使用本地后端？

**A**: 仅在以下特殊场景：
- 后端代码调试
- 需要频繁修改后端逻辑
- 网络不稳定，无法访问远程服务器
- 完全离线开发（但仍需连接远程数据库）

**日常开发建议使用远程模式**

### Q2: 本地后端连接的是哪个数据库？

**A**: 无论本地还是远程后端，**都连接同一个远程数据库**：

```
数据库地址: 124.221.119.134:3306
数据库名称: 投研图灵室_test
```

这样可以确保数据一致性，但本地后端的代码可能与远程不同。

### Q3: 微信小程序请求本地后端失败？

**A**: 检查以下几点：
1. ✅ 微信开发者工具中开启"不校验合法域名"
2. ✅ 后端服务正在运行（`npm run start`）
3. ✅ 后端CORS配置包含本地地址
4. ✅ 本地后端运行在 `http://localhost:3001`

### Q4: 为什么H5开发时有两种API地址？

**A**: 这是Vite proxy的作用：

```
远程模式（推荐）:
浏览器 → https://aity88.online:8443/api

本地模式（调试用）:
浏览器 → /api → Vite proxy → http://localhost:3001/api
```

本地模式的好处是可以调试后端代码，且避免CORS问题。

### Q5: 如何验证当前连接的是哪个后端？

**A**: 查看浏览器控制台的网络请求：

```
远程后端:
Request URL: https://aity88.online:8443/api/auth/login

本地后端:
Request URL: http://localhost:3001/api/auth/login
或
Request URL: http://localhost:5173/api/auth/login (通过proxy)
```

### Q6: 生产环境如何配置？

**A**: 生产环境固定使用远程服务器：

```javascript
useLocalBackend = false // 生产环境必须为false
```

无论H5还是小程序，生产版本都连接：
```
https://aity88.online:8443/api
```
