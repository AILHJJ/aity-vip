# 统计页面图表增强功能说明

**更新日期**: 2026-02-03
**功能模块**: 数据统计页面
**文件路径**: `src/pages/stats/stats.vue`

---

## 📋 功能概述

在原有统计页面的基础上，新增了两个重要的数据可视化图表：

1. **用户角色分布饼图** - 直观展示各类用户的占比情况
2. **消息类型分布横向柱状图** - 展示10种消息类型的数量分布

这些增强功能帮助管理员更好地了解用户构成和内容分布情况。

## 🎯 新增功能详解

### 1. 用户角色分布饼图

#### 功能说明
- 使用纯CSS `conic-gradient` 实现饼图效果
- 展示5种用户角色的占比分布
- 环形图设计（中心镂空），更现代美观
- 包含详细图例，显示角色名称、数量和百分比

#### 颜色方案
```javascript

  admin: { start: '#4facfe', end: '#00f2fe' },        // 蓝色系 - 管理员
  vip_mid: { start: '#43e97b', end: '#38f9d7' },      // 绿色系 - VIP中线
  vip_short: { start: '#ff9a56', end: '#ff6a88' },    // 橙色系 - VIP短线
  trial: { start: '#bdc3c7', end: '#95a5a6' }         // 灰色系 - 体验用户
}
```

#### 数据结构
```javascript

  super_admin: 2,   // 超级管理员数量

  vip_mid: 30,      // VIP中线用户数量
```

#### 样式特点
- **饼图尺寸**: 400rpx × 400rpx

- **阴影效果**: `box-shadow: 0 4rpx 16rpx rgba(0, 0, 0, 0.1)`
- **图例间距**: 16rpx
- **交互效果**: 点击图例项有缩放反馈

## 🔧 技术实现

### API新增

在 `src/api/stats.js` 中新增两个API接口：

```javascript
/**
 * 获取用户角色分布
 * @returns {Promise}
 */
export function getUserRoleDistributionApi() {
  return get('/stats/user-role-distribution')
}

/**
 * 获取消息类型分布
 * @returns {Promise}
 */
export function getMessageTypeDistributionApi() {
  return get('/stats/message-type-distribution')
}
```

### 数据处理

#### 用户角色分布计算
```javascript
const userRoleDistributionArray = computed(() => {
  const distribution = []
  const total = Object.values(userRoleDistribution.value).reduce((sum, val) => sum + val, 0) || 1

  let currentPercent = 0
  Object.entries(userRoleDistribution.value).forEach(([role, count]) => {
    const percent = (count / total) * 100
    distribution.push({
      role,
      label: USER_ROLE_LABELS[role] || role,
      count,
      percent,
      startPercent: currentPercent,
      endPercent: currentPercent + percent,
      color: roleColors[role] || { start: '#cccccc', end: '#cccccc' }
    })
    currentPercent += percent
  })

  return distribution
})
```

#### 消息类型分布计算
```javascript
const messageTypeDistributionArray = computed(() => {
  const distribution = []
  const total = Object.values(messageTypeDistribution.value).reduce((sum, val) => sum + val, 0) || 1
  const maxCount = Math.max(...Object.values(messageTypeDistribution.value), 1)

  Object.entries(messageTypeDistribution.value).forEach(([type, count]) => {
    distribution.push({
      type,
      label: MESSAGE_TYPE_LABELS[type] || type,
      count,
      percent: ((count / total) * 100).toFixed(1),
      barWidth: (count / maxCount) * 100
    })
  })

  return distribution.sort((a, b) => b.count - a.count)
})
```


动态生成 conic-gradient:
```javascript
:style="{
  background: userRoleDistributionArray.map(item =>
    `${item.color.start} ${item.startPercent.toFixed(1)}% ${item.endPercent.toFixed(1)}%`
  ).join(', ')
}"
```

## 💡 使用指南

### 数据加载

所有统计数据在页面加载时自动获取：

```javascript
onMounted(() => {
  // 权限检查
  if (!userStore.isAdmin) {
    uni.showToast({ title: '无权限访问', icon: 'none' })
    setTimeout(() => uni.navigateBack(), 1500)
    return
  }

  // 加载所有统计数据
  loadStats()
})
```

### 下拉刷新

支持下拉刷新所有数据：

```javascript
const onRefresh = () => {
  refreshing.value = true
  loadStats()
}
```

### 空数据处理

每个图表都有友好的空状态提示：

```html
<view v-if="userRoleDistributionArray.length === 0" class="empty-state">
  <text class="empty-text">暂无数据</text>
</view>
```

## 📝 注意事项

1. **权限控制**: 统计页面仅管理员可访问
2. **数据缓存**: 当前实现每次都从API获取最新数据
3. **错误处理**: API调用失败时显示Toast提示
4. **加载状态**: 使用loading和refreshing状态管理加载过程
5. **响应式设计**: 所有图表使用rpx单位，确保不同屏幕适配
