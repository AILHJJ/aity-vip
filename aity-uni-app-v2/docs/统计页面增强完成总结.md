## 🎨 图表设计

### 饼图（用户角色分布）

**实现方式**: CSS `conic-gradient`
```scss
.role-pie-chart {
  width: 400rpx;
  height: 400rpx;
  border-radius: 50%;
  // 中心镂空创建环形效果
  &::after {
    width: 200rpx;
    height: 200rpx;
    background: #ffffff;
    border-radius: 50%;
  }
}
```

**动态渐变生成**:
```javascript
:style="{
  background: userRoleDistributionArray.map(item =>
    `${item.color.start} ${item.startPercent.toFixed(1)}% ${item.endPercent.toFixed(1)}%`
  ).join(', ')
}"
```

### 横向柱状图（消息类型分布）

**实现方式**: Flex布局 + CSS transition
```scss
.type-bar-fill {
  height: 100%;
  width: ${item.barWidth}%;  // 动态宽度
  background: ${getMessageTypeColor(item.type)};
  transition: width 0.6s ease-out;
}
```

## 📊 数据流程

### 1. 数据加载

```
onMounted()
  ↓
权限检查 (userStore.isAdmin)
  ↓
loadStats()
  ↓
并行请求6个API:
  ├─ getStatsApi()                    // 基础统计
  ├─ getUserGrowthApi()               // 用户增长
  ├─ getMessageTrendApi()             // 消息趋势
  ├─ getActiveUsersApi()              // 活跃用户
  ├─ getUserRoleDistributionApi()     // 角色分布 [新增]
  └─ getMessageTypeDistributionApi()  // 类型分布 [新增]
  ↓
数据存储到ref
  ↓
computed自动计算衍生数据
  ↓
视图自动更新
```

### 2. 数据计算

#### 用户角色分布计算
```javascript
原始数据: { super_admin: 2, admin: 8, ... }
  ↓
计算总数: 100
  ↓
计算百分比: super_admin = 2/100 = 2%
  ↓
计算渐变范围: 0% → 2%, 2% → 10%, ...
  ↓
分配颜色: 每个角色对应一种渐变色
  ↓
最终数组: [{ role, label, count, percent, startPercent, endPercent, color }, ...]
```

#### 消息类型分布计算
```javascript
原始数据: { pre_market_comment: 50, morning_comment: 80, ... }
  ↓
计算总数: 370
  ↓
计算百分比: pre_market_comment = 50/370 = 13.5%
  ↓
计算最大值: 80
  ↓
计算相对宽度: pre_market_comment = 50/80 = 62.5%
  ↓
排序: 按数量降序
  ↓
最终数组: [{ type, label, count, percent, barWidth }, ...]
```
