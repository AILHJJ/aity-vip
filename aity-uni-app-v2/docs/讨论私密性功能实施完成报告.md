#### 1. 讨论控制器 (discussionController.js)

**新增方法**:
```javascript
async function updateDiscussionVisibility(req, res) {
  // 验证可见性值
  if (!['public', 'private'].includes(visibility)) {
    return res.status(400).json(badRequest('Invalid visibility value'))
  }

  // 只有管理员可以修改可见性
  if (currentUserRole !== 'super_admin' && currentUserRole !== 'admin') {
    return res.status(403).json(forbidden('Only administrators can change visibility'))
  }

  // 更新可见性
  await discussion.update({ visibility })

  res.json(success({ ... }, 'Visibility updated successfully'))
}
```

**已有功能**:
- ✅ 创建讨论时默认 `visibility = 'private'`
- ✅ 获取讨论列表时的权限过滤
- ✅ 获取讨论详情时的权限检查

## 📊 权限系统设计

### 可见性规则

```javascript
// 后端查询逻辑
if (isAdmin) {
  // 管理员看所有
  return allDiscussions
} else {
  // 普通用户只看：
  return discussions.filter(d =>
    d.visibility === 'public' ||  // 公开讨论
    d.userId === currentUserId      // 自己的私密讨论
  )
}
```

### API权限验证

```javascript
// 讨论详情API
let hasPermission = false

if (isAdmin) {
  hasPermission = true
} else if (discussion.visibility === 'public') {
  hasPermission = true
} else if (discussion.userId === currentUserId) {
  hasPermission = true
}

if (!hasPermission) {
  return 403 Forbidden
}
```
