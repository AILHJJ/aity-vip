## 设计原则

### 1. 专业性

- 采用高端金融产品的设计语言
- 保持界面简洁、内容为王
- 避免过多装饰元素

### 2. 清晰性

- 信息层级分明
- 视觉引导清晰
- 操作反馈及时

### 3. 一致性

- 统一的视觉风格
- 统一的交互模式
- 统一的用词用语

### 4. 高效性

- 减少操作步骤
- 智能默认选项
- 快捷操作支持

## 字体排版

### 字体族

```scss
// iOS
$font-family-ios: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", STHeiti, "Microsoft Yahei", Tahoma, Simsun, sans-serif;

// Android
$font-family-android: Roboto, "PingFang SC", "Helvetica Neue", STHeiti, "Microsoft Yahei", Tahoma, Simsun, sans-serif;

// 小程序
$font-family-mp: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", STHeiti, "Microsoft Yahei", Tahoma, Simsun, sans-serif;
```

### 字号规范

| 用途 | 字号 | 行高 | 字重 | 使用场景 |
|------|------|------|------|---------|
| 大标题 | 48rpx | 1.3 | Bold | 页面主标题 |
| 标题 | 36rpx | 1.4 | Bold | 卡片标题、栏目标题 |
| 副标题 | 32rpx | 1.5 | Medium | 次要标题 |
| 正文大 | 30rpx | 1.6 | Regular | 按钮文字、重要内容 |
| 正文 | 28rpx | 1.6 | Regular | 正文内容 |
| 辅助文字 | 26rpx | 1.5 | Regular | 提示信息 |
| 小文字 | 24rpx | 1.4 | Regular | 标签、注释 |
| 极小字 | 22rpx | 1.4 | Regular | 时间戳、计数 |

### 字重规范


## 动画规范

### 缓动函数

```scss
// 标准
$ease-standard: cubic-bezier(0.4, 0.0, 0.2, 1);

// 进入
$ease-in: cubic-bezier(0.4, 0.0, 1, 1);

// 离开
$ease-out: cubic-bezier(0.0, 0.0, 0.2, 1);

// 弹性
$ease-elastic: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

### 动画时长

```scss
// 快速
$duration-fast: 150ms;

// 标准
$duration-normal: 300ms;

// 慢速
$duration-slow: 500ms;
```

### 常用动画

#### 淡入淡出

```scss
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes fadeOut {
  from { opacity: 1; }
  to { opacity: 0; }
}
```

#### 滑动

```scss
@keyframes slideInUp {
  from {
    transform: translateY(100%);
    opacity: 0;
  }
  to {
    transform: translateY(0);
    opacity: 1;
  }
}

@keyframes slideInDown {
  from {
    transform: translateY(-100%);
    opacity: 0;
  }
  to {
    transform: translateY(0);
    opacity: 1;
  }
}
```

#### 缩放

```scss
@keyframes scaleIn {
  from {
    transform: scale(0.9);
    opacity: 0;
  }
  to {
    transform: scale(1);
    opacity: 1;
  }
}
```

#### 旋转

```scss
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

// 使用示例
.loading-spinner {
  animation: spin 1s linear infinite;
}
```

## 响应式设计

### 屏幕尺寸适配

使用 `rpx` 单位确保多端自适应:

```scss
// rpx 会根据屏幕宽度自动转换
// 设计稿宽度: 750rpx
// iPhone 6 (375px): 1rpx = 0.5px
// iPhone 6 Plus (414px): 1rpx = 0.552px
```

### 断点规范

```scss
// 小屏幕
$breakpoint-small: 600rpx;

// 中屏幕
$breakpoint-medium: 900rpx;

// 大屏幕
$breakpoint-large: 1200rpx;
```

### 响应式布局示例

```scss
.container {
  padding: 30rpx;

  // 小屏幕减少内边距
  @media (max-width: 600rpx) {
    padding: 20rpx;
  }

  // 大屏幕增加内边距
  @media (min-width: 900rpx) {
    padding: 40rpx;
    max-width: 1200rpx;
    margin: 0 auto;
  }
}
```
