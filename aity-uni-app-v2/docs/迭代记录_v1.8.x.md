- ✅ 新增 `message_types` 数据表，支持动态管理消息类型
- ✅ 新增消息类型管理 API:

- ✅ 消息发布页支持从后端动态加载消息类型
- ✅ 管理员可在发布页直接新增消息类型
- ✅ 新增类型支持自定义颜色和图标

#### 数据库变更

```sql
-- 新增 message_types 表
CREATE TABLE IF NOT EXISTS `message_types` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `type` VARCHAR(50) NOT NULL UNIQUE,
  `label` VARCHAR(100) NOT NULL,
  `color` VARCHAR(20) DEFAULT '#667eea',
  `icon` VARCHAR(50) DEFAULT '',
  `sort_order` INT DEFAULT 0,
  `is_active` TINYINT(1) DEFAULT 1,
  `description` VARCHAR(255),
  `created_at` DATETIME,
  `updated_at` DATETIME
);
```

## 🔧 维护指南

### 添加新的消息类型（后台）

1. 通过小程序管理员账号登录
2. 进入"发布消息"页面
3. 点击消息类型旁边的"+ 管理"按钮
4. 填写类型标识（英文）、显示名称、选择颜色
5. 点击"添加类型"

### 常见问题

**Q: 新增的消息类型不显示？**
A: 检查 `message_types` 表中该类型的 `is_active` 字段是否为1

**Q: 删除消息类型失败？**
A: 确保没有消息正在使用该类型
