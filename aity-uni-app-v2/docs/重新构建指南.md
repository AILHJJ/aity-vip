

## ❓ 常见问题

### Q1: 构建失败
**A:** 清除缓存后重新构建
```bash
rmdir /s /q dist
npm run dev:h5
```

### Q2: 看不到优化效果
**A:** 强制刷新浏览器
```
Ctrl + Shift + Delete (清除缓存)
Ctrl + F5 (强制刷新)
```

**A:**
1. 关闭微信开发者工具
2. 重新运行 `npm run dev:mp-weixin`
