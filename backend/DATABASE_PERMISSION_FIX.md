# 数据库权限问题快速修复指南

## 🚨 问题描述
后端服务无法连接到腾讯云数据库，错误信息：
```
Host '58.49.104.171' is not allowed to connect to this MySQL server
```

## 🔧 解决方案

### 方法1: 通过phpMyAdmin Web界面 (推荐，最简单)

1. **访问phpMyAdmin**
   - 打开浏览器访问: `https://124.221.119.134:8888/database/mysql`
   - 用户名: `投研图灵室`
   - 密码: `fl10b312`

2. **设置用户权限**
   - 登录后，点击顶部导航栏的 **"权限"** 标签
   - 找到用户 `投研图灵室`，点击 **"编辑权限"**
   - 在 **"登录信息"** 部分：
     - 主机名: 选择 **"任意主机 (%)"** 
     - 或者输入具体IP: `58.49.104.171`
   - 点击 **"执行"** 保存

3. **验证权限**
   - 运行诊断脚本: `node scripts/diagnose-db-access.js`
   - 查看是否显示 "✅ 连接成功"

### 方法2: 通过SQL命令 (需要管理员权限)

如果你有数据库管理员权限，可以执行以下SQL：

```sql
-- 授权当前IP访问
GRANT ALL PRIVILEGES ON *.* TO '投研图灵室'@'58.49.104.171' IDENTIFIED BY 'fl10b312';
FLUSH PRIVILEGES;

-- 或者授权所有IP (仅用于开发测试)
GRANT ALL PRIVILEGES ON *.* TO '投研图灵室'@'%' IDENTIFIED BY 'fl10b312';
FLUSH PRIVILEGES;
```

### 方法3: 腾讯云控制台设置

1. **登录腾讯云控制台**
   - 访问: https://console.cloud.tencent.com/cdb
   - 找到你的MySQL实例

2. **设置安全组**
   - 进入实例详情 → 安全组
   - 添加规则：
     - 类型: MySQL
     - 源地址: `58.49.104.171` 或 `0.0.0.0/0` (所有IP)
     - 协议端口: `3306`

3. **设置账号权限**
   - 进入账号管理
   - 找到 `投研图灵室` 账号
   - 修改访问主机为 `%` 或具体IP

## ✅ 验证连接

权限设置完成后，运行以下命令验证：

```bash
"

```
