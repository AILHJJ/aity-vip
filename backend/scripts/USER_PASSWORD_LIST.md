## 🔧 用户管理工具

### 查看所有用户

```sql
SELECT 
  id,
  name,
  email,
  role,
  group_id,
  status,
  expire_date,
  created_at
FROM users
ORDER BY id;
```

### 查看过期用户

```sql
SELECT 
  name,
  email,
  role,
  expire_date,
  DATEDIFF(expire_date, CURDATE()) as days_left
FROM users
WHERE expire_date < DATE_ADD(CURDATE(), INTERVAL 7 DAY)
ORDER BY expire_date;
```

### 重置用户密码

```bash
# 使用sync-members.js脚本重置
cd backend
node scripts/sync-members.js

# 或使用个性化密码
node scripts/sync-members.js test custom
```
