# 📸 图片上传功能实现方案

**日期**: 2025-02-05
**目的**: 修复带附件的消息发布功能

---

## 🔴 当前问题

### 问题现象

```
不带附件: ✅ 发布成功
带附件: ❌ 500错误或失败
```

### 根本原因

**Blob URL无法直接发送到服务器**:

```javascript
// H5选择图片后
{
  name: "640(16).png",
  path: "blob:http://localhost:5173/ccf857b9...",  // ❌ 临时URL，服务器无法访问
  size: 174906
}

// 发送到服务器后，服务器尝试访问blob URL
// 结果: 失败 ❌
```

---

## ✅ 解决方案

### 方案架构

```
用户选择图片
    ↓
前端: 获取blob URL或临时路径
    ↓
前端: 调用上传API (POST /api/upload)
    ↓
后端: 接收文件，保存到服务器
    ↓
后端: 返回文件URL
    ↓
前端: 使用服务器URL发布消息
    ↓
完成: 消息创建成功，附件正常显示
```

## 📝 实现步骤

### 第一步：后端添加上传接口

**文件**: `backend/src/routes/upload.js`

**功能**:
- 接收multipart/form-data格式的文件
- 验证文件类型（只允许图片）
- 限制文件大小（10MB）
- 保存到 `backend/uploads/images/`
- 返回文件URL

**API示例**:
```javascript
POST /api/upload
Content-Type: multipart/form-data

Request:
- file: <binary data>

Response (200 OK):
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "url": "/uploads/images/img-1234567890-abc123.jpg",
    "filename": "img-1234567890-abc123.jpg",
    "originalname": "640(16).png",
    "size": 174906,
    "mimetype": "image/jpeg"
  }
}
```

### 第二步：后端配置静态文件服务

**文件**: `backend/src/app.js` 或 `backend/src/server.js`

**添加**:
```javascript
// 静态文件服务
app.use('/uploads', express.static('uploads'));

// 上传路由
app.use('/api/upload', uploadRoutes);
```

### 第三步：前端添加上传API

**文件**: `aity-uni-app-v2/src/api/upload.js` (已创建)

**功能**:
- 封装 `uni.uploadFile`
- 支持小程序和H5
- 返回Promise

### 第四步：前端修改发布逻辑

**文件**: `aity-uni-app-v2/src/pages/create-message/create-message.vue` (已修改)

**流程**:
```javascript
1. 用户点击发布
2. 检查是否有附件
3. 如果有附件，逐个上传
4. 等待所有图片上传完成
5. 使用服务器URL替换blob URL
6. 提交消息数据
7. 显示"发布成功"
```

### 2. 创建上传路由文件

```bash
# 在服务器上创建文件
vi backend/src/routes/upload.js
```

复制下面的代码:
```javascript
const express = require('express');
const router = express.Router();
const multer = require('multer');
const path = require('path');
const fs = require('fs');

// 确保上传目录存在
const uploadDir = path.join(__dirname, '../../uploads/images');
if (!fs.existsSync(uploadDir)) {
  fs.mkdirSync(uploadDir, { recursive: true });
}

// 配置multer
const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, uploadDir);
  },
  filename: (req, file, cb) => {
    const uniqueSuffix = Date.now() + '-' + Math.random().toString(36).substring(2, 15);
    const ext = path.extname(file.originalname);
    cb(null, 'img-' + uniqueSuffix + ext);
  }
});

const fileFilter = (req, file, cb) => {
  const allowedTypes = /jpeg|jpg|png|gif|webp/;
  const extname = allowedTypes.test(path.extname(file.originalname).toLowerCase());
  const mimetype = allowedTypes.test(file.mimetype);

  if (mimetype && extname) {
    cb(null, true);
  } else {
    cb(new Error('只允许上传图片文件'));
  }
};

const upload = multer({
  storage: storage,
  limits: { fileSize: 10 * 1024 * 1024 },
  fileFilter: fileFilter
});

router.post('/', upload.single('file'), (req, res) => {
  try {
    if (!req.file) {
      return res.status(400).json({
        code: 400,
        message: '请选择文件'
      });
    }

    const fileUrl = `/uploads/images/${req.file.filename}`;

    res.json({
      code: 200,
      message: '上传成功',
      data: {
        url: fileUrl,
        filename: req.file.filename,
        originalname: req.file.originalname,
        size: req.file.size
      }
    });
  } catch (error) {
    console.error('上传错误:', error);
    res.status(500).json({
      code: 500,
      message: '上传失败'
    });
  }
});

module.exports = router;
```

## 💡 技术要点

### Multer配置

**存储位置**:
- 目录: `backend/uploads/images/`
- 文件名: `img-{timestamp}-{random}.ext`

**文件验证**:
- 类型: 只允许图片 (jpeg, jpg, png, gif, webp)
- 大小: 最大10MB

**静态文件访问**:
- URL: `/uploads/images/img-xxx.jpg`
- 实际路径: `backend/uploads/images/img-xxx.jpg`

### 前端上传流程

```javascript
// 1. 检测blob URL
if (attach.path.startsWith('blob:')) {
  // 2. 上传到服务器
  const result = await uploadImageApi(attach.path)

  // 3. 使用服务器URL
  uploadedAttachments.push({
    url: result.url,  // /uploads/images/img-xxx.jpg
    ...
  })
}
```
