## 获取帮助

如果你在阅读文档或使用项目过程中遇到问题，可以通过以下方式获取帮助：

1. **查看常见问题**：在文档中查找"常见问题"部分
2. **搜索Issue**：在项目GitHub仓库搜索相关问题
3. **提问**：在项目GitHub仓库创建新的Issue
4. **联系团队**：直接联系项目团队成员
