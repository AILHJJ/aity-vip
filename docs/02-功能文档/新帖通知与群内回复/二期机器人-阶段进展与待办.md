## 三、技术架构（渠道抽象）

```
channelFactory.createBotService(channelName, config, {bindCode})
  ├─ wecom → WecomBotChannel  （企微长连接 WebSocket，图片 AES 解密）
  └─ feishu → FeishuBotChannel（飞书官方 SDK 长连接，图片直接保存）

botService（渠道无关业务：指令解析/发帖/回帖/讨论/绑定/图片缓存）
  └─ 通过 BotChannel 接口收发：start/stop/reply/sendToGroup/downloadImage
```

- **单渠道设计**：同一时间只有 1 个渠道启用（DB `bot_channel_configs` 里 `enabled=true` 唯一）
- **热重载**：配置页保存 → `botConfigService.upsertBotConfig` → 重启 botService 实例
- **指令格式**（企微/飞书通用）：
  ```
  帮助                          → 使用说明
  绑定 <绑定码>                  → 身份绑定（未绑定者发帖/回帖被拒）
  发帖 [公开|私密] # 标题\n正文   → 发消息中心（私密=发帖人+管理员可见）
  回复 <帖子ID> [公开|私密] <内容> → 回讨论帖
  讨论 <帖子ID> <内容>           → 回复消息中心
  ```

## 四、⚠️ 待办清单（按优先级）

2. 事件与回调 → 订阅方式选「**使用长连接接收事件**」

4. 权限管理：开通「接收群聊消息」「发送消息」「读取图片资源」
