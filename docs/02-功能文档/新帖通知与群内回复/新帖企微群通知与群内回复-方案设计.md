## 一、背景与目标

**痛点**：用户在 AITY 产品内发新帖（讨论/提问），管理员无法第一时间感知，处理不及时。

**目标**：
1. 一期（优先）：用户发新帖 → 企业微信群**秒级通知**管理员，点链接直达帖子处理
2. 二期（增强）：管理员在群里 @机器人 直接回复帖子，无需打开产品

**同群复用**：SSL 证书续期失败告警也推送到同一个群机器人，一个群管所有运维+业务通知。

## 二、总体架构

```
┌─────────────────────────────────────────────────────┐
│  企业微信群「AITY运维与客服」                          │
│  └─ 群机器人（webhook，单向推送 ← 一期用这个）           │
│  └─ 智能机器人（API模式，双向对话 ← 二期用这个）         │
└─────────────────────────────────────────────────────┘
        ↑ 一期推送                    ↓ 二期接收(@机器人)
┌──────────────────────┐      ┌──────────────────────┐
│ AITY 后端 (3001)      │      │ AITY 后端新增机器人    │
│ · createDiscussion    │      │ 消息接收与身份校验      │
│   成功后推送通知        │      │ → addDiscussionReply │
│ · 服务器SSL告警脚本    │      └──────────────────────┘
└──────────────────────┘
```

## 四、二期：群内双向操作（发帖 + 回帖，含图文）（工作量约 3~4 天）

> **核心定位**：管理员在企微群里 @机器人 直接完成"发帖"和"回帖"，结果实时同步到小程序/H5，全程不切端。

### 4.1 技术选型（2026-09-14 最终：长连接 WebSocket 模式）

> **回退说明**：曾尝试回调 URL 模式（为支持方案甲 quote 引用识别），但企微**域名主体校验未通过**（aity88.online 备案主体与企业主体不符，政策层面无法用代码解决），回退长连接模式。长连接主动连企微，无需公网回调地址、无域名校验。

| 项 | 值 |
|---|---|
| WebSocket 地址 | `wss://openws.work.weixin.qq.com` |
| 握手命令 | `aibot_subscribe`（含 `bot_id` + `secret`） |
| 收消息命令 | `aibot_msg_callback`（含 msgid/chatid/from.userid/msgtype/text/image） |
| 回消息命令 | `aibot_respond_msg`（支持 text/markdown/image 等） |
| 心跳 | 30 秒 `ping`，断线自动重连 |
| Bot 凭据 | Bot ID + Secret（企微后台「长连接模式」生成） |

> **长连接限制**：msg_callback 不含 `quote`（引用消息）字段，故方案甲（引用识别帖子 ID）不可行，改用方案乙优化版（通知卡片带「回复 95」指令，复制 ID 即可）。

### 4.2 交互设计（含发帖，本次新增）

**场景 A：群内发帖（管理员主动输出内容）**
```
管理员：@AITY回帖助手 发帖 公开 【今日盘前】今天关注xxx板块…
  → 机器人调后端发帖接口（createDiscussion）
  → 帖子同步到小程序/H5「消息中心」
  → 群内回执：✅ 已发布《标题》 https://aity88.online/#/pages/...
```

**场景 B：群内回帖（响应用户，方案乙优化版——通知卡片带回复指令）**
```
用户发帖 → 群收到通知（一期），通知卡片末尾带「👉 回复：@AITY回帖助手 回复 95」
管理员复制帖子 ID，输入：@AITY回帖助手 回复 95 短期看震荡，关注支撑位…
  → 机器人解析帖子 ID + 回复内容
  → 调后端回帖接口（DiscussionReply.create）
  → 回复同步到帖子详情（小程序/H5 用户可见）
  → 群内回执：✅ 已回复《标题》
```

**指令格式**（含私密）：
```
发帖 [公开|私密] # 标题
正文内容（支持 markdown 渲染）       → 发消息到消息中心，缺省=公开
回复 <帖子ID> [公开|私密] <内容>    → 回帖（讨论帖），缺省=公开
绑定 <绑定码>                     → 身份绑定
帮助                            → 返回使用说明
```

**自然语言变体支持**（避免死记硬背）：

| 动作 | 等价写法 |
|---|---|
| 发帖 | `发帖` / `发帖子` / `发个帖子` / `发一个帖子` / `发个帖` |
| 标题 | `# 标题` 或 `## 标题`（markdown，两者均可），标题后换行接正文 |
| 回帖 | `回复` / `回帖` / `回复帖子` |

**关键约定**：
- 发帖**发到消息中心**（有标题+正文，正文支持 markdown 渲染）
- 回帖**发到讨论区**（只有正文，无标题）
- 方案乙优化版（回帖拿帖子 ID）：长连接不支持 `quote` 引用，改为**通知卡片直接给「回复 95」指令**（一期通知卡片末尾加一行），管理员复制 ID 即可，无需打开链接找 ID
- **发帖私密**：指令加 `私密` 关键字，消息中心通过 `groupId` 控制可见性（`all`=全员 / `admin_only`=仅发帖人+管理员），查询逻辑按角色过滤

### 4.3 图片转存（本次一起做）

**接收图片（管理员发图给机器人）**：长连接图片消息结构为 `image.url`（5 分钟有效）+ `image.aeskey`（解密密钥，每个资源唯一）。

```
1. 用 image.url 下载加密图片二进制
2. 用 image.aeskey（base64 解码为 32 字节 key）做 AES-256-CBC 解密（IV = key 前 16 字节，PKCS#7 填充）
3. 解密得到原始图片 → 保存到后端 uploads 目录
4. 拿到图片 URL → 传给发帖/回帖的 images 字段
```

**发送图片（机器人回执带图）**：需先上传临时素材拿 media_id（`aibot_upload_media_init` → `chunk` → `finish`），media_id 3 天有效。**首期回执用文本，不发图**（降低复杂度）。

> ⚠️ **风险标注（已确认接受）**：官方文档明确 `image`/`voice`/`file`/`video` 在长连接模式下**仅支持单聊回调**，群聊 @机器人发图可能收不到。决策：坚持图文一起做，上线后实测；若群聊确实收不到图，再评估「图片走单聊通道」或「回退纯文本」。

### 4.4 身份绑定（关键安全设计）

- 首次使用：管理员群里 @机器人 `绑定 <绑定码>`，绑定码在用户管理后台生成
- 后端映射表 `wecom_user_bindings`（企微 userid ↔ AITY admin 账号 id）
- **未绑定者指令一律拒绝**，防止外部人通过群乱发帖
- ⚠️ **userid 加密说明**：机器人创建者非企业超管时，`from.userid` 为**加密 userid**（本项目机器人由个人账号创建，大概率加密）。绑定机制不受影响——绑定表存"收到的字符串"，匹配用"同一字符串"，只需上线后实测 userid 稳定性即可

### 4.6 难点与对策

| 难点 | 对策 |
|---|---|
| 企微消息重试推送 | 以 msgid 幂等去重（内存 Set + 过期清理） |
| 指令解析容错 | 严格格式校验，格式不对返回使用帮助 |
| 图片 url 5 分钟失效 | 收到消息立即下载解密，不落库延迟处理 |
| 私密回复回执泄密 | 私密回复回执不回显内容，仅提示"已私密回复《xxx》" |
| 群聊发图收不到（文档风险） | 上线实测；收不到则评估单聊通道或回退纯文本 |
| userid 加密导致绑定失败 | 绑定机制不依赖明文，实测 userid 稳定性兜底 |
| 机器人掉线 | WebSocket 自动重连 + 心跳日志，掉线超 10 分钟推 webhook 告警 |
