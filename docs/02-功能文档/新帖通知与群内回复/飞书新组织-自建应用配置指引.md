# 飞书新组织 · 自建应用配置指引（互动机器人）

> 用途：在**新创建的飞书组织**里，配置小程序「群内发帖/回帖」互动机器人
> 你的身份：新组织创建者 = 超级管理员，**所有审核自己批，秒过**
> 生成时间：2026-09-16
>
> 区分两个机器人：
> - **自定义机器人**（webhook）＝通知喇叭，只发不收 → 已建好（AI指令助手），已配到服务器
> - **自建应用**（本指南）＝互动机器人，收指令/发帖/回帖 → 按本指南创建

## 一、创建自建应用（约 2 分钟）

1. 浏览器打开 **https://open.feishu.cn** → 右上角「开发者后台」（确保右上角组织是你的新组织）
2. 点「**创建企业自建应用**」
3. 填写：应用名称 `AITY小助手`、描述 `投研小程序群内互动机器人`、图标随意
4. 创建完成，进入应用详情页

## 二、添加机器人能力（1 分钟）

左侧「**应用能力**」→ 找到「**机器人**」卡片 → 点「**添加**」

## 三、事件与回调（2 分钟，最关键）

左侧「**事件与回调**」：

1. **订阅方式**：选择「**使用长连接接收事件**」→ 点「保存」
   - 不要选「将事件发送至开发者服务器」（要公网地址，会踩域名校验的坑）
2. 切到「**事件配置**」页签（不是"回调配置"）→ 点「**添加事件**」
3. 搜索框输入「**接收消息**」→ 勾选 **接收消息 im.message.receive_v1** → 保存
4. 系统提示需要权限 → 一路「确定/开通」（自动勾选所需权限）

## 四、权限管理（1 分钟）

左侧「**权限管理**」→ 确认以下权限已开通（事件添加时通常自动带上，缺哪个补哪个）：

| 权限 | 说明 |
|---|---|
| im:message | 获取与发送单聊、群组消息 |
| im:message.group_msg | 接收群聊中 @机器人 消息 |
| im:message.p2p_msg | 接收用户发给机器人的单聊消息 |
| im:resource | 获取消息中的图片资源 |

## 五、发布版本（1 分钟）

1. 左侧「**版本管理与发布**」→「**创建版本**」
2. 版本号 `1.0.0`，更新说明 `初始化互动机器人`
3. 可用范围：全体成员（或指定你自己）
4. 提交 → 你是管理员，去管理后台（https://go.feishu.cn/admin）→ 应用审核 → 自己点通过
5. 回开放平台确认应用状态变为「**已启用**」

## 六、拉机器人进群

飞书群「AI投研图灵室」→ 设置 → 群机器人 → 添加机器人 → 找到「AITY小助手」

## 七、启用渠道

从开放平台「**凭证与基础信息**」复制 App ID / App Secret，填到 **管理后台 → 渠道配置 → 飞书 Tab**：

| 字段 | 填写 |
|---|---|
| App ID | 复制的 App ID |
| App Secret | 复制的 App Secret |
| 绑定码 | b8k4n2x9 |
| 启用该渠道 | 打开 |

点「**保存并生效**」→ 后端自动热重载连飞书。
注意：启用飞书后企微机器人会停止（单渠道设计），想切回在渠道配置页重新启用企微即可。

## 八、验收测试（飞书群里操作）

1. @AITY小助手 帮助 → 应回复使用说明
2. @AITY小助手 绑定 b8k4n2x9 → 应回复绑定成功
3. @AITY小助手 发帖 # 测试标题（换行）这是飞书发的测试正文 → 应回发帖成功链接
4. 发一张图片 + @AITY小助手 发帖 # 图片测试（换行）正文 → 测图片随帖（可选）

同时观察开放平台「事件与回调」页长连接状态 → 应显示「已连接」（绿色）。

## 九、异常排查速查

| 现象 | 原因 |
|---|---|
| @机器人 无任何回复 | 长连接未连上 / 事件未订阅 / 版本未发布 |
| 回复"指令格式不正确" | 连接正常，指令写法问题（发「帮助」看格式） |
| 回复"未绑定管理员身份" | 正常安全机制，先发「绑定 b8k4n2x9」 |
| 长连接显示连接失败 | 渠道配置页没启用/保存，或 Secret 错误 |
| 收到消息但回复失败 | 检查 im:message 发送权限 |
