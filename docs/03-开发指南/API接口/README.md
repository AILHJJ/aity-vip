## 🔍 快速查找

### 按功能分类

#### 1. 金融数据 (01-financial-data-api.md)
- 市场概览与涨跌停分布
- 行业资金流向分析
- 连板股票详细分析（NLP）
- 连板天梯（板块数据）
- 指数行情和综合行情
- 概念板块涨跌幅排行
- 板块异动监控

**适用场景**: 实时行情数据展示、市场分析、板块轮动研究

#### 2. 打板功能 (02-trading-board-api.md)
- 涨停池管理（查询、异动、涨停榜）
- 跌停池管理（查询、跌停榜）
- 板块池管理（列表、详情、异动）
- 消费者和订阅者管理

**适用场景**: 涨停跌停监控、短线交易策略、异动提醒

#### 3. AI助手 (03-ai-assistant-api.md)
- Dify工作流集成
- AI对话管理（创建、历史、清空）
- 流式响应（SSE）
- 会话管理（thread_id）

**适用场景**: 智能投顾、AI对话、行情分析建议

#### 4. 核心业务 (04-core-business-api.md)
- **认证接口**: 登录、获取用户信息
- **消息接口**: CRUD、已读、收藏、置顶（11个接口）
- **讨论接口**: 讨论、回复、可见性管理（4个接口）
- **用户接口**: CRUD、密码重置（5个接口）
- **分组接口**: CRUD（4个接口）
- **统计接口**: 个人统计、趋势分析、类型分布（3个接口）
- **市场数据**: 指数行情、市场异动（2个接口）
- **文件上传**: 图片上传（1个接口）
- **健康检查**: API状态（1个接口）

**适用场景**: 用户管理、消息推送、数据统计、系统监控

#### 5. SSE事件 (05-sse-events.md)
- messages/partial - 流式文本输出
- messages/complete - 消息完成
- messages/metadata - 会话元数据
- messages/tool - 工具调用通知
- messages/tool_result - 工具执行结果

**适用场景**: 实时AI对话、流式数据推送、工具调用监控

## 🚀 快速开始

### 1. 环境配置

**开发环境**
```
http://localhost:3001/api
```

**生产环境**
```
https://aity88.online:8443/api
```

**外部API（金融数据）**
```
http://123.60.27.66:7615/TQLEX
```

### 2. 认证方式

**核心业务接口、AI助手、打板功能**
```
Authorization: Bearer <token>
```

**金融数据接口**
```
无需认证
```

**AI助手SSE流**
```
tdx-auth: <token>
```

### 3. 响应格式

**统一响应格式**
```json
{
  "code": 200,
  "message": "Success",
  "data": {}
}
```

**SSE事件格式**
```json
{
  "type": "partial",
  "content": "内容"
}
```

## 📝 维护指南

### 添加新接口文档

1. 创建文件：`XX-module-name-api.md`（XX为序号）
2. 使用标准模板：`templates/api-doc-template.md`
3. 包含必要章节：文档信息、接口概览、接口详情、错误码说明、变更日志
4. 运行生成脚本：`node docs/api/scripts/generate-index.js`
5. 提交代码：`git add docs/api/ && git commit -m "docs: 添加XXX接口文档"`

### 更新现有文档

1. 修改对应的文档文件
2. 更新"文档信息"表格中的版本和最后更新时间
3. 在"变更日志"章节添加变更记录
4. 运行生成脚本更新README（如果接口数量变化）
5. 提交代码：`git add docs/api/ && git commit -m "docs: 更新XXX接口文档"`

### 文档命名规范

- 格式：`序号-模块名-api.md`
- 序号：两位数字，从01开始
- 模块名：小写英文，用连字符分隔
- 示例：`01-financial-data-api.md`
