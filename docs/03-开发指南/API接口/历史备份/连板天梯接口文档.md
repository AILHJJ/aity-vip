# 连板天梯接口文档

## 接口概述

连板天梯接口用于获取连续涨停个股数据，提供两种不同的接口形式，返回内容格式不同，但核心功能一致。

---

## 接口列表

### 1. NLP应用接口（推荐）

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.hq_nlp_app_misc`

**接口说明**: 获取连续涨停个股的详细分析数据，包含30个分析指标，数据格式为N001-N030的键值对。

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "AppType": "misc"
}
```

**参数说明**:
- `AppType`: 应用类型
  - `misc` - 综合分析（默认）
  - `news` - 新闻分析
  - `hot` - 热点分析

**响应示例**:
```json

      "N011": "0",

      "N015": "2026-03-02 09:31:00",
```

**字段说明**:

| `N003` | string | 次新标识：0：默认，1：次新 | "0" |
| `N004` | string | 市场类型：0=深市，1=沪市 | "0" |
| `N005` | string | 现价 | "10.50" |
| `N006` | string | 涨幅 | "+5.23" |

| `N008` | string | 最近一次跌停时间 | "" |

| `N010` | string | 连续涨停天数 | "2" |

| `N014` | string | 封成比 | "85%" |

| `N020` | string | 首次跌停后跌停打开次数 | "0" |

| `N028` | string | 资金净流入 | "50000000" |
| `N029` | string | 主力资金净流入 | "30000000" |
| `N030` | string | 涨停原因 | "热点概念" |

**优势**:
- 数据字段丰富，包含30个分析指标
- 数据格式清晰，易于解析
- 支持多种应用类型（综合分析、新闻分析、热点分析）

### 2. 板块数据接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**接口说明**: 获取连板天梯数据，返回格式为JSON字符串，需要二次解析。

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Blocktype": "0",
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH"
}
```

**参数说明**:
- `Blocktype`: 板块类型（0=股票）
- `Blockstyle`: 板块风格（3=连板）
- `Blockid`: 板块ID（Stock_SCHIGH=连板高度）

**响应示例**:
```json
{
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH",
  "Totalrow": 1,
  "Num": 286,
  "Buf": "[[\"3\",\"1\"],[\"0\",\"002843\",\"深证成指\"],...]"
}
```

**字段说明**:
| 字段名 | 类型 | 说明 |
|--------|------|------|
| `Blockstyle` | Number | 板块风格 |
| `Blockid` | String | 板块ID |
| `Totalrow` | Number | 总行数 |
| `Num` | Number | 板块数量 |
| `Buf` | String | 股票板块数据（JSON字符串） |

**Buf字段解析**:
```json
[
  [
    "3",
    "1"
  ],
  [
    "0",
    "002843",
    "深证成指"
  ]
]
```
- 位置0: 市场类型（0=深市，1=沪市）
- 位置1: 股票代码
- 位置2: 股票名称

**优势**:
- 数据格式紧凑，传输效率高
- 适合大批量数据查询
- 支持多种板块类型和风格

## 接口对比

| 对比项 | NLP应用接口 | 板块数据接口 |
|--------|------------|-------------|
| **接口地址** | HQServ.hq_nlp_app_misc | HQServ.PBXmlBlock |
| **数据格式** | 键值对（N001-N030） | JSON数组字符串 |
| **字段数量** | 30个分析指标 | 3个基础字段 |
| **数据丰富度** | 高（包含资金流向、涨停分析等） | 低（仅基础信息） |
| **解析难度** | 低（直接映射） | 中（需要二次解析） |
| **适用场景** | 详细分析、深度研究 | 快速查询、列表展示 |
| **推荐程度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 前端集成示例

### Vue 3 Composition API

```javascript
import { ref, reactive } from 'vue';
import axios from 'axios';

const API_BASE = 'http://123.60.27.66:7615/TQLEX';

export function useContinuousLimit() {
  const loading = ref(false);
  const error = ref(null);
  const limitStocks = ref([]);

  // 使用NLP应用接口获取连板数据（推荐）
  const getContinuousLimitByNLP = async (appType = 'misc') => {
    loading.value = true;
    error.value = null;
    try {
      const response = await axios.post(
        `${API_BASE}?Entry=HQServ.hq_nlp_app_misc`,
        {
          Head: { Target: 0 },
          AppType: appType
        }
      );
      
      const data = response.data;
      if (data['返回结果'] && Array.isArray(data['返回结果'])) {
        limitStocks.value = data['返回结果'].map(item => ({
          name: item.N001,
          code: item.N002,
          isNew: item.N003 === '1',
          market: item.N004 === '0' ? '深市' : '沪市',
          currentPrice: parseFloat(item.N005) || 0,
          changePercent: parseFloat(item.N006) || 0,
          lastLimitUpTime: item.N007,
          lastLimitDownTime: item.N008,
          boardInfo: item.N009,
          consecutiveLimitUpDays: parseInt(item.N010) || 0,
          consecutiveLimitDownDays: parseInt(item.N011) || 0,
          boardType: item.N012,
          sealAmount: parseInt(item.N013) || 0,
          sealRatio: parseFloat(item.N014) || 0,
          firstLimitUpTime: item.N015,
          firstLimitDownTime: item.N016,
          lastLimitUpOpenTime: item.N017,
          lastLimitDownOpenTime: item.N018,
          firstLimitUpOpenCount: parseInt(item.N019) || 0,
          firstLimitDownOpenCount: parseInt(item.N020) || 0,
          maxLimitUpSealAmount: parseInt(item.N021) || 0,
          maxLimitDownSealAmount: parseInt(item.N022) || 0,
          limitUpAmount: parseInt(item.N023) || 0,
          limitUpSpeed: parseFloat(item.N024) || 0,
          turnoverRate: parseFloat(item.N025) || 0,
          volumeRatio: parseFloat(item.N026) || 0,
          totalAmount: parseInt(item.N027) || 0,
          netInflow: parseInt(item.N028) || 0,
          mainNetInflow: parseInt(item.N029) || 0,
          limitUpReason: item.N030
        }));
      }
      
      return data;
    } catch (err) {
      error.value = err.message;
      throw err;
    } finally {
      loading.value = false;
    }
  };

  // 使用板块数据接口获取连板数据
  const getContinuousLimitByBlock = async (params = {}) => {
    loading.value = true;
    error.value = null;
    try {
      const response = await axios.post(
        `${API_BASE}?Entry=HQServ.PBXmlBlock`,
        {
          Head: { Target: 0 },
          Blocktype: params.blockType || "0",
          Blockstyle: params.blockStyle || "3",
          Blockid: params.blockId || "Stock_SCHIGH"
        }
      );
      
      const data = response.data;
      if (data.Buf) {
        const parsedBlocks = JSON.parse(data.Buf);
        limitStocks.value = parsedBlocks.map(block => ({
          market: block[0] === '0' ? '深市' : '沪市',
          code: block[1],
          name: block[2]
        }));
      }
      
      return data;
    } catch (err) {
      error.value = err.message;
      throw err;
    } finally {
      loading.value = false;
    }
  };

  return {
    loading,
    error,
    limitStocks,
    getContinuousLimitByNLP,
    getContinuousLimitByBlock
  };
}
```

```vue
});
```

## 错误处理

### 常见错误

| 错误类型 | 说明 | 处理建议 |
|----------|------|----------|
| **网络错误** | 无法连接到服务器 | 检查网络连接，确认服务器地址正确 |
| **参数错误** | 请求参数格式不正确 | 检查JSON格式，确保必填参数已提供 |
| **数据解析错误** | 返回数据格式不符合预期 | 检查返回数据结构，处理异常情况 |
| **请求长度错误** | 请求参数过长 | 检查参数长度，确保符合接口要求 |

### 错误处理示例

```javascript
try {
  await getContinuousLimitByNLP();
  ElMessage.success('数据加载成功');
} catch (error) {
  if (error.response) {
    if (error.response.status === 400) {
      ElMessage.error('请求参数错误');
    } else if (error.response.status === 500) {
      ElMessage.error('服务器内部错误');
    }
  } else if (error.request) {
    ElMessage.error('网络错误，请检查连接');
  } else {
    ElMessage.error('数据解析错误');
  }
}
```

## 性能优化

### 1. 数据缓存

```javascript
const CACHE_KEY = 'continuous_limit_cache';
const CACHE_DURATION = 10 * 60 * 1000; // 10分钟

const getContinuousLimitWithCache = async (apiType, params) => {
  const cacheKey = `${CACHE_KEY}_${apiType}_${JSON.stringify(params)}`;
  const cached = localStorage.getItem(cacheKey);
  
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < CACHE_DURATION) {
      return JSON.parse(data['返回结果'] || data.Buf);
    }
  }
  
  let result;
  if (apiType === 'nlp') {
    result = await getContinuousLimitByNLP(params.appType);
  } else {
    result = await getContinuousLimitByBlock(params);
  }
  
  localStorage.setItem(cacheKey, JSON.stringify({
    data: result,
    timestamp: Date.now()
  }));
  
  return JSON.parse(result['返回结果'] || result.Buf);
};
```
