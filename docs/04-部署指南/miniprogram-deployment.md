## 步骤1：配置IP白名单

### 为什么需要配置IP白名单？

微信小程序的代码上传 API 要求调用方的 IP 地址必须在白名单中，这是为了安全考虑。

### 如何配置？

#### 1. 获取当前 IP 地址

访问以下任一网站获取你的公网 IP：
- https://www.ip.cn
- https://ip.sb
- 或在命令行执行：`curl ifconfig.me`

#### 2. 登录微信公众平台

访问：https://mp.weixin.qq.com/

使用小程序管理员账号登录（13545023884@163.com）

#### 3. 添加 IP 白名单

1. 进入 **开发 → 开发管理 → 开发设置**
2. 找到 **小程序代码上传** 部分
3. 点击 **IP 白名单配置**
4. 点击 **添加 IP**
5. 输入你的 IP 地址
6. 点击 **确定**

**注意**：
- IP 白名单配置后立即生效
- 如果你的 IP 地址会变化（如使用动态 IP），需要每次变化后重新添加
- 建议使用固定 IP 或服务器 IP 进行上传

## 步骤2：配置服务器域名

### 为什么需要配置服务器域名？

小程序在生产环境中访问后端 API 时，必须使用已配置的合法域名。

### 如何配置？

#### 1. 登录微信公众平台

访问：https://mp.weixin.qq.com/

#### 2. 配置服务器域名

1. 进入 **开发 → 开发管理 → 开发设置**
2. 找到 **服务器域名** 部分
3. 点击 **修改**
4. 添加以下域名：

**request 合法域名**：
```
https://aity88.online:8443
```

**uploadFile 合法域名**：
```
https://aity88.online:8443
```

**downloadFile 合法域名**：
```
https://aity88.online:8443
```

5. 点击 **保存并提交**

**注意**：
- 域名必须使用 HTTPS 协议
- 域名必须已备案
- 每月只能修改 5 次
- 配置后需要等待几分钟生效

## 步骤3：构建小程序代码

## 步骤4：上传小程序代码

### 方法 1: 使用命令行上传（推荐）

配置完 IP 白名单后，运行以下命令：

```bash

# 上传到微信平台

```

**自定义版本号和描述**：

## 常见问题

### 1. 上传失败：invalid ip

**错误信息**：
```
Error: {"errCode":-10008,"errMsg":"invalid ip: 58.49.104.171"}
```

**原因**：IP 地址未在白名单中

**解决方案**：
1. 登录微信公众平台
2. 进入 开发 → 开发管理 → 开发设置
3. 在 小程序代码上传 部分添加 IP 白名单
4. 添加你的 IP 地址

### 2. 小程序提示 "不在以下 request 合法域名列表中"

**原因**：服务器域名未配置

**解决方案**：
1. 登录微信公众平台
2. 进入 开发 → 开发管理 → 开发设置
3. 配置服务器域名：`https://aity88.online:8443`

### 3. 上传密钥文件不存在

**错误信息**：
```
密钥文件不存在: D:\your-mcp-proxy\AITY_VIP\private.wxb16a33cdd58f05d3.key
```

**解决方案**：
1. 确认密钥文件路径正确
2. 确认密钥文件已下载到项目根目录
3. 如果密钥丢失，需要在微信公众平台重新生成

### 4. 审核被拒绝

**常见原因**：
- 功能描述不清楚
- 测试账号无法登录
- 缺少必要的资质证明
- 内容违规

**解决方案**：
1. 查看审核反馈意见
2. 根据反馈修改代码或补充资料
3. 重新提交审核

### 5. 网络请求失败

**问题**：小程序中 API 请求失败

**解决方案**：
1. ✅ 检查服务器域名是否配置为 `https://aity88.online:8443`
2. ✅ 确认后端服务是否运行（`pm2 status`）
3. ✅ 检查 Nginx 配置是否正确（`nginx -t`）
4. ✅ 查看微信开发者工具控制台错误信息

### 6. 页面白屏

**问题**：小程序打开后页面白屏

**解决方案**：
1. ✅ 检查控制台错误信息
2. ✅ 确认 AppID 配置正确（`wxb16a33cdd58f05d3`）
3. ✅ 检查 `pages.json` 配置是否正确
4. ✅ 确认所有页面文件都已编译
5. ✅ 尝试重新编译小程序
