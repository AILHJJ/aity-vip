# 打板功能

> 打板功能提供涨停板、跌停板、连板天梯等市场极端行情数据
> 最后更新：2026-03-05

---

## 功能概述

打板功能专注于捕捉市场极端行情，包括涨停板、跌停板、强势股、弱势股等数据，帮助用户快速发现市场热点和风险点。

---

## 核心功能

### 1. 涨停板列表
- **实时涨停板数据**：当日所有涨停股票
- **详细信息**：股票代码、名称、现价、涨跌幅、成交量、成交额
- **市场筛选**：沪市、深市
- **连板天数**：显示连续涨停天数

### 2. 跌停板列表
- **实时跌停板数据**：当日所有跌停股票
- **详细信息**：股票代码、名称、现价、涨跌幅、成交量、成交额
- **市场筛选**：沪市、深市

### 3. 连板天梯
- **分层展示**：按连板天数（2连板、3连板、4连板等）
- **排序规则**：每层股票按涨幅排序
- **板块筛选**：全部、主板、创业板、科创板、北证
- **详细信息**：股票代码、名称、现价、涨跌幅、连板天数、所属板块

### 4. 涨停池
- **统计数据**：涨停股票的详细统计
- **排序功能**：按涨跌幅、成交量、成交额等排序
- **分页查询**：支持分页获取数据
- **板块过滤**：按板块代码筛选

### 5. 跌停池
- **统计数据**：跌停股票的详细统计
- **排序功能**：按涨跌幅、成交量、成交额等排序
- **分页查询**：支持分页获取数据
- **板块过滤**：按板块代码筛选

### 6. 强势股列表
- **强势股票**：连续上涨或涨幅较大的股票
- **详细信息**：股票代码、名称、涨跌幅、强势原因
- **市场筛选**：全部、沪市、深市

### 7. 弱势股列表
- **弱势股票**：连续下跌或跌幅较大的股票
- **详细信息**：股票代码、名称、涨跌幅、弱势原因
- **市场筛选**：全部、沪市、深市

## 使用指南

### 查看涨停板
1. 进入"打板"页面
2. 默认显示涨停板列表
3. 可切换市场（沪市/深市）
4. 查看股票详细信息

### 查看连板天梯
1. 在打板页面，切换到"连板天梯"标签
2. 按连板天数分层展示
3. 点击板块标签筛选（全部/主板/创业板/科创板/北证）
4. 查看各连板层级的股票排行

### 查看强势股/弱势股
1. 切换到"强势股"或"弱势股"标签
2. 查看连续上涨或下跌的股票
3. 分析强势或弱势原因

### 使用涨停池/跌停池
1. 切换到"涨停池"或"跌停池"标签
2. 使用排序功能（按涨跌幅、成交量等）
3. 使用板块筛选功能
4. 分页查看更多数据

## 技术架构

### 前端
- **框架**：uni-app (Vue 3)
- **UI组件**：自定义组件 + uni-ui
- **状态管理**：Pinia

### 后端
- **运行环境**：Node.js
- **框架**：Express.js
- **数据源**：外部金融API (http://123.60.27.66:7615/TQLEX)

### 数据流
```
外部金融API → 后端代理 → 前端请求 → UI展示
```

## API接口

### 打板功能核心接口

| 接口名称 | Entry | 功能说明 |
|---------|-------|----------|
| **涨停板列表** | HQServ.PBXmlBlock | 获取涨停板股票列表 |
| **跌停板列表** | HQServ.PBXmlBlock | 获取跌停板股票列表 |
| **涨停池统计** | HQServ.hq_nlp_app_misc | 获取涨停池统计数据 |
| **跌停池统计** | HQServ.hq_nlp_app_misc | 获取跌停池统计数据 |
| **强势股列表** | HQServ.hq_nlp_app_misc | 获取强势股列表 |
| **弱势股列表** | HQServ.hq_nlp_app_misc | 获取弱势股列表 |
| **异动监控** | HQServ.PBPzxh | 获取市场异动数据 |

### 接口参数说明

## 常见问题

### Q: 涨停板和连板天梯有什么区别？
A: 涨停板显示所有当日涨停的股票，连板天梯按连续涨停天数分层展示。

### Q: 如何区分强势股和弱势股？
A: 强势股指连续上涨或涨幅较大的股票，弱势股指连续下跌或跌幅较大的股票。

### Q: 数据更新频率是多少？
A: 实时更新，建议缓存15-20秒。

### Q: 如何使用板块筛选功能？
A: 在涨停池/跌停池页面，可以通过板块代码进行筛选。
