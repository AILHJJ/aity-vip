# 行情中心功能

> 行情中心提供实时市场数据展示和分析功能，采用Neon Flux科技风格设计
> 最后更新：2026-03-05

---

## 功能概述

行情中心是AITY VIP的核心功能模块，提供实时市场数据展示和分析功能，帮助用户快速掌握市场动态。

---

## 核心功能

### 1. 指数行情
- **主要指数**：上证指数、深证成指、创业板指等
- **实时数据**：涨跌幅、成交量、成交额
- **颜色区分**：红涨绿跌

### 2. 市场概览
- **涨跌统计**：上涨/下跌/涨停/跌停股票数量
- **市场情绪**：基于涨跌比例计算情绪分数
- **实时更新**：手动刷新获取最新数据

### 3. 连板天梯
- **分层展示**：按连板天数（2连板、3连板、4连板等）
- **排序规则**：每层股票按涨幅排序
- **板块筛选**：全部、主板、创业板、科创板、北证
- **详细信息**：股票代码、名称、现价、涨跌幅、连板天数

### 4. 行业资金流向
- **资金排行**：行业资金流入/流出TOP10
- **净流入**：显示净流入金额和占比
- **颜色标识**：流入红色、流出绿色

### 5. 涨跌分布
- **区间统计**：涨跌幅区间分布（< -7%, -7%~-5%, -5%~-3%, -3%~0%, 0%~3%, 3%~5%, 5%~7%, >7%）
- **可视化**：直方图展示
- **快速概览**：一键了解市场整体分布

---

## 设计哲学

行情中心采用 **Neon Flux** 科技风格设计理念：

- **视觉语言**：深邃的背景、发光的元素、半透明的卡片
- **色彩系统**：电光青、洋红、翡翠绿在深色背景上跳动
- **数据可视化**：颜色即信息，红色代表下跌的紧迫，绿色代表上涨的动能
- **排版美学**：文字精简、数字突出，信息通过空间关系传达

完整设计哲学请参考：[design-philosophy.md](design-philosophy.md)

## 使用指南

### 查看指数行情
1. 进入行情中心页面
2. 顶部展示主要指数实时行情
3. 点击"刷新"按钮更新数据

### 浏览连板天梯
1. 滚动到"连板天梯"区域
2. 点击板块标签筛选（全部/主板/创业板/科创板/北证）
3. 查看各连板层级的股票排行

### 分析资金流向
1. 滚动到"行业资金流向"区域
2. 查看资金流入/流出TOP10行业
3. 红色代表流入，绿色代表流出

### 查看涨跌分布
1. 滚动到"涨跌分布"区域
2. 查看各涨跌幅区间的股票数量分布
3. 快速了解市场整体情绪

## 技术架构

### 前端
- **框架**：uni-app (Vue 3)
- **UI组件**：自定义组件 + uni-ui
- **状态管理**：Pinia
- **数据可视化**：自定义图表组件

### 后端
- **运行环境**：Node.js
- **框架**：Express.js
- **数据源**：外部金融API (http://123.60.27.66:7615/TQLEX)

### 数据流
```
外部金融API → 后端代理 → 前端请求 → UI展示
```

## API接口

### 市场数据接口
- **获取指数行情**：`GET /api/market/index`
- **获取市场概览**：`GET /api/market/overview`
- **获取连板天梯**：`GET /api/market/continuous-limits`
- **获取行业资金流向**：`GET /api/market/industry-flow`
- **获取涨跌分布**：`GET /api/market/distribution`

详细API文档请参考：[API文档](../../core/API文档.md)
