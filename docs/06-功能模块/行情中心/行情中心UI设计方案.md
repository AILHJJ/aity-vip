# 行情中心UI设计方案

## 一、设计概述

### 1.1 项目背景
重新设计行情中心页面，替换现有 `pages/market/market.vue`，打造更具科技感和视觉冲击力的金融数据展示界面。

### 1.2 设计目标
- **视觉冲击**：科技感风格，深色背景 + 霓虹色彩 + 动态光效
- **信息层次**：卡片折叠式布局，首页摘要 + 点击展开详情
- **用户体验**：流畅的交互动画，清晰的数据可视化

## 四、组件设计

### 4.1 市场温度计

**功能**：展示市场整体情绪和涨跌分布

**数据来源**：`HQServ.PBHQInfo` 接口

**核心元素**：
- 环形仪表盘：显示市场情绪分数（0-100）
- 四象统计：上涨/下跌/涨停/跌停家数
- 涨跌分布条：可视化各区间的股票分布

**交互**：
- 点击"查看详细分布"展开更多数据

### 4.2 指数行情卡片

**功能**：展示主要指数实时行情

**数据来源**：`HQServ.IndexQuote` 接口

**核心元素**：
- 指数名称
- 当前价格（大字突出）
- 涨跌幅（带颜色标识）

**交互**：
- 横向滑动查看更多指数
- 点击进入指数详情页（可选）

### 4.3 连板天梯

**功能**：展示连续涨停股票排行

**数据来源**：`HQServ.hq_nlp_app_misc` 接口（NLP详细版）

**核心元素**：
- 最高连板数 + 涨停总数
- 各级别标签（8板、6板、5板...）
- 股票卡片：名称、价格、封单额、换手率、涨停原因

**交互**：
- 点击"查看完整天梯"进入详情页
- 详情页按连板高度分组展示

### 4.4 资金流向

**功能**：展示行业资金净流入/流出排行

**数据来源**：`HQServ.PBXmlBlock` 接口

**核心元素**：
- Tab切换：流入/流出
- 排行列表：排名、行业名、金额、占比
- 涨跌统计：涨/跌/涨停数

**交互**：
- Tab切换流入/流出
- 点击"查看更多"展开完整列表

## 五、动效规范

### 5.1 加载动画

```css
/* 脉冲发光 */
@keyframes pulse {
  0%, 100% { opacity: 0.5; transform: scale(1); }
  50% { opacity: 1; transform: scale(1.1); }
}

/* 旋转刷新 */
@keyframes spin {
  to { transform: rotate(360deg); }
}
```

### 5.2 交互反馈

| 交互 | 效果 |
|------|------|
| 点击卡片 | 轻微缩放 + 背景变亮 |
| 展开详情 | 向下滑动 + 渐显 |
| Tab切换 | 淡入淡出 |
| 下拉刷新 | 旋转动画 |

## 八、接口对接

### 8.1 需要对接的接口

| 接口 | Entry | 用途 |
|------|-------|------|
| 市场概览 | `HQServ.PBHQInfo` | 市场温度计数据 |
| 指数行情 | `HQServ.IndexQuote` | 主要指数数据 |
| 连板天梯 | `HQServ.hq_nlp_app_misc` | 连板股票详细数据 |
| 资金流入 | `HQServ.PBXmlBlock` (MStock_ZLJX_ADDE_R) | 行业资金流入 |
| 资金流出 | `HQServ.PBXmlBlock` (MStock_ZLJX_ADDE) | 行业资金流出 |

### 8.2 后端API封装

建议在后端创建统一的行情API代理，避免前端直接访问外部接口：

```
GET /api/market/overview      # 市场概览
GET /api/market/index         # 指数行情
GET /api/market/ladder        # 连板天梯
GET /api/market/fund-flow     # 资金流向
```

## 十、验收标准

1. **视觉还原**：与原型图视觉一致性 > 95%
2. **性能要求**：首屏加载 < 2s，交互响应 < 100ms
3. **兼容性**：微信小程序 iOS/Android 双端正常
4. **数据正确**：所有数据从真实接口获取并正确展示
5. **交互流畅**：动画无卡顿，展开收起顺畅
