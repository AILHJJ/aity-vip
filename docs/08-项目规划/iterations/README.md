## 🔄 优化历史

### 优化记录 #8 - 用户隔离与交互全面优化（2026-02-12）

#### 优化背景

**用户体验问题汇总**：
1. 用户反馈：所有登录用户看到的图灵页面对话历史都相同
2. 用户反馈：图灵页面输入完成后无法收起键盘
3. 用户反馈：顶部按钮"新对话"被其他交互元素遮挡
4. 产品需求：需要移除深度思考功能（不是核心功能）
5. 产品需求：需要正确处理金融工具返回的原始JSON数据
6. 产品需求：涨跌幅应该"涨红跌绿"（符合中国股市习惯）
7. 产品需求：数字需要正确格式化（千分位、小数位数、百分比）

---

#### 优化内容

**1. 用户数据隔离（ai-advisor-config.js）**

**问题**：
- ❌ 所有用户登录后看到相同的对话历史
- ❌ 所有用户共享同一个 `threadId` 和 `chat_history`

**解决方案**：
- ✅ 新增 `getUserStorageKey(key)` 函数
- ✅ 基于用户ID生成专属存储key：`ai_advisor_{userId}_{key}`
- ✅ 所有存储函数使用用户专属key

**修改文件**：
- `src/utils/ai-advisor-config.js` (+20行)

**效果**：
- ✅ 用户A只看到用户A的历史
- ✅ 用户B只看到用户B的历史
- ✅ 数据完全隔离，互不干扰
- ✅ 刷新页面后恢复当前用户的对话

**5. threadId参数传递与上下文对话（已正确实现）**

**验证内容**：
- ✅ SSE解析器已正确处理 `messages/tool` 和 `messages/tool_result` 事件
- ✅ `sendAIMessage()` 正确获取并传递 `threadId`
- ✅ `handleMetadata()` 正确保存 `thread_id`
- ✅ `handleNewSession()` 正确清空 `threadId`

**数据流程**：
```
用户首次对话 → threadId: "" → 后台创建新会话
↓
返回 metadata 事件 → 包含 thread_id
↓
自动保存到本地存储（按用户隔离）
↓
用户后续对话 → 自动带上 threadId
↓
实现上下文连续对话记忆
↓
用户点击"新对话" → 清空 threadId
↓
下次对话传递空字符串 → 后台创建新会话
```

**状态**：✅ 已完整实现，无需修改

#### 技术决策记录

**为什么不实现某些功能**：
1. **表格排序**：
   - 原因：需要维护排序状态，增加复杂度
   - 决策：暂不实现，用户可通过查看原始JSON数据排序

2. **万亿格式自动判断**：
   - 原因：参考项目的万亿判断逻辑复杂
   - 决策：简化实现，仅支持>=1亿，不追求完全自动

3. **表格横向滚动**：
   - 原因：需要处理横向滚动事件，增加交互复杂度
   - 决策：使用原生横向滚动，性能更好

**为什么采用参考项目的方案**：
1. **数据结构**：3层数组是标准格式，字段定义清晰
2. **格式化标识**：`"2|0|0"` 这种设计灵活，易于扩展
3. **颜色规则**：涨红跌绿符合中国股市习惯
4. **成熟度**：参考项目已在生产环境验证，可靠性高

**可优化点**：
1. 考虑将数据处理逻辑抽取为独立的工具类（`financialDataParser`）
2. 考虑添加单元测试，覆盖各种格式化场景
3. 考虑添加TypeScript类型定义，提升代码可维护性

#### 附录：快速参考

**LangGraph SSE事件类型**：
| 事件 | 数据内容 | 处理方式 |
|------|---------|---------|
| `messages/partial` | 流式AI文本 | 显示thinking/content |
| `messages/metadata` | thread_id、run_id | 保存threadId |
| `messages/tool` | 工具调用 | 显示"正在调用工具" |
| `messages/tool_result` | 工具响应JSON | **渲染表格数据** |
| `messages/complete` | AI总结文本 | 显示markdown |

**数据结构**：
```javascript
[
  [0, "", 0, "", "0"],  // 元数据
  ["POS", "market", "sec_code", "sec_name", "now_price", "chg0#", "所属行业", "timestamps"],  // 字段定义
  ["", "", "", "2|0|0", "2|0|0", "0|0|0", ""],  // 格式化标识
  ["000001", "沪市", "平安银行", "12.45", "2.35", "银行业", "2024-01-15 10:30:00"]  // 实际数据
]
```

**格式化标识解析**：
```javascript
"2|0|0"  // 涨跌幅+2位小数+颜色（typeFlag=2）
"1|0|0"  // 千分位+符号（typeFlag=1）
"0|0|0"  // 文本类型，不做格式化（typeFlag=0）
```
