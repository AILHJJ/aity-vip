## 二、设计方案

### 2.1 设计决策

**决策1: 模型特定提示词配置**
- **背景**: 不同AI模型的特点和能力差异很大，统一提示词无法充分发挥各模型优势
- **方案**: 为每个AI模型配置专属提示词，根据模型特点调整优化策略
- **原因**: 推理模型需要强调逻辑严密，快速模型需要强调简洁有力，通俗模型需要增强可读性
- **影响**: 提升各模型的优化效果，提高输出质量和一致性

**决策2: 三级提示词优先级机制**
- **背景**: 用户需要灵活配置提示词，同时要有合理的默认值
- **方案**: 数据库自定义提示词 > 代码中模型特定提示词 > 通用默认提示词
- **原因**: 平衡灵活性和易用性，用户可以自定义，也有合理默认值
- **影响**: 增强系统灵活性，用户可以根据需求调整

**决策3: 集中式配置管理**
- **背景**: 16个模型的提示词需要统一管理和维护
- **方案**: 在代码中定义MODEL_SPECIFIC_PROMPTS对象，集中管理所有模型提示词
- **原因**: 便于维护、更新和版本控制，清晰的代码结构
- **影响**: 提高可维护性，降低维护成本

### 2.2 技术方案

**提示词设计原则**（统一核心要求）:
1. **信息完整**: 保留原文所有信息、数据、URL，不删除、不添加、不篡改
2. **格式规范**: Markdown格式（### 标题、- 列表、** 粗体）
3. **结构优化**: 核心观点置顶（1-2句话），关键信息列表化
4. **突出重点**: 操作建议醒目标注，关键数据突出显示
5. **直接输出**: 无开场白、结束语，用户可直接使用

**模型特性适配策略**:
- **推理能力强**（DeepSeek-R1, GLM-4.7）: 强调逻辑严密、深度分析、论证充分，适用复杂投资分析
- **速度快**（Qwen-Flash, Turbo）: 强调快速响应、简洁有力，适用大批量快速处理
- **通俗易懂**（豆包）: 强调简化表达、增强可读性，适用普通投资者
- **综合能力强**（Qwen3-Max）: 强调专业视角、全面优化，适用高质量内容

**实际提示词示例**（供后续参考）:

**推理模型提示词示例**（DeepSeek-R1）:
```
你是专业的投资研究助手，擅长逻辑推理和深度分析。

【核心要求】
1. 保留原文所有信息、数据、URL链接
2. 梳理逻辑关系，强化论证过程
3. 深度挖掘数据背后的投资逻辑
4. Markdown格式：### 标题、- 列表、**粗体**

【输出格式】
### 核心观点
（1-2句话概括最关键的投资逻辑）

### 详细分析
- 逻辑论证：梳理观点之间的逻辑关系
- 数据分析：深度挖掘数据含义
- 投资逻辑：提炼核心投资逻辑

### 操作建议
（操作建议醒目标注，含标的、价位、时机）

直接输出优化结果，无开场白、结束语。
```

**快速模型提示词示例**（Qwen-Turbo）:
```
你是专业的投资研究助手，快速简洁地优化投研内容。

【核心要求】
1. 保留所有信息、数据、URL
2. 极简优化，核心置顶
3. 简洁有力，突出重点

【输出格式】
### 核心观点
（1句话）

### 要点列表
- 关键信息1
- 关键信息2

### 操作建议
（标的、价位、时机）

直接输出，无冗余。
```

**避免踩坑**:

1. **提示词长度控制**: 过长会影响响应速度和成本，要根据模型定位调整长度
2. **核心要求一致性**: 所有模型的核心要求必须一致（信息完整、格式规范），差异仅在于优化策略侧重点
3. **模板字符串转义**: 在代码中定义提示词时注意反引号和`${}`的转义
4. **向后兼容性**: 新增功能不应影响现有功能，默认行为保持一致
5. **文档同步更新**: 代码更新后及时更新文档，确保文档与代码一致
