## 📝 任务详细说明

### 任务1: 消息中心页面UI优化

#### 需求背景
当前消息中心页面的筛选部分占用空间过大，推送范围需要展开才能查看，消息类型文字过长，影响管理员操作体验。

#### 技术方案
1. **前端界面优化**:
   - 压缩筛选部分的padding和margin
   - 使用更紧凑的布局（如flex布局）
   - 推送范围直接显示为标签（如"全部"、"短线"）
   - 新增"置顶"消息类型

2. **消息类型简化**:
   - 将现有消息类型改为2个字：
     - "持仓分析" → "持仓"
     - "机会快讯" → "机会"
     - "个股解盘" → "解盘"
     - "风控提示" → "风控"
     - "系统通知" → "系统"
     - "交流讨论" → "交流"

3. **后端调整**（如需）:
   - 在`message_types`表中添加"置顶"类型
   - 调整消息类型字段长度（VARCHAR(2)）

#### 拆分步骤
1. 修改消息中心页面的筛选部分样式
2. 修改消息类型显示为2个字
3. 新增"置顶"消息类型
4. 测试所有功能

#### 测试计划
- [ ] 测试筛选部分是否更紧凑
- [ ] 测试推送范围是否直接显示
- [ ] 测试消息类型是否为2个字
- [ ] 测试"置顶"类型是否正常工作

### 任务2: 消息列表优化

#### 需求背景
当前消息列表中，时间显示单独占一行，浪费屏幕空间；推送范围没有明确显示。

#### 技术方案
1. **布局调整**:
   - 将时间显示和消息标签放在同一行
   - 使用flex布局，左对齐标签，右对齐时间
   - 确保两个标签（消息类型+推送范围）都能显示

2. **信息展示**:
   - 在消息卡片中明确显示推送范围（"全部"或"短线"）
   - 使用不同颜色区分不同类型的标签

#### 拆分步骤
1. 修改消息列表的布局样式
2. 添加推送范围显示
3. 调整标签样式，确保两个标签都能显示
4. 测试所有功能

2. **消息标签管理功能修复**:

### 任务4: 行情中心页面UI重设计

#### 需求背景
当前行情中心页面缺乏金融科技感，用户阅读体验有待提升。

#### 技术方案
1. **配色方案**:
   - 主色调：深蓝色（代表科技、专业）
   - 辅助色：金色/橙色（代表金融、活跃）
   - 背景色：浅灰/白色（保证可读性）
   - 涨跌颜色：红涨绿跌（符合中国股市习惯）

2. **字体选择**:
   - 使用无衬线字体（如PingFang SC、Microsoft YaHei）
   - 数字使用等宽字体（如DIN、Roboto Mono）

3. **布局优化**:
   - 使用卡片式设计，信息层次更清晰
   - 重点信息（如涨跌幅）使用大字号、粗体
   - 使用投影、边框等视觉元素增强层次感

4. **参考设计**:
   - 同花顺、东方财富等金融APP的设计风格
   - Material Design或iOS的设计规范

#### 拆分步骤
1. 制定配色方案和字体方案
2. 重新设计行情中心页面的布局
3. 实施新的样式（CSS/SCSS）
4. 测试所有功能

#### 测试计划
- [ ] 测试页面是否具有金融科技感
- [ ] 测试用户体验是否提升
- [ ] 测试信息层次是否清晰
- [ ] 测试不同屏幕尺寸下的显示效果
