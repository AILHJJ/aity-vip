# AI投顾配置指南

> 本文档介绍AI投顾模块的配置方法和使用说明
> 最后更新：2026-02-28

---

## 📋 概述

AI投顾模块支持多模型配置和版本管理，管理员可以在后台灵活配置AI模型参数。

---

## 🔧 配置入口

管理员登录后，访问 **管理后台 → AI配置** 页面进行配置。

---

## 📝 配置项说明

### 基础配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 模型名称 | AI模型显示名称 | GLM-4 |
| API地址 | AI服务API地址 | - |
| API密钥 | API认证密钥 | - |

### 高级配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 温度(Temperature) | 控制回复随机性 | 0.7 |
| 最大Token数 | 单次回复最大长度 | 2048 |
| 系统提示词 | AI角色设定 | - |

---

## 🔄 版本管理

### 版本规则

- 每次保存配置会自动创建新版本
- 版本号格式: v1.0.0
- 支持回滚到历史版本

### 版本操作

1. **查看历史**: 点击"版本历史"查看所有版本
2. **回滚版本**: 选择历史版本，点击"回滚"
3. **比较差异**: 选择两个版本进行对比

---

## 🔌 多模型配置

### 添加新模型

1. 点击"添加模型"
2. 填写模型名称和API配置
3. 保存后即可在列表中看到

### 切换模型

在模型列表中，点击"设为默认"即可切换当前使用的模型。

### 支持的模型类型

- GLM系列（智谱AI）
- 通义千问（阿里云）
- 文心一言（百度）
- 自定义OpenAI兼容接口

---

## 🛠️ 常见问题

### Q: 如何测试配置是否正确？

在配置页面点击"测试连接"按钮，系统会发送测试请求验证配置。

### Q: 配置保存在哪里？

配置保存在数据库 `ai_configs` 表中，支持环境变量覆盖。

### Q: 如何批量导入配置？

支持通过JSON文件批量导入配置，格式参考：

```json
{
  "name": "GLM-4",
  "apiUrl": "https://open.bigmodel.cn/api/paas/v4/chat/completions",
  "model": "glm-4",
  "temperature": 0.7,
  "maxTokens": 2048
}
```
