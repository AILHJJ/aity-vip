## 🔍 各层详解

### 第0行：元数据

**格式**: `[0, "", 0, "", "0", "", ...]`

**作用**:
- 提供字段的唯一标识符（POS）
- 用于字段映射和数据索引

**示例**:
```javascript
[0, "", 0, "", "0", "", ""]
  ↓   ↓   ↓   ↓   ↓   ↓
  0   1   2   3   4   5    // 位置索引
```

**用途**: 将位置索引映射到字段名称
- 位置3对应字段"sec_name"
- 位置4对应字段"now_price"

---

### 第1行：字段定义

**格式**: `["POS", "market", "sec_code", "sec_name", "now_price", "chg0#", "所属行业", "timestamps"]`

**作用**: 定义每列数据的业务含义

**常见字段**:

| 字段名 | 含义 | 示例值 |
|--------|------|--------|
| `POS` | 位置标识 | "0", "1", "2" |
| `market` | 市场代码 | "1"=沪市, "0"=深市 |
| `sec_code` | 证券代码 | "000001", "600000" |
| `sec_name` | 证券名称 | "平安银行", "万科A" |
| `now_price` | 现价 | "12.45", "35.67" |
| `chg0#` | 涨跌幅 | "2.35", "-1.2" |
| `所属行业` | 所属行业 | "银行业", "房地产业" |
| `timestamps` | 时间戳 | "2024-01-15 10:30:00" |

**字段映射规则**:

```javascript
// 创建字段映射：row0[index] -> row1[index]
const fieldMapping = {}
row1.forEach((field, index) => {
  fieldMapping[row0[index]] = field
})

// 示例：
// row0[3] = "3"
// row1[3] = "sec_name"
// fieldMapping["3"] = "sec_name"
```

---

### 第2行：格式化标识

**格式**: `["", "", "", "2|0|0", "2|0|0", "0|0|0", "" ]`

**作用**: 定义每列数据的格式化规则（颜色、千分位、百分比等）

**标识格式**: `"typeFlag|subType|specialFlag"`

**参数说明**:

| 参数 | 位置 | 可能值 | 说明 |
|------|------|--------|------|
| `typeFlag` | 第1位 | "0", "1", "2", "3" | 决定格式化类型和颜色规则 |
| `subType` | 第2位 | "0", "1", "2" | 决定子格式（千分位、百分比） |
| `specialFlag` | 第3位 | "0", "1" | 特殊标识（前缀符号等） |

---

## 🎨 格式化标识详解

### typeFlag（第1位）

#### typeFlag = "0"：文本类型

**含义**: 文本类型，不做格式化

**示例**:
```javascript
"0|0|0"  // 文本类型，原样显示
```

**处理**: 直接返回原始值

---

#### typeFlag = "1"：涨跌幅（默认规则）

**含义**: 涨跌幅字段，默认颜色规则

**示例**:
```javascript
"1|0|0"  // 涨跌幅+默认颜色规则
```

**颜色规则**:
- 正数(>0): **红色** `<span class="color-up">2.35%</span>`
- 负数(<0): **绿色** `<span class="color-down">1.2%</span>`
- 零(=0): 默认颜色 `<span>0.0%</span>`

**CSS定义**:
```css
.color-up {
  color: #fc4a4a;  /* 上涨：红色 */
}

.color-down {
  color: #229d45;  /* 下跌：绿色 */
}
```

---

#### typeFlag = "2"：涨跌幅（反向规则）

**含义**: 涨跌幅字段，反向颜色规则

**示例**:
```javascript
"2|0|0"  // 涨跌幅+反向颜色规则
```

**颜色规则**:
- 正数(>0): **绿色** `<span class="color-down">2.35%</span>`
- 负数(<0): **红色** `<span class="color-up">1.2%</span>`
- 零(=0): 默认颜色

**使用场景**: 某些金融指标可能需要反向颜色（如融资融券）

---

#### typeFlag = "3"：涨跌幅（特殊规则）

**含义**: 涨跌幅字段，特殊规则（>1涨，≤1跌）

**示例**:
```javascript
"3|0|0"  // 涨跌幅+特殊规则
```

**颜色规则**:
- >1: **红色** `<span class="color-up">2.35%</span>`
- ≤-1: **绿色** `<span class="color-down">1.2%</span>`
- -1到1之间: 默认颜色

**使用场景**: 特殊的涨跌判断标准

---

### subType（第2位）

#### subType = "0"：不处理

**含义**: 不进行子格式化

**示例**:
```javascript
"1|0|0"  // 涨跌幅，不进行子格式化
```

---

#### subType = "1"：千分位格式化

**含义**: 添加千分位分隔符

**示例**:
```javascript
"1|1|0"  // 价格字段+千分位格式
```

**格式化规则**:
```javascript
function formatThousands(num) {
  const str = num.toString()
  const parts = str.split('.')
  parts[0] = parts[0].replace(/\B(?=(\d{3})+(?!\d))/g, ',')
  return parts.join('.')
}
```

**效果对比**:
```
原始值: 1234567.89
格式化: 1,234,567.89
```

---

#### subType = "2"：百分比格式化

**含义**: 添加百分号和符号

**示例**:
```javascript
"1|2|0"  // 涨跌幅+百分比格式
```

**格式化规则**:
```javascript
function formatPercentage(num) {
  const sign = num > 0 ? '+' : ''
  return `${sign}${num.toFixed(2)}%`
}
```

**效果对比**:
```
原始值: 2.35
格式化: +2.35%

原始值: -1.2
格式化: -1.2%
```

---

### specialFlag（第3位）

#### specialFlag = "0"：默认规则

**含义**: 使用默认规则，无特殊处理

---

#### specialFlag = "1"：添加前缀符号

**含义**: 添加前缀符号（如"+"号）

**示例**:
```javascript
"1|0|1"  // 价格字段+前缀符号
```

**效果对比**:
```
原始值: 12.45
格式化: +12.45
```

## 🔧 完整格式化逻辑

### 代码实现

```javascript
function formatCellValue(value, formatFlag, fieldName, rowData) {
  // 解析格式化标识："2|0|0"
  const flags = formatFlag ? formatFlag.split('|') : []

  const typeFlag = flags[0] || '0'
  const subType = flags[1] || '0'
  const specialFlag = flags[2] || '0'

  // 获取原始数值
  let numValue = parseFloat(value)

  // === 涨跌幅字段 ===
  if (isChangeField(fieldName)) {
    if (typeFlag === '1') {
      // 默认规则：正数涨红，负数跌绿
      if (numValue > 0) {
        return `<span class="color-up">${numValue}%</span>`
      } else if (numValue < 0) {
        return `<span class="color-down">${Math.abs(numValue)}%</span>`
      } else {
        return `<span>${numValue}%</span>`
      }
    }
    if (typeFlag === '2') {
      // 反向规则：正数跌绿，负数涨红
      if (numValue > 0) {
        return `<span class="color-down">${numValue}%</span>`
      } else if (numValue < 0) {
        return `<span class="color-up">${Math.abs(numValue)}%</span>`
      } else {
        return `<span>${numValue}%</span>`
      }
    }
    if (typeFlag === '3') {
      // 特殊规则：>1涨，≤1跌
      if (numValue > 1) {
        return `<span class="color-up">${numValue}%</span>`
      } else if (numValue < -1) {
        return `<span class="color-down">${Math.abs(numValue)}%</span>`
      } else {
        return `<span>${numValue}%</span>`
      }
    }
  }

  // === 价格字段 ===
  if (fieldName === 'now_price') {
    // 小数位数控制：2位或3位
    const decimals = typeFlag === '2' ? 2 : (typeFlag === '3' ? 3 : 2)
    const prefix = specialFlag === '1' ? '+' : ''
    return `${prefix}${numValue.toFixed(decimals)}`
  }

  // === 百分比字段 ===
  if (subType === '2') {
    const sign = numValue > 0 ? '+' : ''
    return `${sign}${numValue.toFixed(2)}%`
  }

  // === 千分位处理 ===
  if (subType === '1') {
    return formatThousands(numValue)  // 1,234.56
  }

  // === 万亿处理 ===
  if (Math.abs(numValue) >= 100000000) {
    return (numValue / 100000000).toFixed(2) + '亿'
  }

  return value
}
```

## 📚 使用示例

### 解析3层数据

```javascript
// 原始数据
const data = [
  [0, "", 0, "", "0", "", ""],
  ["POS", "market", "sec_code", "sec_name", "now_price", "chg0#", "所属行业", "timestamps"],
  ["", "", "", "2|0|0", "1|0|0", "0|0|0", ""],
  ["000001", "1", "000001", "平安银行", "12.45", "2.35", "银行业", "2024-01-15 10:30:00"]
]

// 1. 提取各行
const row0 = data[0]  // 元数据
const row1 = data[1]  // 字段定义
const row2 = data[2]  // 格式化标识
const rows = data.slice(3)  // 实际数据

// 2. 创建字段映射
const fieldMapping = {}
row1.forEach((field, index) => {
  fieldMapping[row0[index]] = field
})
// 结果: { "3": "sec_name", "4": "now_price", "5": "chg0#" }

// 3. 创建格式化标识映射
const formatFlags = {}
row2.forEach((flag, index) => {
  formatFlags[row0[index]] = flag
})
// 结果: { "3": "", "4": "1|0|0", "5": "2|0|0" }

// 4. 格式化单元格
const cellValue = "12.45"
const fieldName = "now_price"
const formatFlag = formatFlags["4"]  // "1|0|0"

const formattedCell = formatCellValue(cellValue, formatFlag, fieldName, row)
// 结果: "12.45"
```

### 渲染表格

```javascript
// 生成HTML表格
let tableHtml = '<table class="tool-result-table">'

// 表头
tableHtml += '<thead><tr>'
Object.values(fieldMapping).forEach(header => {
  tableHtml += `<th>${header}</th>`
})
tableHtml += '</tr></thead>'

// 数据行
tableHtml += '<tbody>'
rows.forEach(row => {
  tableHtml += '<tr>'
  row.forEach((cell, index) => {
    const fieldName = Object.keys(fieldMapping)[index]
    const formatFlag = formatFlags[fieldName]
    const formattedCell = formatCellValue(cell, formatFlag, fieldName, row)
    tableHtml += `<td>${formattedCell}</td>`
  })
  tableHtml += '</tr>'
})
tableHtml += '</tbody></table>'
```
