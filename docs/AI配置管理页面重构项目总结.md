## 项目目标

### 原有问题
1. ❌ 功能按钮组织混乱（"一键测试全部"和"提示词管理"在一起）
2. ❌ 列表过长（所有厂商模型全部展示）
3. ❌ 操作按钮不直观（仅emoji图标）
4. ❌ 按钮文字过长（"应用到所有模型"、"恢复默认"）

### 解决方案
1. ✅ Tab切换设计（模型管理/提示词管理/连接测试）
2. ✅ 厂商下拉选择器（一次显示一个厂商）
3. ✅ 文字+图标操作按钮
4. ✅ 简化按钮文字（"应用全部"、"恢复"）

### 关键技术点

#### 1. Tab切换实现
```javascript
const activeTab = ref('models')

const switchTab = (tab) => {
  activeTab.value = tab
  if (tab === 'prompts' && !currentPrompt.value) {
    loadCurrentPrompt()
  }
}
```

#### 2. 厂商选择器
```javascript
const selectedProviderIndex = ref(0)

const currentProvider = computed(() => {
  if (providers.value.length === 0) return null
  return providers.value[selectedProviderIndex.value]
})

const providerOptions = computed(() => {
  return providers.value.map(p => ({
    label: p.providerName,
    value: p.provider
  }))
})
```
