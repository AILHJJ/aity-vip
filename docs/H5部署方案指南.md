# H5 项目部署方案指南

## 📋 文档概述

本文档为开发团队提供 H5 项目的多种部署方案，包括本地测试、腾讯云部署、CI/CD 自动化部署等，帮助团队根据项目需求选择最合适的部署策略。

**适用人群**：前端开发、运维工程师、全栈开发

## 1. 部署方案概览

### 1.1 方案对比

| 部署方式 | 适用场景 | 技术门槛 | 成本 | 维护难度 |
|---------|---------|---------|------|---------|
| **本地静态服务器** | 开发测试 | 低 | 免费 | 低 |
| **腾讯云 Webify** | 生产环境 | 低 | 按量付费 | 极低 |

```

    │
    ├── 个人项目/小型团队
```

## 2. 本地测试部署

### 2.1 使用开发服务器

```bash
# 进入项目目录
cd d:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2

# 启动开发服务器
npm run dev:h5

# 访问地址
# http://localhost:5173
```

**特点**：
- ✅ 支持热更新
- ✅ 有源码映射，便于调试
- ❌ 性能较低，不适合测试生产构建

### 2.2 使用静态服务器（推荐用于测试生产构建）

```bash
# 1. 编译 H5 项目
npm run build:h5

# 2. 使用 npx serve 托管编译产物
npx serve dist/build/h5 -p 8080

# 3. 访问地址
# http://localhost:8080
```

**特点**：
- ✅ 使用生产构建产物
- ✅ 更接近真实生产环境
- ✅ 启动速度快
- ❌ 不支持热更新

### 2.3 本地部署对比

| 特性 | 开发服务器 | 静态服务器 |
|------|-----------|-----------|
| 启动命令 | `npm run dev:h5` | `npx serve dist/build/h5 -p 8080` |
| 访问地址 | http://localhost:5173 | http://localhost:8080 |
| 热更新 | ✅ 支持 | ❌ 不支持 |
| 源码映射 | ✅ 有 | ❌ 无 |
| 生产环境模拟 | ❌ 不完全 | ✅ 更接近 |
| 适用场景 | 开发调试 | 测试生产构建 |

## 3. 腾讯云部署方案

### 3.1 方案一：腾讯云静态网站托管（Webify）⭐ 推荐

#### 3.1.1 方案优势

- **简单易用**：可视化操作，无需服务器运维知识
- **成本优化**：按实际使用量付费，无需预购服务器
- **自动化**：支持 Git 集成，自动部署
- **内置功能**：自动 HTTPS、CDN 加速、自定义域名

#### 3.1.2 部署步骤

**方式 A：手动上传部署**

```bash
# 1. 编译项目
npm run build:h5

# 2. 登录腾讯云控制台
# 访问：https://console.cloud.tencent.com/webify

# 3. 创建新项目
# - 点击"新建项目"
# - 选择"静态网站托管"

# 4. 上传文件
# - 上传 dist/build/h5 目录下的所有文件
# - 或拖拽文件夹到控制台

# 5. 获取访问地址
# - 系统会自动分配临时域名
# - 如：https://your-project-xxx.webify.app
```

**方式 B：Git 自动部署（推荐）**

```bash
# 1. 将代码推送到 GitHub/GitLab
git add .
git commit -m "Update H5 project"
git push origin main

# 2. 在腾讯云 Webify 中配置
# - 选择"导入 Git 仓库"
# - 授权访问 GitHub/GitLab
# - 选择项目仓库

# 3. 配置构建设置
# 构建命令：npm run build:h5
# 输出目录：dist/build/h5

# 4. 自动部署
# - 每次推送到 main 分支会自动触发部署
# - 支持预览部署（Pull Request）
```

#### 3.1.3 配置自定义域名

```
1. 在 Webify 控制台选择"域名管理"
2. 点击"添加域名"
3. 输入您的域名（如：h5.yourdomain.com）
4. 按照提示配置 DNS 解析
5. 等待 SSL 证书自动颁发
6. 完成！
```

### 3.2 方案二：云服务器 + Nginx

#### 3.2.1 适用场景

- 需要部署后端服务
- 需要完全控制服务器环境
- 有专业的运维团队

#### 3.2.2 部署步骤

**步骤 1：准备云服务器**

```bash
# 购买腾讯云服务器（CVM）
# 推荐配置：2核4G，带宽 5Mbps
# 系统：Ubuntu 20.04 LTS
```

**步骤 2：上传文件到服务器**

```bash
# 本地执行：上传编译产物
scp -r dist/build/h5/* user@your-server:/var/www/h5/

# 或使用 rsync（支持增量上传）
rsync -avz --delete dist/build/h5/ user@your-server:/var/www/h5/
```

**步骤 3：安装和配置 Nginx**

```bash
# SSH 登录服务器
ssh user@your-server

# 安装 Nginx
sudo apt update
sudo apt install nginx

# 配置站点
sudo nano /etc/nginx/sites-available/h5-app
```

**Nginx 配置示例**：

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/h5;
    index index.html;

    # 启用 gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;

    # 处理单页应用路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 缓存静态资源
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

**步骤 4：启用配置并重启 Nginx**

```bash
# 创建符号链接
sudo ln -s /etc/nginx/sites-available/h5-app /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

**步骤 5：配置 HTTPS（SSL）**

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx

# 申请 SSL 证书
sudo certbot --nginx -d your-domain.com

# 自动续期（Certbot 会自动配置）
```

## 4. CI/CD 自动化部署

### 4.1 GitHub Actions 自动化部署

#### 4.1.1 配置工作流

创建文件：`.github/workflows/deploy-h5.yml`

```yaml
name: Deploy H5 to Tencent Cloud

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    
    steps:
    # 检出代码
    - name: Checkout code
      uses: actions/checkout@v3
    
    # 设置 Node.js
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        cache: 'npm'
    
    # 安装依赖
    - name: Install dependencies
      run: npm ci
    
    # 构建项目
    - name: Build H5
      run: npm run build:h5
    
    # 部署到腾讯云 Webify
    - name: Deploy to Webify
      uses: tencent-cloud/webify-deploy-action@v1
      with:
        api-id: ${{ secrets.TENCENT_WEBIFY_API_ID }}
        api-key: ${{ secrets.TENCENT_WEBIFY_API_KEY }}
        project-id: ${{ secrets.TENCENT_WEBIFY_PROJECT_ID }}
        dist-dir: ./dist/build/h5
```

#### 4.1.2 配置 Secrets

在 GitHub 仓库设置中添加以下 Secrets：

```
TENCENT_WEBIFY_API_ID     # 腾讯云 API ID
TENCENT_WEBIFY_API_KEY    # 腾讯云 API Key
TENCENT_WEBIFY_PROJECT_ID # Webify 项目 ID
```

### 4.2 自动化部署流程

```
开发者推送代码
    │
    ▼
GitHub Actions 触发
    │
    ├── 安装依赖
    ├── 构建 H5 项目
    ├── 运行测试（可选）
    └── 部署到腾讯云
    │
    ▼
自动通知部署结果
```

## 5. 部署方案选择指南

### 5.1 决策树

```
开始部署
    │
    ├── 只是本地测试？
    │   ├── 需要热更新？ → 使用开发服务器
    │   └── 测试生产构建？ → 使用静态服务器
    │
    ├── 需要生产环境？
    │   ├── 有后端服务？
    │   │   ├── 有运维团队？ → 云服务器 + Nginx
    │   │   └── 无运维团队？ → 考虑 Serverless
    │   │
    │   └── 纯前端项目？
    │       ├── 需要自定义域名？
    │       │   ├── 是 → 腾讯云 Webify + 自定义域名
    │       │   └── 否 → 腾讯云 Webify（临时域名）
    │       │
    │       └── 需要 CI/CD？
    │           ├── 是 → Webify + GitHub Actions
    │           └── 否 → 手动上传部署
```

### 5.2 场景推荐

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| **个人项目** | 腾讯云 Webify | 免费额度足够，简单易用 |
| **初创团队** | 腾讯云 Webify + 自定义域名 | 成本低，快速上线 |
| **中型企业** | Webify + CI/CD | 自动化部署，团队协作 |
| **大型项目** | 云服务器 + Nginx + CI/CD | 完全控制，性能优化 |
| **需要后端** | 云服务器 + Docker | 统一部署前端后端 |

## 6. 常见问题与解决方案

### 6.1 部署失败

**问题**：上传到服务器后页面空白

**解决方案**：
```bash
# 检查文件是否完整
ls -la /var/www/h5/

# 检查 Nginx 配置
cat /etc/nginx/sites-available/h5-app

# 检查错误日志
sudo tail -f /var/log/nginx/error.log
```

### 6.2 路由问题

**问题**：刷新页面 404

**解决方案**：
```nginx
# 在 Nginx 配置中添加
location / {
    try_files $uri $uri/ /index.html;
}
```

### 6.3 缓存问题

**问题**：更新后页面未变化

**解决方案**：
```bash
# 清除 Nginx 缓存
sudo rm -rf /var/cache/nginx/*

# 或添加版本号
# 在 index.html 中引用带 hash 的资源
```

### 6.4 HTTPS 问题

**问题**：SSL 证书配置失败

**解决方案**：
```bash
# 检查证书状态
sudo certbot certificates

# 重新申请证书
sudo certbot --nginx -d your-domain.com --force-renewal
```
