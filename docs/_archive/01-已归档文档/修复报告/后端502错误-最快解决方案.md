# 🚨 后端502错误 - 最快解决方案

## 问题根源

**确定原因**: 服务器上新增了`marketRoutes.js`,需要axios依赖,但服务器上没有运行`npm install`

**证据**:
- ✅ package.json里有axios
- ✅ 代码逻辑正确
- ❌ 服务器node_modules里没有axios
- ❌ 导致require('axios')失败
- ❌ 整个应用无法启动

---

## ⚡ 最快解决(在服务器上执行)

### 方案1: 一键修复(推荐)

```bash
cd /tmp/AITY/backend

# 安装依赖(包括axios)
npm install

# 重启服务
pm2 restart aity-backend

# 查看状态
pm2 status
pm2 logs aity-backend --lines 20
```

**预计耗时**: 30秒

---

### 方案2: 如果方案1不行,完整重建

```bash
cd /tmp/AITY/backend

# 1. 停止并删除旧服务
pm2 stop aity-backend
pm2 delete aity-backend

# 2. 安装依赖
npm install

# 3. 重新启动
pm2 start src/index.js --name "aity-backend"

# 4. 查看状态和日志
pm2 status
pm2 logs aity-backend --lines 30

# 5. 测试API
curl -I http://localhost:8443/api/auth/login
```

---

### 方案3: 临时禁用行情功能(快速恢复服务)

如果npm install太慢或网络有问题:

```bash
cd /tmp/AITY/backend

# 编辑index.js,注释掉marketRoutes
sed -i "s|app.use('/api/market', marketRoutes);|// app.use('/api/market', marketRoutes);|" src/index.js

# 重启
pm2 restart aity-backend

# 测试
curl -I http://localhost:8443/api/auth/login
```

**这样可以让服务先启动,之后再启用行情功能**
