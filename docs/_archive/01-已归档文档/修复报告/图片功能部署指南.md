## 方法一: 快速部署 (推荐)

### 1. SSH连接到腾讯云服务器

```bash
# SSH登录 (请替换为你的实际IP和用户)
ssh root@你的服务器IP

# 或使用密钥
ssh -i 你的密钥.pem root@你的服务器IP
```

### 2. 进入后端目录并拉取最新代码

```bash
# 进入项目目录
cd /root/AITY_VIP/backend

# 或你的实际部署路径
# cd /path/to/your/backend

# 拉取最新代码
git pull origin feature/iteration-1
```

### 3. 重启后端服务

```bash
# 使用PM2重启 (推荐)
pm2 restart aity-backend

# 或者如果服务名不同,先查看
pm2 list
pm2 restart 你的服务名

# 如果没有PM2,可以使用其他方式
npm run start
```

### 4. 验证部署

```bash
# 检查服务状态
pm2 status

# 查看日志
pm2 logs aity-backend

# 测试API
curl https://aity88.online:8443/health
```

### 5. 验证图片CORS修复

访问任意包含图片的消息,检查:
- ✅ 图片正常显示
- ✅ 浏览器控制台没有 CORS 错误
- ✅ 点击图片可以预览

## 故障排查

### 问题1: 图片仍然无法显示

**检查**:
```bash
# 检查静态文件目录权限
ls -la /root/AITY_VIP/backend/src/uploads/

# 确保目录可读
chmod -R 755 /root/AITY_VIP/backend/src/uploads/
```

### 问题2: CORS 错误仍然存在

**检查**:
```bash
# 查看后端日志
pm2 logs aity-backend

# 手动测试CORS头
curl -I https://aity88.online:8443/uploads/测试图片.jpg

# 应该看到:
# Access-Control-Allow-Origin: *
# Cross-Origin-Resource-Policy: cross-origin
```

### 问题3: 服务启动失败

**检查**:
```bash
# 查看详细错误
pm2 logs aity-backend --err

# 检查端口占用
netstat -tulpn | grep 3001

# 检查环境变量
cat /root/AITY_VIP/backend/.env
```

## 技术细节

本次更新的关键修改:

### 后端 (backend/src/index.js)
为 `/uploads` 静态文件服务添加了 CORS 响应头:
```javascript
app.use('/uploads', (req, res, next) => {
  res.header('Access-Control-Allow-Origin', '*');
  res.header('Access-Control-Allow-Methods', 'GET');
  res.header('Access-Control-Allow-Headers', 'Content-Type');
  res.header('Cross-Origin-Resource-Policy', 'cross-origin');
  next();
}, express.static(path.join(__dirname, 'uploads')));
```

- 添加 `handleImageError()` 函数
