## 1. 产品概述

### 1.1 背景

问小达3.0版本（基于LangGraph接口实现的AI对话版本）已在App端上线运行数月，功能相对稳定。为避免重复开发，现需要在现有3.0版本基础上进行简单调整，适配出PC客户端内嵌版本以及浏览器版本。

### 1.2 目标

- 复用现有3.0版本代码，最小化开发成本
- 保持现有交互和UI不变，仅做大屏适配
- 支持PC客户端内嵌版本和Web浏览器版本

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 交互不变 | AI对话页面的所有交互保持不变 |
| 功能保留 | 收藏、分享、查看更多等按钮全部保留 |
| 最小改动 | 仅调整布局适配大屏，不修改核心逻辑 |

## 2. 整体布局设计

### 2.1 三栏布局结构

PC网页版采用三栏布局设计：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              顶部栏 (Header)                             │
│  [← 切换回普通版本]                                                      │
├────────────┬──────────────────────────────────────┬────────────────────┤
│            │                                      │                    │
│   左侧栏   │            中间主体区域              │     右侧栏         │
│  (我的收藏) │          (AI对话界面)               │   (详情页)         │
│            │                                      │   (动态展开)       │
│            │                                      │                    │
│  ┌────────┐│  ┌────────────────────────────────┐ │                    │
│  │新会话  ││  │                                │ │                    │
│  └────────┘│  │      对话内容区域              │ │                    │
│            │  │                                │ │                    │
│  历史对话  │  └────────────────────────────────┘ │                    │
│  收藏问句  │  ┌────────────────────────────────┐ │                    │
│            │  │ [深度思考] [输入框...] [发送]  │ │  0~400px           │
│            │  └────────────────────────────────┘ │                    │
│            │                                      │                    │
│  ┌────────┐│                                      │                    │
│  │用户信息││          自适应宽度                  │                    │
│  └────────┘│                                      │                    │
└────────────┴──────────────────────────────────────┴────────────────────┘
   ~280px
```

### 2.2 布局规格

| 区域 | 宽度 | 说明 |
|------|------|------|
| 顶部栏 | 100% | 固定高度，仅包含版本切换链接 |
| 左侧栏 | 约280px | 固定宽度，包含我的收藏、新会话按钮、底部用户登录信息 |
| 中间主体 | 自适应 | 占据剩余空间，AI对话界面（含对话内容和输入区域） |
| 右侧栏 | 0~400px | 默认收起，点击"查看更多"后展开 |

> **注意**：输入框不在整个页面底部，而是在中间主体区域内部，保持与现有3.0版本一致的设计

#### 3.2.4 历史对话Tab

**数据来源**
- 接口：`GET /threads`
- 说明：基于LangGraph的会话管理接口

**列表项设计**

| 字段 | 说明 |
|------|------|
| 会话标题 | 显示该会话的首句问句（截取前30字） |
| 时间 | 会话创建时间或最后更新时间 |
| 当前标识 | 当前活动会话显示高亮状态 |

**列表项样式**
```
┌────────────────────────────┐
│ ● 贵州茅台的最新股价是多少... │  ← 当前会话（高亮）
│   2026-03-12 10:30         │
├────────────────────────────┤
│   帮我找一下今天涨停的股票    │  ← 历史会话
│   2026-03-11 15:20         │
├────────────────────────────┤
│   最新的CPI数据是多少       │
│   2026-03-10 09:15         │
└────────────────────────────┘
```

**交互行为**

| 操作 | 行为 |
|------|------|
| 点击会话 | 在中间区域加载该会话的所有对话记录 |
| 滚动加载 | 列表支持滚动，可加载更多历史会话 |
| 继续对话 | 加载历史后，可基于该会话继续对话 |

**接口说明**

```
GET /threads
Response:
{
  "threads": [
    {
      "thread_id": "thread_abc123",
      "created_at": "2026-03-12T10:30:00Z",
      "last_message": "贵州茅台的最新股价是..."
    }
  ]
}

GET /threads/{threadId}
Response:
{
  "messages": [
    {
      "role": "user",
      "content": "贵州茅台的最新股价是多少？"
    },
    {
      "role": "assistant",
      "content": "贵州茅台（600519.SH）的最新价为..."
    }
  ]
}
```

## 4. 平台差异化功能

> **重要说明**：PC客户端版和Web浏览器版的差异很小，无需在原型图或UI中显示切换按钮。两个版本采用同一套代码，通过平台检测自动控制功能显示/隐藏。以下差异仅需在开发和测试时注意即可。

### 4.1 差异点汇总

| 差异项 | Web浏览器版 | PC客户端版 | 实现方式 |
|--------|-------------|------------|----------|
| 添加自选股 | 不显示按钮 | 显示"加自选"按钮 | `v-if="isPCClient"` 条件渲染 |
| 股票/指数名称点击 | 普通文本，不可点击 | 链接样式，可点击跳转行情页 | 条件渲染 + 样式切换 |
| 其他所有功能 | 完全一致 | 完全一致 | 无差异 |

### 4.2 添加自选股功能

#### Web浏览器版

| 位置 | 处理方式 |
|------|----------|
| 详情页"添加"按钮 | 不显示（v-if="isPCClient"） |
| 表格勾选框 | 不显示 |
| 批量操作栏 | 不显示 |

#### PC客户端版

| 位置 | 功能说明 |
|------|----------|
| 详情页"添加"按钮 | 显示，点击后批量添加到自选股 |
| 表格勾选框 | 显示，支持多选 |
| 批量操作栏 | 显示全选和批量添加功能 |

**交互流程（PC客户端）**
1. 用户在详情页勾选多只股票
2. 点击"添加"按钮
3. 调用客户端接口添加到本地自选股
4. 显示添加成功提示

### 4.3 股票名称点击跳转

#### Web浏览器版

| 元素 | 样式 | 行为 |
|------|------|------|
