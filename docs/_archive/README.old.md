## 🎯 项目概述

VIP投研内部分享系统是一个面向内部用户的私密投研分享平台，主要功能包括：

- **消息推送**：管理员向指定分组的用户群发投研消息（支持图片+文字）
- **消息管理**：用户查看历史消息，支持搜索、收藏和导出
- **讨论功能**：用户就消息发起讨论，支持公开/私密设置
- **用户管理**：管理员统一注册用户和分组管理，支持邮箱和用户名双重登录
- **统计功能**：消息数量趋势、用户活跃度等数据统计，支持Excel导出

## 🛠️ 技术架构

### 前端
- **当前技术栈**：Vue 3 (Composition API) + Element Plus + Vite 4.x
- **目标技术栈**：uni-app (支持多端部署)
- **状态管理**：Pinia 2.x
- **路由管理**：Vue Router 4.x (当前) / uni-app路由 (目标)
- **HTTP客户端**：Axios 1.x

### 后端
- **运行环境**：Node.js v20.20.0+
- **Web框架**：Express.js
- **数据库**：MySQL 5.7.0+ (云服务器使用8.x)
- **ORM框架**：Sequelize
- **身份认证**：JWT (JSON Web Token)
- **进程管理**：PM2 6.x

## 📦 部署支持

- ✅ **H5 网页**：可部署到任何静态网站托管服务
- 🔄 **微信小程序**：开发中（迁移到 uni-app）
