**错误信息**：`Invalid username or token`

**解决方案**：

---

### 问题3：SSL证书申请失败

**错误信息**：`Failed to connect to github.com port 443`

**原因**：域名未解析到服务器IP

**解决方案**：
1. 检查域名DNS解析是否生效
   ```bash
   nslookup aity88.online
   ```

2. 等待DNS生效后重试（可能需要几分钟到几小时）

3. 检查80端口是否开放
   ```bash
   netstat -tlnp | grep :80
   ```

---

### 问题4：后端服务无法启动

**检查步骤**：
```bash
# 1. 查看PM2错误日志
pm2 logs aity-backend --err

# 2. 检查端口是否被占用
netstat -tlnp | grep 3001

# 3. 手动运行测试
cd /root/aity-vip/backend
npm run dev
```

---

### 问题5：Nginx配置错误

**检查步骤**：
```bash
# 1. 测试Nginx配置
nginx -t

# 2. 查看Nginx错误日志
tail -f /var/log/nginx/aity-error.log

# 3. 重载Nginx
nginx -s reload
```
