### V6版本核心优势

**V6版本完全复用真实项目`tdx-wenda-ai`（`D:\your-mcp-proxy\问小达网页代码\3.0版本\tdx-wenda-ai`）的设计**，具有以下优势：

1. **布局结构100%一致**
   - 使用`.tdx-container` / `.tdx-main` / `.tdx-view` / `.tdx-fixed-bottom`结构
   - 完全复用`page_main1.vue`的布局设计
   - 保证与移动端/PC客户端的体验一致性

2. **样式完全统一**
   - 背景渐变：`linear-gradient(138deg, #e7ebfc 9%, #efe7f8 67%)`
   - 滚动区域：`.tdx-view`的`padding-bottom: 100px`
   - 输入框区域：`.ui-search`组件的完整样式

3. **交互逻辑一致**
   - 支持下拉刷新加载历史
   - 欢迎页面（UiWelcome组件）
   - 免责声明栏（van-notice-bar）
   - 思考过程展示
   - Markdown渲染

4. **开发效率提升**
   - 前端开发时可以直接参考`page_main1.vue`的实现
   - CSS样式可以直接复用`page_main.scss`
   - 组件可以直接引用Vue组件

## 核心功能模块

### 1. 三栏布局

```
┌─────────┬────────────────────┬──────────┐
│ 左侧栏   │   中间主体区域       │  右侧栏   │
│ 260px   │   flex: 1          │  520px   │
│         │                    │  (可选)   │
└─────────┴────────────────────┴──────────┘
```

**布局要点:**
- 左侧栏宽度: 260px（展开）/ 60px（收起）
- 右侧栏宽度: 520px（展开）/ 0（收起）
- 中间主体区域自适应剩余空间
- 右侧栏默认隐藏，点击"查看更多"展开

### 2. 左侧栏功能

#### 2.1 展开状态
- **顶部区域（仅V5）**: Logo、版本切换
- **新会话按钮**: 渐变背景，点击创建新threadId
- **Tab切换**: 历史对话 / 收藏问句
- **历史对话列表**: 最近10条对话记录
- **收藏问句列表**: 按分类展示收藏的问句
- **底部用户信息（仅V5）**: 头像、用户名、登录状态

#### 2.2 收起状态（60px宽）
- **3个图标按钮**（垂直排列）:
  - 新会话（+ 图标）
  - 历史（时钟图标）
  - 收藏（星星图标）
- **用户头像**（仅V5）
- **其他内容隐藏**

**设计要求:**
- 图标按钮: 44x44px，带边框，hover时变蓝色
- 平滑过渡动画（0.3s ease）
- 点击图标自动展开左侧栏并跳转到对应tab

### 3. 中间主体区域 ⭐ V6版本完全复用真实项目

#### 3.3 输入框区域（.tdx-fixed-bottom）

**关键布局:**
```
┌────────────────────────────────┐
│  分类标签栏（11个标签）           │
│  [展开按钮] [投资目标] [大势研判] │
└────────────────────────────────┘
┌────────────────────────────────┐
│  输入框                         │
│  [textarea]                     │
├────────────────────────────────┤
│  [深度思考按钮]     [发送按钮]   │
└────────────────────────────────┘
```

**设计要求:**
- 分类标签栏和输入框**整合在一起**，都包裹在 `.ui-search` 容器内
- 分类标签栏在输入框**正上方**，宽度一致
- 标签栏背景: 半透明白色 `rgba(255,255,255,0.6)`
- 输入框背景: 渐变色 `linear-gradient(138deg, #e7ebfc 9%, #efe7f8 67%)`
- 支持标签栏展开/收起切换
- 11个分类标签：投资目标、大势研判、行业分析、股票诊断、选股票、买卖点研判、走势预测、AI复盘、账户管理、热力雷达、智能图说

### 4. 右侧详情页

#### 4.1 结构组成
1. **标题栏**: 问句标题 + 结果数量 + 操作按钮（加自选、关闭）
2. **解析条件展示行** ⭐:
   - 位置：标题栏下方
   - 背景：渐变色 `linear-gradient(138deg, #f0f4ff 0%, #f8f5ff 100%)`
   - 显示：问句被解析成的条件标签（带✓图标）
   - 示例：`✓ 涨跌幅=涨停` `✓ 按成交额降序` `✓ 当日数据`
3. **数据表格**: 展示查询结果
4. **分页加载**: "查看更多"按钮

#### 4.2 分页交互 ⭐
**交互流程:**
1. 初始显示10条数据
2. 点击"查看更多" → 显示"加载中..."
3. 加载完成后：
   - 新数据追加到表格末尾
   - 内容自动向上滚动
   - 右侧栏出现垂直滚动条
   - 支持鼠标滚轮控制

**技术要求:**
- 自定义滚动条：8px宽，圆角
- 边界检测：防止过度滚动
- 平滑滚动动画
- 加载状态提示

## 交互设计要点

### 1. 平滑动画
- 所有过渡效果: `transition: all 0.2s ease`
- 侧边栏收起/展开: `transition: all 0.3s ease`
- 按钮hover: 微上移 + 阴影增强

### 2. 响应式适配
- 最小支持分辨率: 1366x768
- 推荐分辨率: 1920x1080
- 左侧栏收起后为中间区域腾出空间

### 3. 无障碍设计
- 所有按钮添加 `title` 提示
- 图标按钮配合文字标签
- 键盘导航支持
- Enter键发送消息

### 4. 性能优化
- 滚动区域使用 `position: absolute` 避免重排
- 图片懒加载
- 虚拟滚动（长列表）
