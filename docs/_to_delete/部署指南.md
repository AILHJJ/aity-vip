# AITY VIP 部署指南

## 目录结构

```
腾讯云服务器 /tmp/AITY/
├── backend/              # 后端代码
│   └── src/              # 源代码
└── aity-uni-app-v2/      # 前端代码
    └── dist/build/h5/    # H5 编译输出
```

## 快速更新（推荐）

在服务器上执行一键更新脚本：

```bash
# 获取最新脚本并执行
curl -o update-aity.sh https://raw.githubusercontent.com/AILHJJ/aity-vip/feature/iteration-1/scripts/update-aity.sh
chmod +x update-aity.sh
bash update-aity.sh
```

## 手动更新步骤

### 1. 更新后端

```bash
cd /tmp/AITY/backend
git pull origin feature/iteration-1
pm2 restart all
```

### 2. 更新前端

```bash
cd /tmp/AITY/aity-uni-app-v2
git pull origin feature/iteration-1
npm run build:h5
```

### 3. 部署到 Nginx

```bash
# 复制编译结果到 Nginx 目录
cp -r /tmp/AITY/aity-uni-app-v2/dist/build/h5/* /usr/share/nginx/html/aity/
```

## 后端 vs 前端更新对比

| 项目 | 需要编译 | 更新命令 |
|------|---------|---------|
| 后端 Node.js | 否 | `git pull` + `pm2 restart` |
| 前端 uni-app | 是 | `git pull` + `npm run build:h5` + 复制到 Nginx |

## 首次部署

如果服务器还没有代码，按以下步骤操作：

### 1. 克隆后端代码

```bash
cd /tmp
mkdir -p AITY && cd AITY

# 克隆后端
git clone --filter=blob:none --sparse https://github.com/AILHJJ/aity-vip.git temp_backend
cd temp_backend
git sparse-checkout set backend
git checkout feature/iteration-1
mv backend ../backend
cd ..
rm -rf temp_backend
```

### 2. 克隆前端代码

```bash
# 克隆前端
git clone --filter=blob:none --sparse https://github.com/AILHJJ/aity-vip.git temp_frontend
cd temp_frontend
git sparse-checkout set aity-uni-app-v2
git checkout feature/iteration-1
mv aity-uni-app-v2 ../aity-uni-app-v2
cd ..
rm -rf temp_frontend
```

### 3. 安装依赖并启动

```bash
# 后端
cd /tmp/AITY/backend
npm install --production
npm run start  # 或使用 pm2 start

# 前端
cd /tmp/AITY/aity-uni-app-v2
npm install
npm run build:h5

# 部署到 Nginx
mkdir -p /usr/share/nginx/html/aity
cp -r /tmp/AITY/aity-uni-app-v2/dist/build/h5/* /usr/share/nginx/html/aity/
```

## 配置说明

### 环境变量

后端需要配置 `.env.production` 文件：

```env
NODE_ENV=production
PORT=3001
DB_HOST=localhost
DB_NAME=aity_vip
DB_USER=your_db_user
DB_PASSWORD=your_db_password
JWT_SECRET=your_jwt_secret
```

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /usr/share/nginx/html/aity;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api {
        proxy_pass http://localhost:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 故障排查

### 后端启动失败

```bash
# 检查端口占用
lsof -i :3001

# 检查日志
pm2 logs

# 检查数据库连接
mysql -u root -p -e "SHOW DATABASES;"
```

### 前端访问 404

```bash
# 检查 Nginx 目录
ls -la /usr/share/nginx/html/aity/

# 检查 Nginx 配置
nginx -t

# 重载 Nginx
systemctl reload nginx
```

### Git 拉取失败

```bash
# 检查网络
ping github.com

# 使用代理（如需要）
git config --global http.proxy http://proxy-server:port
```
