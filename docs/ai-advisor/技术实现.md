## 1. 用户数据隔离

### 问题背景

**原有问题**：
- ❌ 所有用户登录后看到相同的对话历史
- ❌ 所有用户共享同一个 `threadId` 和 `chat_history`
- ❌ 用户A发送的消息，用户B也能看到

### 解决方案

**实现机制**：
- ✅ 基于用户ID生成专属存储key
- ✅ 所有存储函数使用用户专属key
- ✅ 刷新页面后恢复当前用户的对话

**核心代码**：

文件：`aity-uni-app-v2/src/utils/ai-advisor-config.js`

```javascript
/**
 * 获取当前用户的存储Key
 * @param {String} key - 基础key名称
 * @returns {String} - 用户专属的key（格式：ai_advisor_{userId}_{key}）
 */
export function getUserStorageKey(key) {
  try {
    // 获取用户store
    const userStore = useUserStore()
    const userId = userStore.userId || 'anonymous'

    // 返回用户专属的key
    return `ai_advisor_${userId}_${key}`
  } catch (error) {
    console.error('获取用户存储Key失败:', error)
    // 降级方案：使用固定key（所有用户共享，仅用于错误恢复）
    return `ai_advisor_${key}`
  }
}
```

**修改的函数**：

```javascript
// 保存会话ID到本地存储（按用户隔离）
export function saveThreadId(threadId) {
  const key = getUserStorageKey('thread_id')
  uni.setStorageSync(key, threadId)
}

// 从本地存储获取会话ID（按用户隔离）
export function getThreadId() {
  const key = getUserStorageKey('thread_id')
  return uni.getStorageSync(key) || ''
}

// 保存对话历史到本地存储（按用户隔离）
export function saveChatHistory(messages) {
  try {
    const key = getUserStorageKey('chat_history')
    uni.setStorageSync(key, JSON.stringify(messages))
  } catch (error) {
    console.error('保存对话历史失败:', error)
  }
}

// 从本地存储获取对话历史（按用户隔离）
export function getChatHistory() {
  try {
    const key = getUserStorageKey('chat_history')
    const history = uni.getStorageSync(key)
    return history ? JSON.parse(history) : []
  } catch (error) {
    console.error('获取对话历史失败:', error)
    return []
  }
}

// 清空当前用户的对话历史
export function clearChatHistory() {
  const historyKey = getUserStorageKey('chat_history')
  const threadKey = getUserStorageKey('thread_id')
  uni.removeStorageSync(historyKey)
  uni.removeStorageSync(threadKey)
}
```

### 实现效果

- ✅ 用户A只看到用户A的历史
- ✅ 用户B只看到用户B的历史
- ✅ 数据完全隔离，互不干扰
- ✅ 刷新页面后恢复当前用户的对话

## 2. 金融工具表格渲染

### 问题背景

**原有问题**：
- ❌ 只显示AI的markdown总结文本
- ❌ 原始JSON数据（工具返回）未渲染
- ❌ 涨跌幅无颜色区分
- ❌ 数字格式不统一（缺失千分位）

### 解决方案

**实现机制**：
- ✅ 新增 `tool_result` 事件处理
- ✅ 保存工具响应原始数据
- ✅ 新增工具调用提示显示
- ✅ 新增工具结果表格渲染（优先于markdown文本）
- ✅ 实现完整的3层数据结构解析
- ✅ 实现字段映射和格式化标识解析
- ✅ 实现涨跌颜色规则：涨红(#fc4a4a)、跌绿(#229d45)
- ✅ 实现数字格式化：千分位、百分比、小数位数、万亿

### 3层数据结构解析

**数据结构**：

```javascript
[
  [0, "", 0, "", "0"],  // 第0行：元数据
  ["POS", "market", "sec_code", "sec_name", "now_price", "chg0#", "所属行业", "timestamps"],  // 第1行：字段定义
  ["", "", "", "2|0|0", "2|0|0", "0|0|0", ""],  // 第2行：格式化标识
  ["000001", "沪市", "平安银行", "12.45", "2.35", "银行业", "2024-01-15 10:30:00"],  // 第3行：实际数据
  ["000002", "沪市", "万科A", "18.67", "-1.2", "房地产业", "2024-01-15 10:30:00"]   // 第4行：实际数据
]
```

**解析逻辑**：

```javascript
function renderToolResultTable(toolResult) {
  try {
    const data = JSON.parse(toolResult)

    if (!Array.isArray(data) || data.length < 3) {
      return ''
    }

    // 提取各行数据
    const row0 = data[0] || []  // 元数据
    const row1 = data[1] || []  // 字段定义
    const row2 = data[2] || []  // 格式化标识
    const rows = data.slice(3)    // 实际数据行

    // 创建字段映射：row0[index] -> row1[index]
    const fieldMapping = {}
    row1.forEach((field, index) => {
      fieldMapping[row0[index]] = field
    })

    // 创建格式化标识映射：row0[index] -> row2[index]
    const formatFlags = {}
    row2.forEach((flag, index) => {
      formatFlags[row0[index]] = flag
    })

    // 生成HTML表格
    let tableHtml = '<table class="tool-result-table">'
    tableHtml += '<thead><tr>'

    // 渲染表头（使用字段定义）
    const headers = Object.values(fieldMapping)
    headers.forEach(header => {
      const cleanHeader = header.replace(/<br>.*$/, '')
      tableHtml += `<th>${cleanHeader}</th>`
    })
    tableHtml += '</tr></thead><tbody>'

    // 渲染数据行
    rows.forEach((row, rowIndex) => {
      tableHtml += '<tr>'
      row.forEach((cell, cellIndex) => {
        const fieldName = Object.keys(fieldMapping)[cellIndex]
        const formatFlag = formatFlags[fieldName]

        // 应用格式化函数
        const formattedCell = formatCellValue(cell, formatFlag, fieldName, row)

        tableHtml += `<td>${formattedCell}</td>`
      })
      tableHtml += '</tr>'
    })

    tableHtml += '</tbody></table>'

    return tableHtml
  } catch (error) {
    console.error('解析工具结果失败:', error)
    return `<pre style="white-space: pre-wrap;">${toolResult}</pre>`
  }
}
```

### 格式化标识解析

**标识格式**：`"typeFlag|subType|specialFlag"`

**解析规则**：

```javascript
function formatCellValue(value, formatFlag, fieldName, rowData) {
  // 解析格式化标识："2|0|0"
  const flags = formatFlag ? formatFlag.split('|') : []

  const typeFlag = flags[0] || '0'
  const subType = flags[1] || '0'
  const specialFlag = flags[2] || '0'

  // 获取原始数值
  let numValue = parseFloat(value)

  // === 涨跌幅字段 ===
  if (isChangeField(fieldName)) {
    if (typeFlag === '1') {
      // 默认规则：正数涨红，负数跌绿，0平盘
      if (numValue > 0) {
        return `<span class="color-up">${numValue}%</span>`
      } else if (numValue < 0) {
        return `<span class="color-down">${Math.abs(numValue)}%</span>`
      } else {
        return `<span>${numValue}%</span>`
      }
    }
    if (typeFlag === '2') {
      // 反向规则：正数跌绿，负数涨红
      if (numValue > 0) {
        return `<span class="color-down">${numValue}%</span>`
      } else if (numValue < 0) {
        return `<span class="color-up">${Math.abs(numValue)}%</span>`
      } else {
        return `<span>${numValue}%</span>`
      }
    }
    if (typeFlag === '3') {
      // 特殊规则：>1涨，≤1跌
      if (numValue > 1) {
        return `<span class="color-up">${numValue}%</span>`
      } else if (numValue < -1) {
        return `<span class="color-down">${Math.abs(numValue)}%</span>`
      } else {
        return `<span>${numValue}%</span>`
      }
    }
  }

  // === 价格字段 ===
  if (fieldName === 'now_price') {
    // 小数位数控制：2位或3位
    const decimals = typeFlag === '2' ? 2 : (typeFlag === '3' ? 3 : 2)
    const prefix = specialFlag === '1' ? '+' : ''
    return `${prefix}${numValue.toFixed(decimals)}`
  }

  // === 百分比字段 ===
  if (subType === '2') {
    const sign = numValue > 0 ? '+' : ''
    return `${sign}${numValue.toFixed(2)}%`
  }

  // === 千分位处理 ===
  if (subType === '1') {
    return formatThousands(numValue)  // 1,234.56
  }

  // === 万亿处理 ===
  if (Math.abs(numValue) >= 100000000) {
    return (numValue / 100000000).toFixed(2) + '亿'
  }

  return value
}
```

### 千分位格式化

```javascript
function formatThousands(num) {
  const str = num.toString()
  const parts = str.split('.')
  parts[0] = parts[0].replace(/\B(?=(\d{3})+(?!\d))/g, ',')
  return parts.join('.')
}
```

## 3. LangGraph框架SSE事件处理

### SSE事件类型

**支持的事件**：

| 事件 | 数据内容 | 处理方式 |
|------|---------|---------|
| `messages/partial` | 流式AI文本 | 显示thinking/content |
| `messages/metadata` | thread_id、run_id | 保存threadId |
| `messages/tool` | 工具调用 | 显示"正在调用工具" |
| `messages/tool_result` | 工具响应JSON | **渲染表格数据** |
| `messages/complete` | AI总结文本 | 显示markdown |

### 核心代码

**SSE消息处理**：

```javascript
function handleSSEMessage(event) {
  try {
    const data = JSON.parse(event.data)

    // 处理不同类型的事件
    if (data.type === 'partial') {
      // 流式AI文本
      const newContent = data.content || ''
      if (lastMessage) {
        lastMessage.content += newContent
        lastMessage.thinking = true
      }
      scrollToBottom(false)
    }

    else if (data.type === 'complete') {
      // 完整消息
      const completeContent = data.content || ''
      if (lastMessage) {
        lastMessage.content = completeContent
        lastMessage.thinking = false
        lastMessage.isComplete = true
      }
      scrollToBottom(true)
    }

    else if (data.type === 'metadata') {
      // 元数据：thread_id
      const threadId = data.thread_id || ''
      if (threadId) {
        saveThreadId(threadId)
        console.log('会话ID已保存:', threadId)
      }
    }

    else if (data.type === 'tool') {
      // 工具调用
      const toolName = data.tool_name || '未知工具'
      if (lastMessage) {
        lastMessage.toolCalls = [{
          function: {
            name: toolName,
            arguments: JSON.stringify(data.args)
          }
        }]
      }
      console.log('正在调用工具:', toolName)
    }

    else if (data.type === 'tool_result') {
      // 工具响应结果
      const toolName = data.tool_name
      const toolResult = JSON.stringify(data.tool_result)

      if (toolName === '金融选股') {
        if (lastMessage) {
          lastMessage.toolResult = toolResult
          lastMessage.isTable = true
        }
      }

      console.log('工具响应结果:', toolName, toolResult)
      scrollToBottom(false)
    }

  } catch (error) {
    console.error('解析SSE消息失败:', error)
  }
}
```

## 5. 输入框交互优化

### 问题背景

**原有问题**：
- ❌ Enter键行为单一（只支持发送）
- ❌ 输入完成后无法收起键盘
- ❌ 点击外部区域无响应

### 解决方案

**实现机制**：
- ✅ 修改placeholder提示："Enter换行，Shift+Enter发送"
- ✅ 新增键盘状态管理：`keyboardHeight`、`isKeyboardVisible`
- ✅ 添加键盘高度变化监听：`@keyboardheightchange`
- ✅ 添加输入框焦点事件：`@focus`、`@blur`
- ✅ 新增点击外部区域关闭键盘：`handleScrollAreaClick()`
- ✅ 发送消息后自动收起键盘：`uni.hideKeyboard()`
- ✅ 添加 `adjust-position="true"` 避免键盘遮挡内容

### 核心代码

**状态管理**：

```javascript
const keyboardHeight = ref(0)
const isKeyboardVisible = ref(false)
```

**事件处理**：

```javascript
function onKeyboardHeightChange(e) {
  keyboardHeight.value = e.detail.height
  isKeyboardVisible.value = e.detail.height > 0
}

function onInputFocus() {
  isKeyboardVisible.value = true
}

function onInputBlur() {
  setTimeout(() => {
    isKeyboardVisible.value = false
  }, 200)
}

function handleScrollAreaClick() {
  if (isKeyboardVisible.value) {
    uni.hideKeyboard()
    isKeyboardVisible.value = false
  }
}

async function handleSendMessage() {
  // 发送消息逻辑...

  // 发送后自动收起键盘
  uni.hideKeyboard()
  isKeyboardVisible.value = false
}
```

**模板绑定**：

```vue
<template>
  <textarea
    v-model="inputContent"
    placeholder="Enter换行，Shift+Enter发送"
    @keyboardheightchange="onKeyboardHeightChange"
    @focus="onInputFocus"
    @blur="onInputBlur"
    adjust-position="true"
  />

  <scroll-view
    class="scroll-area"
    @click="handleScrollAreaClick"
  >
    <!-- 对话内容 -->
  </scroll-view>

```

### 实现效果

- ✅ 支持Enter换行，更符合输入习惯

## 7. 技术决策记录

### 为什么不实现某些功能

**1. 表格排序**
- **原因**: 需要维护排序状态，增加复杂度
- **决策**: 暂不实现，用户可通过查看原始JSON数据排序

**2. 万亿格式自动判断**
- **原因**: 参考项目的万亿判断逻辑复杂
- **决策**: 简化实现，仅支持>=1亿，不追求完全自动

**3. 表格横向滚动**
- **原因**: 需要处理横向滚动事件，增加交互复杂度
- **决策**: 使用原生横向滚动，性能更好

### 为什么采用参考项目的方案

**1. 数据结构**：3层数组是标准格式，字段定义清晰
**2. 格式化标识**：`"2|0|0"` 这种设计灵活，易于扩展
**3. 颜色规则**：涨红跌绿符合中国股市习惯
**4. 成熟度**：参考项目已在生产环境验证，可靠性高

### 可优化点

**1. 考虑将数据处理逻辑抽取为独立的工具类（`financialDataParser`）**
**2. 考虑添加单元测试，覆盖各种格式化场景**
**3. 考虑添加TypeScript类型定义，提升代码可维护性**
