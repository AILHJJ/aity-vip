# 金融数据接口最终文档

## 一、接口概述

本文档整合了所有金融行情相关的核心接口，包括市场概览、涨跌停分布、行业资金流向、连板天梯和指数行情等数据，用于金融分析和决策支持。

---

## 二、基础信息

**接口基础地址**: `http://123.60.27.66:7615/TQLEX`

**请求方式**: `POST`

**认证方式**: 无需认证

**Content-Type**: `application/json`

---

## 三、接口列表

### 1. 概念板块涨幅/跌幅排行前三接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBHYStat`

**接口说明**: 获取概念板块涨幅或跌幅排行前三的数据

**请求参数（按涨幅排序）**:
```json
{
  "Head": {
    "CharSet": "1",
    "Target": 0,
    "SSOToken": "string"
  },
  "Num": "3",
  "Blocktype": "0",
  "Desc_order": "0",
  "Iszangsu": "0",
  "Pos": "-1",
  "Needtotalnum": "2"
}
```

**请求参数（按跌幅排序）**:
```json
{
  "Head": {
    "CharSet": "1",
    "Target": 0,
    "SSOToken": "string"
  },
  "Num": "3",
  "Blocktype": "0",
  "Desc_order": "1",
  "Iszangsu": "0",
  "Pos": "-1",
  "Needtotalnum": "2"
}
```

**参数说明**:
- `Head.CharSet`: 字符集（1=UTF-8）
- `Head.Target`: 目标值，默认0
- `Head.SSOToken`: 认证令牌
- `Num`: 返回数量（3=前三）
- `Blocktype`: 板块类型（0=概念板块）
- `Desc_order`: 排序方式（0=升序，1=降序）
- `Iszangsu`: 是否包含藏股（0=不包含）
- `Pos`: 起始位置（-1=从头开始）
- `Needtotalnum`: 是否需要总数（2=需要）

**响应示例**:
```json
{
  "Setcode": 1,
  "Code": "999999",
  "num": 146,
  "zstddeDataList": [
    {
      "Value": 14628266000,
      "Rate": [
        {
          "value": [
            8114,
            7140,
            3927,
            3726
          ]
        }
      ]
    }
  ]
}
```

**字段说明**:
| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `Setcode` | Number | 市场代码 | 1 |
| `Code` | String | 股票市场 | "999999" |
| `num` | Number | 数量 | 146 |
| `zstddeDataList` | Array | 每分钟资金流向数据 | - |
| `zstddeDataList[].Value` | Number | 总数据(额,量或单数) | 14628266000 |
| `zstddeDataList[].Rate` | Array | 4个数组：特大/大/中/小单 | - |
| `zstddeDataList[].Rate[].value` | Array | 4个数据：买入/卖出/主买/主卖 | [8114,7140,3927,3726] |

### 3. 连板天梯接口 - 板块数据接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**接口说明**: 获取连板天梯数据，返回格式为JSON字符串，需要二次解析

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Blocktype": "0",
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH"
}
```

**参数说明**:
- `Blocktype`: 板块类型（0=股票）
- `Blockstyle`: 板块风格（3=连板）
- `Blockid`: 板块ID（Stock_SCHIGH=连板高度）

**响应示例**:
```json
{
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH",
  "Totalrow": 1,
  "Num": 286,
  "Buf": "[[\"3\",\"1\"],[\"0\",\"002843\",\"深证成指\"],...]"
}
```

**字段说明**:
| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `Blockstyle` | Number | 板块风格 | "3" |
| `Blockid` | String | 板块ID | "Stock_SCHIGH" |
| `Totalrow` | Number | 总行数 | 1 |
| `Num` | Number | 板块数量 | 286 |
| `Buf` | String | 股票板块数据（JSON字符串） | "[[\"3\",\"1\"],[\"0\",\"002843\",\"深证成指\"]]" |

**Buf字段解析**:
```json
[
  [
    "3",
    "1"
  ],
  [
    "0",
    "002843",
    "深证成指"
  ]
]
```
- 位置0: 市场类型（0=深市，1=沪市）
- 位置1: 股票代码
- 位置2: 股票名称

### 6. 综合行情接口（PBCombHQ）

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBCombHQ`

**接口说明**: 获取多个指数的实时行情数据，支持自定义返回字段

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "WantCol": ["VOL", "NOW", "CLOSE"],
  "Setcode": ["1", "0", "1", "0", "1", "2"],
  "Code": ["999999", "399001", "000300", "399006", "000688", "899050"]
}
```

**参数说明**:
- `Head.Target`: 目标值，默认0
- `WantCol`: 需要返回的列（可选）
  - `VOL` - 成交量
  - `NOW` - 现价
  - `CLOSE` - 收盘价
  - 其他可能的列：`OPEN`（开盘价）、`HIGH`（最高价）、`LOW`（最低价）等
- `Setcode`: 市场代码数组
  - `1` - 沪市
  - `0` - 深市
  - `2` - 其他市场
- `Code`: 指数代码数组
  - `999999` - 上证指数
  - `399001` - 深证成指
  - `000300` - 沪深300
  - `399006` - 创业板指
  - `000688` - 科创50
  - `899050` - 北证50

**响应示例**:
```json
{
  "code": "999999",
  "setcode": "1",
  "name": "上证指数",
  "close": 3000.00,
  "now": 3050.00,
  "vol": 100000000,
  "EXT_ZF": "1.67"
}
```

**字段说明**:
| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `code` | String | 指数代码 | "999999" |
| `setcode` | String | 市场代码 | "1" |

| `close` | Number | 昨收价 | 3000.00 |
| `now` | Number | 现价 | 3050.00 |
| `vol` | Number | 成交量 | 100000000 |

## 六、数据处理逻辑

### 1. 市场概览数据处理
- **时间格式化**: 将`HQDate`和`HQTime`转换为可读格式（如：2026年03月02日 15:00:00）
- **成交额单位转换**: 将元转换为亿元（除以1e8）
- **成交量单位转换**: 根据数值大小转换为亿手或万手
- **涨跌比计算**: 上涨家数/下跌家数
- **数据验证**: 处理异常数据和边界情况

### 2. 涨跌分布数据处理
- **区间数据提取**: 从`BspInfo`中提取各区间的涨跌家数
- **涨跌停数据处理**: 优先使用`BspInfo`中的数据，若缺失则使用`HQInfo`中的数据
- **比例计算**: 计算各区间占比、涨幅>3%和跌幅>3%的比例
- **数据可视化准备**: 为图表展示准备结构化数据

### 3. 资金流向数据处理
- **单位转换**: 将资金金额从元转换为亿元
- **排序处理**: 按资金流向金额排序，获取TOP5行业
- **数据结构转换**: 将原始数据转换为前端展示所需的格式

### 4. 连板数据处理
- **板块数据接口解析**: 解析`Buf`字段，按连板高度分组
- **NLP数据接口解析**: 映射N001-N030字段到结构化数据
- **统计计算**: 计算总连板股票数、最高连板高度
- **情绪分析**: 基于连板数据进行市场情绪评估

### 5. 指数行情数据处理
- **数据格式化**: 格式化价格、涨跌幅等数值
- **涨跌标识**: 根据涨跌幅设置红色/绿色标识
- **数据排序**: 按指数重要性排序展示

### 缓存配置

```javascript
const CACHE_CONFIG = {
  MARKET_OVERVIEW: {
    duration: 10000,     // 10秒
    key: 'market_overview_cache'
  },
  INDUSTRY_FLOW: {
    duration: 15000,     // 15秒
    key: 'industry_flow_cache'
  },
  CONTINUOUS_LIMIT: {
    duration: 20000,     // 20秒
    key: 'continuous_limit_cache'
  },
  INDEX_QUOTE: {
    duration: 5000,      // 5秒
    key: 'index_quote_cache'
  }
};

// 缓存实现
const getWithCache = async (cacheKey, fetchFn, duration) => {
  const cached = localStorage.getItem(cacheKey);
  
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < duration) {
      return data;
    }
  }
  
  const result = await fetchFn();
  localStorage.setItem(cacheKey, JSON.stringify({
    data: result,
    timestamp: Date.now()
  }));
  
  return result;
};
```

### 常见错误

| 错误类型 | 说明 | 处理建议 |
|----------|------|----------|
| **网络错误** | 无法连接到服务器 | 检查网络连接，确认服务器地址正确 |
| **参数错误** | 请求参数格式不正确 | 检查JSON格式，确保必填参数已提供 |
| **数据解析错误** | 返回数据格式不符合预期 | 检查返回数据结构，处理异常情况 |
| **请求长度错误** | 请求参数过长 | 检查参数长度，确保符合接口要求 |
