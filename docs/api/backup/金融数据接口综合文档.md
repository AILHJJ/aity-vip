# 金融数据接口综合文档

## 概述

本文档记录所有金融数据接口，用于图灵AI功能的实时行情数据支持，包括指数行情、板块分析、NLP分析、资金流向等。

---

## 基础信息

**接口地址**: `http://123.60.27.66:7615/TQLEX`

**请求方式**: `POST`

**认证方式**: 无需认证

**Content-Type**: `application/json`

---

## 接口列表

### 1. 指数行情接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.IndexQuote`

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Code": "000001.SZ,399001.SZ,000300.SH,000016.SH,000688.SH,000905.SH"
}
```

**参数说明**:
- `Code`: 指数代码列表，逗号分隔
  - `000001.SZ` - 上证指数
  - `399001.SZ` - 深证成指
  - `000300.SH` - 沪深300
  - `000016.SH` - 上证50
  - `000688.SH` - 科创50
  - `000905.SH` - 中证500

**响应示例**:
```json
{
  "Head": {
    "Target": 0,
    "Time": "2026-02-11 09:30:00"
  },
  "Data": [
    {
      "Code": "000001.SZ",
      "Name": "上证指数",
      "Price": 3245.67,
      "Change": 12.34,
      "ChangePct": 0.38,
      "Volume": 123456789000,
      "Amount": 987654321000,
      "High": 3250.12,
      "Low": 3230.45,
      "Open": 3238.90,
      "LastClose": 3233.33
    }
  ]
}
```

**字段说明**:
- `Code`: 指数代码
- `Name`: 指数名称
- `Price`: 最新价
- `Change`: 涨跌额
- `ChangePct`: 涨跌幅(%)
- `Volume`: 成交量
- `Amount`: 成交额
- `High`: 最高价
- `Low`: 最低价
- `Open`: 开盘价
- `LastClose`: 昨收价

### 2. 连板天梯接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Blocktype": "0",
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH"
}
```

**参数说明**:
- `Blocktype`: 板块类型（0=股票）
- `Blockstyle`: 板块风格（3=连板）
- `Blockid`: 板块ID（Stock_SCHIGH=连板高度）

**响应示例**:
```json
{
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH",
  "Totalrow": 1,
  "Num": 286,
  "Buf": "[[\"3\",\"1\"],[\"0\",\"002843\",\"深证成指\"],...]"
}
```

**字段说明**:
- `Blockstyle`: 板块风格
- `Blockid`: 板块ID
- `Totalrow`: 总行数
- `Num`: 板块数量
- `Buf`: 股票板块数据（JSON字符串）

**Buf字段解析**:
```json
[
  [
    "3",
    "1"
  ],
  [
    "0",
    "002843",
    "深证成指"
  ]
]
```
- 位置0: 市场类型（0=深市，1=沪市）
- 位置1: 股票代码
- 位置2: 股票名称

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.hq_nlp_app_misc`

**字段说明**:
- `N001`: 证券名称
- `N002`: 证券代码
- `N003`: 次新标识（0=默认，1=次新）
- `N004`: 市场类型（0=深市，1=沪市）
- `N005`: 现价
- `N006`: 涨幅
- `N007`: 最近一次涨停时间
- `N008`: 最近一次跌停时间
- `N009`: 几天几板
- `N010`: 连续涨停天数
- `N011`: 连续跌停天数
- `N012`: 板型（龙头、中军、跟风、妖股）
- `N013`: 封单额
- `N014`: 封成比
- `N015`: 首次涨停时间
- `N016`: 首次跌停时间
- `N017`: 最后涨停打开时间
- `N018`: 最后跌停打开时间
- `N019`: 首次涨停后涨停打开次数
- `N020`: 首次跌停后跌停打开次数
- `N021`: 最高涨停封单额
- `N022`: 最高跌停封单额
- `N023`: 涨停金额
- `N024`: 涨速（5分钟）
- `N025`: 换手率
- `N026`: 量比
- `N027`: 总金额
- `N028`: 资金净流入
- `N029`: 主力资金净流入
- `N030`: 涨停原因

### 4. 行业资金净流入接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Code": "HY,1,0,3",
  "Blockid": "MStock_ZLJX_ADDE_R"
}
```

**参数说明**:
- `Code`: 查询条件 `HY,1,0,3`
  - `HY`: 行业（Industry）
  - `1`: 排序方式（1=按净流入降序）
  - `0`: 数据来源（0=实时）
  - `3`: 取前N名（此处为前3名）
- `Blockid`: 数据块ID（MStock_ZLJX_ADDE_R=净流入排名）

**响应示例**:
```json
{
  "Head": {
    "Target": 0,
    "Time": "2026-02-11 15:00:00"
  },
  "Data": [
    {
      "Code": "BK00001",
      "Name": "半导体",
      "NetInflow": 1234567890.50,
      "NetInflowPct": 8.5,
      "MainInflow": 2345678901.00,
      "RetailInflow": -1111111110.50,
      "StockCount": 45,
      "UpCount": 38,
      "DownCount": 7,
      "LimitUpCount": 5,
      "AvgChangePct": 3.2
    }
  ]
}
```

**字段说明**:
- `Code`: 行业代码
- `Name`: 行业名称
- `NetInflow`: 净流入金额（元）
- `NetInflowPct`: 净流入占比（%）
- `MainInflow`: 主力流入金额
- `RetailInflow`: 散户流入金额
- `StockCount`: 行业股票总数
- `UpCount`: 上涨股票数
- `DownCount`: 下跌股票数
- `LimitUpCount`: 涨停股票数
- `AvgChangePct`: 平均涨跌幅（%）

## 前端集成示例

### Vue 3 Composition API

```javascript
import { ref, reactive } from 'vue';
import axios from 'axios';

const API_BASE = 'http://123.60.27.66:7615/TQLEX';

export function useFinancialData() {
  const loading = ref(false);
  const error = ref(null);

  // 获取指数行情
  const getIndexQuote = async (codes) => {
    loading.value = true;
    error.value = null;
    try {
      const response = await axios.post(
        `${API_BASE}?Entry=HQServ.IndexQuote`,
        {
          Head: { Target: 0 },
          Code: codes.join(',')
        }
      );
      return response.data.Data;
    } catch (err) {
      error.value = err.message;
      throw err;
    } finally {
      loading.value = false;
    }
  };

  // 获取连板天梯
  const getBlockData = async (params) => {
    loading.value = true;
    error.value = null;
    try {
      const response = await axios.post(
        `${API_BASE}?Entry=HQServ.PBXmlBlock`,
        {
          Head: { Target: 0 },
          Blocktype: params.blockType || "0",
          Blockstyle: params.blockStyle || "3",
          Blockid: params.blockId || "Stock_SCHIGH"
        }
      );
      
      // 解析返回的数据
      const data = response.data;
      if (data.Buf) {
        const parsedBlocks = JSON.parse(data.Buf);
        return parsedBlocks;
      }
      return [];
    } catch (err) {
      error.value = err.message;
      throw err;
    } finally {
      loading.value = false;
    }
  };

  // 获取连板股票详细分析数据（NLP）
  const getContinuousLimitDetail = async (appType = 'misc') => {
    loading.value = true;
    error.value = null;
    try {
      const response = await axios.post(
        `${API_BASE}?Entry=HQServ.hq_nlp_app_misc`,
        {
          Head: { Target: 0 },
          AppType: appType
        }
      );
      
      // 处理返回数据
      const data = response.data;
      if (data['返回结果'] && Array.isArray(data['返回结果'])) {
        return data['返回结果'].map(item => ({
          name: item.N001,
          code: item.N002,
          isNew: item.N003 === '1',
          market: item.N004 === '0' ? '深市' : '沪市',
          currentPrice: parseFloat(item.N005) || 0,
          changePercent: parseFloat(item.N006) || 0,
          boardInfo: item.N009,
          consecutiveLimitUpDays: parseInt(item.N010) || 0,
          netInflow: parseInt(item.N028) || 0,
          limitUpReason: item.N030
        }));
      }
      return [];
    } catch (err) {
      error.value = err.message;
      throw err;
    } finally {
      loading.value = false;
    }
  };

  // 获取行业资金流向
  const getIndustryFlow = async (direction = 'inflow') => {
    loading.value = true;
    error.value = null;
    try {
      const blockId = direction === 'inflow' ? 'MStock_ZLJX_ADDE_R' : 'MStock_ZLJX_ADDE';
      const response = await axios.post(
        `${API_BASE}?Entry=HQServ.PBXmlBlock`,
        {
          Head: { Target: 0 },
          Code: 'HY,1,0,3',
          Blockid: blockId
        }
      );
      return response.data.Data;
    } catch (err) {
      error.value = err.message;
      throw err;
    } finally {
      loading.value = false;
    }
  };

  return {
    loading,
    error,
    getIndexQuote,
    getBlockData,
    getContinuousLimitDetail,
    getIndustryFlow
  };
}
```

## 数据缓存策略

### 缓存配置

```javascript
const CACHE_CONFIG = {
  INDEX_QUOTE: {
    duration: 5000,      // 指数行情：5秒
    key: 'index_quote_cache'
  },
  BLOCK_DATA: {
    duration: 10000,    // 连板天梯：10秒
    key: 'block_data_cache'
  },
  NLP_DATA: {
    duration: 30000,     // NLP分析：30秒
    key: 'nlp_data_cache'
  },
  FUND_FLOW: {
    duration: 15000,     // 资金流向：15秒
    key: 'fund_flow_cache'
  }
};
```

### 缓存实现

```javascript
const getWithCache = async (cacheKey, fetchFn, duration) => {
  const cached = localStorage.getItem(cacheKey);
  
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < duration) {
      return data;
    }
  }
  
  const result = await fetchFn();
  localStorage.setItem(cacheKey, JSON.stringify({
    data: result,
    timestamp: Date.now()
  }));
  
  return result;
};

// 使用示例
const indexData = await getWithCache(
  CACHE_CONFIG.INDEX_QUOTE.key,
  () => getIndexQuote(['000001.SZ', '399001.SZ']),
  CACHE_CONFIG.INDEX_QUOTE.duration
);
```

## 错误处理

### 常见错误

| 错误类型 | 说明 | 处理建议 |
|----------|------|----------|
| **网络错误** | 无法连接到服务器 | 检查网络连接，确认服务器地址正确 |
| **参数错误** | 请求参数格式不正确 | 检查JSON格式，确保必填参数已提供 |
| **数据解析错误** | 返回数据格式不符合预期 | 检查返回数据结构，处理异常情况 |
| **请求长度错误** | 请求参数过长 | 检查参数长度，确保符合接口要求 |

### 错误处理示例

```javascript
try {
  await getIndexQuote();
  ElMessage.success('数据加载成功');
} catch (error) {
  if (error.response) {
    if (error.response.status === 400) {
      ElMessage.error('请求参数错误');
    } else if (error.response.status === 500) {
      ElMessage.error('服务器内部错误');
    }
  } else if (error.request) {
    ElMessage.error('网络错误，请检查连接');
  } else {
    ElMessage.error('数据解析错误');
  }
}
```

  const results = [];
