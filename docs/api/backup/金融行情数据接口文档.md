# 金融行情数据接口文档

## 接口概述

本文档记录金融行情相关的核心接口，包括市场概览、涨跌停分布、行业资金流向等数据，用于金融分析和决策支持。

---

## 接口列表

### 1. 市场概览与涨跌停分布接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBHQInfo`

**接口说明**: 获取市场整体概况、涨跌停分布、涨幅区间分布等数据

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Setcode": "1",
  "Code": "880005",
  "HasHQInfo": "1",
  "BspNum": "5"
}
```

**参数说明**:
- `Setcode`: 市场代码（1=A股）
- `Code`: 指数代码（880005=沪深A股）
- `HasHQInfo`: 是否包含HQInfo数据（1=包含）
- `BspNum`: 涨跌分布区间数量（5=5个区间）

**响应示例**:
```json
{
  "BspInfo": [
    {
      "BuyV": "1200",
      "SellV": "800",
      "Range": "0-3"
    },
    {
      "BuyV": "800",
      "SellV": "400",
      "Range": "3-5"
    },
    {
      "BuyV": "400",
      "SellV": "200",
      "Range": "5-7"
    },
    {
      "BuyV": "200",
      "SellV": "100",
      "Range": ">7"
    },
    {
      "BuyV": "100",
      "SellV": "20",
      "Range": "limit"
    }
  ],
  "HQInfo": {
    "HQDate": "20260302",
    "HQTime": "150000",
    "MaxP": "4000",
    "Now": "2500",
    "Average": "1500",
    "Amount": "500000000000",
    "Volume": "300000000",
    "TotalBuyv": "100",
    "TotalSellv": "20"
  }
}
```

**字段说明**:

| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `BspInfo` | Array | 涨跌分布信息 | 见响应示例 |
| `BspInfo[].BuyV` | String | 上涨家数 | "1200" |
| `BspInfo[].SellV` | String | 下跌家数 | "800" |
| `BspInfo[].Range` | String | 涨跌区间 | "0-3" |
| `HQInfo` | Object | 市场基础信息 | 见响应示例 |
| `HQInfo.HQDate` | String | 行情日期 | "20260302" |
| `HQInfo.HQTime` | String | 行情时间 | "150000" |
| `HQInfo.MaxP` | String | 总股票数 | "4000" |
| `HQInfo.Now` | String | 上涨家数 | "2500" |
| `HQInfo.Average` | String | 下跌家数 | "1500" |
| `HQInfo.Amount` | String | 成交额 | "500000000000" |
| `HQInfo.Volume` | String | 成交量 | "300000000" |
| `HQInfo.TotalBuyv` | String | 涨停家数 | "100" |
| `HQInfo.TotalSellv` | String | 跌停家数 | "20" |

**数据解析逻辑**:
1. **涨跌区间分布**:
   - 0-3%: 小幅上涨/下跌
   - 3-5%: 中幅上涨/下跌
   - 5-7%: 大幅上涨/下跌
   - >7%: 超大幅上涨/下跌
   - limit: 涨停/跌停

2. **市场概况**:
   - 总股票数: `HQInfo.MaxP`
   - 上涨家数: `HQInfo.Now`
   - 下跌家数: `HQInfo.Average`
   - 成交额: `HQInfo.Amount`
   - 成交量: `HQInfo.Volume`
   - 涨停家数: `HQInfo.TotalBuyv`
   - 跌停家数: `HQInfo.TotalSellv`

### 2. 行业资金净流出接口

**接口地址**: `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**接口说明**: 获取行业资金净流出数据，按净流出金额排序

**请求参数**:
```json
{
  "Head": {
    "Target": 0
  },
  "Code": "HY,1,0,3",
  "Blockid": "MStock_ZLJX_ADDE"
}
```

**参数说明**:
- `Code`: 板块类型（HY=行业）
- `Blockid`: 板块ID（MStock_ZLJX_ADDE=资金净流出）

**响应示例**:
```json
{
  "Blockstyle": "3",
  "Blockid": "MStock_ZLJX_ADDE",
  "Totalrow": 1,
  "Num": 30,
  "Buf": "[["0","HY001","银行","0","0","0","1000000000"],["0","HY002","房地产","0","0","0","800000000"],["0","HY003","钢铁","0","0","0","600000000"]]"
}
```

**字段说明**:
| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `Blockstyle` | String | 板块风格 | "3" |
| `Blockid` | String | 板块ID | "MStock_ZLJX_ADDE" |
| `Totalrow` | Number | 总行数 | 1 |
| `Num` | Number | 板块数量 | 30 |
| `Buf` | String | 行业资金数据（JSON字符串） | 见响应示例 |

**Buf字段解析**:
```json
[
  ["0","HY001","银行","0","0","0","1000000000"],
  ["0","HY002","房地产","0","0","0","800000000"],
  ["0","HY003","钢铁","0","0","0","600000000"]
]
```
- 位置0: 市场类型（0=深市，1=沪市）
- 位置1: 行业代码
- 位置2: 行业名称
- 位置3-5: 预留字段
- 位置6: 资金净流出金额

## 错误处理

### 常见错误

| 错误类型 | 说明 | 处理建议 |
|----------|------|----------|
| **网络错误** | 无法连接到服务器 | 检查网络连接，确认服务器地址正确 |
| **参数错误** | 请求参数格式不正确 | 检查JSON格式，确保必填参数已提供 |
| **数据解析错误** | 返回数据格式不符合预期 | 检查返回数据结构，处理异常情况 |
| **数据为空** | 接口返回数据为空 | 检查市场是否开盘，或使用缓存数据 |

## 性能优化

### 1. 数据缓存

```python
import time
import json

# 缓存配置
CACHE_DURATION = 60  # 缓存60秒
cache_data = {}
cache_time = {}

def get_cached_data(key):
    """获取缓存数据"""
    if key in cache_data and time.time() - cache_time.get(key, 0) < CACHE_DURATION:
        return cache_data[key]
    return None

def set_cached_data(key, data):
    """设置缓存数据"""
    cache_data[key] = data
    cache_time[key] = time.time()

# 使用缓存
def get_market_overview_with_cache():
    cache_key = "market_overview"
    cached = get_cached_data(cache_key)
    if cached:
        return cached
    
    data = get_market_overview()
    if data:
        set_cached_data(cache_key, data)
    return data
```

### 2. 并行请求

```python
import asyncio
import aiohttp

async def fetch_api(session, entry, params):
    url = f"http://123.60.27.66:7615/TQLEX?Entry={entry}"
    async with session.post(url, json=params) as response:
        return await response.json()

async def get_all_data():
    async with aiohttp.ClientSession() as session:
        # 并行请求所有接口
        tasks = [
            fetch_api(session, "HQServ.PBHQInfo", {
                "Head": {"Target": 0},
                "Setcode": "1",
                "Code": "880005",
                "HasHQInfo": "1",
                "BspNum": "5"

                "Head": {"Target": 0},

            fetch_api(session, "HQServ.PBXmlBlock", {
                "Head": {"Target": 0},
                "Code": "HY,1,0,3",
                "Blockid": "MStock_ZLJX_ADDE"
            })
        ]
        return await asyncio.gather(*tasks)

# 使用示例
if __name__ == "__main__":
```
