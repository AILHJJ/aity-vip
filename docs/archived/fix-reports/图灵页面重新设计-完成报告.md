## ⚠️ 可能的问题

### 问题1: 行情不显示
**原因**: 后端服务未启动或CORS问题
**解决**:
```bash
cd backend
pm2 restart aity-backend
```

### 问题2: 涨跌颜色不对
**原因**: 数据解析问题
**检查**: 浏览器Console查看数据格式

### 问题3: 免责声明每次都弹
**原因**: 本地存储失败
**解决**: 清除小程序缓存重试

### 问题4: 功能卡片点击无反应
**原因**: JavaScript错误
**解决**: 检查Console错误信息
