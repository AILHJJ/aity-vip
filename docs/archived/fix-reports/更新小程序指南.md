# 投研图灵室 - 小程序更新指南

## 🚀 最快速的更新方式

### 方式一：使用快速更新脚本（推荐）

1. **双击运行脚本**
   ```
   scripts\quick-update.bat
   ```

2. **按提示输入信息**
   - 版本号：例如 `1.0.2`
   - 版本描述：例如 `修复登录问题`

3. **等待完成**
   - 脚本会自动构建和上传
   - 完成后会显示下一步操作提示

4. **提交审核**
   - 登录微信公众平台
   - 找到新上传的版本
   - 点击提交审核

---

### 方式二：仅构建不上传

如果你想先在微信开发者工具中预览，再决定是否上传：

1. **双击运行脚本**
   ```
   scripts\quick-build.bat
   ```

2. **打开微信开发者工具**
   - 导入项目：`aity-uni-app-v2\dist\build\mp-weixin`
   - AppID：`wxb16a33cdd58f05d3`
   - 预览和测试

3. **确认无误后上传**
   - 在微信开发者工具中点击"上传"
   - 或运行 `quick-update.bat`

---

### 方式三：命令行方式

如果你熟悉命令行：

```bash
# 进入项目目录
cd aity-uni-app-v2

# 构建
npm run build:mp-weixin

# 上传（自定义版本号和描述）
set VERSION=1.0.2 && set DESC=修复登录问题 && npm run upload:weixin
```

## 📋 完整更新流程

### 1. 修改代码
在 `aity-uni-app-v2/src/` 目录下修改你的代码

### 2. 本地测试（可选）
```bash
cd aity-uni-app-v2
npm run dev:mp-weixin
```
在微信开发者工具中测试

### 3. 构建生产版本
运行 `scripts\quick-build.bat` 或：
```bash
cd aity-uni-app-v2
npm run build:mp-weixin
```

### 4. 上传到微信平台
运行 `scripts\quick-update.bat` 或：
```bash
set VERSION=1.0.2 && set DESC=更新说明 && npm run upload:weixin
```

### 5. 提交审核
1. 登录 https://mp.weixin.qq.com/
2. 进入：开发管理 → 版本管理
3. 在"开发版本"中找到新版本
4. 点击"提交审核"

### 6. 等待审核
- 审核时间：1-7 个工作日
- 可在"审核版本"中查看进度

### 7. 发布上线
- 审核通过后，点击"发布"
- 用户即可使用新版本

## ⚠️ 注意事项

### 版本号规则
- 格式：`主版本.次版本.修订号`
- 例如：`1.0.0` → `1.0.1` → `1.0.2`
- 每次上传版本号应递增

### 常见问题

#### 1. 上传失败：invalid ip
**原因**：IP 地址未在白名单中

**解决**：
1. 登录微信公众平台
2. 进入：开发 → 开发管理 → 开发设置
3. 在"小程序代码上传"部分添加 IP 白名单
4. 添加你的 IP 地址

#### 2. 构建失败
**原因**：代码语法错误或依赖问题

**解决**：
1. 检查控制台错误信息
2. 修复代码错误
3. 确保依赖已安装：`npm install`

#### 3. 审核被拒
**原因**：不符合微信小程序规范

**解决**：
1. 查看审核反馈
2. 根据反馈修改代码
3. 重新提交审核

## 📝 版本管理建议

### 版本号含义
- **1.x.x**：主版本号，重大功能更新
- **x.1.x**：次版本号，新增功能
- **x.x.1**：修订号，bug 修复

### 版本描述示例
- `修复登录页面显示问题`
- `新增消息搜索功能`
- `优化讨论区加载速度`
- `更新用户协议`

### Git 提交建议
每次更新前先提交代码到 Git：
```bash
git add .
git commit -m "feat: 新增消息搜索功能"
git push
```
