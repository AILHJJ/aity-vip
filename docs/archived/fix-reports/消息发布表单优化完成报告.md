## 三、localStorage使用方式

### 3.1 策略选择记忆功能

#### **保存策略选择**
```javascript
// Key定义
const STRATEGY_KEY = 'last_selected_strategy'

// 用户选择策略时保存
uni.setStorageSync(STRATEGY_KEY, 'short_term') // 或 'mid_term'
```

#### **恢复策略选择**
```javascript
// 页面加载时恢复
const lastStrategy = uni.getStorageSync(STRATEGY_KEY)
if (lastStrategy) {
  formData.value.strategy = lastStrategy
}
```

### 3.2 草稿自动保存

#### **草稿保存**
```javascript
// Key定义
const DRAFT_KEY = 'message_draft'

// 自动保存草稿（包含所有表单字段）
uni.setStorageSync(DRAFT_KEY, JSON.stringify(formData.value))
```

#### **草稿恢复**
```javascript
// 页面加载时检查并恢复
const draft = uni.getStorageSync(DRAFT_KEY)
if (draft) {
  const draftData = JSON.parse(draft)
  // 恢复所有字段
  formData.value = {
    strategy: draftData.strategy,
    pushTarget: draftData.pushTarget,
    messageTypes: draftData.messageTypes,
    title: draftData.title,
    content: draftData.content,
    attachments: draftData.attachments
  }
}
```

### 3.3 localStorage数据示例

#### **策略选择**
```json
// Key: last_selected_strategy
"short_term"
```

#### **草稿数据**
```json
// Key: message_draft
{
  "strategy": "short_term",

  "messageTypes": ["pre_market_comment", "morning_focus"],
  "title": "今日盘前策略分析",
  "content": "# 市场预览\n\n...",

}
```

## 十、使用说明

### 10.1 发布新消息（管理员）
1. 进入发布消息页面
2. 选择策略类型（短线/中线）- 必填
3. 选择推送对象（短线VIP/中线VIP/全部用户）- 必填
4. 选择消息类型（可选一个或多个）- 可选
5. 输入消息标题 - 必填
6. 输入消息内容（支持Markdown）- 必填
7. 上传附件（可选）
8. 点击"发布消息"

### 10.2 编辑已有消息（管理员）
1. 从消息详情页点击"编辑"
2. 表单自动填充原有数据
3. 修改需要的字段
4. 点击"发布消息"（实际是保存修改）

### 10.3 localStorage管理
```javascript
// 查看当前存储的策略选择
uni.getStorageSync('last_selected_strategy')

// 查看当前草稿
uni.getStorageSync('message_draft')

// 清除草稿（用户点击"取消"草稿恢复时）
uni.removeStorageSync('message_draft')

// 策略选择会一直保留，直到用户选择不同的策略
```
