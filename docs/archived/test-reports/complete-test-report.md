## 🔧 发现并修复的问题

### 问题1: 行情页面权限缺失 ✅ 已修复

**问题描述**:
- 行情页面在pages.json第一位，成为默认首页
- 不需要登录就能访问行情功能
- 与产品需求不符（应该是二级功能）

**修复方案**:
1. 将登录页设为首页（pages.json第一位）
2. 行情页面移到pages列表末尾
3. 在行情页面添加登录检查逻辑

**修复代码**:
```javascript
// market.vue
import { useUserStore } from '../../store/user'

const userStore = useUserStore()

// 检查登录状态
const checkLogin = () => {
  if (!userStore.isLoggedIn) {
    uni.showToast({
      title: '请先登录',
      icon: 'none',
      duration: 2000
    })
    setTimeout(() => {
      uni.navigateTo({
        url: '/pages/login/login'
      })
    }, 1500)
    return false
  }
  return true
}

onMounted(() => {
  if (checkLogin()) {
    refreshData()
  }
})
```
