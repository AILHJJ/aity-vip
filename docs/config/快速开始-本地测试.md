本指南帮助你快速启动本地测试环境。

- ✅ 后端服务已启动（`backend/src/index.js`）
- ✅ 数据库已配置并包含测试数据

- ✅ 手机和电脑在同一 WiFi 网络

## 方案 B: 微信小程序本地测试

### 1. 确认小程序已编译

小程序代码已编译完成，输出目录：
```
D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\dev\mp-weixin
```

### 2. 打开微信开发者工具

#### 步骤 1: 导入项目
1. 打开微信开发者工具
2. 点击 **"+"** 创建项目
3. 填写信息：
   - **项目名称**: AITY VIP 本地测试
   - **目录**: `D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\dev\mp-weixin`
   - **AppID**: 选择 **"测试号"**
4. 点击 **"确定"**

#### 步骤 2: 配置开发设置
1. 点击右上角 **"详情"**
2. 在 **"本地设置"** 中勾选：
   - ✅ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
3. 关闭详情面板

#### 步骤 3: 测试
- 在模拟器中测试功能
- 点击 **"预览"** 扫码在手机上测试

### 3. 真机测试

1. 点击工具栏 **"预览"** 按钮
2. 使用微信扫描二维码
3. 在手机微信中打开小程序

**注意**:
- 确保手机和电脑在同一 WiFi
- 确保后端服务正在运行
- 首次加载可能需要几秒钟

## 常见问题快速解决

### 问题 1: 小程序无法连接后端

**检查清单**:
```bash
# 1. 检查后端服务是否运行
curl http://localhost:3001/api/health

# 2. 检查本机 IP
ipconfig
# 确认 IPv4 地址是否为 192.168.2.140

# 3. 检查防火墙
# Windows: 允许 Node.js 通过防火墙
```

**解决方案**:
- 确保后端服务正在运行
- 确保微信开发者工具中勾选了"不校验合法域名"
- 检查防火墙设置

### 问题 2: 修改代码后没有更新

**H5**:
- Vite 会自动热更新，刷新浏览器即可

**小程序**:
1. 保存文件
2. 等待 Vite 重新编译（查看命令行输出）
3. 在微信开发者工具中点击 **"编译"**

### 问题 3: 登录后提示 token 过期

**解决方案**:
1. 清除浏览器缓存或小程序缓存
2. 重新登录
3. 如果问题持续，重启后端服务

## 测试流程建议

### 第一步: H5 快速验证（5-10 分钟）
1. 启动 H5 开发服务器
2. 在浏览器中登录测试

1. 导入项目到微信开发者工具
2. 在模拟器中测试
3. 验证小程序特有交互

### 第三步: 真机测试（15-20 分钟）
1. 使用 "预览" 功能在手机上测试
2. 测试真实使用场景
3. 验证性能和用户体验
