## 环境准备

### 1. 必备软件
- **Node.js**: v16+ (推荐 v18)
- **MySQL**: v8.0+
- **微信开发者工具**: 最新稳定版
- **代码编辑器**: VS Code (推荐)

### 2. 获取本机 IP 地址
打开命令行，执行：
```bash
ipconfig
```
找到 `IPv4 地址`，例如：`192.168.2.140`

**重要**: 确保手机和电脑在同一局域网内。

## 后端配置

### 1. 安装依赖
```bash
cd backend
npm install
```

### 2. 配置数据库
编辑 `backend/.env` 文件：
```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=aity_vip

# JWT 配置
JWT_SECRET=your-secret-key-here
JWT_EXPIRES_IN=24h

# 服务器配置
PORT=3001
NODE_ENV=development
```

### 3. 初始化数据库
```bash
# 创建数据库
mysql -u root -p
CREATE DATABASE aity_vip CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
exit;

# 导入表结构
cd backend
node scripts/init-db.js

# 创建测试数据
node scripts/create-test-data.js
```

### 4. 配置 CORS（重要）
编辑 `backend/src/index.js`，确保 CORS 配置包含本机 IP：

```javascript
app.use(cors({
  origin: [
    'http://localhost:5173',
    'http://localhost:5174',
    'http://localhost:5175',
    'http://192.168.2.140:5173',  // 添加本机 IP
    'http://192.168.2.140:5174',
    'http://192.168.2.140:5175'
  ],
  credentials: true
}));
```

### 5. 启动后端服务
```bash
cd backend
node src/index.js
```

**验证**: 访问 `http://localhost:3001/api/health`，应返回：
```json
{
  "status": "ok",
  "timestamp": "2026-01-30T..."
}
```

## 前端配置

### 1. 安装依赖
```bash
cd aity-uni-app-v2
npm install
```

### 2. 验证 API 配置
打开 `src/utils/request.js`，确认配置正确：

```javascript
const BASE_URL = process.env.NODE_ENV === 'development'
  ? (typeof window !== 'undefined' && window.location.protocol === 'http:'
      ? '/api'  // H5 开发环境使用代理
      : 'http://192.168.2.140:3001/api')  // 小程序开发环境使用本机 IP
  : 'https://aity88.online:8443/api'  // 生产环境
```

**说明**:
- H5 模式：使用 Vite 代理 `/api` → `http://localhost:3001/api`
- 小程序模式：直接访问 `http://192.168.2.140:3001/api`

### 3. 验证 Vite 代理配置
打开 `vite.config.js`，确认代理配置：

```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:3001',
      changeOrigin: true
    }
  }
}
```

## 小程序本地测试

### 1. 编译小程序代码
```bash
cd aity-uni-app-v2
npm run dev:mp-weixin
```

**输出目录**: `dist/dev/mp-weixin`

### 2. 打开微信开发者工具

#### 步骤 1: 导入项目
1. 打开微信开发者工具
2. 点击 **"+"** 创建项目
3. 填写项目信息：
   - **项目名称**: AITY VIP 本地测试
   - **目录**: 选择 `D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\dev\mp-weixin`
   - **AppID**: 选择 **"测试号"**（本地测试无需正式 AppID）
   - **开发模式**: 小程序
4. 点击 **"确定"**

#### 步骤 2: 配置开发设置
1. 点击右上角 **"详情"**
2. 在 **"本地设置"** 中勾选：
   - ✅ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
   - ✅ **不校验安全域名、TLS 版本以及 HTTPS 证书**
3. 关闭详情面板

#### 步骤 3: 编译运行
- 微信开发者工具会自动编译项目
- 等待编译完成（左下角显示 "编译成功"）
- 在模拟器中查看效果

### 3. 真机调试

#### 方法 1: 预览（推荐）
1. 点击工具栏 **"预览"** 按钮
2. 扫描生成的二维码
3. 在手机微信中打开小程序

**注意**:
- 手机必须和电脑在同一局域网
- 后端服务必须正在运行
- 首次访问可能需要等待几秒

#### 方法 2: 真机调试
1. 点击工具栏 **"真机调试"** 按钮
2. 扫描二维码
3. 可以在开发者工具中查看手机上的日志

### 4. 常见调试技巧

#### 查看网络请求
1. 点击 **"调试器"** 标签
2. 选择 **"Network"** 面板
3. 查看 API 请求和响应

#### 查看控制台日志
1. 点击 **"调试器"** 标签
2. 选择 **"Console"** 面板
3. 查看 `console.log` 输出

#### 清除缓存
1. 点击 **"清缓存"** → **"清除全部缓存"**
2. 重新编译项目

## 常见问题

### 1. 小程序无法连接后端

**症状**:
- 登录失败，提示 "网络请求失败"
- Network 面板显示请求失败

**解决方案**:
1. **检查后端服务是否运行**:
   ```bash
   # 访问健康检查接口
   curl http://localhost:3001/api/health
   ```

2. **检查本机 IP 是否正确**:
   ```bash
   ipconfig
   # 确认 IPv4 地址是否为 192.168.2.140
   ```

3. **检查防火墙设置**:
   - Windows: 允许 Node.js 通过防火墙
   - 或临时关闭防火墙测试

4. **检查是否勾选"不校验合法域名"**:
   - 微信开发者工具 → 详情 → 本地设置 → 勾选

### 2. H5 可以访问，小程序不行

**原因**: H5 使用代理，小程序直接访问 IP

**解决方案**:
1. 确认 `src/utils/request.js` 中的 IP 地址正确
2. 确认后端 CORS 配置包含本机 IP
3. 重新编译小程序：`npm run dev:mp-weixin`

### 3. 修改代码后小程序没有更新

**解决方案**:
1. **保存文件**: 确保代码已保存
2. **等待编译**: Vite 会自动重新编译（查看命令行输出）
3. **刷新小程序**: 在微信开发者工具中点击 "编译"
4. **清除缓存**: 清缓存 → 清除全部缓存 → 重新编译

### 4. 手机扫码后小程序打不开

**解决方案**:
1. **检查网络**: 手机和电脑必须在同一 WiFi
2. **检查后端**: 确保后端服务正在运行
3. **检查 IP**: 使用 `ipconfig` 确认 IP 地址
4. **重新预览**: 点击 "预览" 重新生成二维码

### 5. 登录后提示 token 过期

**原因**: 后端 JWT 配置问题

**解决方案**:
1. 检查 `backend/.env` 中的 `JWT_SECRET`
2. 重启后端服务
3. 清除小程序缓存
4. 重新登录

### 6. 图片或资源加载失败

**原因**: 资源路径配置问题

**解决方案**:
1. 检查 `manifest.json` 中的 `h5.router.base` 配置
2. 使用相对路径或绝对路径
3. 确保资源文件存在于 `static` 目录

## 测试流程建议

### 第一阶段: H5 测试（快速验证）
1. 启动后端服务
2. 启动 H5 开发服务器
3. 在浏览器中测试核心功能
4. 修复发现的问题

### 第二阶段: 小程序模拟器测试
1. 编译小程序代码
2. 在微信开发者工具中测试
3. 验证小程序特有功能
4. 检查网络请求是否正常

### 第三阶段: 真机测试
1. 使用 "预览" 功能在手机上测试
2. 测试真实网络环境
3. 验证用户体验
4. 收集性能数据
