## 🔐 SSH密钥配置

### 密钥信息

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **私钥路径** | D:\Git\.ssh\id_rsa_deploy | SSH私钥文件路径 |
| **公钥路径** | D:\Git\.ssh\id_rsa_deploy.pub | SSH公钥文件路径 |
| **备份路径** | d:\your-mcp-proxy\AITY_VIP\ssh_keys_backup\ | 密钥备份目录 |
| **密钥类型** | RSA | 密钥算法 |
| **密钥长度** | 4096 | 密钥位数 |
| **密钥密码** | 无 | 无密码保护 |

### 生成SSH密钥

**Windows系统：**

```bash
# 打开Git Bash
cd ~/.ssh

# 生成密钥
ssh-keygen -t rsa -b 4096 -f id_rsa_deploy -N ""

# 查看公钥
cat id_rsa_deploy.pub
```

**Linux/macOS系统：**

```bash
# 生成密钥
ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa_deploy -N ""

# 查看公钥
cat ~/.ssh/id_rsa_deploy.pub
```

### 配置服务器公钥

**复制公钥到服务器：**

```bash
# Windows系统
ssh-copy-id -i D:\Git\.ssh\id_rsa_deploy.pub root@124.221.119.134

# Linux/macOS系统
ssh-copy-id -i ~/.ssh/id_rsa_deploy.pub root@124.221.119.134
```

**手动配置：**

1. **登录服务器：**
   ```bash
   ssh root@124.221.119.134
   ```

2. **编辑authorized_keys文件：**
   ```bash
   vi ~/.ssh/authorized_keys
   ```

3. **粘贴公钥内容**

4. **保存文件**

```bash

ssh -i D:\Git\.ssh\id_rsa_deploy root@124.221.119.134 "echo 'SSH免密登录成功！'"
```
