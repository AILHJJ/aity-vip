## 后端部署

### 1. 连接服务器
```bash
ssh root@aity88.online
# 或使用 IP 地址
ssh root@your_server_ip
```

### 2. 安装必要软件

#### 安装 Node.js (v18 LTS)
```bash
# 使用 nvm 安装
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 18
nvm use 18
node -v  # 验证安装
```

#### 安装 MySQL
```bash
# 安装 MySQL 8.0
sudo apt update
sudo apt install mysql-server -y

# 启动 MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# 安全配置
sudo mysql_secure_installation
```

#### 安装 PM2（进程管理器）
```bash
npm install -g pm2
```

### 3. 部署后端代码

#### 方法 1: Git 部署（推荐）
```bash
# 创建项目目录
mkdir -p /var/www/aity-vip
cd /var/www/aity-vip

# 克隆代码（如果使用 Git）
git clone https://github.com/AILHJJ/aity-vip.git .

# 或者使用 scp 上传代码
# 在本地执行：
# scp -r D:\your-mcp-proxy\AITY_VIP\backend root@aity88.online:/var/www/aity-vip/
```

#### 方法 2: 手动上传
使用 FTP 工具（如 FileZilla）上传 `backend` 目录到服务器。

### 4. 配置生产环境

#### 创建生产环境配置文件
```bash
cd /var/www/aity-vip/backend
nano .env.production
```

**内容**:
```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=fl
DB_PASSWORD=fl10b312
DB_NAME=投研图灵室

# JWT 配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=24h

# 服务器配置
PORT=3001
NODE_ENV=production

# CORS 配置
ALLOWED_ORIGINS=https://aity88.online:8443,https://servicewechat.com

# 日志配置
LOG_LEVEL=info
LOG_FILE=/var/log/aity-vip/backend.log
```

### 5. 配置数据库

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库和用户
CREATE DATABASE IF NOT EXISTS `投研图灵室` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'fl'@'localhost' IDENTIFIED BY 'fl10b312';
GRANT ALL PRIVILEGES ON `投研图灵室`.* TO 'fl'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 初始化数据库表结构
cd /var/www/aity-vip/backend
NODE_ENV=production node scripts/init-db.js

# 创建初始管理员账号
NODE_ENV=production node scripts/create-admin.js
```

### 6. 安装依赖并启动服务

```bash
cd /var/www/aity-vip/backend

# 安装生产依赖
npm install --production

# 使用 PM2 启动服务
npm run pm2:start

# 设置开机自启
npm run pm2:save

# 查看服务状态
npm run pm2:list
npm run pm2:logs
```

### 7. 配置 Nginx 反向代理

#### 安装 Nginx
```bash
sudo apt install nginx -y
```

#### 配置 HTTPS
```bash
sudo nano /etc/nginx/sites-available/aity-vip
```

**配置内容**:
```nginx
# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name aity88.online;
    return 301 https://$server_name:8443$request_uri;
}

# HTTPS 配置
server {
    listen 8443 ssl http2;
    server_name aity88.online;

    # SSL 证书配置
    ssl_certificate /etc/nginx/ssl/aity88.online.crt;
    ssl_certificate_key /etc/nginx/ssl/aity88.online.key;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;

    # 安全头
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 前端静态文件（H5版本）
    location / {
        root /root/private-sharing-app/aity-uni-app-v2/dist/build/h5;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://localhost:3001/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;

        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 健康检查
    location /health {
        proxy_pass http://localhost:3001/api/health;
        access_log off;
    }

    # 日志
    access_log /var/log/nginx/aity-vip-access.log;
    error_log /var/log/nginx/aity-vip-error.log;
}
```

#### 启用配置
```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/aity-vip /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
sudo systemctl enable nginx
```

### 8. 配置防火墙

```bash
# 允许 HTTP、HTTPS 和自定义端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 8443/tcp
sudo ufw allow 22/tcp  # SSH

# 启用防火墙
sudo ufw enable
sudo ufw status
```

### 9. 验证后端部署

```bash
# 测试健康检查
curl https://aity88.online:8443/api/health

# 应返回：
# {"status":"ok","timestamp":"2026-01-30T..."}
```

## 小程序发布

### 1. 配置小程序信息

#### 在微信公众平台配置
1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 **开发 → 开发管理 → 开发设置**

#### 配置服务器域名
在 **服务器域名** 中添加：
- **request 合法域名**: `https://aity88.online:8443`
- **uploadFile 合法域名**: `https://aity88.online:8443`
- **downloadFile 合法域名**: `https://aity88.online:8443`

**注意**:
- 域名必须使用 HTTPS
- 域名必须已备案
- 每月只能修改 5 次

#### 配置业务域名（如果使用 web-view）
在 **业务域名** 中添加：
- `aity88.online`

### 2. 上传代码

#### 使用微信开发者工具上传

1. **打开项目**:
   - 打开微信开发者工具
   - 导入项目：`D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2\dist\build\mp-weixin`
   - AppID: `wxb16a33cdd58f05d3`

2. **配置生产环境**:
   - 点击 **详情 → 本地设置**
   - **取消勾选** "不校验合法域名"（生产环境必须校验）

3. **上传代码**:
   - 点击工具栏 **"上传"** 按钮
   - 填写版本号：`1.0.0`
   - 填写项目备注：`首次发布版本`
   - 点击 **"上传"**

4. **验证上传**:
   - 登录微信公众平台
   - 进入 **版本管理**
   - 查看 **开发版本** 中是否有刚上传的版本

### 3. 提交审核

#### 在微信公众平台操作

1. **进入版本管理**:
   - 登录微信公众平台
   - 开发管理 → 版本管理

2. **提交审核**:
   - 在 **开发版本** 中找到刚上传的版本
   - 点击 **"提交审核"**

3. **填写审核信息**:
   - **功能页面**: 选择首页、消息列表、讨论区等核心页面
   - **测试账号**: 提供测试账号和密码（如 `trial_user` / `123456`）
   - **补充说明**: 说明应用功能和使用场景

4. **等待审核**:
   - 审核时间：通常 1-7 个工作日
   - 可在 **审核版本** 中查看审核进度

### 4. 发布上线

审核通过后：
1. 进入 **版本管理**
2. 在 **审核版本** 中点击 **"发布"**
3. 确认发布
4. 发布成功后，用户可在微信中搜索并使用小程序

## 域名配置

### 1. DNS 配置

确保域名 `aity88.online` 已正确解析到服务器 IP：

```bash
# 检查 DNS 解析
nslookup aity88.online
dig aity88.online
```

### 2. SSL 证书配置

#### 使用腾讯云免费证书

1. 登录腾讯云控制台
2. 进入 **SSL 证书管理**
3. 申请免费证书（DV 型，1 年有效期）
4. 下载证书文件（Nginx 格式）
5. 上传到服务器：
   ```bash
   sudo mkdir -p /etc/nginx/ssl
   sudo cp aity88.online.crt /etc/nginx/ssl/
   sudo cp aity88.online.key /etc/nginx/ssl/
   sudo chmod 600 /etc/nginx/ssl/aity88.online.key
   ```

#### 自动续期（使用 Let's Encrypt）

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx -y

# 申请证书
sudo certbot --nginx -d aity88.online

# 自动续期（Certbot 会自动配置 cron job）
sudo certbot renew --dry-run
```

## 安全加固

### 1. 数据库安全

```bash
# 禁止 root 远程登录
mysql -u root -p
UPDATE mysql.user SET Host='localhost' WHERE User='root';
FLUSH PRIVILEGES;

# 定期备份数据库
# 创建备份脚本
sudo nano /usr/local/bin/backup-db.sh
```

**备份脚本内容**:
```bash
#!/bin/bash
BACKUP_DIR="/var/backups/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

mysqldump -u fl -p'fl10b312' 投研图灵室 > $BACKUP_DIR/aity_vip_$DATE.sql
gzip $BACKUP_DIR/aity_vip_$DATE.sql

# 保留最近 7 天的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +7 -delete
```

```bash
# 设置执行权限
sudo chmod +x /usr/local/bin/backup-db.sh

# 添加到 crontab（每天凌晨 2 点备份）
sudo crontab -e
# 添加：0 2 * * * /usr/local/bin/backup-db.sh
```

### 2. 应用安全

#### 环境变量保护
```bash
# 设置文件权限
chmod 600 /root/private-sharing-app/backend/.env.production
chown www-data:www-data /root/private-sharing-app/backend/.env.production
```

#### 日志管理
```bash
# 创建日志目录
sudo mkdir -p /var/log/aity-vip
sudo chown www-data:www-data /var/log/aity-vip

# 配置日志轮转
sudo nano /etc/logrotate.d/aity-vip
```

**日志轮转配置**:
```
/var/log/aity-vip/*.log {
    daily
    rotate 14
    compress
    delaycompress
    notifempty
    create 0640 www-data www-data
    sharedscripts
    postrotate
        pm2 reloadLogs
    endscript
}
```

### 3. 服务器安全

```bash
# 禁用 root SSH 登录
sudo nano /etc/ssh/sshd_config
# 修改：PermitRootLogin no

# 使用密钥登录
# 在本地生成密钥对
ssh-keygen -t rsa -b 4096

# 上传公钥到服务器
ssh-copy-id user@aity88.online

# 重启 SSH 服务
sudo systemctl restart sshd
```

## 监控与维护

### 1. 服务监控

#### 使用 PM2 监控
```bash
# 查看服务状态
pm2 status

# 查看日志
pm2 logs aity-backend

# 查看详细信息
pm2 show aity-backend

# 监控面板
pm2 monit
```

#### 配置 PM2 监控告警
```bash
# 安装 PM2 Plus（可选）
pm2 install pm2-logrotate
pm2 set pm2-logrotate:max_size 10M
pm2 set pm2-logrotate:retain 7
```

### 2. 性能监控

#### 使用 Nginx 状态监控
```nginx
# 在 Nginx 配置中添加
location /nginx_status {
    stub_status on;
    access_log off;
    allow 127.0.0.1;
    deny all;
}
```

#### 数据库性能监控
```bash
# 查看慢查询日志
sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
# 添加：
# slow_query_log = 1
# slow_query_log_file = /var/log/mysql/slow-query.log
# long_query_time = 2

# 重启 MySQL
sudo systemctl restart mysql
```

### 3. 定期维护任务

#### 每日任务
- 检查服务状态：`pm2 status`
- 查看错误日志：`pm2 logs aity-backend --err`
- 检查磁盘空间：`df -h`

#### 每周任务
- 更新系统包：`sudo apt update && sudo apt upgrade`
- 检查安全更新：`sudo unattended-upgrades`
- 审查访问日志：`sudo tail -n 100 /var/log/nginx/aity-vip-access.log`

#### 每月任务
- 数据库优化：`mysqlcheck -u root -p --optimize --all-databases`
- 清理旧日志：`sudo journalctl --vacuum-time=30d`
- 审查用户活动：检查异常登录和操作

## 常见问题

### 1. 小程序提示 "不在以下 request 合法域名列表中"

**解决方案**:
1. 检查微信公众平台中的服务器域名配置
2. 确保域名使用 HTTPS
3. 确保域名已备案
4. 等待配置生效（最多 5 分钟）

### 2. 后端服务无法访问

**解决方案**:
```bash
# 检查服务状态
pm2 status

# 检查端口占用
netstat -tlnp | grep 3001

# 检查防火墙
sudo ufw status

# 查看日志
pm2 logs aity-backend --lines 100
```

### 3. SSL 证书过期

**解决方案**:
```bash
# 检查证书有效期
openssl x509 -in /etc/nginx/ssl/aity88.online.crt -noout -dates

# 续期证书（Let's Encrypt）
sudo certbot renew

# 重启 Nginx
sudo systemctl restart nginx
```

### 4. 数据库连接失败

**解决方案**:
```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 测试连接
mysql -u aity_user -p -h localhost aity_vip_prod

# 检查用户权限
mysql -u root -p
SHOW GRANTS FOR 'aity_user'@'localhost';
```
