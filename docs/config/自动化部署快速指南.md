# 自动化部署快速指南

## 🚀 三步完成部署

只需要 3 个步骤，30 分钟完成部署！

---

## 步骤 1：上传文件到服务器（5分钟）

### 在本地 Windows 执行

打开 PowerShell 或 CMD，执行以下命令：

```bash
# 进入项目目录
cd D:\your-mcp-proxy\AITY_VIP

# 上传后端代码
scp -r backend root@aity88.online:/var/www/aity-vip/

# 上传部署脚本
scp scripts/deploy-auto.sh root@aity88.online:/tmp/
```

**输入密码后等待上传完成**

---

## 步骤 2：运行自动化部署脚本（20-25分钟）

### 连接到服务器

```bash
ssh root@aity88.online
```

### 运行部署脚本

```bash
# 给脚本添加执行权限
chmod +x /tmp/deploy-auto.sh

# 运行部署脚本
bash /tmp/deploy-auto.sh
```

**脚本会自动完成以下操作**：

1. ✅ 安装 Node.js 18
2. ✅ 安装 PM2
3. ✅ 安装 Nginx
4. ✅ 检查项目目录
5. ✅ 测试数据库连接
6. ✅ 创建环境配置文件
7. ✅ 安装项目依赖
8. ✅ 初始化数据库
9. ✅ 创建日志目录
10. ✅ 启动后端服务
11. ✅ 配置 Nginx
12. ✅ 配置防火墙

**等待脚本执行完成，看到 "🎉 部署完成！" 即可**

---

## 步骤 3：验证部署（5分钟）

### 在服务器上测试

```bash
# 测试健康检查接口
curl http://localhost:3001/api/health
```

**应该返回**：
```json
{"status":"ok","timestamp":"..."}
```

### 在本地浏览器测试

打开浏览器，访问：
```
https://aity88.online:8443/api/health
```

**应该看到相同的 JSON 响应**

### 测试小程序连接

1. 打开微信开发者工具
2. 打开小程序项目
3. 编译运行
4. 尝试登录（trial_user / 123456）
5. 查看消息列表

**如果能正常登录和查看消息**：✅ 部署成功！

## ⚠️ 关于 SSL 证书

### 如果你已有 SSL 证书

在本地执行：

```bash
# 上传证书文件
scp your_cert_path/aity88.online.crt root@aity88.online:/etc/nginx/ssl/
scp your_cert_path/aity88.online.key root@aity88.online:/etc/nginx/ssl/
```

然后在服务器上重启 Nginx：

```bash
systemctl restart nginx
```

### 如果没有 SSL 证书

在服务器上执行：

```bash
# 安装 Certbot
apt-get install -y certbot python3-certbot-nginx

# 申请免费证书
certbot --nginx -d aity88.online

# 按照提示操作即可
```

## ❓ 常见问题

### 问题 1：上传文件失败

**原因**：SSH 连接问题或权限问题

**解决**：
1. 确认可以 SSH 连接到服务器
2. 确认有 root 权限
3. 检查目标目录是否存在：`mkdir -p /var/www/aity-vip`

### 问题 2：脚本执行失败

**解决**：
1. 查看错误信息
2. 记录失败的步骤
3. 告诉我具体的错误信息

### 问题 3：服务启动失败

**解决**：
```bash
# 查看详细日志
pm2 logs aity-backend --err --lines 50

# 检查环境配置
cat /var/www/aity-vip/backend/.env.production

# 测试数据库连接
mysql -h 124.221.119.134 -u fl -pfl10b312 -e "SELECT 1;"
```

### 问题 4：Nginx 配置失败

**原因**：SSL 证书不存在

**解决**：
1. 上传 SSL 证书（见上文）
2. 或使用 Let's Encrypt 申请免费证书
3. 重新运行脚本或手动配置 Nginx
