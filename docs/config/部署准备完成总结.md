### 立即需要做的事情

#### 1. 配置微信公众平台（必须）

**步骤 1: 添加 IP 白名单**

1. 登录微信公众平台：https://mp.weixin.qq.com/
2. 进入 **开发 → 开发管理 → 开发设置**
3. 找到 **小程序代码上传** 部分
4. 点击 **IP 白名单配置**
5. 添加 IP：`58.49.104.171`（你的当前 IP）

**步骤 2: 配置服务器域名**

1. 在同一页面找到 **服务器域名** 部分
2. 点击 **修改**
3. 添加域名：
   - request 合法域名：`https://aity88.online:8443`
   - uploadFile 合法域名：`https://aity88.online:8443`
   - downloadFile 合法域名：`https://aity88.online:8443`
4. 保存并提交

#### 2. 上传小程序代码

配置完 IP 白名单后，在本地执行：

```bash
cd D:\your-mcp-proxy\AITY_VIP\aity-uni-app-v2
npm run upload:weixin
```

#### 3. 部署后端到服务器

**方式 1: 使用自动化脚本（推荐）**

参考文档：`docs/config/服务器部署详细指令.md` 的"方式 1"部分

## 常见问题预防

### 1. 小程序上传失败：invalid ip

**原因**：IP 地址未在白名单中

**解决**：在微信公众平台添加 IP 白名单（见上文"下一步操作"）

### 2. 小程序提示域名不合法

**原因**：服务器域名未配置

**解决**：在微信公众平台配置服务器域名（见上文"下一步操作"）

### 3. 服务器部署失败

**原因**：可能是权限、网络或配置问题

**解决**：参考 `docs/config/服务器部署详细指令.md` 中的故障排查部分
