## 📦 部署流程

### 1. 环境准备

#### 安装Node.js

```bash
# 安装Node.js v20.20.0
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

# 验证版本
node -v
npm -v
```

#### 安装PM2

```bash
# 安装PM2
npm install -g pm2

# 验证版本
pm -v
```

#### 安装Nginx

```bash
# 安装Nginx
apt-get update
apt-get install -y nginx

# 启动Nginx
systemctl start nginx

# 设置开机自启
systemctl enable nginx

# 验证状态
systemctl status nginx
```

#### 安装MySQL

```bash
# 安装MySQL
apt-get install -y mysql-server

# 启动MySQL
systemctl start mysql

# 设置开机自启
systemctl enable mysql

# 验证状态
systemctl status mysql
```

### 3. Nginx配置

#### 基本配置

```nginx
# 创建Nginx配置文件
cat > /etc/nginx/sites-available/aity-vip << EOF
server {
    listen 8080;
    server_name aity88.online;
    return 301 https://$host:8443$request_uri;
}

server {
    listen 8443 ssl http2;
    server_name aity88.online;
    
    # 证书配置
    ssl_certificate /etc/letsencrypt/live/aity88.online/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/aity88.online/privkey.pem;
    
    # SSL配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-SHA384;
    ssl_prefer_server_ciphers on;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;
    ssl_session_tickets off;
    
    # HSTS配置
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    
    # 前端静态文件（H5版本）
    location / {
        root /root/private-sharing-app/aity-uni-app-new/dist/build/h5;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    # 后端API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
EOF

# 创建软链接
ln -s /etc/nginx/sites-available/aity-vip /etc/nginx/sites-enabled/

# 测试配置
nginx -t

# 重启Nginx
systemctl restart nginx
```

### 4. HTTPS配置

#### 申请SSL证书

**使用Let's Encrypt（免费）**

```bash
# 安装Certbot
apt-get install -y certbot python3-certbot-nginx

# 申请证书
certbot --nginx -d aity88.online

# 自动续期配置
echo "0 0 1 * * certbot renew --quiet" > /etc/cron.d/certbot-renew
```

#### 证书配置

**证书文件路径**

| 文件 | 路径 | 用途 |
|------|------|------|
| 完整证书链 | /etc/letsencrypt/live/aity88.online/fullchain.pem | 包含服务器证书和中间证书 |
| 私钥 | /etc/letsencrypt/live/aity88.online/privkey.pem | 服务器私钥 |
| 证书 | /etc/letsencrypt/live/aity88.online/cert.pem | 服务器证书 |
| 链证书 | /etc/letsencrypt/live/aity88.online/chain.pem | 中间证书 |

#### 安全配置

**SSL优化配置**

```nginx
# SSL优化配置
ssl_protocols TLSv1.2 TLSv1.3;
ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-SHA384;
ssl_prefer_server_ciphers on;
ssl_session_cache shared:SSL:10m;
ssl_session_timeout 10m;
ssl_session_tickets off;
ssl_stapling on;
ssl_stapling_verify on;
resolver 8.8.8.8 8.8.4.4 valid=300s;
resolver_timeout 5s;
```

**安全头部**

```nginx
# 安全头部
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self';" always;
add_header X-XSS-Protection "1; mode=block" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
```

## 🚨 常见问题与解决方案

### 1. 服务器登录问题

**问题**：无法通过SSH连接服务器

**解决方案**：
- 检查服务器IP地址是否正确
- 检查SSH密钥是否正确
- 检查服务器防火墙是否开放22端口
- 检查服务器是否运行

### 2. 数据库连接问题

**问题**：后端服务无法连接数据库

**解决方案**：
- 检查数据库服务是否运行
- 检查数据库配置是否正确
- 检查数据库用户权限是否正确
- 检查数据库密码是否正确

### 3. Nginx配置问题

**问题**：访问网站显示502错误

**解决方案**：
- 检查Nginx配置是否正确
- 检查后端服务是否运行
- 检查后端服务端口是否正确
- 检查Nginx日志

### 4. HTTPS配置问题

**问题**：HTTPS证书无效

**解决方案**：
- 检查证书是否过期
- 检查证书配置是否正确
- 检查域名是否正确
- 重新申请证书

### 5. 小程序部署问题

**问题**：小程序无法访问API

**解决方案**：
- 检查服务器域名是否在小程序后台配置
- 检查HTTPS证书是否有效
- 检查API服务是否运行
- 检查API路由是否正确

### 6. 性能问题

**问题**：系统响应缓慢

**解决方案**：
- 检查服务器资源使用情况
- 优化数据库查询
- 使用缓存
- 升级服务器配置

### 7. 安全问题

**问题**：系统存在安全漏洞

**解决方案**：
- 定期更新依赖
- 加强权限验证
- 防止SQL注入
- 防止XSS攻击
