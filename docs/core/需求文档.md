## 📋 项目概述

VIP投研内部分享系统是一个面向内部用户的私密投研分享平台，管理员可以向指定分组的用户群发推送投研消息，用户可以查看历史消息并发起讨论。系统集成AI投顾（图灵）功能，提供智能化的投资咨询服务。

### 项目目标

- **信息安全**: 确保投研信息的私密分享
- **高效管理**: 简化消息推送和用户管理流程
- **多端支持**: 支持H5和小程序多端访问
- **AI赋能**: 集成AI投顾，提供智能咨询服务
- **数据驱动**: 提供丰富的统计分析功能

## 🏷️ 消息标签与类型

### 消息标签（权限控制）

| 标签名称 | 说明 | 可见用户 |
|----------|------|----------|
| 短线策略 | 短线投资策略 | vip_short, trial, admin |
| 中线策略 | 中线投资策略 | vip_mid, trial, admin |
| 全部用户 | 所有人可见 | 所有VIP用户 |

**标签规则**:
- 消息标签可以多选
- 多选时，满足任一标签的用户都能看到
- 没有标签的消息所有人可见
- trial用户不受标签限制

### 消息类型（内容分类）

| 类型代码 | 类型名称 | 说明 |
|----------|----------|------|
| pre_market_comment | 盘前点评 | 开盘前的市场分析 |
| morning_comment | 早盘点评 | 上午开盘后的市场分析 |
| morning_focus | 早盘关注 | 上午值得关注的个股或板块 |
| afternoon_comment | 尾盘点评 | 下午收盘前的市场分析 |
| afternoon_focus | 尾盘关注 | 下午值得关注的个股或板块 |
| close_comment | 收盘点评 | 全天市场走势的总结 |

| daily | 日常消息 | 日常消息（默认） |

## 📰 消息功能

### 消息发布

- **实时发布**: 立即发布
- **定时发布**: 设置发布时间，精确到分钟
- **消息状态**: draft（草稿）、scheduled（定时）、published（已发布）

### 消息管理

- **编辑**: 只能编辑自己发布的消息
- **删除**: super_admin可删除所有，admin可删除自己的
- **置顶**: 管理员可置顶重要消息
- **收藏**: 用户可收藏消息

### 消息内容

- **标题**: 必填
- **内容**: 支持Markdown语法
- **图片**: 支持图片上传，单张不超过10MB
- **附件**: 支持附件关联

### Markdown主题样式 (v1.8.1新增)

- **主题选择**: 12种预设主题样式
- **交互优化**: 下拉选择器+颜色预览（编辑区下方）
- **记忆功能**: localStorage保存上次选择
- **AI优化**: 一键AI内容优化（与主题选择同行）
- **小程序粘贴**: 工具栏粘贴图片按钮

## 💬 讨论功能

### 讨论属性

| 属性 | 说明 |
|------|------|
| 状态 | pending（待回复）、replied（已回复） |
| 可见性 | private（私密）、public（公开） |

### 讨论规则

- 所有登录用户都可以发起讨论
- 讨论必须关联消息
- 讨论默认私密（private）
- 私密讨论只有管理员和发起者可见
- 管理员可修改讨论可见性
- 有人回复后状态自动变为已回复

## 🤖 AI投顾（图灵）

### 核心功能

- **流式对话**: SSE实时响应
- **上下文记忆**: ThreadId机制保持对话连续性
- **用户隔离**: 每个用户的对话历史独立存储
- **金融工具**: 支持股票查询、行情展示
- **多模型配置**: 支持多种AI模型切换

### 数据展示

- **表格渲染**: 金融工具结果以表格形式展示
- **颜色规则**: 涨红跌绿（符合中国股市习惯）
- **数字格式化**: 千分位、百分比、万亿格式

### 配置管理

- **模型配置**: 支持多模型配置
- **版本管理**: 配置版本控制
- **参数调整**: 可调整温度、最大token等参数

## 🔐 安全与隐私

### 密码安全

- 最小长度: 6位
- 密码永不过期

### 登录安全

- 支持邮箱/用户名双重登录
- JWT Token有效期: 24小时
- 支持"记住我"功能

### 数据隐私

- 用户邮箱仅管理员可见
- 用户手机号仅管理员可见
- 用户真实姓名仅管理员可见
