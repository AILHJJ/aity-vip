## 🎯 项目简介

VIP投研内部分享系统是一个面向内部用户的私密投研分享平台，管理员可以向指定分组的用户群发推送投研消息，用户可以查看历史消息并发起讨论。系统支持讨论内容的可见性控制，确保信息安全和隐私保护。

### 项目目标

- **信息安全**：确保投研信息的私密分享
- **高效管理**：简化消息推送和用户管理流程
- **多端支持**：支持H5和小程序多端访问
- **数据驱动**：提供丰富的统计分析功能

---

## 🚀 核心功能

### 1. 消息推送

- **定向推送**：管理员向指定分组的用户群发投研消息
- **多媒体支持**：支持图片+文字的消息格式
- **消息分类**：支持多种消息类型（盘前点评、早盘点评、尾盘点评等）
- **定时发布**：支持实时发布和定时发布，精确到分钟
- **发布管理**：定时发布可取消，支持消息撤回

### 2. 消息管理

- **历史消息**：用户可以方便地查看自己收到的消息以及历史消息
- **搜索功能**：支持按关键词、日期、类型搜索消息
- **收藏功能**：支持消息收藏，方便后续查看
- **导出功能**：支持消息导出为Excel格式
- **无限滚动**：消息列表支持无限滚动，每页显示20条

### 3. 讨论功能

- **讨论发起**：用户在收到消息后可以就该消息发起讨论
- **可见性控制**：讨论内容默认只有管理员可见（私密）
- **权限管理**：管理员可以设置讨论可见性（公开/私密）
  - **公开**：所有用户可见
  - **私密**：只有管理员和发起者可见
- **富文本支持**：讨论支持富文本编辑
- **状态管理**：讨论状态自动变化，有人回复后自动变为已回复

### 4. 用户管理

- **统一注册**：由管理员统一注册用户和分组管理
- **权限设置**：管理员可以设置用户权限、分组和有效日期
- **状态管理**：支持用户状态管理（活跃/非活跃）
- **双重登录**：支持邮箱和用户名双重登录，系统智能识别
- **记住我**：支持"记住我"功能，Token有效期24小时

### 5. 统计功能

- **消息统计**：消息数量趋势、消息类型分布、消息标签分布
- **用户统计**：用户活跃度、用户增长趋势、分组用户数
- **讨论统计**：讨论数量趋势、讨论回复率
- **数据导出**：支持多种时间范围统计和Excel导出

## 🛠️ 技术栈

### 当前技术栈

#### 前端
- **基础框架**：Vue 3 (Composition API)
- **构建工具**：Vite 4.x
- **UI组件库**：Element Plus 2.x
- **状态管理**：Pinia 2.x
- **路由管理**：Vue Router 4.x
- **HTTP客户端**：Axios 1.x
- **富文本渲染**：Marked 11.x + DOMPurify 3.x
- **图表库**：ECharts 5.x
- **日期处理**：Day.js 1.x
- **表单验证**：VeeValidate 4.x + Yup 1.x
- **样式方案**：SCSS 1.x
- **代码规范**：ESLint 8.x + Prettier 3.x

#### 后端
- **运行环境**：Node.js v20.20.0+
- **Web框架**：Express.js
- **数据库**：MySQL 5.7.0+
- **ORM框架**：Sequelize
- **身份认证**：JWT (JSON Web Token)
- **进程管理**：PM2 6.x
- **文件上传**：Multer
- **安全防护**：Helmet, CORS, Express Rate Limit

### 迁移计划

#### 目标框架
- **前端框架**：uni-app
- **迁移状态**：开发中
- **预期完成时间**：约2-3周
- **支持平台**：H5、微信小程序、支付宝小程序、百度小程序、字节跳动小程序

#### 迁移优势
- **一套代码多端运行**：减少维护成本
- **小程序原生体验**：性能接近原生应用
- **开发效率提升**：统一的开发规范和工具链
- **生态丰富**：支持各种小程序平台的特性
