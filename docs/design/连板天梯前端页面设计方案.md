# 连板天梯前端页面设计方案

## 一、产品概述

### 1.1 产品定位

连板天梯是金融小程序的核心功能之一，用于展示市场连续涨停个股的实时数据，帮助用户快速识别市场热点、龙头股和强势股，辅助投资决策。

### 1.2 目标用户

- **短线投资者**：关注连板股票，寻找短线机会
- **打板族**：专门追踪涨停板，进行打板操作
- **趋势投资者**：通过连板数据判断市场情绪和热点方向
- **新手投资者**：通过连板天梯学习市场热点和龙头股

### 1.3 核心价值

- **快速发现热点**：实时展示连板个股，快速识别市场热点
- **精准定位龙头**：通过板型分类，快速找到龙头股
- **深度数据分析**：30个分析指标，全面了解个股情况
- **辅助投资决策**：结合资金流向、涨停分析等数据，辅助投资决策

## 六、性能优化

### 6.1 数据缓存

**策略**：
- 使用localStorage缓存数据
- 缓存时间：10分钟
- 缓存键：`continuous_limit_cache`

**实现**：
```javascript
const getWithCache = async (cacheKey, fetchFn, duration) => {
  const cached = localStorage.getItem(cacheKey);
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < duration) {
      return data;
    }
  }
  const result = await fetchFn();
  localStorage.setItem(cacheKey, JSON.stringify({
    data: result,
    timestamp: Date.now()
  }));
  return result;
};
```

### 7.2 增量更新

**策略**：
- 只更新变化的数据
- 减少数据传输量

**实现**：
```javascript
const diffData = (oldData, newData) => {
  return newData.filter(item => {
    const oldItem = oldData.find(old => old.code === item.code);
    return !oldItem || JSON.stringify(oldItem) !== JSON.stringify(item);
  });
};
```

<template>

      <el-icon @click="showSearch = true"><Search /></el-icon>
    </div>

    <MarketOverview :data="marketData" />

    <FilterBar
      v-model:days="selectedDays"
      v-model:boardType="selectedBoardType"
      v-model:isNew="selectedIsNew"
      v-model:market="selectedMarket"
      @change="handleFilterChange"
    />

    <div class="list-header">
      <span>证券名称</span>
      <span>代码</span>
      <span @click="handleSort('changePercent')">
        涨幅 {{ sortField === 'changePercent' ? sortIcon : '' }}
      </span>
      <span @click="handleSort('consecutiveLimitUpDays')">
        连板 {{ sortField === 'consecutiveLimitUpDays' ? sortIcon : '' }}
      </span>
      <span @click="handleSort('netInflow')">
        资金 {{ sortField === 'netInflow' ? sortIcon : '' }}
      </span>
    </div>

    <div class="stock-list" v-loading="loading">
      <StockCard
        v-for="stock in filteredStocks"
        :key="stock.code"
        :stock="stock"
        @click="handleStockClick"
        @longpress="handleStockLongPress"
      />
    </div>

    <ChartContainer :data="filteredStocks" />
  </div>
</template>

<script setup>
import { ref, computed, onMounted } from 'vue';
import { getContinuousLimit } from '@/api/continuous-limit';
import MarketOverview from '@/components/MarketOverview.vue';
import FilterBar from '@/components/FilterBar.vue';
import StockCard from '@/components/StockCard.vue';
import ChartContainer from '@/components/ChartContainer.vue';

const loading = ref(false);
const showSearch = ref(false);
const stockList = ref([]);
const selectedDays = ref([]);
const selectedBoardType = ref([]);
const selectedIsNew = ref('all');
const selectedMarket = ref('all');
const sortField = ref('changePercent');
const sortOrder = ref('desc');

const marketData = computed(() => {
  const data = stockList.value;
  return {
    totalCount: data.length,
    limitUpCount: data.filter(s => s.consecutiveLimitUpDays > 0).length,
    limitDownCount: data.filter(s => s.consecutiveLimitDownDays > 0).length,
    maxDays: Math.max(...data.map(s => s.consecutiveLimitUpDays), 0),
    avgChange: data.reduce((sum, s) => sum + s.changePercent, 0) / data.length || 0
  };
});

const filteredStocks = computed(() => {
  let result = [...stockList.value];

  if (selectedDays.value.length > 0) {
    result = result.filter(s => selectedDays.value.includes(s.consecutiveLimitUpDays));
  }

  if (selectedBoardType.value.length > 0) {
    result = result.filter(s => selectedBoardType.value.includes(s.boardType));
  }

  if (selectedIsNew.value !== 'all') {
    result = result.filter(s => s.isNew === (selectedIsNew.value === 'new'));
  }

  if (selectedMarket.value !== 'all') {
    result = result.filter(s => s.market === selectedMarket.value);
  }

  result.sort((a, b) => {
    const aVal = a[sortField.value];
    const bVal = b[sortField.value];
    return sortOrder.value === 'desc' ? bVal - aVal : aVal - bVal;
  });

  return result;
});

const sortIcon = computed(() => {
  return sortOrder.value === 'desc' ? '↓' : '↑';
});

const fetchData = async () => {
  loading.value = true;
  try {
    stockList.value = await getContinuousLimit();
  } catch (error) {
    console.error('获取数据失败:', error);
  } finally {
    loading.value = false;
  }
};

const handleFilterChange = () => {
  // 筛选变化，自动更新列表
};

const handleSort = (field) => {
  if (sortField.value === field) {
    sortOrder.value = sortOrder.value === 'desc' ? 'asc' : 'desc';
  } else {
    sortField.value = field;
    sortOrder.value = 'desc';
  }
};

const handleStockClick = (stock) => {
  uni.navigateTo({
    url: `/pages/stock/detail?code=${stock.code}`
  });
};

const handleStockLongPress = (stock) => {
  uni.showActionSheet({
    itemList: ['加入自选', '分享'],
    success: (res) => {
      if (res.tapIndex === 0) {
        // 加入自选
      } else if (res.tapIndex === 1) {
        // 分享
      }
    }
  });
};

onMounted(() => {
  fetchData();
  setInterval(fetchData, 10000);
});
</script>
