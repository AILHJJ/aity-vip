## 登录问题

### Q1: 忘记密码怎么办？

**问题**: 我忘记了登录密码，无法登录系统

**答案**:
1. 联系管理员重置密码
2. 提供你的邮箱地址
3. 管理员会为你设置新密码
4. 首次登录后建议立即修改密码

**预防措施**:
- 定期修改密码（建议每3个月）
- 使用密码管理工具
- 设置密码提示问题

---

### Q2: 登录后显示"未授权"？

**问题**: 登录成功但显示401或403错误

**可能原因**:
1. Token已过期
2. 权限不足
3. 账号被停用

**解决方案**:
1. 退出登录，重新登录
2. 检查账号状态是否为active
3. 联系管理员确认权限

---

### Q3: 为什么无法登录？

**问题**: 输入正确的邮箱和密码但仍无法登录

**排查步骤**:
1. 检查网络连接
2. 清除小程序缓存
3. 确认账号状态是否为active
4. 检查是否被限制登录次数
5. 联系管理员确认账号是否存在

## 消息相关

### Q4: 为什么看不到某些消息？

**问题**: 其他用户能看到某些消息，但我看不到

**可能原因**:
1. 消息设置了标签（短线策略/中线策略）
2. 用户角色不匹配标签权限

**解决方案**:
1. 确认你的用户角色（VIP中线/短线）
2. 查看"我的"页面了解权限范围
3. 如需查看其他消息，联系管理员调整权限
4. 升级用户等级以获取更多权限

**权限对照**:
- VIP中线用户：可看"中线策略"标签消息
- VIP短线用户：可看"短线策略"标签消息
- 体验用户：可看所有消息
- 管理员：可看所有消息

---

### Q5: 消息收藏后在哪里查看？

**问题**: 我收藏了消息但找不到收藏列表

**答案**:
1. 进入"我的"页面
2. 点击"我的收藏"
3. 所有收藏的消息都在这里

**取消收藏**:
- 在收藏列表中点击星标图标
- 或在消息详情页点击取消收藏

---

### Q6: 消息搜索不到内容？

**问题**: 使用搜索功能但找不到相关消息

**优化建议**:
1. 使用不同的关键词尝试
2. 确认筛选条件（类型、标签）
3. 检查关键词拼写
4. 尝试搜索部分关键词（如"科技"而非"人工智能科技"）
5. 下拉刷新重新获取数据

**搜索范围**:
- 消息标题
- 消息内容
- 发送者名称

---

### Q7: 图片显示不出来或加载很慢？

**问题**: 消息中的图片无法显示或加载缓慢

**可能原因**:
1. 网络连接问题
2. 图片文件过大
3. 服务器响应慢

**解决方案**:
1. 检查网络连接（切换WiFi/4G/5G）
2. 下拉刷新重新加载
3. 清理小程序缓存
4. 点击图片预览加载大图
5. 等待加载完成（不要快速滑动）

## 讨论相关

### Q8: 创建讨论后为什么看不到？

**问题**: 发起了讨论但在列表中看不到

**可能原因**:
1. 讨论设置为私密（private）
2. 未选择关联的消息
3. 缓存未刷新

**解决方案**:
1. 查看我的讨论页面（私密讨论只在"我的"中显示）
2. 下拉刷新讨论列表
3. 确认讨论状态是否为pending
4. 检查筛选条件

---

### Q9: 无法回复讨论怎么办？

**问题**: 讨论的回复按钮不可点击或无法发送

**可能原因**:
1. 讨论已关闭
2. 权限不足
3. 内容为空

**解决方案**:
1. 确认讨论状态（closed状态不可回复）
2. 检查是否登录
3. 输入回复内容后再发送
4. 联系管理员确认权限

---

### Q10: 讨论回复数不更新？

**问题**: 讨论显示的回复数量与实际不符

**解决方案**:
1. 下拉刷新
2. 进入讨论详情查看实际回复
3. 清除缓存重新加载
4. 退出登录重新进入

## AI投顾相关

### Q11: AI回复很慢或一直显示"思考中"？

**问题**: 发送问题后AI长时间不回复

**可能原因**:
1. 网络延迟
2. AI正在调用工具查询数据
3. 问题较复杂需要更多思考时间
4. 服务器负载高

**正常等待时间**:
- 简单问题：3-10秒
- 复杂问题（含工具调用）：10-30秒
- 数据查询问题：可能长达1分钟

**解决方案**:
1. 耐心等待，AI正在处理
2. 检查网络连接
3. 重新发送同样的问题
4. 尝试简化问题描述

**注意事项**:
- 不要频繁发送相同问题
- 不要在等待时退出页面
- 保持网络稳定

---

### Q12: AI记不住之前的对话内容？

**问题**: 开启新对话后，AI不知道之前的对话

**原因**: 这是正常的！新对话会清空上下文记忆

**数据流程**:
```
当前对话 → 有上下文记忆
    ↓
点击"新对话" → 清空上下文
    ↓
下次对话 → 无上下文记忆（重新开始）
```

**恢复上下文**:
- 不要点击"新对话"
- 继续在当前对话中提问
- AI会记住整个对话历史

---

### Q13: AI为什么给出错误的股票数据？

**问题**: AI返回的股票价格或涨跌幅不准确

**说明**:
1. AI数据来自通达信接口
2. 数据有延迟（非实时）
3. 数据仅供参考，不构成投资建议

**注意事项**:
- 数据可能有15-20分钟延迟
- 市场数据以实际交易为准
- AI分析仅供参考，不作为投资依据

**使用建议**:
- 结合多个数据源验证
- 关注实时市场行情
- 咨询专业投资顾问

---

### Q14: 工具调用失败怎么办？

**问题**: AI调用金融工具时显示"工具调用失败"

**可能原因**:
1. 网络连接问题
2. 数据接口异常
3. 查询参数不正确

**解决方案**:
1. 检查网络连接
2. 重新发送问题
3. 换个方式提问（如用股票代码而非名称）
4. 等待一段时间后重试

**示例**:
- 原："平安银行今天表现怎么样？"
- 改："000001今天表现怎么样？"

## 性能问题

### Q15: 小程序运行缓慢怎么办？

**问题**: 页面加载慢、操作卡顿

**排查步骤**:
1. 检查网络连接（建议使用WiFi）
2. 清理小程序缓存（设置 → 清除缓存）
3. 关闭其他后台应用
4. 退出重新登录
5. 检查手机存储空间是否充足

**优化建议**:
- 定期清理缓存
- 使用稳定网络环境
- 保持小程序版本最新

## 账户问题

### Q17: 如何修改个人资料？

**问题**: 想要修改用户名或邮箱

**答案**:
1. 进入"我的"页面
2. 点击"编辑资料"按钮
3. 修改可编辑字段
4. 点击"保存"

**注意**:
- 邮箱修改后需要重新验证
- 用户名修改需管理员审批
- 某些字段可能不支持修改

---

### Q18: 账号到期了怎么办？

**问题**: 登录时提示账号已过期

**解决方案**:
1. 联系管理员续期
2. 确认续期条件和流程
3. 续期后重新登录
4. 及时更新到期时间

**预防**:
- 关注到期提醒（如有）
- 提前联系管理员续期
- 了解不同用户等级的权限和有效期

---

### Q19: 如何查看我的权限？

**问题**: 不确定当前账号有哪些权限

**查看方式**:
1. 进入"我的"页面
2. 查看"用户角色"信息
3. 参考[用户操作手册](user-guide.md)了解各角色权限

**权限快速查询**:
- super_admin: 所有权限
- admin: 发布消息、查看统计
- vip_mid/vip_short: 查看对应策略消息
- trial: 体验所有功能

## 其他问题

### Q20: 如何分享消息给好友？

**问题**: 想要分享某条消息给微信好友

**操作步骤**:
1. 进入消息详情页
2. 点击"分享"按钮
3. 选择分享方式：
   - 发送给好友
   - 分享到朋友圈
   - 保存图片

**注意**:
- 需要用户授权微信权限
- 某些敏感消息可能无法分享

---

### Q21: 如何退出登录？

**问题**: 想要退出当前账号

**操作步骤**:
1. 进入"我的"页面
2. 滚动到最底部
3. 点击"退出登录"按钮
4. 确认退出

**退出后**:
- 清除本地缓存
- 清除登录Token
- 下次需要重新登录
