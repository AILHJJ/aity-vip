## 🔌 API接口配置

### 后端API配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| **后端地址（本地）** | http://localhost:3001 | 本地后端API地址 |
| **后端地址（云服务器）** | http://124.221.119.134:3001 | 云服务器后端API地址 |
| **API前缀** | /api | API路由前缀 |

### 主要API接口

#### 认证相关
- POST /api/auth/login - 用户登录（支持邮箱或用户名）

#### 消息相关
- GET /api/messages - 获取消息列表
- GET /api/messages/:id - 获取消息详情
- POST /api/messages - 发送消息

#### 讨论相关
- GET /api/discussions - 获取讨论列表
- GET /api/discussions/:id - 获取讨论详情
- POST /api/discussions - 创建讨论
- POST /api/discussions/:id/replies - 添加讨论回复

#### 用户相关
- GET /api/users - 获取用户列表
- POST /api/users - 创建用户
- PUT /api/users/:id - 更新用户
- DELETE /api/users/:id - 删除用户

#### 分组相关
- GET /api/groups - 获取分组列表
- POST /api/groups - 创建分组
- PUT /api/groups/:id - 更新分组
- DELETE /api/groups/:id - 删除分组

#### 统计相关
- GET /api/stats/overview - 获取统计概览
- GET /api/stats/users - 获取用户统计
- GET /api/stats/messages - 获取消息统计

#### 健康检查
- GET /api/health - 健康检查
