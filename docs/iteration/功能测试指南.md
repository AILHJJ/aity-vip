## 常见问题

### Q1: 登录后看不到消息？
**A:** 检查用户的权限标签，trial 用户只能看到标签为"全部用户"的消息。

### Q2: 无法创建讨论？
**A:** 讨论必须关联到一条消息，请先选择一条消息，然后在消息详情页发起讨论。

### Q3: 看不到某个讨论？
**A:** 检查讨论的可见性设置，私密讨论只有创建者和管理员可以查看。

### Q4: 消息类型筛选不生效？
**A:** 确保后端 API 正常运行，检查浏览器控制台是否有错误信息。

### Q5: 收藏功能不工作？
**A:** 检查用户是否已登录，收藏功能需要登录后才能使用。
