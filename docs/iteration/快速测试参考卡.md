## 🎯 核心测试点

### 1️⃣ 权限测试（最重要）
```
trial_user 登录 → 应该只看到 5 条消息
vip_mid_user 登录 → 应该看到 8 条消息（包含中线策略）
vip_short_user 登录 → 应该看到 8 条消息（包含短线策略）
admin 登录 → 应该看到 13 条消息（所有）
```

### 2️⃣ 消息类型测试
10种消息类型：
- 盘前点评 (pre_market_comment)
- 早盘点评 (morning_comment)
- 早盘关注 (morning_focus)
- 尾盘点评 (afternoon_comment)
- 尾盘关注 (afternoon_focus)
- 收盘点评 (close_comment)
- 风险提示 (risk_warning)
- 系统消息 (system)
- 重要消息 (important)
- 日常消息 (daily)

### 3️⃣ 讨论可见性测试
```
公开讨论 → 所有人可见
私密讨论 → 仅创建者和管理员可见
```

## 🐛 常见问题快速排查

| 问题 | 检查项 |
|------|--------|
| 看不到消息 | 检查用户权限标签 |
| 无法创建讨论 | 必须先选择一条消息 |
| 看不到某个讨论 | 检查讨论可见性设置 |
| 收藏不工作 | 确认已登录 |
| API 报错 | 检查后端服务是否运行 |

## 📝 测试顺序建议

1. **基础功能测试** (5分钟)
   - 使用 admin 登录
   - 查看消息列表
   - 查看消息详情
   - 测试收藏功能

2. **权限测试** (10分钟)
   - 依次使用 5 个账号登录
   - 验证每个账号看到的消息数量
   - 验证消息权限过滤正确性

3. **讨论功能测试** (10分钟)
   - 创建公开讨论
   - 创建私密讨论
   - 添加回复
   - 验证可见性权限

4. **管理功能测试** (10分钟)
   - 创建消息（多类型、多标签）
   - 用户管理
   - 数据统计

5. **搜索功能测试** (5分钟)
   - 搜索消息
   - 搜索讨论

## 💡 测试技巧

1. **使用浏览器隐私模式**：方便快速切换不同账号
2. **打开开发者工具**：查看网络请求和控制台错误
3. **记录测试结果**：使用测试检查清单
4. **截图保存问题**：方便后续修复

## 📞 需要帮助？

如果测试过程中遇到问题：
1. 检查后端和前端服务是否正常运行
2. 查看浏览器控制台错误信息
3. 查看后端日志输出
4. 参考完整的《功能测试指南.md》
