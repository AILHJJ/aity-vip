# 2026-08-08 讨论关联消息回显修复

## 问题

在“发起交流”页面手动选择关联消息后，创建成功的讨论详情页有时不显示关联消息；从消息详情页直接发起讨论则可以显示消息标题。

## 原因分析

- 手动 picker 只直接读取 `messages[index].id`，没有统一处理字符串 ID、`messageId` 或 `message_id` 字段。
- 创建页没有保存手动选择的消息对象，因此提交前无法可靠确认当前 ID 对应的消息。
- 详情页只依赖后端返回 `linkedMessage`，没有在已有 `messageId` 时补查消息详情。
- 现有后端创建接口和数据库字段支持 `messageId`，本次不修改后端、不涉及数据库迁移。

## 修复内容

- 新增 `src/utils/discussion-link.mjs`，统一规范化和查找关联消息 ID。
- 手动选择后保存所选消息并显示预览。
- 创建 payload 使用规范化后的 `messageId`。
- 创建成功后直接进入讨论详情，传递 `fallbackMessageId` 便于立即验证。
- 详情页在关联消息摘要缺失时，通过现有消息详情接口补齐内容。
- 关联消息卡显示标题、类型、时间、内容摘要，并支持点击查看原文。

## 验证

- `node aity-uni-app-v2/scripts/test-discussion-link.mjs`：通过。
- `node --check`：通过。
- `npm run build:mp-weixin`：通过。
- 构建产物：`aity-uni-app-v2/dist/build/mp-weixin`。

## 微信开发者工具验收

1. 导入 `aity-uni-app-v2/dist/build/mp-weixin`。
2. 选择一个消息，进入“发起交流”。
3. 手动选择另一条关联消息，确认创建页出现“已选择”预览。
4. 填写内容并创建。
5. 创建成功后应直接进入讨论详情，显示“基于此消息讨论”卡片和内容摘要。
6. 点击卡片，应能打开对应消息详情。

## 备注

本次不更新腾讯云后端。若仍有历史讨论缺少 `messageId`，前端无法从数据库恢复原始关联关系，需要通过服务器数据库或接口日志单独核查。
