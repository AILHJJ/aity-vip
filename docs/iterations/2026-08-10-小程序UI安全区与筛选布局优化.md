# 2026-08-10 小程序 UI 安全区与筛选布局优化

## 一、背景

本次走查针对微信小程序小屏设备，重点处理首屏信息密度、微信状态栏/胶囊避让、筛选操作和页面导航一致性问题。

## 二、本次变更

### 1. 消息中心

- 筛选区默认收起为一行摘要，不再常驻占用三行首屏空间。
- “全部”和“未读”保留为快捷入口，未读数量继续直接展示。
- 点击筛选摘要后展开消息类型、推送范围和阅读状态筛选。
- 增加重置和完成操作，已选筛选条件在收起状态显示摘要。

### 2. 行情及相关页面

- 新增共用 `app-nav-bar` 组件，动态读取微信状态栏和胶囊按钮尺寸。
- 行情首页增加“行情中心”标题栏，移除可拖动悬浮刷新按钮。
- 刷新操作移动到数据更新时间栏，复用原有 `updateTime` 和 `handleRefresh` 逻辑。
- 连板天梯、行情图、AI 图灵统一使用安全区导航，避免不同设备顶部遮挡。

### 3. 个人中心

- 移除与底部 Tab 重复的“行情中心”和“消息中心”入口。
- 修复修改邮箱菜单方向箭头显示异常。
- 版本信息同步为前端包版本 `v1.6.0`。

## 三、验证方式

在 `aity-uni-app-v2` 目录执行：

```powershell
npm run verify:mp-weixin
```

该命令包含：

- 讨论关联消息测试；
- 小程序 UI 结构契约测试；
- 微信小程序生产构建。

构建产物：`dist/build/mp-weixin`。

## 四、验收重点

- iPhone 刘海屏和灵动岛设备：行情标题、指数卡片不被顶部遮挡。
- 消息中心：默认首屏显示更多消息；点击“未读”可直接进入未读列表；点击筛选可展开完整条件。
- 行情页：刷新不再遮挡行情卡片，更新时间与刷新入口保持在同一信息栏。
- 连板天梯、行情图、AI 图灵：返回按钮和标题避开状态栏、胶囊区域。

## 五、未纳入本次范围

- TabBar 图标资源替换；
- 全量深色主题适配；
- 管理页面拆分和视觉回归截图自动化。

上述内容作为后续独立 UI 迭代，避免与本次安全区和首屏布局修复混合发布。
