# 讨论回复图片与默认私密优化

## 背景

讨论详情页已经提供回复图片上传入口，但后端回复校验要求 `content` 必填，导致只上传图片、不输入文字时会被接口拒绝。

同时，为符合投研交流场景的合规和隐私要求，回复默认可见性需要更明确：

- 管理员回复默认公开，可主动选择私密。
- 普通用户回复默认私密。

## 本次调整

- 后端 `POST /api/discussions/:id/replies` 支持“文字或图片至少一个”，允许只发图片回复。
- 新增回复隐私策略：
  - 管理员默认公开回复。
  - 管理员选择私密时发送私密回复。
  - 普通用户回复一律默认私密。
- 私密回复可见范围调整为：
  - 管理员可见。
  - 讨论发起人可见。
  - 回复者本人可见。
  - 其他用户不可见。
- 小程序讨论详情页：
  - 普通用户按钮改为“发送私密回复”。
  - 管理员按钮保持“公开回复 / 私密回复”。
  - 移除底部剪贴板图片提示，减少小程序屏幕占用。
  - 编辑回复时允许只保留图片后提交。

## 发布影响

本次同时包含后端和小程序前端变更。

- 后端需要部署到腾讯云后，图片-only 回复和普通用户默认私密的接口兜底才会生效。
- 小程序需要重新构建并用微信开发者工具上传版本，用户侧按钮文案和底部布局才会生效。
