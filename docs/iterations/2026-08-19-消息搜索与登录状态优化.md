# 消息搜索与登录状态优化

## 迭代目标

解决消息搜索只能覆盖当前已加载内容，以及用户 7 天 JWT 过期后没有明确重新登录提示的问题。

## 本次变更

### 后端

- `GET /api/messages` 支持 `keyword` 查询参数。
- 关键词同时匹配消息标题和正文，结果继续遵循角色可见范围和分页规则。
- 无效或过期 JWT 从 HTTP 403 调整为 HTTP 401。
- 账号到期、账号停用仍使用 HTTP 403，并保留“联系管理员续期/启用”的业务提示。
- 新增无数据库依赖的鉴权中间件单测。

### 小程序与 H5 共用前端

- 消息搜索确认、选择历史和清空关键词都会重新请求服务端第 1 页。
- 移除前端对角色权限和关键词的重复过滤，避免前端规则落后于后端可见性规则。
- 搜索无结果显示专用空状态。
- 非登录请求收到 401 时只提示一次“登录已过期，请重新登录”，清理 token、用户信息和未读数后跳转登录页。
- H5 构建补充根级 `vue-router@4.4.4`，修复 uni-app 编译器无法解析依赖的问题。
