# 用户到期自动失效与延期激活

## 业务规则

- VIP 用户和体验用户的到期日期按北京时间计算。
- 到期日当天仍可使用，从次日开始视为已到期。
- 到期用户自动更新为 `inactive`。
- 到期用户不能继续登录，也不能使用已有 token 查看消息、讨论等需要登录的功能。
- 管理员不受 `expireDate` 限制。
- 管理员延期后不会自动恢复账号，必须再次点击“启用”。
- 仍处于过去到期日的用户不能被直接启用，必须先延期。

## 实现位置

- `backend/src/utils/userAccessPolicy.js`
  - 统一计算到期状态。
  - 同步到期用户为 `inactive`。
- `backend/src/services/userExpiryService.js`
  - 服务启动时执行一次到期账号同步。
  - 服务运行期间每 15 分钟自动扫描并停用到期账号。
- `backend/src/controllers/authController.js`
  - 登录和获取当前用户信息时执行到期检查。
- `backend/src/utils/jwtUtils.js`
  - 所有携带 token 的接口执行数据库状态检查，阻止旧 token 绕过到期限制。
- `backend/src/controllers/userController.js`
  - 管理员列表加载时同步到期状态。
  - 创建/编辑用户时，过去到期日自动保存为 `inactive`。
  - 启用用户时拒绝仍已到期的账号。
- `aity-uni-app-v2/src/pages/user-management/user-management.vue`
  - 到期用户显示“已到期”。
  - 提示“延期后再启用”。

## 管理员操作流程

1. 打开用户管理，确认账号显示“已到期”。
2. 点击“编辑”，修改到期日期并保存。
3. 点击“启用”。
4. 用户重新登录小程序后恢复访问。
