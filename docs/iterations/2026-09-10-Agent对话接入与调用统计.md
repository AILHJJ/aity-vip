# Agent 对话接入与调用统计迭代记录

## 迭代目标

将小程序原有的旧 AI 代理链路切换为智能体广场封装的 OpenAPI 对话接口。小程序只访问 AITY VIP 后端，真实 API Key 仅保存在服务器环境配置中；用户界面统一使用“Agent”文案，并支持管理员选择默认 Agent 和查看调用统计。

## 基线与范围

- 本地基线：`AITY_VIP_iteration_current`
- Git 分支：`feature/iteration-baseline-20260808`
- 小程序目录：`aity-uni-app-v2`
- 后端目录：`backend`
- 本次不直接切换腾讯云生产服务，需完成本地验收和环境配置后再发布。
- 旧目录 `AITY_VIP_feature_9ac21eb` 不属于本次维护基线。

## 实现内容

### 后端

- 新增 Agent OpenAPI 客户端，调用 `GET /openapi/v1/agents` 和 `POST /openapi/v1/chat/completions`。
- 新增 AITY VIP 后端接口：
  - `GET /api/ai-advisor/config`
  - `GET /api/ai-advisor/agents`（管理员）
  - `PUT /api/ai-advisor/config`（管理员）
  - `POST /api/ai-advisor/chat`
  - `GET /api/ai-advisor/usage/personal`
  - `GET /api/ai-advisor/usage`（管理员）
- 新增默认 Agent 配置表和调用统计表。
- 调用统计只保存请求标识、用户、Agent、状态、耗时和错误码，不保存完整投研问题、回答正文、API Key、运行用户或平台内部配置。
- `externalUserId` 固定由后端根据 JWT 用户 ID 生成，忽略客户端伪造值。
- 上游 Agent 列表只下发标识、名称、简介、图标和分类等安全字段。

### 小程序

- AI 页面标题、欢迎区域和管理员入口统一改为“Agent”。
- 对话通过 AITY VIP 后端发送，保留后端返回的 `conversationId` 以支持多轮对话。
- 新增管理员 Agent 配置和调用统计页面，不展示或编辑服务器密钥。
- 清理旧的 `wenda`、旧代理地址和思考模式配置。
- 修复 Agent 请求失败后“正在输入”占位消息不会消失的问题。

## 服务端环境配置

生产环境只在腾讯云共享环境文件中配置，禁止提交到 Git：

```text
AGENT_OPENAPI_BASE_URL=<智能体广场 OpenAPI 地址>
AGENT_OPENAPI_API_KEY=<服务器专用 API Key>
AGENT_OPENAPI_DEFAULT_AGENT_ID=<可选兜底 Agent 标识>
AGENT_OPENAPI_TIMEOUT_MS=120000
```

推荐文件：`/root/aity-vip/shared/backend.env`。当前 release 的 `backend/.env.production` 应链接到该共享文件。真实密钥不写入文档、代码、日志、构建产物或数据库。

## 数据库迁移

发布前在生产数据库执行一次：

```text
backend/migrations/20260909-create-agent-settings-and-usage.sql
```

迁移完成后，管理员首次进入“Agent 管理”，确认已授权 Agent 列表并选择默认 Agent。

## OpenAPI 联调顺序

1. 在服务器共享环境文件补充真实 Base URL 和 API Key。
2. 执行数据库迁移。
3. 按 `prepare -> switch -> health check` 发布后端 release。
4. 使用管理员 JWT 请求 `/api/ai-advisor/agents`，确认返回已授权 Agent。
5. 在小程序管理员页面选择默认 Agent。
6. 使用测试用户发起一次对话，确认回答、会话续接和个人/全局统计。
7. 若上游未授权、应用运行身份未配置或 Agent 不可用，保持旧版本，不切换生产流量。

## 发布与回滚

- 腾讯云只使用 `/root/aity-vip/releases/<版本>` 和 `/root/aity-vip/current`，不直接覆盖线上目录。
- 发布流程固定为准备 release、执行切换、健康检查；只有 `switch` 会改变线上版本。
- 小程序不部署到腾讯云，使用 `dist/build/mp-weixin` 导入微信开发者工具，开发版和体验版由微信工具管理。
- 后端异常时使用项目回滚脚本切回上一版，并保留共享环境文件不变：

```powershell
.\scripts\腾讯云后端发布管理.ps1 -Action rollback
```

- 数据库迁移为新增表，回滚代码不会删除统计数据；若确认废弃功能，另行设计数据清理，不在发布回滚中执行破坏性操作。
