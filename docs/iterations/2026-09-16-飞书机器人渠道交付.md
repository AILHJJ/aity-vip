## 一、背景

二期目标：企微群/飞书群内 @机器人 直接发帖、回帖、绑定身份，并对接图片。
过程中关键转折：企微回调 URL 模式因**域名主体校验不通过**回退长连接；飞书侧因 WorkBuddy 占用原应用，最终在**用户自建的新组织**里重建，三个机器人分工落地。

## 二、交付内容

| 模块 | 说明 |
|---|---|
| 渠道抽象重构 | `BotChannel` 接口 + `channelFactory`，业务逻辑（`botService`）渠道无关 |
| 企微渠道 | 长连接 WebSocket + 发帖/回帖/绑定/图片 AES 解密（含发帖私密） |
| 飞书渠道 | 官方 SDK 长连接 + 消息/回复/主动推送/图片下载 |
| 通知双通道 | 新帖/回帖/发帖通知同时推企微群 + 飞书群（webhook，HMAC key=string_to_sign） |
| 渠道配置管理 | DB 存储 + 后台 API + 配置页热重载（管理 → 渠道配置） |
| 未读回复提醒 | 交流 tab 角标 + 我的讨论徽标 + `last_seen_replies_at` 字段 |
| UI 优化 | profile 菜单 emoji→uni-icons、预设头像、发布页按钮 PC 适配、悬浮球拖动恢复 |
| H5 嵌入适配 | iframe 双滚动条修复 + 窄面板 zoom 自动缩放 |
