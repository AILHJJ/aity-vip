## 功能清单

### 已实现功能 ✅

1. **指数行情展示**
   - 上证指数、深证成指、创业板指等主要指数
   - 实时涨跌幅和成交量展示

2. **市场概览**
   - 上涨/下跌/涨停/跌停统计
   - 市场情绪分数计算

3. **连板天梯**
   - 按连板天数分层展示（2连板、3连板、4连板等）
   - 每层股票按涨幅排序
   - 板块筛选功能（全部、主板、创业板、科创板、北证）

4. **行业资金流向**
   - 行业资金流入/流出排行
   - 净流入金额展示

5. **涨跌分布图表**
   - 涨跌幅区间分布可视化
   - 直方图展示

6. **UI设计**
   - Neon Flux科技风格
   - 响应式布局
   - 动态渐变效果

### 规划中功能 🔄

1. **异动监控**（优先级：中）
   - 板块异动实时监控
   - 异动推送提醒
   - 异动历史查询
   - API接口已规划，待开发

2. **自选股管理**（优先级：高）
   - 自选股列表页面
   - 行情中心添加自选功能
   - 自选股实时行情展示

3. **股票搜索**（优先级：高）
   - 股票代码/名称搜索
   - 快速跳转功能

4. **分时/K线图**（优先级：中）
   - 分时图展示
   - K线图技术分析
   - 技术指标叠加

5. **实时推送**（优先级：低）
   - WebSocket实时数据推送
   - 自动刷新机制

## 技术架构

### 前端技术栈
- **框架**: uni-app (Vue 3)
- **UI组件**: 自定义组件 + uni-ui
- **数据可视化**: 自定义图表组件
- **状态管理**: Pinia

### 后端技术栈
- **运行环境**: Node.js
- **框架**: Express.js
- **数据源**: 外部金融API (http://123.60.27.66:7615/TQLEX)

### 数据流
```
外部金融API → 后端代理 → 前端请求 → UI展示
```
