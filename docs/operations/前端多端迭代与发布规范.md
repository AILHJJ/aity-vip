# Frontend Multi-target Release Guide

The frontend should be maintained as one uni-app codebase: `aity-uni-app-v2`.

| Target | Source | Build | Publish |
| --- | --- | --- | --- |
| Weixin mini-program | `aity-uni-app-v2/` | `npm run build:mp-weixin` | Weixin DevTools or `miniprogram-ci` |
| H5 | `aity-uni-app-v2/` | `npm run build:h5` | Upload `dist/build/h5/` to `/var/www/html/h5` after backup |

Mini-program publishing does not require Tencent Cloud server operations unless backend APIs, database schema, domain, certificate, or upload settings changed.

The old server source `/var/www/frontend` is historical H5 code and should not be used as the main iteration baseline.
