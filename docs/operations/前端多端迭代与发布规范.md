# 前端多端迭代与发布规范

前端统一维护一套 uni-app 源码：`aity-uni-app-v2`。

| 目标端 | 源码目录 | 构建命令 | 发布方式 |
| --- | --- | --- | --- |
| 微信小程序 | `aity-uni-app-v2/` | `.\scripts\一键构建微信小程序.ps1` 或 `npm run build:mp-weixin` | 微信开发者工具或 `miniprogram-ci` |
| H5 | `aity-uni-app-v2/` | `npm run build:h5` | 备份后上传 `dist/build/h5/` 到服务器静态目录 |

微信小程序发布通常不需要操作腾讯云服务器，除非本次改动涉及后端 API、数据库结构、域名、证书或上传配置。

旧服务器源码 `/var/www/frontend` 属于历史 H5 代码，不作为后续主迭代基线。

## 微信小程序推荐流程

```powershell
.\scripts\一键构建微信小程序.ps1
```

构建产物：

```text
aity-uni-app-v2/dist/build/mp-weixin
```

用微信开发者工具导入该目录后预览、体验版上传或正式上传。
