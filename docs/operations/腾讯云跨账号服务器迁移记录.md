3. 新机保留现有服务，用系统 Node 22 部署当前线上两个 release，沿用 releases/current/shared；迁移时不混入新功能。
4. 私密环境通过加密通道传输；保留 JWT 和业务加密密钥。AITY 的实际生产加载文件应核对 `.env.production` 与 shared/backend.env 软链；不要仅写 `.env` 后假定生效。

### 回滚边界

当前DNS未切换，但生产业务已在新机。不能再按“放弃新机、恢复旧进程”处理。Caddyfile.before-migration是只有默认页的早期配置，当前生产状态下不能直接恢复它，否则主站HTTPS和业务路由会消失。

切换后有新写入时，不允许直接恢复早期快照或仅回切DNS；必须先停止写入、保护新机增量，再处理数据库与文件反向同步。已实际完成切换，并实测过启用生产前的保护恢复；生产启用后的数据反向迁移尚未演练，不声称零停机或任意时刻一键恢复旧库。
