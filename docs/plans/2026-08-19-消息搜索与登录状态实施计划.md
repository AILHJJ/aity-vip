# 消息搜索与登录状态实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让消息搜索覆盖后端可见历史消息，并让 JWT 过期在小程序中明确引导用户重新登录。

**Architecture:** 后端在现有消息可见性查询条件上增加标题/正文关键词条件，继续使用现有分页接口。鉴权中间件将 JWT 失效与账号业务失效分为 401 和 403；小程序统一在请求层处理 JWT 401，并清理本地用户状态。

**Tech Stack:** Node.js、Express、Sequelize、Jest、uni-app、Vue 3、微信小程序构建。
