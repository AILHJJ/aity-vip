# Agent 对话接入与调用统计 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 AITY VIP 的旧 AI 代理切换为服务端 OpenAPI Agent 对话，并提供动态 Agent 展示、管理员默认配置和按用户调用统计。

**Architecture:** AITY VIP 后端持有 OpenAPI API Key，通过服务层查询已授权 Agent 和调用统一对话接口。小程序只访问 AITY VIP JWT 鉴权接口；默认 Agent 安全元数据和调用统计写入独立 MySQL 表，真实密钥和运行用户不入库、不下发。

**Tech Stack:** Node.js、Express、Axios、Sequelize、MySQL、Jest、uni-app、Vue 3、微信小程序。
