# 文档工具快速使用指南

本文档提供文档管理工具的快速使用示例。

## 快速命令

### 1. 生成文档索引
```bash
cd docs/scripts
node generate-index.js --output ../doc-index.json
```

### 2. 校验文档
```bash
cd docs/scripts
node validate-docs.js --output ../validation-report.md --format markdown
```

### 3. 归档迭代文档
```bash
cd docs/scripts
node archive-iteration.js \
  --name "2026-03-feature-name" \
  --docs "../06-features/feature-name/*.md" \
  --description "功能描述" \
  --tags "tag1,tag2"
```

## 常用场景

### 场景1: 版本发布前检查
```bash
# 1. 校验所有文档
node validate-docs.js

# 2. 生成文档索引
node generate-index.js --output ../doc-index.json

# 3. 如果通过，提交到git
git add ../doc-index.json
git commit -m "docs: 更新文档索引"
```

### 场景2: 迭代完成后归档
```bash
# 先预览要归档的文件
node archive-iteration.js \
  --name "2026-03-iteration-name" \
  --docs "../06-features/iteration/*.md" \
  --dry-run

# 确认后执行归档
node archive-iteration.js \
  --name "2026-03-iteration-name" \
  --docs "../06-features/iteration/*.md" \
  --description "迭代描述" \
  --tags "feature,frontend"
```

### 场景3: 生成文档统计报告
```bash
# 生成JSON格式的索引
node generate-index.js --output ../doc-index.json

# 生成Markdown格式的索引
node generate-index.js --output ../INDEX.md --format markdown

# 生成校验报告
node validate-docs.js --output ../validation-report.md --format markdown
```

## 注意事项

1. **路径问题**: 所有路径都是相对于`docs/scripts`目录的
2. **通配符支持**: `archive-iteration.js`支持使用通配符（如`*.md`）
3. **干运行**: 使用`--dry-run`参数可以预览操作而不实际执行
4. **格式选择**: 大多数工具支持JSON和Markdown两种输出格式
