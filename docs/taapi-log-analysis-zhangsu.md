## 涨速数据含义

**涨速** 是通达信选股系统中的一个技术指标，用于衡量股价上涨的速度。

- **数值范围**: 通常为 0 到几之间
- **计算方式**: 基于股价在短时间内的涨幅变化率
- **用途**: 按"涨速"排序可以快速找到正在加速上涨的股票
- **排序**: 响应中 `KEY: "涨速"` 表示结果按涨速降序排列
