## 🔧 测试数据

### 消息类型

```
pre_market_comment  - 盘前点评
morning_comment     - 早盘点评
morning_focus       - 早盘关注
afternoon_comment   - 尾盘点评
afternoon_focus     - 尾盘关注
close_comment       - 收盘点评
risk_warning        - 风险提示
system              - 系统消息
important           - 重要消息
daily               - 日常消息（默认）
```

### 消息标签

```
短线策略 - vip_short可见
中线策略 - vip_mid可见
全部用户 - 所有VIP可见
```

### 分组

```
all   - 全部用户
mid   - 中线策略
short - 短线策略
```

## 🧪 测试场景

### 1. 权限测试

```bash
# 使用VIP账户登录
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"vip_mid@test.com","password":"test123"}'

# 验证权限限制
# - vip_mid只能看中线策略和全部用户的消息
# - trial可以看所有消息
```

### 2. 消息测试

```bash
# 管理员创建消息
curl -X POST http://localhost:3001/api/messages \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "测试消息",
    "content": "这是一条测试消息",
    "type": "daily",
    "groupId": "all",
    "tags": ["全部用户"]
  }'
```

### 3. 讨论测试

```bash
# 创建讨论
curl -X POST http://localhost:3001/api/discussions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "messageId": 1,
    "content": "这是一条测试讨论",
    "visibility": "private"
  }'
```

## ⚠️ 注意事项

1. **生产环境**：请勿在生产环境使用测试账户
2. **密码安全**：测试账户使用简单密码，仅供测试
3. **数据清理**：测试完成后建议清理测试数据
4. **Token有效期**：JWT Token有效期为24小时
