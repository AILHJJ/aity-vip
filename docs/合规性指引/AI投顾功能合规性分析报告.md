# AI投顾功能合规性分析报告

**分析日期**: 2026-02-11
**分析范围**: AI投顾助手功能模块
**合规依据**: 中国证监会相关法规、基金法、证券法

---

## 📋 执行摘要

经分析,当前产品中使用的"**AI投顾**"命名和功能存在**严重的合规风险**。根据中国证监会《关于做好公开募集证券投资基金投资顾问业务试点工作的通知》及相关法规,"投顾"属于受监管的金融服务业务,需要相关资质。

### 🚨 风险等级: **极高**

---

## ⚖️ 法规要求

### 1. 投资顾问业务资质要求

根据《证券法》第160条和《证券投资顾问业务暂行规定》:

```
投资顾问业务属于特许经营业务,机构需同时满足:
1. 取得中国证监会核准的业务资质
2. 注册资本不低于5000万元人民币
3. 具备相应数量的执业投资顾问(至少10名)
4. 通过证监会组织的专业考试
5. 建立合规管理和风险控制系统
```

### 2. 禁止性行为

根据法规,以下行为属于**违规**:

- ❌ 未取得资质使用"投顾"、"投资顾问"等名称
- ❌ 向投资者提供具体投资建议(买入/卖出特定股票)
- ❌ 承诺收益或保证收益
- ❌ 使用"AI投顾"、"智能投顾"等名称误导投资者
- ❌ 收取投资顾问费用(除非有资质)

### 3. 处罚措施

违规后果包括:
- 📛 责令改名、整改
- 💰 处以3万-30万元罚款
- ⚖️ 情节严重的,吊销业务许可证
- ⚖️ 构成犯罪的,追究刑事责任

## 🔍 当前功能合规性分析

### ✅ 合规的功能

1. **信息查询服务**
   - 股市行情查询
   - 板块热点分析
   - 基础金融信息展示

2. **教育性内容**
   - 投资知识普及
   - 市场解读
   - 数据分析展示

### ⚠️ 灰色地带的功能

1. **选股工具**
   - 当前状态: 提供"金融选股工具"
   - 风险: 如果推荐具体股票,可能被视为投资建议
   - 建议: 改为"选股筛选器",强调数据展示,不做推荐

2. **AI问答助手**
   - 当前状态: 可以回答投资相关问题
   - 风险: 如果给出具体买卖建议,违规
   - 建议: 添加明确免责声明

### 🚨 严重违规的功能

1. **名称使用"AI投顾助手"** ❌
   - 问题: "投顾"是特许经营用语
   - 风险: 未使用资质即使用该名称
   - 必须改名!

2. **快捷问题包含推荐词汇**
   - "推荐几只优质股票" ❌
   - 问题: "推荐"暗示投资建议
   - 必须修改!

## 📝 合规化整改方案

### 第一阶段: 紧急整改 (必须立即执行)

#### 1. 更改产品命名

**原名称**: AI投顾助手
**建议新名称** (按合规性排序):

1. ✅ **"智能助手"** (最安全)
   - 符合: 纯技术定位
   - 说明: AI技术支持的信息查询助手

2. ✅ **"AI问答助手"** (推荐)
   - 符合: 强调问答功能
   - 说明: 基于AI的智能问答服务

3. ✅ **"投资小助手"** (可用)
   - 符合: "小助手"非专业术语
   - 说明: 辅助信息查询工具

4. ⚠️ **"智能分析助手"** (谨慎)
   - 符合: 强调数据分析
   - 说明: 仍需避免具体建议

**严禁使用的词汇**:
- ❌ 投顾 / 投资顾问
- ❌ 理财顾问
- ❌ 智能投顾
- ❌ 推荐 + 具体股票名称
- ❌ 买入 / 卖出 建议
- ❌ 保证收益 / 承诺收益

#### 2. 修改快捷问题

**当前快捷问题**:
```javascript
const quickQuestions = [
  '今天股市行情怎么样？',      ✅ 合规
  '有什么热门板块？',          ✅ 合规
  '推荐几只优质股票'           ❌ 违规
]
```

**修改建议**:
```javascript
const quickQuestions = [
  '今天股市行情怎么样？',      ✅ 合规
  '有什么热门板块？',          ✅ 合规
  '帮我筛选科技板块股票'       ✅ 合规 - 强调"筛选"而非"推荐"
]
```

#### 3. 添加强制性免责声明

在页面显眼位置添加:

```
⚠️ 免责声明
本服务仅为智能信息查询工具,所提供内容仅供参考:
• 不构成任何投资建议
• 不构成对任何证券的买卖建议
• 不承诺收益,不保证收益
• 投资有风险,入市需谨慎
• 请根据自身情况独立判断
```

#### 4. 工具重命名

**当前**: "金融选股工具"
**建议改为**: "股票筛选工具" 或 "数据查询工具"
