## 〇、v1.7.0 更新日志 (2026-02-27)

### 新增功能

| 模块 | 功能 | 说明 |
|------|------|------|
| 用户管理 | 密码修改 | 编辑用户时支持安全修改密码（开关控制+双重验证） |
| 用户管理 | 邮箱/昵称编辑 | 支持修改用户邮箱和昵称 |
| 用户管理 | 交易日计算 | 显示剩余交易日（排除周末） |
| 用户管理 | 自定义延期 | 快速延期支持自定义天数输入 |
| 消息系统 | 图片粘贴 | 创建消息支持Ctrl+V粘贴图片 |
| Markdown | 主题扩展 | 新增5个高端主题（金融专业/暗夜模式/简约优雅/高对比度/护眼绿） |
| AI图灵 | 用户隔离 | 对话记录按用户隔离存储 |
| AI图灵 | 合规提示 | 输入框显示AI内容合规提示 |

### 问题修复

| 模块 | 问题 | 解决方案 |
|------|------|---------|
| 用户管理 | 到期时间显示"长期有效" | 修复字段名不匹配问题，显示实际到期日期 |
| 消息列表 | Markdown未渲染 | 列表页使用完整Markdown渲染 |
| AI图灵 | 顶部栏遮挡状态栏 | 优化padding和safe-area适配 |
| 消息系统 | 无法粘贴图片 | 新增剪贴板粘贴事件处理 |
