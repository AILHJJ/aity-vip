# 行情中心UI改进设计方案

## 概述

对行情中心页面（market.vue）进行UI改进，主要包括：
1. 涨跌停卡片改为分组型上下布局
2. 三个Tab改为三个独立卡片
3. 连板天梯个股支持快捷展开

## 当前问题

### 1. 涨跌停卡片布局
- **当前**：4个卡片水平排列，数字在上、文字在下
- **问题**：布局单调，视觉层次不够清晰

### 2. Tab切换
- **当前**：连板天梯、资金流向、涨跌分布需要切换Tab查看
- **问题**：用户需要多次点击才能查看不同数据，不够直观

### 3. 个股详情
- **当前**：点击个股弹出Modal查看详情
- **问题**：交互成本高，无法快速浏览多只股票的关键信息

## 设计方案

### 1. 涨跌停卡片 - 分组型布局

```
┌─────────────────────────────────────┐
│  市场温度计                          │
├──────────────────┬──────────────────┤
│     上涨         │      下跌        │
│    1287         │     4107        │
├──────────────────┼──────────────────┤
│     涨停         │      跌停        │
│      81         │       31        │
└──────────────────┴──────────────────┘
│  市场情绪  ████░░░░░░  21  恐惧    │
└─────────────────────────────────────┘
```

**特点**：
- 2x2网格布局，上下结构（文字在上，数字在下）
- 左侧绿色区域（上涨/涨停），右侧红色区域（下跌/跌停）
- 情绪条合并到同一卡片底部

## 技术实现要点

### 1. 模板结构变更

**market.vue**：
- 移除 `<view class="tabs">` 和 Tab 切换逻辑
- 将 `v-if="activeTab === 'xxx'"` 改为直接显示
- 重构 `stats-grid` 为 `thermometer-section`

### 2. 新增状态

```javascript
// 个股展开状态
const expandedStocks = ref([])  // 存储展开的股票code

const toggleStockExpand = (code) => {
  const idx = expandedStocks.value.indexOf(code)
  if (idx > -1) {
    expandedStocks.value.splice(idx, 1)
  } else {
    expandedStocks.value.push(code)
  }
}
```

### 3. 样式调整

- 使用 grid 布局实现 2x2 涨跌停网格
- 添加展开/收起动画过渡
- 保持现有的 Neon Flux 科技风格

## 文件修改清单

| 文件 | 修改内容 |
|------|----------|
| `market.vue` | 重构模板结构、移除Tab、新增展开逻辑 |
| `market.vue` (style) | 新增thermometer、展开卡片样式 |

## 预期效果

1. **更直观**：三个数据模块一目了然，无需切换
2. **更高效**：快捷展开查看个股关键信息
3. **更美观**：分组布局视觉层次更清晰
