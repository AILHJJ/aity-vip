# 消息发布表单优化 - 变更日志

## 版本: v1.0.0
## 发布日期: 2026-02-06

---

## 🎯 优化目标

将策略类型提升为核心业务属性，优化用户发布消息的体验。

---

## ✨ 新功能

### 1. 策略类型字段（置顶）
- **位置**: 表单第一个字段，最显眼位置
- **样式**: 特殊高亮区域（渐变背景 + 紫色边框）
- **标识**: 带★星标，红色脉冲动画
- **选项**:
  - ◉ 短线策略（默认）
  - ○ 中线策略
- **功能**: 记忆上次选择（localStorage key: 'last_selected_strategy'）

### 2. 推送对象字段
- **可见性**: 仅管理员可见
- **选项**:
  - ◉ 短线VIP（默认）
  - ○ 中线VIP
  - ○ 全部用户
- **功能**: 根据策略类型自动同步默认值

### 3. 消息类型多选
- **变更**: 从单选改为多选
- **样式**: 复选框样式（☐/☑）
- **选项**:
  - 盘前点评、早盘关注、午盘点评、尾盘关注
  - 涨停分析、龙虎榜分析、个股研究、行业分析
  - 宏观经济、其他
- **功能**: 可选一个或多个，或全不选

---

## 🔄 功能变更

### 表单字段顺序调整

**优化前**:
1. 消息标题
2. 消息类型（单选）
3. 目标用户（多选标签）
4. 消息内容
5. 附件

**优化后**:
1. **策略类型**（置顶，必填）⭐
2. **推送对象**（管理员，必填）
3. **消息类型**（多选，可选）
4. 消息标题（必填）
5. 消息内容（必填）
6. 附件（可选）

### 数据结构变更

**优化前**:
```javascript
{
  title: '',
  type: 'pre_market_comment',  // 单个类型
  tags: ['short_term'],         // 目标用户标签
  content: '',
  attachments: []
}
```

**优化后**:
```javascript
// 表单数据结构
{
  strategy: 'short_term',       // 策略类型（单选）
  pushTarget: 'short_term',     // 推送对象（单选）
  messageTypes: [],             // 消息类型（多选数组）
  title: '',
  content: '',
  attachments: []
}

// 提交时转换为后端格式
{
  title: '',
  type: 'pre_market_comment',   // 兼容旧字段
  tags: [
    'short_term',               // 策略标签
    'short_term',               // 推送对象标签
    'pre_market_comment',       // 消息类型标签（可多个）
    'morning_focus'
  ],
  content: '',
  attachments: []
}
```
