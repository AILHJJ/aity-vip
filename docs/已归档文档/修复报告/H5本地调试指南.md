## 📊 常见问题排查

### 问题1: CORS错误

**症状**:
```
Access to XMLHttpRequest at 'https://aity88.online:8443/api/messages'
from origin 'http://localhost:5173' has been blocked by CORS policy
```

**解决**: 后端需要配置CORS

**检查**:
```bash
# 查看后端CORS配置
cd backend
grep -r "cors" src/
```

### 问题2: Token过期

**症状**: 401 Unauthorized

**解决**: 重新登录

### 问题3: 数据格式错误

**症状**: 500 Server Error

**解决**:
1. 在Console中查看 `formData.value`
2. 检查每个字段的值和类型
3. 确保tags是数组

### 问题4: 附件处理错误

**症状**: 500 Server Error

**解决**:
- 清空附件字段
- 只测试文本消息
