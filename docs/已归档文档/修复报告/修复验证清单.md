## 回滚方案

如果修复后出现新问题：

### 回滚步骤
1. 恢复以下文件到修复前状态：
   - `src/pages.json`
   - `src/utils/request.js`
   - `src/api/discussion.js`

2. 重新编译：
   ```bash
   npm run build:mp-weixin
   ```

3. 上传旧版本：
   - 版本号：1.6.0（或之前的版本）
   - 备注：回滚到修复前版本

### 紧急修复
如果需要快速修复但不想回滚：
1. 将超时时间增加到 120000ms（2分钟）
2. 禁用重试机制（避免重复提交）
3. 添加更详细的错误日志
