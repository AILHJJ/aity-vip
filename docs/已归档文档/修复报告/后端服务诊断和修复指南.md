## ✅ 立即执行的修复命令

### 在服务器上执行以下命令(按顺序):

```bash
# 1. 停止当前服务
pm2 stop aity-backend

# 2. 删除旧的PM2进程
pm2 delete aity-backend

# 3. 检查端口占用(如果有)
netstat -tlnp | grep :8443
# 如果有进程占用,杀掉它:
# kill -9 <PID>

# 4. 清理PM2缓存
pm2 flush

# 5. 重新启动服务
pm2 start npm --name "aity-backend" -- start

# 6. 查看启动日志(重要!)
pm2 logs aity-backend --lines 50

# 7. 检查服务状态
pm2 status

# 8. 等待10秒后测试API
sleep 10
curl http://localhost:8443/api/auth/login -X POST -H "Content-Type: application/json" -d '{"username":"test","password":"test"}'
```

## 🚨 最可能的原因和快速修复

### 原因1: 新增的marketRoutes路由有问题

**快速修复**: 临时注释掉行情路由

```bash
cd /tmp/AITY/backend

# 编辑index.js,注释掉行情路由
vim src/index.js
# 找到这一行:
# app.use('/api/market', marketRoutes);
# 改为:
# // app.use('/api/market', marketRoutes);

# 保存并重启
pm2 restart aity-backend

# 测试登录
curl http://localhost:8443/api/auth/login ...
```

**如果这样可以,说明是marketRoutes的问题,需要修复该文件**

---

### 原因2: axios依赖未安装

```bash
cd /tmp/AITY/backend

# 检查axios是否安装
npm list axios

# 如果没有,安装它
npm install axios

# 重启
pm2 restart aity-backend
```

---

### 原因3: 端口被占用

```bash
# 查看8443端口
netstat -tlnp | grep :8443

# 如果有其他进程占用
# 方式1: 杀掉进程
kill -9 <PID>

# 方式2: 更改端口
vim .env
# 修改 PORT=8443 为 PORT=8444
# 同时修改nginx配置
```
