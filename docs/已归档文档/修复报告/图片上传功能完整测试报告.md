## 🐛 已修复的问题

### 问题1: Vue 3 Proxy对象导致500错误

**原因**:
```javascript
// 错误代码
tags: formData.value.tags  // Proxy对象
attachments: formData.value.attachments  // Proxy对象
```

**解决**:
```javascript
// 正确代码
tags: [...formData.value.tags]  // 展开运算符
attachments: formData.value.attachments.map(...)  // map创建新对象
```

**Commit**: `49f14ec`

---

### 问题2: HTTP状态码判断不完整

**原因**:
```javascript
// 只支持200
if (res.statusCode === 200) {
  resolve(res.data)
}
```

**解决**:
```javascript
// 支持2xx范围
if (res.statusCode >= 200 && res.statusCode < 300) {
  resolve(res.data)
}
```

**Commit**: `e69f42a`

---

### 问题3: 消息详情页面无法显示

**原因**:
```javascript
// 检查res.success，但API返回的是code: 200
if (res.success) { ... }
```

**解决**:
```javascript
// 兼容两种格式
if (res.success || res.code === 200) { ... }
```

**Commit**: `f61c1a9`

## 📸 图片上传功能详解

### 功能流程

```
1. 用户选择图片
   ↓
2. 前端检测到blob URL或临时路径
   ↓
3. 调用上传API (POST /api/upload)
   - 文件: multipart/form-data格式
   - 显示进度: "上传图片 1/N"
   ↓
4. 后端接收并保存文件
   - 验证文件类型
   - 生成唯一文件名
   - 保存到uploads/images/
   ↓
5. 返回服务器URL
   - /uploads/images/img-{timestamp}-{random}.ext
   ↓
6. 前端使用服务器URL发布消息
   ↓
7. 消息创建成功，图片正常显示 ✅
```

### API端点

**上传图片**:
```http
POST https://aity88.online:8443/api/upload
Content-Type: multipart/form-data
Authorization: Bearer <token>

Response (200 OK):
```

## 🔧 技术细节

### 前端实现

**自动上传逻辑** (`create-message.vue`):
```javascript
// 检测blob URL
if (attach.path.startsWith('blob:') || attach.path.startsWith('wxfile://')) {
  // 自动上传
  const uploadResult = await uploadImageApi(attach.path)

  // 使用服务器URL
  uploadedAttachments.push({
    url: uploadResult.url,
    ...
  })
}
```

**错误处理**:
```javascript
try {
  await uploadImageApi(attach.path)
} catch (uploadErr) {
  // 单个图片失败不影响其他图片
  console.error('第 ${i + 1} 个附件上传失败:', uploadErr)
  uni.showToast({
    title: `图片 ${i + 1} 上传失败`,
    icon: 'none'
  })
}
```

### 后端实现

**文件验证** (`upload.js`):
```javascript
// 类型验证
const allowedTypes = /jpeg|jpg|png|gif|webp/;
const extname = allowedTypes.test(path.extname(file.name).toLowerCase());
const mimetype = allowedTypes.test(file.mimetype);

// 只允许图片
if (!mimetype || !extname) {
  return res.status(400).json({
    message: '只允许上传图片文件'
  });
}
```

**文件命名**:
```javascript
// 唯一文件名避免冲突
const uniqueSuffix = Date.now() + '-' + Math.random().toString(36).substring(2, 15);
const filename = 'img-' + uniqueSuffix + path.extname(file.name);
```
