# 金融数据接口文档

## 概述

本文档记录所有金融数据接口，用于图灵AI功能的实时行情数据支持。

## 接口列表

### 1. 指数行情接口

**接口地址：** `http://123.60.27.66:7615/TQLEX?Entry=HQServ.IndexQuote`

**请求方法：** POST

**请求头：**
```
Content-Type: application/json
```

**请求参数：**
```json
{
  "Head": {
    "Target": 0
  },
  "Code": "000001.SZ,399001.SZ,000300.SH,000016.SH,000688.SH,000905.SH"
}
```

**参数说明：**
- `Code`: 指数代码列表，逗号分隔
  - `000001.SZ` - 上证指数
  - `399001.SZ` - 深证成指
  - `000300.SH` - 沪深300
  - `000016.SH` - 上证50
  - `000688.SH` - 科创50
  - `000905.SH` - 中证500

**响应示例：**
```json
{
  "Head": {
    "Target": 0,
    "Time": "2026-02-11 09:30:00"
  },
  "Data": [
    {
      "Code": "000001.SZ",
      "Name": "上证指数",
      "Price": 3245.67,
      "Change": 12.34,
      "ChangePct": 0.38,
      "Volume": 123456789000,
      "Amount": 987654321000,
      "High": 3250.12,
      "Low": 3230.45,
      "Open": 3238.90,
      "LastClose": 3233.33
    }
  ]
}
```

**字段说明：**
- `Code`: 指数代码
- `Name`: 指数名称
- `Price`: 最新价
- `Change`: 涨跌额
- `ChangePct`: 涨跌幅(%)
- `Volume`: 成交量
- `Amount`: 成交额
- `High`: 最高价
- `Low`: 最低价
- `Open`: 开盘价
- `LastClose`: 昨收价

### 2. 连板天梯接口

**接口地址：** `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**请求方法：** POST

**请求头：**
```
Content-Type: application/json
```

**请求参数：**
```json
{
  "Head": {
    "Target": 0
  },
  "Blocktype": "0",
  "Blockstyle": "3",
  "Blockid": "Stock_SCHIGH"
}
```

**参数说明：**
- `Blocktype`: 板块类型（0=股票）
- `Blockstyle`: 板块样式（3=连板）
- `Blockid`: 数据块ID（Stock_SCHIGH=连板高度）

**响应示例：**
```json
{
  "Head": {
    "Target": 0,
    "Time": "2026-02-11 15:00:00"
  },
  "Data": [
    {
      "Code": "000001.SZ",
      "Name": "平安银行",
      "Price": 12.34,
      "Change": 1.12,
      "ChangePct": 10.0,
      "HighDays": 5,
      "LimitStatus": 1,
      "Volume": 123456700,
      "Amount": 152345678.90,
      "BuyOrders": 125000,
      "SellOrders": 0,
      "FirstLimitTime": "09:30:00",
      "OpenCount": 3,
      "Industry": "银行",
      "Reason": "AI概念"
    }
  ]
}
```

**字段说明：**
- `Code`: 股票代码
- `Name`: 股票名称
- `Price`: 最新价
- `Change`: 涨跌额
- `ChangePct`: 涨跌幅(%)
- `HighDays`: 连板天数（核心字段）
- `LimitStatus`: 涨停状态（1=涨停，0=未涨停）
- `Volume`: 成交量
- `Amount`: 成交额
- `BuyOrders`: 买盘量
- `SellOrders`: 卖盘量
- `FirstLimitTime`: 首次涨停时间
- `OpenCount`: 开板次数
- `Industry`: 所属行业
- `Reason`: 涨停原因概念

**使用场景：**
- 显示市场连板梯队（2板、3板、4板...）
- 分析市场高度和情绪
- 捕捉龙头股和强势股

### 3. 行业资金净流入接口

**接口地址：** `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**请求方法：** POST

**请求头：**
```
Content-Type: application/json
```

**请求参数：**
```json
{
  "Head": {
    "Target": 0
  },
  "Code": "HY,1,0,3",
  "Blockid": "MStock_ZLJX_ADDE_R"
}
```

**参数说明：**
- `Code`: 查询条件 `HY,1,0,3`
  - `HY`: 行业（Industry）
  - `1`: 排序方式（1=按净流入降序）
  - `0`: 数据来源（0=实时）
  - `3`: 取前N名（此处为前3名）
- `Blockid`: 数据块ID（MStock_ZLJX_ADDE_R=净流入排名）

**响应示例：**
```json
{
  "Head": {
    "Target": 0,
    "Time": "2026-02-11 15:00:00"
  },
  "Data": [
    {
      "Code": "BK00001",
      "Name": "半导体",
      "NetInflow": 1234567890.50,
      "NetInflowPct": 8.5,
      "MainInflow": 2345678901.00,
      "RetailInflow": -1111111110.50,
      "StockCount": 45,
      "UpCount": 38,
      "DownCount": 7,
      "LimitUpCount": 5,
      "AvgChangePct": 3.2
    }
  ]
}
```

**字段说明：**
- `Code`: 行业代码
- `Name`: 行业名称
- `NetInflow`: 净流入金额（元）
- `NetInflowPct`: 净流入占比（%）
- `MainInflow`: 主力流入金额
- `RetailInflow`: 散户流入金额
- `StockCount`: 行业股票总数
- `UpCount`: 上涨股票数
- `DownCount`: 下跌股票数
- `LimitUpCount`: 涨停股票数
- `AvgChangePct`: 平均涨跌幅（%）

**使用场景：**
- 追踪热点板块资金动向
- 判断市场主线
- 辅助板块轮动策略

### 4. 行业资金净流出接口

**接口地址：** `http://123.60.27.66:7615/TQLEX?Entry=HQServ.PBXmlBlock`

**请求方法：** POST

**请求头：**
```
Content-Type: application/json
```

**请求参数：**
```json
{
  "Head": {
    "Target": 0
  },
  "Code": "HY,1,0,3",
  "Blockid": "MStock_ZLJX_ADDE"
}
```

**参数说明：**
- `Code`: 查询条件 `HY,1,0,3`
  - `HY`: 行业（Industry）
  - `1`: 排序方式（1=按净流出降序，即流出最多的在前）
  - `0`: 数据来源（0=实时）
  - `3`: 取前N名（此处为前3名）
- `Blockid`: 数据块ID（MStock_ZLJX_ADDE=净流出排名）

**响应示例：**
```json
{
  "Head": {
    "Target": 0,
    "Time": "2026-02-11 15:00:00"
  },
  "Data": [
    {
      "Code": "BK00002",
      "Name": "房地产",
      "NetOutflow": -987654321.00,
      "NetOutflowPct": -5.2,
      "MainOutflow": -1234567890.00,
      "RetailOutflow": 246913569.00,
      "StockCount": 32,
      "UpCount": 5,
      "DownCount": 27,
      "LimitDownCount": 2,
      "AvgChangePct": -1.8
    }
  ]
}
```

**字段说明：**
- `NetOutflow`: 净流出金额（元，负值）
- `NetOutflowPct`: 净流出占比（%，负值）
- `MainOutflow`: 主力流出金额
- `RetailOutflow`: 散户流出金额
- `LimitDownCount`: 跌停股票数
- 其他字段同净流入接口

**使用场景：**
- 识别资金撤离的板块
- 规避风险板块
- 判断市场调整方向

## 接口使用规范

### 请求频率限制
- 指数行情：每5秒刷新一次
- 连板天梯：每10秒刷新一次
- 资金流向：每15秒刷新一次

### 错误处理
```javascript
try {
  const response = await fetch(API_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(requestData)
  })
  const data = await response.json()
  if (data.Head?.Error) {
    throw new Error(data.Head.Error)
  }
  return data.Data
} catch (error) {
  console.error('API请求失败:', error)
  return null
}
```

### 数据缓存策略
```javascript
const CACHE_DURATION = {
  INDEX_QUOTE: 5000,      // 指数行情：5秒
  CONTINUOUS_LIMIT: 10000, // 连板天梯：10秒
  FUND_FLOW: 15000         // 资金流向：15秒
}
```
