   **内容**：
   ```markdown
   # 金融工具数据格式说明

   ## 完整数据结构

   ```javascript
   [
     [0, "", 0, "", "0"],  // 元数据行
     ["POS", "market", "sec_code", "sec_name", "now_price", "chg0#", "所属行业", "timestamps"],  // 字段定义
     ["", "", "", "2|0|0", "2|0|0", "0|0|0", ""],  // 格式化标识
     ["000001", "沪市", "平安银行", "12.45", "2.35", "银行业", "2024-01-15 10:30:00"],  // 数据行1
     ["000002", "沪市", "万科A", "18.67", "-1.2", "房地产业", "2024-01-15 10:30:00"],  // 数据行2
     // ... 更多数据行
   ]
   ```

   ## 格式化标识详解

   ### 标识格式
   ```
   "typeFlag|subType|specialFlag"
   ```

   ### typeFlag（第1位）
   - "0" = 文本类型，不做格式化
   - "1" = 涨跌幅（默认规则：正数涨红，负数跌绿）
   - "2" = 涨跌幅（反向规则：正数跌绿，负数涨红）
   - "3" = 涨跌幅（特殊规则：>1涨，≤1跌）

   ### subType（第2位）
   - "0" = 不处理
   - "1" = 千分位格式化
   - "2" = 百分比格式化

   ### specialFlag（第3位）
   - "0" = 默认规则
   - "1" = 添加前缀符号

   ## 示例解析

   ### 示例1：涨跌幅字段
   - 标识: `"2|0|0"`（实际是 `"1|0|0"`）
   - 解析: type=1, subType=0, special=0
   - 含义: 涨跌幅 + 默认颜色规则
   - 格式: `2.35%`（正数红色，负数绿色）

   ### 示例2：价格字段
   - 标识: `"1|0|0"`
   - 解析: type=1, subType=0, special=0
   - 含义: 千分位格式
   - 格式: `1,234.56`

   ### 示例3：成交量字段
   - 标识: `"0|0|0"`
   - 解析: type=0
   - 含义: 文本类型
   - 格式: 原样显示

   ## 字段映射规则

   ```javascript
   // 从第1行（字段定义）创建映射
   const fieldMapping = {}
   row1.forEach((field, index) => {
     fieldMapping[row0[index]] = field
   })

   // 示例：
   // row0[3] = "3"
   // row1[3] = "sec_name"
   // fieldMapping["3"] = "sec_name"
   ```

   ## 颜色规则

   ```javascript
   if (numValue > 0) {
     return '<span class="color-up">红色#fc4a4a</span>'
   } else if (numValue < 0) {
     return '<span class="color-down">绿色#229d45</span>'
   } else {
     return '<span>默认颜色</span>'
   }
   ```
   ```
