## 功能实现详情

### 1. VIP用户标签显示规则

**VIP短线用户（vip_short）：**
- ✅ 只显示"短线策略"标签
- ❌ 不显示"全部用户"标签
- ❌ 不显示"中线策略"标签

**VIP中线用户（vip_mid）：**
- ✅ 只显示"中线策略"标签
- ❌ 不显示"全部用户"标签
- ❌ 不显示"短线策略"标签

**VIP同时有短线和中线标签：**
- ✅ 显示"短线+中线"组合标签（特殊样式）

### 2. 管理员标签显示规则

**管理员（admin/super_admin）：**
- ✅ 显示"短线策略"标签
- ✅ 显示"中线策略"标签
- ❌ 不显示"全部用户"标签
- ✅ 如果同时有短线和中线，分别显示两个标签（不组合）

### 3. 标签样式设计

**短线策略标签：**
- 图标：⚡
- 颜色：绿色渐变
- 样式类：`tag-short-term`

**中线策略标签：**
- 图标：📈
- 颜色：蓝色渐变
- 样式类：`tag-mid-term`

**组合标签（短线+中线）：**
- 图标：⚡📈
- 标签文字："短线+中线"
- 样式类：`tag-combined`
- 特殊效果：左侧半边绿色渐变，右侧半边透明渐变，视觉上呈现双色效果

### 逻辑函数（第254-317行）

```javascript
// 获取显示的标签列表（根据用户权限和业务规则）
const getDisplayTags = (tags) => {
    if (!tags || !Array.isArray(tags)) {
        return []
    }

    const displayTags = []
    const hasShortTerm = tags.includes(MESSAGE_TAGS.SHORT_TERM)
    const hasMidTerm = tags.includes(MESSAGE_TAGS.MID_TERM)

    // VIP用户：只显示策略标签（短线/中线），不显示推送对象标签
    if (!userStore.isAdmin) {
        // 如果同时有短线和中线标签，显示为"短线+中线"
        if (hasShortTerm && hasMidTerm) {
            displayTags.push({
                key: 'combined',
                label: '短线+中线',
                icon: '⚡📈',
                class: 'tag-short-term tag-mid-term tag-combined'
            })
        } else if (hasShortTerm) {
            displayTags.push({
                key: MESSAGE_TAGS.SHORT_TERM,
                label: MESSAGE_TAG_LABELS[MESSAGE_TAGS.SHORT_TERM],
                icon: '⚡',
                class: 'tag-short-term'
            })
        } else if (hasMidTerm) {
            displayTags.push({
                key: MESSAGE_TAGS.MID_TERM,
                label: MESSAGE_TAG_LABELS[MESSAGE_TAGS.MID_TERM],
                icon: '📈',
                class: 'tag-mid-term'
            })
        }
    } else {
        // 管理员：显示所有标签（除了all_users）
        for (const tag of tags) {
            // 跳过 all_users 标签
            if (tag === MESSAGE_TAGS.ALL_USERS) {
                continue
            }

            // 处理策略标签
            if (tag === MESSAGE_TAGS.SHORT_TERM) {
                displayTags.push({
                    key: MESSAGE_TAGS.SHORT_TERM,
                    label: MESSAGE_TAG_LABELS[MESSAGE_TAGS.SHORT_TERM],
                    icon: '⚡',
                    class: 'tag-short-term'
                })
            } else if (tag === MESSAGE_TAGS.MID_TERM) {
                displayTags.push({
                    key: MESSAGE_TAGS.MID_TERM,
                    label: MESSAGE_TAG_LABELS[MESSAGE_TAGS.MID_TERM],
                    icon: '📈',
                    class: 'tag-mid-term'
                })
            }
        }
    }

    return displayTags
}
```

## 功能优势

### 1. 用户体验提升
- VIP用户只看到自己关心的策略标签，界面更简洁
- 不显示"全部用户"标签，减少用户困惑
- 组合标签清晰展示同时包含的策略

### 2. 权限控制清晰
- 前端根据用户角色动态显示标签
- 不修改后端代码，保持API兼容性
- VIP用户看不到推送对象标签，保护业务信息

### 3. 可维护性提升
- 集中的标签处理逻辑函数
- 清晰的注释说明业务规则
- 易于扩展新的标签类型

### 4. 视觉优化
- 渐变色彩区分不同策略类型
- 组合标签的双色效果直观
- 保持与整体设计风格一致

## 注意事项

1. **性能优化：**
   - `getDisplayTags()` 函数在每次渲染时调用，但逻辑简单，性能影响可忽略
   - 如需进一步优化，可以使用 `computed` 缓存结果

2. **扩展性：**
   - 如需添加新的标签类型，只需在 `getDisplayTags()` 函数中添加对应的处理逻辑
   - 新标签样式在 SCSS 中添加对应的 class

3. **兼容性：**
   - 兼容旧数据（tags字段可能为空或不存在）
   - 兼容不同用户角色（VIP、管理员等）
