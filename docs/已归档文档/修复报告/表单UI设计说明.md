# 消息发布表单 - UI设计说明

## 设计原则

1. **优先级驱动**: 策略类型作为核心业务属性，视觉层级最高
2. **一致性**: 单选用圆形○，多选用方形☐，符合用户习惯
3. **反馈及时**: 点击、选中都有视觉反馈
4. **清晰分组**: 不同字段用间距和样式区分

## 组件设计规范

### 1. 策略类型区域（核心字段）

#### 样式特点
- **特殊背景**: 浅灰蓝渐变背景
- **紫色边框**: 2rpx实线边框
- **圆角**: 16rpx大圆角
- **阴影**: 柔和阴影突出显示
- **星标**: 红色★，带脉冲动画

#### 尺寸规范
```scss
padding: 32rpx          // 内边距
border-radius: 16rpx    // 圆角
margin-bottom: 50rpx    // 与下一字段间距
```

#### 星标动画
```scss
@keyframes pulse {
  0%, 100% {
    opacity: 1;
    transform: scale(1);
  }
  50% {
    opacity: 0.7;
    transform: scale(1.1);  // 放大1.1倍
  }
}
animation: pulse 2s ease-in-out infinite;
```

---

### 2. 单选按钮组（○/◉）

#### 未选中状态
```scss
background: #ffffff
border: 2rpx solid #e0e0e0
border-radius: 12rpx
padding: 24rpx 32rpx

icon: ○  (未选中)
      ◉  (选中)
color: #667eea  // 未选中时图标颜色
```

#### 选中状态
```scss
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
border: transparent
box-shadow: 0 4rpx 12rpx rgba(102, 126, 234, 0.3)

icon: ◉
color: #ffffff  // 选中时图标和文字都是白色
```

#### 交互反馈
```scss
&:active {
  transform: scale(0.98);  // 点击时缩小
}
transition: all 0.3s;  // 平滑过渡
```

## 状态设计

### Normal（默认状态）
- 背景: 白色 #ffffff
- 边框: 灰色 #e0e0e0
- 文字: 深灰 #333333
- 图标: 紫色 #667eea

### Active（选中状态）
- 背景: 紫色渐变
- 边框: 透明
- 文字: 白色 #ffffff
- 图标: 白色 #ffffff
- 阴影: 紫色阴影

### Pressed（按压状态）
- 缩放: 0.98倍
- 过渡: 0.3s

### Disabled（禁用状态）
- 透明度: 0.6
- 不响应点击

## 响应式设计

### 小屏设备（<375px）
- 复选框自动换行更频繁
- 字体大小保持不变
- 内边距略微减小

### 大屏设备（>768px）
- 复选框可以显示更多列
- 最大宽度限制（可选）

---

## 无障碍设计

### 视觉提示
- 必填字段: 红色星标★
- 选中状态: 颜色 + 图标变化
- 点击反馈: 缩放动画

### 对比度
- 文字与背景对比度 > 4.5:1
- 选中状态对比度更高

## 浏览器兼容性

### 支持的CSS特性
- ✅ Flexbox布局
- ✅ Linear Gradient渐变
- ✅ CSS Animation
- ✅ CSS Transform
- ✅ CSS Transition

### 降级方案
- 渐变不支持的浏览器: 使用纯色背景
- 动画不支持的浏览器: 静态显示
- Unicode字符不显示: 使用CSS绘制图形

## 性能优化

### CSS优化
- 使用transform代替position变化
- 使用will-change提示浏览器优化
- 避免过度使用box-shadow

### 渲染优化
- 复选框使用虚拟滚动（如果超过20个）
- 懒加载图片附件
- 防抖表单保存
