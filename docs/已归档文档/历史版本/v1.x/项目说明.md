# VIP投研内部分享系统

## 项目概述

VIP投研内部分享系统是一个面向内部用户的私密投研分享平台，管理员可以向指定分组的用户群发推送投研消息，用户可以查看历史消息并发起讨论。系统支持讨论内容的可见性控制，确保信息安全和隐私保护。

## 核心功能

### 1. 消息推送
- 管理员可以向指定分组的用户群发推送消息（支持图片+文字）
- 支持消息类型分类和分组管理
- 支持实时发布和定时发布
- 定时发布精确到分钟，可取消

### 2. 消息管理
- 用户可以方便地查看自己收到的消息以及历史消息
- 支持搜索功能和按日期查看
- 消息列表支持无限滚动，每页显示20条
- 支持消息收藏功能
- 支持消息导出功能

### 3. 讨论功能
- 用户在收到消息后可以就该消息发起讨论
- 讨论内容默认只有管理员可见（私密）
- 管理员可以设置讨论可见性（公开/私密）
  - 公开：所有用户可见
  - 私密：只有管理员和发起者可见
- 讨论支持富文本
- 讨论状态自动变化：有人回复后自动变为已回复

### 4. 用户管理
- 由管理员统一注册用户和分组管理
- 管理员可以设置用户权限、分组和有效日期
- 支持用户状态管理（活跃/非活跃）
- **支持邮箱和用户名双重登录**：系统智能识别输入内容是邮箱还是用户名，提供灵活的登录方式
- 支持"记住我"功能，Token有效期24小时

### 5. 统计功能
- 消息数量趋势
- 消息类型分布
- 消息标签分布
- 用户活跃度
- 消息阅读率
- 讨论数量趋势
- 讨论回复率
- 分组用户数
- 用户增长趋势
- 支持多种时间范围统计和Excel导出

### 当前部署流程

#### H5 版本
1. **构建 H5 版本**：`npm run build:h5`
2. **部署**：将 dist/build/h5 目录部署到静态网站托管服务
3. **配置 HTTPS**：确保服务器支持 HTTPS（小程序要求）

#### 小程序版本（开发中）
1. **构建小程序版本**：
   - 微信：`npm run build:mp-weixin`
   - 支付宝：`npm run build:mp-alipay`
   - 百度：`npm run build:mp-baidu`
   - 字节跳动：`npm run build:mp-toutiao`
2. **部署小程序**：使用对应平台的开发者工具导入构建后的代码
3. **配置服务器域名**：在各平台后台配置 HTTPS 域名

### HTTPS 部署要求

- **必须使用 HTTPS**：所有小程序平台都强制要求
- **域名备案**：服务器域名必须完成备案
- **SSL 证书**：使用 Let's Encrypt 免费证书或付费证书
- **Nginx 配置**：参考 [HTTPS部署与安全指南.md](./HTTPS部署与安全指南.md)
