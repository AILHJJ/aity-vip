## Page Object 设计建议

```javascript
class MyOrdersPage {
  // 页面元素定位
  get orderTitle() { return $('//android.widget.TextView[@text="我的订单"]'); }
  get tabAll() { return $('text=全部'); }
  get tabPendingPayment() { return $('text=待付款'); }
  get tabPendingShipment() { return $('text=待发货'); }
  get tabPendingReceipt() { return $('text=待收货'); }
  get tabCompleted() { return $('text=已完成'); }
  get orderList() { return $('#order_list'); }
  get backButton() { return $('#iv_back'); }

  // 页面操作方法
  async waitForPageLoad() {
    await this.orderTitle.waitForDisplayed();
  }

  async switchTab(tabName) {
    await $(`text=${tabName}`).click();
  }

  async getOrders() {
    const items = await $$('//*[@resource-id="order_item"]');
    return items;
  }

  async clickConfirmReceipt(orderIndex) {
    const btn = await $$('//*[@resource-id="btn_confirm_receipt"]')[orderIndex];
    await btn.click();
    // 处理确认对话框
    await this.handleConfirmDialog();
  }

  async clickBuyAgain(orderIndex) {
    const btn = await $$('//*[@resource-id="btn_buy_again"]')[orderIndex];
    await btn.click();
  }

  async clickOrderItem(orderIndex) {
    const items = await this.getOrders();
    await items[orderIndex].click();
  }

  async pullToRefresh() {
    await this.orderList.touchAction([
      { action: 'press', x: 500, y: 200 },
      { action: 'moveTo', x: 500, y: 800 },
      'release'
    ]);
  }

  async handleConfirmDialog() {
    // 实现确认对话框处理逻辑
  }
}
```

## 自动化测试注意事项

1. **等待策略**: 订单列表加载需要设置合理的等待时间
2. **元素定位**: 建议优先使用 resource-id，其次使用 text 或 xpath
3. **状态验证**: 每次操作后需验证订单状态的正确性
4. **数据清理**: 测试后需要清理测试产生的订单数据
5. **并发测试**: 如果同时测试多个账号，注意数据隔离
6. **截图保存**: 关键步骤建议保存截图用于问题定位
