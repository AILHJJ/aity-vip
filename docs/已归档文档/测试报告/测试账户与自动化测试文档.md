## 自动化测试

### 测试环境
- **本地后端**: http://localhost:3001
- **本地H5**: http://localhost:5176
- **测试数据库**: 投研图灵室_test

### 测试工具
- **Playwright**: 用于H5/Web端自动化测试
- **Chrome**: D:/your-mcp-proxy/AITY_VIP/chrome-win64/chrome.exe

### 运行测试

```bash
# 方式1: 使用playwright-skill
cd C:/Users/DELL/.claude/skills/playwright-skill
BASE_URL=http://localhost:5176 node run.js C:/tmp/playwright-test-aity-v4.js

# 方式2: 直接运行
node C:/tmp/playwright-test-aity-v4.js
```

### 测试结果存储
- **截图目录**: `D:/your-mcp-proxy/AITY_VIP/test-results/`
- **视频目录**: `D:/your-mcp-proxy/AITY_VIP/test-results/videos/`

## 新建测试账户

如需新建测试账户，可使用以下SQL:

```sql
-- 新建普通测试用户
INSERT INTO users (username, email, password, role, vip_status, vip_expire_time)
VALUES ('testuser', 'testuser@example.com', '$2b$10$...', 'user', 'normal', NULL);

-- 新建VIP测试用户
INSERT INTO users (username, email, password, role, vip_status, vip_expire_time)
VALUES ('testvip', 'testvip@example.com', '$2b$10$...', 'user', 'active', DATE_ADD(NOW(), INTERVAL 1 YEAR));
```

或通过管理后台创建。

## 注意事项

1. 测试账户密码统一使用 `123456` 便于记忆
2. 自动化测试不会实际提交消息（避免产生测试数据）
3. 视频文件为webm格式，可用Chrome或VLC播放
4. 测试前确保本地后端服务已启动
