## 📋 测试流程

### 新功能测试流程
1. **需求分析** → 编写自然语言测试用例
2. **快速验证** → 使用自然语言测试
3. **稳定后** → 转换为脚本
4. **团队共享** → 添加到测试库

### 回归测试流程
1. **准备环境** → 启动测试环境
2. **运行脚本** → 执行测试脚本
3. **查看结果** → 检查录屏和报告
4. **问题修复** → 修复失败用例

## 💡 最佳实践

### 选择合适的测试方式

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 新功能验证 | 自然语言 | 快速、灵活 |
| 临时测试 | 自然语言 | 无需准备 |
| 回归测试 | 脚本 | 可重复、稳定 |
| 团队共享 | 脚本 | 标准化 |
| CI/CD集成 | 脚本 | 自动化 |
