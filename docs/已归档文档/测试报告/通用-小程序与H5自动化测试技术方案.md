# 通用-小程序与H5自动化测试技术方案

## 1. 测试概述

### 1.1 测试目标
- 确保应用功能正常运行
- 验证跨浏览器/设备兼容性
- 提高代码质量，减少回归问题
- 降低测试成本，提高测试效率

### 1.2 适用场景
- Web应用（H5）
- 小程序（微信、支付宝等）
- 混合应用（Hybrid App）

## 2. 技术选型

| 测试类型 | 推荐工具 | 适用平台 | 优势 |
|---------|---------|---------|------|
| H5自动化测试 | Playwright | Web | 多浏览器支持、自动等待、截图/录屏 |
| 小程序测试 | uni-automator | 微信小程序 | 与uni-app集成、支持真机测试 |
| 性能测试 | Lighthouse | Web | 详细性能报告、优化建议 |
| 视觉回归测试 | Percy | Web | 自动对比视觉差异 |
| API测试 | Postman/Newman | 通用 | 接口测试、自动化集成 |

## 3. 环境搭建

### 3.1 H5测试环境

**安装依赖**：
```bash
# 安装Playwright
npm install -D @playwright/test

# 安装浏览器
npx playwright install
```

**配置文件**（playwright.config.js）：
```javascript
const { defineConfig, devices } = require('@playwright/test');

module.exports = defineConfig({
  testDir: './tests/e2e',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 2 : 1,
  reporter: [
    ['html', { outputFolder: './tests/e2e/reports/html' }],
    ['json', { outputFile: './tests/e2e/reports/json/results.json' }]
  ],
  use: {
    baseURL: process.env.BASE_URL || 'http://localhost:5173',
    screenshot: 'only-on-failure',
    video: 'retain-on-failure',
    actionTimeout: 10000,
    navigationTimeout: 30000,
  },
  projects: [
    {
      name: 'chromium',
      use: { ...devices['Desktop Chrome'] },
    },
    {
      name: 'firefox',
      use: { ...devices['Desktop Firefox'] },
    },
    {
      name: 'webkit',
      use: { ...devices['Desktop Safari'] },
    },
    {
      name: 'iPhone 12',
      use: { ...devices['iPhone 12'] },
    },
  ],
});
```

## 4. 测试用例设计

### 4.1 H5测试用例

**核心测试场景**：
- 页面加载与导航
- 表单提交与验证
- 数据展示与交互
- 响应式布局
- 错误处理

**示例测试用例**：
```javascript
// tests/e2e/specs/login.spec.js
const { test, expect } = require('@playwright/test');

test('用户登录测试', async ({ page }) => {
  await page.goto('http://localhost:5173/#/login');
  await page.fill('input[name="username"]', 'test@example.com');
  await page.fill('input[name="password"]', 'password123');
  await page.click('button[type="submit"]');
  await expect(page).toHaveURL('http://localhost:5173/#/home');
});
```

### 4.2 小程序测试用例

**核心测试场景**：
- 小程序启动
- 页面跳转
- 功能交互
- 权限申请
- 网络请求

**示例测试用例**：
```javascript
// tests/mini-program/login.test.js
const automator = require('@dcloudio/uni-automator');

describe('小程序登录测试', () => {
  let page;
  
  before(async () => {
    page = await automator.launch({
      projectPath: './',
      cliPath: 'C:\\Program Files (x86)\\Tencent\\WeChat Web Developer Tools\\cli.bat'
    });
  });
  
  it('登录功能测试', async () => {
    await page.navigateTo('/pages/login/login');
    await page.input('#username', 'test@example.com');
    await page.input('#password', 'password123');
    await page.click('.login-btn');
    await page.waitForNavigation();
    const currentPage = await page.getCurrentPage();
    expect(currentPage.path).toBe('/pages/index/index');
  });
  
  after(async () => {
    await page.close();
  });
});
```

## 5. 自动化测试流程

### 5.1 本地测试

**H5测试**：
1. 启动开发服务器：`npm run dev`
2. 运行测试：`npx playwright test`
3. 查看报告：`npx playwright show-report`

**小程序测试**：
1. 构建小程序：`npm run build:mp-weixin`
2. 运行测试：`npx uni-automator test --platform mp-weixin`

### 5.2 CI/CD集成

**GitHub Actions配置**：
```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: 18
      - name: Install dependencies
        run: npm install
      - name: Install Playwright browsers
        run: npx playwright install --with-deps
      - name: Run H5 tests
        run: npm run dev & npx playwright test
      - name: Upload test results
        if: always()
        uses: actions/upload-artifact@v3
        with:
          name: test-results
          path: tests/e2e/reports
```

## 6. 最佳实践

### 6.1 测试用例设计
- 使用页面对象模式（Page Object Model）
- 编写独立、可重复的测试用例
- 覆盖核心功能和边界情况
- 使用参数化测试提高覆盖率

### 6.2 测试执行
- 定期运行测试（本地和CI）
- 分析测试失败原因
- 及时修复测试用例
- 维护测试数据

### 6.3 性能优化
- 使用Lighthouse定期评估性能
- 优化首屏加载时间
- 减少网络请求
- 优化资源加载

## 7. 常见问题与解决方案

| 问题 | 解决方案 |
|------|----------|
| 测试不稳定 | 使用固定的测试数据、增加适当的等待时间 |
| 网络依赖 | 使用mock数据、模拟网络请求 |
| 跨浏览器差异 | 使用Playwright的多浏览器测试 |
| 小程序测试环境配置 | 确保微信开发者工具服务端口开启 |
| 测试速度慢 | 并行运行测试、优化测试用例 |

## 8. 总结

自动化测试是保证应用质量的重要手段，通过合理的技术选型和测试策略，可以显著提高开发效率和产品质量。本方案提供了通用的小程序与H5自动化测试框架，可根据具体项目需求进行调整和扩展。
