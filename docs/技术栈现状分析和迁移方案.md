- ✅ **一套代码，多端运行**
- ✅ **满足用户需求**

- **前端**：Vue 3 + Vite + Vue Router + Element Plus + Pinia

## 📋 开发规范

### 1. 组件使用规范
- ✅ 使用 uni-app 组件：`<view>`, `<text>`, `<checkbox>` 等
- ✅ H5 端可使用 Element Plus（条件编译）
- ✅ 小程序端使用 uni-ui 组件

### 2. 路由配置规范
- ✅ 使用 pages.json 作为主要路由配置
- ✅ H5 端可同时使用 Vue Router（可选）

### 3. API 调用规范
- ✅ 小程序端使用 `uni.request()`
- ✅ H5 端可使用 `axios`（可选）

### 4. 多端兼容性规范
- ✅ 使用条件编译处理平台差异
- ✅ 避免使用平台特定 API
- ✅ 测试 H5 和小程序端运行效果

## 🎯 后续迭代指南

### 项目基础
- **主要开发项目**：`d:\your-mcp-proxy\AITY_VIP\aity-uni-app-new`
- **参考项目**：`d:\your-mcp-proxy\AITY_VIP\frontend`（仅用于业务逻辑参考）

### 开发流程
1. **代码修改**：在 `aity-uni-app-new` 项目中进行
2. **测试**：同时测试 H5 和小程序端
3. **部署**：分别构建 H5 和小程序版本

### 注意事项
- **组件使用**：优先使用 uni-app 内置组件或 uni-ui 组件
- **路由跳转**：使用 `uni.navigateTo()` 等 uni-app 路由 API
- **API 调用**：使用 `uni.request()` 进行网络请求
- **多端兼容**：使用条件编译处理平台差异

## 🔧 技术支持

### 常见问题解决方案
1. **依赖冲突**：使用 `--legacy-peer-deps` 安装依赖
2. **组件兼容性**：优先使用 uni-app 内置组件
3. **路由配置**：使用 pages.json 配置页面路由
4. **API 调用**：使用 uni-app 提供的 API 替代 Web API
