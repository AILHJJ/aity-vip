## 2. 部署方案

### 2.1 方案一：Docker 容器化部署（推荐）

**前提条件：**
- 服务器已安装 Docker 和 Docker Compose
- 服务器已开放 8443 和 8080 端口

**部署步骤：**

1. **创建 Docker Compose 配置文件**
   ```yaml
   # docker-compose.yml
   version: '3.8'
   
   services:
     backend:
       build: ./backend
       ports:
         - "3001:3001"
       environment:
         - NODE_ENV=production
         - PORT=3001
       restart: unless-stopped
       networks:
         - aity-network
     
     frontend:
       build: ./frontend
       ports:
         - "5173:5173"
       restart: unless-stopped
       networks:
         - aity-network
     
     nginx:
       image: nginx:latest
       ports:
         - "8080:80"
         - "8443:443"
       volumes:
         - ./nginx/nginx.conf:/etc/nginx/nginx.conf
         - ./nginx/ssl:/etc/nginx/ssl
       depends_on:
         - backend
         - frontend
       restart: unless-stopped
       networks:
         - aity-network
   
   networks:
     aity-network:
       driver: bridge
   ```

2. **创建 Dockerfile**

   **后端 Dockerfile：**
   ```dockerfile
   # backend/Dockerfile
   FROM node:18-alpine
   
   WORKDIR /app
   
   COPY package*.json ./
   RUN npm install --production
   
   COPY . .
   
   EXPOSE 3001
   
   CMD ["npm", "start"]
   ```

   **前端 Dockerfile：**
   ```dockerfile
   # frontend/Dockerfile
   FROM node:18-alpine as build
   
   WORKDIR /app
   
   COPY package*.json ./
   RUN npm install
   
   COPY . .
   RUN npm run build
   
   FROM nginx:alpine
   
   COPY --from=build /app/dist /usr/share/nginx/html
   
   EXPOSE 5173
   
   CMD ["nginx", "-g", "daemon off;"]
   ```

3. **创建 Nginx 配置**
   ```nginx
   # nginx/nginx.conf
   events {
     worker_connections 1024;
   }
   
   http {
     server {
       listen 80;
       server_name aity88.online;
       
       return 301 https://$server_name:8443$request_uri;
     }
     
     server {
       listen 443 ssl;
       server_name aity88.online;
       
       ssl_certificate /etc/nginx/ssl/aity88.online.crt;
       ssl_certificate_key /etc/nginx/ssl/aity88.online.key;
       
       ssl_protocols TLSv1.2 TLSv1.3;
       ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384';
       ssl_prefer_server_ciphers off;
       
       add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
       add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:;" always;
       add_header X-Frame-Options "DENY" always;
       add_header X-Content-Type-Options "nosniff" always;
       add_header X-XSS-Protection "1; mode=block" always;
       
       location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
         expires 1y;
         add_header Cache-Control "public, max-age=31536000, immutable";
       }
       
       location / {
         proxy_pass http://frontend:5173;
         proxy_set_header Host $host;
         proxy_set_header X-Real-IP $remote_addr;
         proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
         proxy_set_header X-Forwarded-Proto $scheme;
       }
       
       location /api {
         proxy_pass http://backend:3001;
         proxy_set_header Host $host;
         proxy_set_header X-Real-IP $remote_addr;
         proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
         proxy_set_header X-Forwarded-Proto $scheme;
       }
     }
   }
   ```

4. **部署命令**
   ```bash
   # 在项目根目录执行
   cd /path/to/project
   docker-compose up -d
   ```

### 2.2 方案二：传统部署（PM2 + Nginx）

**前提条件：**
- 服务器已安装 Node.js 和 npm
- 服务器已安装 PM2 和 Nginx
- 服务器已开放 8443 和 8080 端口

**部署步骤：**

1. **安装依赖**
   ```bash
   # 安装 PM2
   npm install -g pm2
   
   # 安装 Nginx
   # Ubuntu/Debian
   apt update && apt install -y nginx
   
   # CentOS/RHEL
   yum install -y epel-release && yum install -y nginx
   ```

2. **配置 PM2**
   ```json
   // backend/ecosystem.config.js
   module.exports = {
     apps: [
       {
         name: 'aity-vip-backend',
         script: 'index.js',
         instances: 1,
         exec_mode: 'fork',
         env: {
           NODE_ENV: 'production',
           PORT: 3001
         }
       }
     ]
   };
   ```

3. **配置 Nginx**
   ```nginx
   # /etc/nginx/conf.d/aity-vip-https.conf
   # HTTP重定向至HTTPS
   server {
     listen 8080;
     server_name aity88.online;
     
     return 301 https://$server_name:8443$request_uri;
   }
   
   # HTTPS服务器配置
   server {
     listen 8443 ssl http2;
     server_name aity88.online;
     
     # SSL证书配置
     ssl_certificate /etc/nginx/ssl/aity88.online.crt;
     ssl_certificate_key /etc/nginx/ssl/aity88.online.key;
     
     # SSL协议配置
     ssl_protocols TLSv1.2 TLSv1.3;
     ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384';
     ssl_prefer_server_ciphers off;
     
     # HSTS配置
     add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
     
     # CSP配置
     add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:;" always;
     
     # 其他安全头部
     add_header X-Frame-Options "DENY" always;
     add_header X-Content-Type-Options "nosniff" always;
     add_header X-XSS-Protection "1; mode=block" always;
     
     # 缓存配置
     location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
       expires 1y;
       add_header Cache-Control "public, max-age=31536000, immutable";
     }
     
     # 反向代理配置
     location / {
       proxy_pass http://localhost:5173;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
     }
     
     location /api {
       proxy_pass http://localhost:3001;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
     }
   }
   ```

4. **部署命令**
   ```bash
   # 构建前端
   cd frontend
   npm install && npm run build
   
   # 部署前端
   scp -r dist/* root@124.221.119.134:/var/www/aity-vip/frontend
   
   # 部署后端
   cd ../backend
   npm install --production
   scp -r * root@124.221.119.134:/var/www/aity-vip/backend
   
   # 启动后端服务
   ssh root@124.221.119.134 "cd /var/www/aity-vip/backend && pm2 start ecosystem.config.js"
   
   # 重启 Nginx
   ssh root@124.221.119.134 "nginx -t && systemctl reload nginx"
   ```

## 4. 腾讯云服务器登录校验问题解决方案

### 4.1 解决方案一：使用密钥登录

**步骤：**
1. **生成 SSH 密钥对**
   ```bash
   # Linux/Mac
   ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
   
   # Windows (PowerShell)
   ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
   ```

2. **复制公钥到服务器**
   ```bash
   # Linux/Mac
   ssh-copy-id root@124.221.119.134
   
   # Windows (PowerShell)
   type $env:USERPROFILE\.ssh\id_rsa.pub | ssh root@124.221.119.134 "cat >> .ssh/authorized_keys"
   ```

3. **配置 SSH 客户端**
   ```bash
   # ~/.ssh/config
   Host aity-vip
     HostName 124.221.119.134
     User root
     IdentityFile ~/.ssh/id_rsa
     Port 22
   ```

### 4.2 解决方案二：使用密码登录

**注意：** 密码登录安全性较低，建议仅用于测试环境。

**步骤：**
1. **启用密码登录**
   ```bash
   # 编辑 SSH 配置文件
   vi /etc/ssh/sshd_config
   
   # 修改以下配置
   PasswordAuthentication yes
   
   # 重启 SSH 服务
   systemctl restart sshd
   ```

2. **使用密码登录**
   ```bash
   ssh root@124.221.119.134
   ```

## 6. 故障排查

### 6.1 常见问题

**1. 端口被占用**
```bash
# 检查端口占用
lsof -i :8443
lsof -i :8080
lsof -i :3001
lsof -i :5173

# 释放端口
kill -9 <PID>
```

**2. Nginx 配置错误**
```bash
# 检查 Nginx 配置
nginx -t

# 查看 Nginx 日志
tail -f /var/log/nginx/error.log
```

**3. 后端服务启动失败**
```bash
# 查看 PM2 日志
pm2 logs aity-vip-backend

# 查看 Docker 日志
docker logs <container_id>
```

**4. 防火墙问题**
```bash
# 检查防火墙状态
ufw status # Ubuntu/Debian
systemctl status firewalld # CentOS/RHEL

# 开放端口
ufw allow 8443/tcp
ufw allow 8080/tcp
ufw allow 3001/tcp
ufw allow 5173/tcp
```

## 8. 总结

**推荐部署方案：**
- **生产环境**：使用 Docker 容器化部署，便于管理和扩展
- **测试环境**：使用传统部署，配置简单快速

**部署优势：**
- **Docker 部署**：环境隔离、版本控制、快速部署

- 配置监控工具，及时发现和解决问题
