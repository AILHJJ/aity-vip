# 部署指南

## 文档说明

本指南为通用部署指南，适用于各种服务器环境。

**腾讯云服务器专属部署方案**：请参考 [腾讯云部署方案.md](./腾讯云部署方案.md)，包含腾讯云特定配置和登录校验问题解决方案。

## 服务器配置

### 推荐配置
- **CPU**：2核
- **内存**：4GB
- **磁盘**：50GB SSD
- **操作系统**：CentOS 7.9 或 Ubuntu 20.04 LTS

### 网络配置
- **开放端口**：
  - 80（HTTP）
  - 443（HTTPS）
  - 3001（后端API）
  - 22（SSH，仅开发环境需要）

## 环境搭建

### 1. 安装系统依赖

#### CentOS
```bash
yum update -y
yum install -y gcc-c++ make wget curl git
```

#### Ubuntu
```bash
apt update -y
apt install -y build-essential wget curl git
```

### 2. 安装 Node.js

```bash
# 下载并安装 Node.js 16
wget https://nodejs.org/dist/v16.20.0/node-v16.20.0-linux-x64.tar.xz
tar -xf node-v16.20.0-linux-x64.tar.xz
mv node-v16.20.0-linux-x64 /usr/local/node

# 配置环境变量
echo 'export PATH=/usr/local/node/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 验证安装
node -v
npm -v
```

### 3. 安装 MySQL

#### CentOS
```bash
yum install -y mariadb-server
systemctl start mariadb
systemctl enable mariadb

# 初始化 MySQL
mysql_secure_installation
```

#### Ubuntu
```bash
apt install -y mysql-server
mysql_secure_installation
```

### 4. 安装 Nginx

#### CentOS
```bash
yum install -y nginx
systemctl start nginx
systemctl enable nginx
```

#### Ubuntu
```bash
apt install -y nginx
systemctl start nginx
systemctl enable nginx
```

### 5. 安装 PM2

```bash
npm install -g pm2
```

## 项目部署

### 1. 准备部署目录

```bash
mkdir -p /var/www/aity-vip/frontend
mkdir -p /var/www/aity-vip/backend
```

### 2. 配置 Nginx

```bash
# 创建 Nginx 配置文件
vi /etc/nginx/conf.d/aity-vip.conf
```

配置内容：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/aity-vip/frontend;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 3. 重启 Nginx

```bash
systemctl restart nginx
```

### 4. 部署项目

使用项目中的部署脚本：

```bash
# 在本地执行部署脚本
cd scripts
bash deploy.sh
```

### 5. 配置环境变量

```bash
# 在服务器上配置环境变量
cd /var/www/aity-vip/backend
cp .env.example .env
vi .env
```

配置内容：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your-password
DB_NAME=aity_vip

# JWT配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=24h

# 服务器配置
PORT=3001
NODE_ENV=production
```

### 6. 初始化数据库

```bash
# 在服务器上执行数据库初始化
cd /var/www/aity-vip/backend
node init-test-data.js
```

### 7. 启动后端服务

```bash
# 使用 PM2 启动后端服务
cd /var/www/aity-vip/backend
pm install
pm run build
pm run start:prod

# 查看服务状态
pm run pm2:status
```

## 自动化部署

### 使用 CI/CD

推荐使用 GitHub Actions 或 GitLab CI 实现自动化部署：

#### GitHub Actions 示例

创建 `.github/workflows/deploy.yml` 文件：

```yaml
name: Deploy to Tencent Cloud

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Set up Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '16'
      
      - name: Install dependencies
        run: |
          cd frontend
          npm install
          cd ../backend
          npm install
      
      - name: Build frontend
        run: |
          cd frontend
          npm run build
      
      - name: Deploy to server
        uses: easingthemes/ssh-deploy@v2.1.5
        with:
          SSH_PRIVATE_KEY: ${{ secrets.SSH_PRIVATE_KEY }}
          ARGS: '-rltgoDzvO --delete'
          SOURCE: 'frontend/dist/'
          REMOTE_HOST: ${{ secrets.REMOTE_HOST }}
          REMOTE_USER: ${{ secrets.REMOTE_USER }}
          TARGET: '/var/www/aity-vip/frontend'
      
      - name: Deploy backend
        uses: easingthemes/ssh-deploy@v2.1.5
        with:
          SSH_PRIVATE_KEY: ${{ secrets.SSH_PRIVATE_KEY }}
          ARGS: '-rltgoDzvO --delete'
          SOURCE: 'backend/'
          REMOTE_HOST: ${{ secrets.REMOTE_HOST }}
          REMOTE_USER: ${{ secrets.REMOTE_USER }}
          TARGET: '/var/www/aity-vip/backend'
      
      - name: Restart backend service
        uses: appleboy/ssh-action@v0.1.4
        with:
          host: ${{ secrets.REMOTE_HOST }}
          username: ${{ secrets.REMOTE_USER }}
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          script: |
            cd /var/www/aity-vip/backend
            npm install
            pm2 restart ecosystem.config.js
```

## 常见问题

### 1. 端口占用

```bash
# 查看端口占用
lsof -i :3001

# 杀掉占用端口的进程
kill -9 <PID>
```

### 2. 数据库连接失败

- 检查数据库服务是否运行
- 检查数据库用户名和密码
- 检查数据库是否存在
- 检查数据库用户权限

### 3. 前端页面空白

- 检查 Nginx 配置
- 检查前端构建文件是否正确部署
- 检查浏览器控制台错误信息

### 4. 后端 API 无法访问

- 检查后端服务是否运行
- 检查 PM2 日志
- 检查 Nginx 反向代理配置
- 检查服务器防火墙规则

## 运维建议

### 1. 定期备份

```bash
# 数据库备份
mysqldump -u root -p aity_vip > aity_vip_backup_$(date +%Y%m%d).sql

# 代码备份
tar -czf aity-vip-backup_$(date +%Y%m%d).tar.gz /var/www/aity-vip
```

### 2. 监控告警

- 配置服务器监控
- 配置应用监控
- 配置日志分析

### 3. 安全加固

- 定期更新系统和依赖
- 配置防火墙规则
- 使用 HTTPS
- 定期修改密码和密钥

### 4. 性能优化

- 配置 Nginx 缓存
- 优化数据库查询
- 使用 CDN 加速静态资源
- 配置负载均衡（高并发场景）
