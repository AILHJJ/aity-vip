# 部署指南

## 服务器配置

### 推荐配置
- **CPU**：2核
- **内存**：4GB
- **磁盘**：50GB SSD
- **操作系统**：CentOS 7.9 或 Ubuntu 20.04 LTS

### 网络配置
- **开放端口**：
  - 80（HTTP）
  - 443（HTTPS）
  - 3001（后端API）
  - 22（SSH，仅开发环境需要）

## 环境搭建

### 1. 安装系统依赖

#### CentOS
```bash
yum update -y
yum install -y gcc-c++ make wget curl git
```

#### Ubuntu
```bash
apt update -y
apt install -y build-essential wget curl git
```

### 2. 安装 Node.js

```bash
# 下载并安装 Node.js 16
wget https://nodejs.org/dist/v16.20.0/node-v16.20.0-linux-x64.tar.xz
tar -xf node-v16.20.0-linux-x64.tar.xz
mv node-v16.20.0-linux-x64 /usr/local/node

# 配置环境变量
echo 'export PATH=/usr/local/node/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 验证安装
node -v
npm -v
```

### 3. 安装 MySQL

#### CentOS
```bash
yum install -y mariadb-server
systemctl start mariadb
systemctl enable mariadb

# 初始化 MySQL
mysql_secure_installation
```

#### Ubuntu
```bash
apt install -y mysql-server
mysql_secure_installation
```

### 4. 安装 Nginx

#### CentOS
```bash
yum install -y nginx
systemctl start nginx
systemctl enable nginx
```

#### Ubuntu
```bash
apt install -y nginx
systemctl start nginx
systemctl enable nginx
```

### 5. 安装 PM2

```bash
npm install -g pm2
```

## 项目部署

### 1. 准备部署目录

```bash
mkdir -p /var/www/aity-vip/frontend
mkdir -p /var/www/aity-vip/backend
```

### 2. 配置 Nginx

```bash
# 创建 Nginx 配置文件
vi /etc/nginx/conf.d/aity-vip.conf
```

配置内容：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/aity-vip/frontend;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 3. 重启 Nginx

```bash
systemctl restart nginx
```

### 4. 部署项目

使用项目中的部署脚本：

```bash
# 在本地执行部署脚本
cd scripts
bash deploy.sh
```

### 5. 配置环境变量

```bash
# 在服务器上配置环境变量
cd /var/www/aity-vip/backend
cp .env.example .env
vi .env
```

配置内容：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your-password
DB_NAME=aity_vip

# JWT配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=24h

# 服务器配置
PORT=3001
NODE_ENV=production
```

### 6. 初始化数据库

```bash
# 在服务器上执行数据库初始化
cd /var/www/aity-vip/backend
node init-test-data.js
```

### 7. 启动后端服务

```bash
# 使用 PM2 启动后端服务
cd /var/www/aity-vip/backend
pm install
pm run build
pm run start:prod

# 查看服务状态
pm run pm2:status
```

## 自动化部署

### GitHub Actions CI/CD

项目已配置完整的 GitHub Actions CI/CD 流水线，支持自动测试、构建和部署：

#### 配置文件

项目根目录下的 `.github/workflows/ci-cd.yml` 文件包含了完整的 CI/CD 配置：

- **测试阶段**：运行前后端代码质量检查和依赖安装
- **构建阶段**：构建前端项目并上传构建产物
- **部署阶段**：自动部署到测试环境（develop 分支）
- **发布阶段**：自动部署到生产环境（main 分支）

#### 环境变量配置

在 GitHub 仓库的 `Settings > Secrets and variables > Actions` 中配置以下环境变量：

- `SSH_PRIVATE_KEY`：服务器 SSH 私钥
- `REMOTE_HOST`：服务器 IP 地址
- `REMOTE_USER`：服务器用户名
- `DB_PASSWORD`：数据库密码（可选）
- `JWT_SECRET`：JWT 密钥（可选）

#### 工作流程

1. **代码提交**：开发者推送到 `develop` 或 `main` 分支
2. **自动测试**：GitHub Actions 运行代码质量检查
3. **自动构建**：构建前端项目并生成构建产物
4. **自动部署**：
   - `develop` 分支：部署到测试环境
   - `main` 分支：部署到生产环境

#### 部署状态查看

在 GitHub 仓库的 `Actions` 标签页中查看部署状态和日志。

## 常见问题

### 1. 端口占用

```bash
# 查看端口占用
lsof -i :3001

# 杀掉占用端口的进程
kill -9 <PID>
```

### 2. 数据库连接失败

- 检查数据库服务是否运行
- 检查数据库用户名和密码
- 检查数据库是否存在
- 检查数据库用户权限

### 3. 前端页面空白

- 检查 Nginx 配置
- 检查前端构建文件是否正确部署
- 检查浏览器控制台错误信息

### 4. 后端 API 无法访问

- 检查后端服务是否运行
- 检查 PM2 日志
- 检查 Nginx 反向代理配置
- 检查服务器防火墙规则
