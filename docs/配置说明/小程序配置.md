### 小程序申请流程

#### 1. 注册小程序账号

1. **访问微信公众平台**：
   - 访问 [微信公众平台](https://mp.weixin.qq.com/)
   - 点击「立即注册」按钮

2. **选择账号类型**：
   - 选择「小程序」类型
   - 点击「查看类型区别」了解不同类型账号的区别

3. **填写注册信息**：
   - 邮箱：使用未被微信公众平台注册过的邮箱
   - 密码：设置密码
   - 验证码：填写邮箱收到的验证码

4. **激活账号**：
   - 登录邮箱，点击激活链接
   - 填写主体信息

#### 2. 完善小程序信息

1. **登录微信公众平台**：
   - 使用注册时的邮箱和密码登录

2. **完善基本信息**：
   - **小程序名称**：填写「VIP投研内部分享」
   - **小程序头像**：上传小程序头像
   - **小程序简介**：填写小程序简介
   - **服务类目**：选择「金融信息服务」和「企业管理」

3. **绑定开发者**：
   - 在「成员管理」中添加开发者
   - 填写开发者的微信账号

### 小程序开发配置

#### 1. 服务器域名配置

1. **登录微信公众平台**：
   - 访问 [微信公众平台](https://mp.weixin.qq.com/)
   - 使用账号：13545023884@163.com 登录

2. **进入开发设置**：
   - 点击左侧菜单「开发」→「开发设置」

3. **配置服务器域名**：
   - **request合法域名**：https://aity88.online:8443
   - **uploadFile合法域名**：https://aity88.online:8443
   - **downloadFile合法域名**：https://aity88.online:8443
   - **socket合法域名**：（可选）

4. **保存配置**：
   - 点击「保存并提交」按钮
   - 等待配置生效（通常需要5-10分钟）

#### 2. 开发工具配置

1. **下载微信开发者工具**：
   - 访问 [微信开发者工具官网](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   - 下载并安装最新版本

2. **登录开发者工具**：
   - 打开微信开发者工具
   - 使用微信扫码登录

3. **导入项目**：
   - 点击「导入项目」按钮
   - 填写项目信息：
     - **项目名称**：VIP投研内部分享
     - **AppID**：wxb16a33cdd58f05d3
     - **项目目录**：选择 `aity-uni-app-new/dist/build/mp-weixin` 目录
     - **是否在当前目录创建project.config.json**：选择「是」

4. **配置项目**：
   - 在「详情」→「本地设置」中配置：
     - **ES6转ES5**：开启
     - **增强编译**：开启
     - **使用npm模块**：开启
     - **不校验合法域名**：开发阶段可开启，发布前必须关闭

#### 3. 代码适配

1. **使用uni-app开发**：
   - 使用uni-app框架开发小程序
   - 确保代码兼容微信小程序

2. **处理平台差异**：
   - 使用条件编译处理平台差异
   - 示例：
     ```javascript
     // #ifdef MP-WEIXIN
     // 微信小程序特有的代码
     // #endif
     ```

3. **测试兼容性**：
   - 在微信开发者工具中测试代码
   - 确保所有功能正常运行

### 小程序发布流程

#### 1. 构建小程序代码

```bash
# 进入前端目录
cd aity-uni-app-new

# 构建微信小程序版本
npm run build:mp-weixin
```

#### 2. 上传代码

1. **打开微信开发者工具**：
   - 打开已导入的项目

2. **上传代码**：
   - 点击「上传」按钮
   - 填写版本信息：
     - **版本号**：如 1.0.0
     - **版本描述**：简要说明本次更新内容

3. **确认上传**：
   - 点击「确定」按钮
   - 等待代码上传完成

#### 3. 提交审核

1. **登录微信公众平台**：
   - 访问 [微信公众平台](https://mp.weixin.qq.com/)
   - 使用账号：13545023884@163.com 登录

2. **进入版本管理**：
   - 点击左侧菜单「管理」→「版本管理」

3. **提交审核**：
   - 找到刚上传的版本
   - 点击「提交审核」按钮

4. **填写审核信息**：
   - **审核类型**：选择「常规审核」
   - **功能介绍**：填写小程序的主要功能
   - **测试账号**：填写测试账号和密码（可选）
   - **备注**：填写其他需要说明的信息

5. **提交审核**：
   - 点击「提交审核」按钮
   - 等待审核结果

#### 4. 发布上线

1. **审核通过后**：
   - 登录微信公众平台
   - 点击左侧菜单「管理」→「版本管理」

2. **发布版本**：
   - 找到审核通过的版本
   - 点击「发布」按钮

3. **确认发布**：
   - 点击「确定」按钮
   - 等待发布完成

4. **推广使用**：
   - 生成小程序码
   - 分享给用户

### 小程序审核注意事项

#### 1. 内容合规

- **金融信息服务**：确保小程序内容符合金融监管要求
- **企业管理**：确保小程序内容符合企业管理相关规定
- **隐私保护**：完善用户隐私协议，确保用户数据安全
- **广告合规**：确保小程序中没有违规广告

#### 2. 技术合规

- **HTTPS**：确保所有API接口使用HTTPS
- **域名配置**：确保所有域名已在微信后台配置
- **代码质量**：确保代码质量，避免恶意代码
- **性能优化**：确保小程序性能良好，避免卡顿

#### 3. 审核周期

- **审核时间**：微信小程序审核一般需要 1-3 个工作日
- **加急审核**：特殊情况下可申请加急审核
- **审核结果**：审核结果会通过微信公众平台通知

#### 4. 常见审核问题

- **服务类目不符**：确保选择的服务类目与小程序内容相符
- **内容违规**：确保小程序内容符合微信平台规范
- **技术问题**：确保小程序技术实现符合微信平台要求
- **隐私保护**：确保用户隐私协议完善
