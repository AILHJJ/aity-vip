## 🎯 项目概述

VIP 投研内部分享系统是一个面向内部用户的私密投研分享平台，支持消息推送、讨论、用户管理和统计分析等功能。系统采用 uni-app 框架开发，支持 H5 和多端小程序部署。

**核心功能：**
- 消息推送和管理
- 讨论功能（支持私密/公开）
- 用户管理和权限控制
- 统计分析和数据导出

**技术栈：**
- 前端：Vue 3 + uni-app + Vite
- 后端：Node.js + Express + MySQL
- 部署：Nginx + PM2 + HTTPS

### 2. 项目配置

#### 2.1 修改 manifest.json

**文件路径：** `d:\your-mcp-proxy\AITY_VIP\aity-uni-app-new\manifest.json`

找到 `mp-weixin` 配置并修改：

```json
{
  "mp-weixin": {
    "appid": "wxb16a33cdd58f05d3",
    "setting": {
      "urlCheck": false,
      "es6": true,
      "postcss": true,
      "minified": true
    },
    "usingComponents": true
  }
}
```

**配置说明：**
- `appid`: 固定为 `wxb16a33cdd58f05d3`
- `urlCheck`: 开发阶段设为 `false`，生产环境建议设为 `true`
- `es6`: 启用 ES6 转 ES5
- `minified`: 启用代码压缩

#### 2.2 配置服务器域名

**操作步骤：**
1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入"开发" -> "开发管理" -> "开发设置" -> "服务器域名"
3. 配置以下域名：

| 配置项 | 域名 | 说明 |
|--------|------|------|
| **request合法域名** | https://aity88.online:8443 | API 请求域名 |
| **uploadFile合法域名** | https://aity88.online:8443 | 文件上传域名 |
| **downloadFile合法域名** | https://aity88.online:8443 | 文件下载域名 |

**注意事项：**
- 必须使用 HTTPS 协议
- 域名已备案
- 开发阶段可以在微信开发者工具中勾选"不校验合法域名"

#### 2.3 修改 API 基础地址

**文件路径：** `d:\your-mcp-proxy\AITY_VIP\aity-uni-app-new\src\utils\request.js`

修改 `baseURL` 配置：

```javascript
// 开发环境
const baseURL = 'http://localhost:3001/api'

// 生产环境（小程序必须使用 HTTPS）
const baseURL = 'https://aity88.online:8443/api'
```

**建议使用环境变量：**
```javascript
const baseURL = process.env.NODE_ENV === 'production'
  ? 'https://aity88.online:8443/api'
  : 'http://localhost:3001/api'
```

#### 5.3 Nginx 配置

**文件路径：** `/etc/nginx/sites-available/aity-vip`

```nginx
server {
  listen 8080;
  server_name aity88.online;
  return 301 https://$server_name:8443$request_uri;
}

server {
  listen 8443 ssl http2;
  server_name aity88.online;
  
  # SSL证书配置
  ssl_certificate /etc/nginx/ssl/aity88.online.crt;
  ssl_certificate_key /etc/nginx/ssl/aity88.online.key;
  
  # SSL协议配置
  ssl_protocols TLSv1.2 TLSv1.3;
  ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384';
  ssl_prefer_server_ciphers off;
  
  # 安全头部
  add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
  add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:;" always;
  add_header X-Frame-Options "DENY" always;
  add_header X-Content-Type-Options "nosniff" always;
  add_header X-XSS-Protection "1; mode=block" always;
  
  # 缓存配置
  location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
    expires 1y;
    add_header Cache-Control "public, max-age=31536000, immutable";
  }
  
  # 反向代理配置
  location / {
    proxy_pass http://localhost:5173;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
  
  location /api {
    proxy_pass http://localhost:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

### 7. 常见问题及解决方案

#### 7.1 网络请求失败

**问题：** 小程序中 API 请求失败

**解决方案：**
1. ✅ 检查服务器域名是否配置为 `https://aity88.online:8443`
2. ✅ 确认后端服务是否运行（`pm2 status`）
3. ✅ 检查 Nginx 配置是否正确（`nginx -t`）
4. ✅ 开发阶段勾选"不校验合法域名"
5. ✅ 查看微信开发者工具控制台错误信息

#### 7.2 页面白屏

**问题：** 小程序打开后页面白屏

**解决方案：**
1. ✅ 检查控制台错误信息
2. ✅ 确认 AppID 配置正确（`wxb16a33cdd58f05d3`）
3. ✅ 检查 `pages.json` 配置是否正确
4. ✅ 确认所有页面文件都已编译
5. ✅ 尝试重新编译小程序（`npm run dev:mp-weixin`）

#### 7.3 登录失败

**问题：** 小程序登录功能不工作

**解决方案：**
1. ✅ 检查 token 存储是否正常（`uni.getStorageSync('token')`）
2. ✅ 确认后端 JWT 配置正确（`JWT_SECRET`）
3. ✅ 检查 CORS 配置（`CORS_ORIGINS`）
4. ✅ 查看网络请求日志（微信开发者工具 Network 面板）
5. ✅ 测试后端登录 API（使用 Postman）

#### 7.4 图片不显示

**问题：** 小程序中图片无法显示

**解决方案：**
1. ✅ 确保图片使用 HTTPS 协议
2. ✅ 在微信公众平台配置 `downloadFile` 合法域名
3. ✅ 检查图片 URL 是否正确
4. ✅ 查看控制台是否有图片加载错误
5. ✅ 测试图片链接是否可以直接访问

#### 7.5 编译失败

**问题：** 小程序编译失败

**解决方案：**
1. ✅ 检查依赖是否安装完整（`npm install`）
2. ✅ 查看编译错误信息
3. ✅ 检查 `manifest.json` 配置是否正确
4. ✅ 检查 `pages.json` 配置是否正确
5. ✅ 尝试清理缓存后重新编译

### 8. 性能优化

#### 8.1 分包加载

**配置文件：** `d:\your-mcp-proxy\AITY_VIP\aity-uni-app-new\pages.json`

```json
{
  "pages": [
    "pages/login/login",
    "pages/messages/messages",
    "pages/message-detail/message-detail"
  ],
  "subPackages": [
    {
      "root": "pages/admin",
      "pages": [
        "user-management/user-management",
        "stats/stats"
      ]
    },
    {
      "root": "pages/discussions",
      "pages": [
        "discussions",
        "discussion-detail",
        "create-discussion"
      ]
    }
  ]
}
```

**优势：**
- 减少首屏加载时间
- 提高小程序启动速度
- 优化内存占用

#### 8.2 图片优化

**最佳实践：**
- 使用 WebP 格式图片
- 压缩图片大小（建议 < 200KB）
- 使用 CDN 加速图片加载
- 实现图片懒加载
- 合理设置图片缓存策略

#### 8.3 代码优化

**最佳实践：**
- 启用代码压缩（`minified: true`）
- 移除未使用的代码
- 使用按需加载
- 减少第三方库的使用
- 优化组件渲染性能

#### 8.4 网络优化

**最佳实践：**
- 使用 HTTP/2 协议
- 实现请求缓存
- 减少 HTTP 请求次数
- 合理设置请求超时时间
- 实现网络错误重试机制
