## 技术要点

### 1. 跨平台 API 配置
- 使用环境变量和运行时检测区分 H5 和小程序
- H5 使用 Vite 代理避免 CORS 问题
- 小程序直接访问本机 IP 进行本地测试

### 2. CORS 配置
- 后端支持多个来源（localhost + 本机 IP）
- 生产环境需要配置实际域名
- 小程序需要在微信公众平台配置服务器域名

### 3. 开发工作流
- 本地开发：H5 快速迭代 → 小程序模拟器测试 → 真机测试
- 生产部署：构建生产版本 → 部署后端 → 发布小程序

### 4. 安全考虑
- 开发环境使用测试号，不校验域名
- 生产环境必须使用 HTTPS 和已备案域名
- 环境变量分离，生产配置独立管理

## 注意事项

### 本地测试
1. **网络要求**: 手机和电脑必须在同一 WiFi 网络
2. **防火墙**: 确保 Windows 防火墙允许 Node.js 访问
3. **域名校验**: 微信开发者工具必须勾选"不校验合法域名"
4. **IP 地址**: 如果本机 IP 变化，需要更新配置并重新编译

### 生产部署
1. **域名备案**: 域名必须已备案才能使用
2. **SSL 证书**: 必须配置有效的 SSL 证书
3. **服务器域名**: 必须在微信公众平台配置服务器域名
4. **审核时间**: 小程序审核通常需要 1-7 个工作日
