# VIP投研内部分享系统

## 项目概述

VIP投研内部分享系统是一个面向内部用户的私密投研分享平台，管理员可以向指定分组的用户群发推送投研消息，用户可以查看历史消息并发起讨论。系统支持讨论内容的可见性控制，确保信息安全和隐私保护。

## 核心功能

### 1. 消息推送
- 管理员可以向指定分组的用户群发推送消息（支持图片+文字）
- 支持消息类型分类和分组管理
- 支持实时发布和定时发布
- 定时发布精确到分钟，可取消

### 2. 消息管理
- 用户可以方便地查看自己收到的消息以及历史消息
- 支持搜索功能和按日期查看
- 消息列表支持无限滚动，每页显示20条
- 支持消息收藏功能
- 支持消息导出功能

### 3. 讨论功能
- 用户在收到消息后可以就该消息发起讨论
- 讨论内容默认只有管理员可见（私密）
- 管理员可以设置讨论可见性（公开/私密）
  - 公开：所有用户可见
  - 私密：只有管理员和发起者可见
- 讨论支持富文本
- 讨论状态自动变化：有人回复后自动变为已回复

### 4. 用户管理
- 由管理员统一注册用户和分组管理
- 管理员可以设置用户权限、分组和有效日期
- 支持用户状态管理（活跃/非活跃）
- **支持邮箱和用户名双重登录**：系统智能识别输入内容是邮箱还是用户名，提供灵活的登录方式
- 支持"记住我"功能，Token有效期24小时

### 5. 统计功能
- 消息数量趋势
- 消息类型分布
- 消息标签分布
- 用户活跃度
- 消息阅读率
- 讨论数量趋势
- 讨论回复率
- 分组用户数
- 用户增长趋势
- 支持多种时间范围统计和Excel导出

## 技术栈

### 前端
- **基础框架**: Vue 3 (Composition API) + uni-app
- **构建工具**: Vite 4.x + @dcloudio/vite-plugin-uni
- **UI组件库**: uni-ui（小程序端）+ Element Plus 2.x（H5端）
- **状态管理**: Pinia 2.x
- **路由管理**: pages.json（uni-app 路由）+ Vue Router 4.x（H5端可选）
- **HTTP客户端**: uni.request（小程序端）+ Axios 1.x（H5端可选）
- **富文本渲染**: Marked 11.x + DOMPurify 3.x
- **图表库**: ECharts 5.x
- **日期处理**: Day.js 1.x
- **表单验证**: VeeValidate 4.x + Yup 1.x
- **样式方案**: SCSS 1.x
- **代码规范**: ESLint 8.x + Prettier 3.x

### 后端
- **运行环境**: Node.js v20.20.0+
- **Web框架**: Express.js
- **数据库**: MySQL 5.7.0+
- **ORM框架**: Sequelize
- **身份认证**: JWT (JSON Web Token)
- **进程管理**: PM2 6.x
- **文件上传**: Multer
- **安全防护**: Helmet, CORS, Express Rate Limit

## 项目部署

### 支持的部署平台
- ✅ **H5 网页**：可部署到任何静态网站托管服务
- ✅ **微信小程序**：可提交到微信小程序平台
- ✅ **支付宝小程序**：可提交到支付宝小程序平台
- ✅ **百度小程序**：可提交到百度小程序平台
- ✅ **字节跳动小程序**：可提交到字节跳动小程序平台

### 部署流程
1. **构建 H5 版本**：`npm run build:h5`
2. **构建小程序版本**：`npm run build:mp-weixin`（微信）
3. **部署 H5**：将 dist/build/h5 目录部署到静态网站托管服务
4. **部署小程序**：使用小程序开发者工具导入 dist/build/mp-weixin 目录并提交
