# VIP投研内部分享系统

## 项目概述

VIP投研内部分享系统是一个面向内部用户的私密投研分享平台，管理员可以向指定分组的用户群发推送投研消息，用户可以查看历史消息并发起讨论。系统支持讨论内容的可见性控制，确保信息安全和隐私保护。

## 核心功能

### 1. 消息推送
- 管理员可以向指定分组的用户群发推送消息（支持图片+文字）
- 支持消息类型分类和分组管理
- 支持实时发布和定时发布
- 定时发布精确到分钟，可取消

### 2. 消息管理
- 用户可以方便地查看自己收到的消息以及历史消息
- 支持搜索功能和按日期查看
- 消息列表支持无限滚动，每页显示20条
- 支持消息收藏功能
- 支持消息导出功能

### 3. 讨论功能
- 用户在收到消息后可以就该消息发起讨论
- 讨论内容默认只有管理员可见（私密）
- 管理员可以设置讨论可见性（公开/私密）
  - 公开：所有用户可见
  - 私密：只有管理员和发起者可见
- 讨论支持富文本
- 讨论状态自动变化：有人回复后自动变为已回复

### 4. 用户管理
- 由管理员统一注册用户和分组管理
- 管理员可以设置用户权限、分组和有效日期
- 支持用户状态管理（活跃/非活跃）
- **支持邮箱和用户名双重登录**：系统智能识别输入内容是邮箱还是用户名，提供灵活的登录方式
- 支持"记住我"功能，Token有效期24小时

### 5. 统计功能
- 消息数量趋势
- 消息类型分布
- 消息标签分布
- 用户活跃度
- 消息阅读率
- 讨论数量趋势
- 讨论回复率
- 分组用户数
- 用户增长趋势
- 支持多种时间范围统计和Excel导出

- **表单验证**: VeeValidate 4.x + Yup 1.x
- **样式方案**: SCSS 1.x
- **代码规范**: ESLint 8.x + Prettier 3.x

## 安装说明

### 1. 环境要求
- **Node.js**: v20.20.0+
- **MySQL**: 5.7.0+
- **Git**: 最新版本
- **PowerShell**: 5.1+（推荐7+）

### 2. 安装步骤

#### 2.1 克隆项目
```bash
cd d:\your-mcp-proxy\AITY_VIP
```

#### 2.2 安装依赖

**后端依赖安装：**
```bash
cd backend
npm install
```

**前端依赖安装：**
```bash
cd ../frontend
npm install
```

#### 2.3 数据库配置

1. 登录MySQL并创建数据库：
```sql
CREATE DATABASE private_sharing_app;
```

2. 执行数据库迁移脚本：
```bash
mysql -u root -p private_sharing_app < database/database.sql
```

3. 配置环境变量：
   - 复制 `backend/.env.example` 为 `backend/.env`
   - 修改 `backend/.env` 文件中的数据库连接信息

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_NAME=private_sharing_app
DB_USER=root
DB_PASSWORD=your_database_password

# JWT配置
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=24h

# 服务器配置
PORT=3001
HOST=0.0.0.0

# 文件上传配置
UPLOAD_DIR=./uploads
MAX_FILE_SIZE=10485760
```

## API文档

### 认证相关
- POST /api/auth/login - 用户登录（支持邮箱或用户名）

### 消息相关
- GET /api/messages - 获取消息列表
- GET /api/messages/:id - 获取消息详情
- POST /api/messages - 发送消息
- PUT /api/messages/:id - 更新消息
- DELETE /api/messages/:id - 删除消息

### 讨论相关
- GET /api/discussions - 获取讨论列表
- GET /api/discussions/:id - 获取讨论详情
- POST /api/discussions - 创建讨论
- PUT /api/discussions/:id - 更新讨论可见性
- POST /api/discussions/:id/replies - 添加讨论回复

### 用户相关
- GET /api/users - 获取用户列表
- POST /api/users - 创建用户
- PUT /api/users/:id - 更新用户
- DELETE /api/users/:id - 删除用户

### 统计相关
- GET /api/statistics/messages - 消息统计数据
- GET /api/statistics/discussions - 讨论统计数据
- GET /api/statistics/users - 用户统计数据

详细API文档请参考 [API文档.md](./API文档.md)

## 开发指南

### 代码规范
- 遵循JavaScript ES6+语法
- 使用模块化开发
- 函数和变量命名清晰，使用驼峰命名法
- 遵循Conventional Commits提交规范

### Git工作流
- 主分支：main - 生产环境代码
- 开发分支：develop - 开发环境代码
- 功能分支：feature/* - 新功能开发
- 修复分支：fix/* - Bug修复
- 发布分支：release/* - 版本发布

### 提交规范
- feat: 新增功能
- fix: 修复bug
- docs: 文档更新
- style: 代码格式调整
- refactor: 重构代码
- test: 测试相关
- chore: 构建/工具链相关

## 安全注意事项
- 敏感信息（如数据库密码、JWT密钥）应通过环境变量配置
- 定期更新依赖包，修复安全漏洞
- 实现合理的权限控制，防止越权访问
- 密码复杂度要求：至少6位
- Token有效期：24小时
